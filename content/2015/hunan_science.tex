\begin{problem}
已知直线 \(l: \begin{cases}
x = 5 + \frac{\sqrt{3}}{2} t,\\
y = \sqrt{3} + \frac{1}{2} t,
\end{cases}\) （\(t\) 为参数），以坐标原点为极点，\(x\) 轴的正半轴为极轴建立极坐标系，曲线 \(C\) 的极坐标方程为 \(\rho = 2\cos \theta\).

\begin{enumerate}
\item 将曲线 \(C\) 的极坐标方程化为直角坐标方程；
\item 设点 \(M\) 的直角坐标为 \((5, \sqrt{3})\)，直线 \(l\) 与曲线 \(C\) 的交点为 \(A\)，\(B\)，求 \( |MA|\cdot|MB| \) 的值.
\end{enumerate}
\end{problem}

\begin{problem}
设 \(a > 0\)，\(b > 0\)，且 \(a + b = \frac{1}{a} + \frac{1}{b}\). 证明：

\begin{enumerate}
\item \(a + b \geqslant 2\)；
\item \(a^2 + a < 2\) 与 \(b^2 + b < 2\) 不可能同时成立.
\end{enumerate}
\end{problem}

\begin{problem}
设 \(\triangle ABC\) 的内角 \(A\)，\(B\)，\(C\) 的对边分别为 \(a\)，\(b\)，\(c\)，\(a = b \tan A\)，且 \(B\) 为钝角.

\begin{enumerate}
\item 证明： \( B - A = \frac{\pi}{2} \)；
\item 求 \( \sin A + \sin C \) 的取值范围.
\end{enumerate}
\end{problem}

\begin{problem}
某商场举行有奖促销活动，顾客购买一定金额的商品后即可抽奖，每次抽奖都是从装有4个红球，6个白球的甲箱和装有5个红球，5个白球的乙箱中，各随机摸出1个球. 在摸出的2个球中，若都是红球，则获一等奖；若只有1个红球，则获二等奖；若没有红球，则不获奖.

\begin{enumerate}
\item 求顾客抽奖 1 次能获奖的概率；
\item 若某顾客有 3 次抽奖的机会，记该顾客在 3 次抽奖中获一等奖的次数为 X，求 X 的分布列和数学期望.
\end{enumerate}
\end{problem}

\begin{problem}
已知抛物线 \(C_1: x^2 = 4y\) 的焦点 \(F\) 也是椭圆 \(C_2: \frac{y^2}{a^2} + \frac{x^2}{b^2} = 1 (a > b > 0)\) 的一个焦点，\(C_1\) 与 \(C_2\) 的公共弦长为 \(2\sqrt{6}\).

\begin{enumerate}
\item 求 \(C_{2}\) 的方程；
\item 过点 \(F\) 的直线 \(l\) 与 \(C_1\) 相交于 \(A\)，\(B\) 两点，与 \(C_2\) 相交于 \(C\)，\(D\) 两点，且 \(\overrightarrow{AC}\) 与 \(\overrightarrow{BD}\) 同向.
\begin{circlelist}
\item 若 \( |AC| = |BD| \)，求直线 \( l \) 的斜率；
\item 设 \(C_1\) 在点 \(A\) 处的切线与 \(x\) 轴的交点为 \(M\)，证明： 直线 \(l\) 绕点 \(F\) 旋转时，\(\triangle MFD\) 总是钝角三角形.
\end{circlelist}
\end{enumerate}
\end{problem}

\begin{problem}
已知 \(a > 0\)，函数 \(f(x) = \e^{ax}\sin x\) （\(x \in [0, +\infty)\)），记 \(x_n\) 为 \(f(x)\) 的从小到大的第 \(n\) （\(n \in \mathbf{N}^*\)）个极值点. 证明：

\begin{enumerate}
\item 数列 \( \left\{f(x_{n})\right\} \) 是等比数列；
\item 若 \(a \geqslant \frac{1}{\sqrt{\e^{2} - 1}}\)，则对一切 \(n \in \mathbf{N}^*\)，\(x_n < |f(x_n)|\) 恒成立.
\end{enumerate}
\end{problem}
