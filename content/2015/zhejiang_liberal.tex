\begin{problem}
在 \(\triangle ABC\) 中，内角 \(A, B, C\) 所对的边分别为 \(a, b, c\). 已知 \(\tan \left(\frac{\pi}{4} + A\right) =\) (1) 求 \( \frac{\sin 2A}{\sin 2A + \cos^{2} A} \) 的值; (2) 若 \(B = \frac{\pi}{4}, a = 3\)，求 \(\triangle ABC\) 的面积.
\end{problem}

\begin{problem}
已知数列 \(\{a_{n}\}\) 和 \(\{b_{n}\}\) 满足 \(a_{1} = 2, b_{1} = 1, a_{n+1} = 2a_{n} (n \in \mathbf{N}^{*})\)，\[ b _{1} + \frac {1}{2} b _{2} + \frac {1}{3} b _{3} + \dots + \frac {1}{n} b _{n} = b _{n + 1} - 1 (n \in \mathbf {N} ^{*}). \] (1) 求 \( a_{n} \) 与 \( b_{n} \) ; (2) 记数列 \(\{a_{n}b_{n}\}\) 的前 \(n\) 项和为 \(T_{n}\)，求 \(T_{n}\).
\end{problem}

\begin{problem}
如图，在三棱柱 \(ABC - A_{1}B_{1}C_{1}\) 中，\(\angle BAC = 90^{\circ}\)，\(AB = AC = 2\)，\(A_{1}A = 4\)，\(A_{1}\) 在底面 \(ABC\) 的射影为 \(BC\) 的中点，\(D\) 是 \(B_{1}C_{1}\) 的中点. (1) 证明: \(A_{1}D \perp\) 平面 \(A_{1}BC\); (2) 求直线 \(A_{1}B\) 和平面 \(BB_{1}C_{1}C\) 所成的角的正弦值.
\end{problem}

\begin{problem}

\end{problem}
