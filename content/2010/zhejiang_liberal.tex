\begin{problem}
设 \(P = \{x \mid x < 1\}\)，\(Q = \{x \mid x^2 < 4\}\)，则 \(P \cap Q =\)（\quad）

\choices
    {\(\{x\mid -1 < x < 2\}\)}
    {\(\{x\mid -3 < x < -1\}\)}
    {\(\{x\mid 1 < x < 4\}\)}
    {\(\{x\mid -2 < x < 1\}\)}

\begin{answer}
D
\end{answer}

\begin{solution}
由 \(x^2<4\) 得 \(-2<x<2\)，所以
\(Q=\{x\mid -2<x<2\}\). 与 \(P=\{x\mid x<1\}\) 取交集，得到
\(P\cap Q=\{x\mid -2<x<1\}\)，故选 D.
\end{solution}
\end{problem}

\begin{problem}
已知函数 \(f(x) = \log_2(x + 1)\)，若 \(f(\alpha) = 1\)，则 \(\alpha =\)（\quad）

\choices
    {\(0\)}
    {\(1\)}
    {\(2\)}
    {\(3\)}

\begin{answer}
B
\end{answer}

\begin{solution}
函数有定义必须满足 \(x+1>0\). 由 \(f(\alpha)=1\) 得
\(\log_2(\alpha+1)=1\)，于是 \(\alpha+1=2^1=2\)，所以
\(\alpha=1\)，故选 B.
\end{solution}
\end{problem}

\begin{problem}
设 \(\i\) 为虚数单位，则 \(\frac{5 - \i}{1 + \i} =\)（\quad）

\choices
    {\(-2 - 3\i\)}
    {\(-2 + 3\i\)}
    {\(2 - 3\i\)}
    {\(2 + 3\i\)}

\begin{answer}
C
\end{answer}

\begin{solution}
分母 \(1+\i\) 的共轭复数为 \(1-\i\)，因此
\[
\frac{5-\i}{1+\i}=\frac{(5-\i)(1-\i)}{(1+\i)(1-\i)}
=\frac{5-5\i-\i+\i^2}{2}
=\frac{4-6\i}{2}=2-3\i
\]
故选 C.
\end{solution}
\end{problem}

\begin{problem}
某程序框图如图所示，若输出的 \(S = 57\)，则判断框内为（\quad）

\texfigure[max width=0.32\linewidth]{img_repaint/2010/zhejiang_liberal/q4_fig1.tex}

\choices
    {\(k > 4\)}
    {\(k > 5\)}
    {\(k > 6\)}
    {\(k > 7\)}

\begin{answer}
A
\end{answer}

\begin{solution}
初始时 \(S=1\)，\(k=1\). 每循环一次先令 \(k=k+1\)，再令
\(S=2S+k\)，所以各次循环后的数值依次为
\((S,k)=(4,2)\)，\((11,3)\)，\((26,4)\)，\((57,5)\).
当输出 \(S=57\) 时，判断框必须在 \(k=5\) 时回答“是”，因此判断条件可为
\(k>4\)，故选 A. 若条件为 \(k>5\)、\(k>6\) 或 \(k>7\)，则在 \(k=5\) 时不能输出 \(57\).
\end{solution}
\end{problem}

\begin{problem}
设 \(S_n\) 为等比数列 \(\{a_n\}\) 的前 \(n\) 项和，\(8a_2 + a_5 = 0\)，则 \(\frac{S_5}{S_2} =\)（\quad）

\choices
    {\(-11\)}
    {\(-8\)}
    {\(5\)}
    {\(11\)}

\begin{answer}
A
\end{answer}

\begin{solution}
设等比数列的公比为 \(q\). 按等比数列的定义，\(q\ne0\). 因为所求比值有意义，所以
\(S_2\ne0\). 若 \(a_2=0\)，则 \(a_1=a_2/q=0\)，从而 \(S_2=0\)，矛盾，故
\(a_2\ne0\). 又
\(a_5=a_2q^3\)，由题设得
\[
8a_2+a_5=a_2(8+q^3)=0
\]
所以 \(q^3=-8\)，即 \(q=-2\). 因而
\[
\frac{S_5}{S_2}
=\frac{a_1(1-q^5)/(1-q)}{a_1(1-q^2)/(1-q)}
=\frac{1-q^5}{1-q^2}
=\frac{1-(-2)^5}{1-(-2)^2}
=\frac{33}{-3}=-11
\]
故选 A.
\end{solution}
\end{problem}

\begin{problem}
设 \(0 < x < \frac{\pi}{2}\)，则“\(x \sin^2 x < 1\)”是“\(x \sin x < 1\)”的（\quad）

\choices
    {充分而不必要条件}
    {必要而不充分条件}
    {充分必要条件}
    {既不充分也不必要条件}

\begin{answer}
B
\end{answer}

\begin{solution}
记命题甲为“\(x\sin^2x<1\)”，记命题乙为“\(x\sin x<1\)”.
由于 \(0<x<\frac{\pi}{2}\)，有 \(0<\sin x<1\)，故
\[
x\sin^2x<x\sin x
\]
所以命题乙成立时必有命题甲成立，即命题甲是命题乙的必要条件.

下面说明命题甲不是命题乙的充分条件. 函数 \(g(x)=x\sin x\) 在
\(\left(0,\frac{\pi}{2}\right)\) 上严格递增，因为
\(g'(x)=\sin x+x\cos x>0\). 又 \(g(1)=\sin1<1\)，而
\(g\left(\frac{\pi}{2}\right)=\frac{\pi}{2}>1\)，所以存在唯一的
\(x_0\in\left(1,\frac{\pi}{2}\right)\) 使 \(g(x_0)=1\). 此时
\(x_0\sin^2x_0=\sin x_0<1\). 由连续性，取 \(x>x_0\) 且足够接近 \(x_0\)，仍有
\(x\sin^2x<1\)，但因 \(g\) 严格递增而有 \(x\sin x>1\). 因此命题甲不充分.

所以“\(x\sin^2x<1\)”是“\(x\sin x<1\)”的必要而不充分条件，故选 B.
\end{solution}
\end{problem}

\begin{problem}
若实数 \(x\)，\(y\) 满足不等式组 \(\begin{cases}
x + 3y - 3 \geqslant 0,\\
2x - y - 3 \leqslant 0,\\
x - y + 1 \geqslant 0,
\end{cases}\) 则 \(x + y\) 的最大值为（\quad）

\choices
    {\(9\)}
    {\(\frac{15}{7}\)}
    {\(1\)}
    {\(\frac{7}{15}\)}

\begin{answer}
A
\end{answer}

\begin{solution}
由 \(2x-y-3\leqslant0\) 得 \(y\geqslant2x-3\)，由
\(x-y+1\geqslant0\) 得 \(y\leqslant x+1\). 因而
\[
2x-3\leqslant x+1
\]
即 \(x\leqslant4\). 再由 \(y\leqslant x+1\) 得
\[
x+y\leqslant2x+1\leqslant9
\]
当 \(x=4\)，\(y=5\) 时，三条约束分别为 \(16\geqslant0\)、\(0\leqslant0\)、\(0\geqslant0\)，故该点可行且 \(x+y=9\). 所以最大值为 \(9\)，故选 A.
\end{solution}
\end{problem}

\begin{problem}
若某几何体的三视图（单位：\(\mathrm{cm}\)）如图所示，则此几何体的体积是（\quad）

\bitmapfigure[max width=0.46\linewidth]{img/2010/zhejiang_liberal/q8_fig1.png}

\choices
    {\(\frac{352}{3} \mathrm{~cm}^3\)}
    {\(\frac{320}{3} \mathrm{~cm}^3\)}
    {\(\frac{224}{3} \mathrm{~cm}^3\)}
    {\(\frac{160}{3} \mathrm{~cm}^3\)}

\begin{answer}
B
\end{answer}

\begin{solution}
由三视图可知，该几何体由一个高为 \(2\mathrm{~cm}\)、底面边长为
\(4\mathrm{~cm}\) 的正方柱，和一个高为 \(2\mathrm{~cm}\)、上底边长为
\(4\mathrm{~cm}\)、下底边长为 \(8\mathrm{~cm}\) 的正方台组成.

正方柱的体积为
\[
V_1=4^2\times2=32\mathrm{~cm}^3
\]
正方台的上下底面积分别为 \(16\mathrm{~cm}^2\) 和 \(64\mathrm{~cm}^2\)，所以
\[
V_2=\frac{2}{3}\left(16+64+\sqrt{16\times64}\right)
=\frac{2}{3}(16+64+32)=\frac{224}{3}\mathrm{~cm}^3
\]
因此
\[
V=V_1+V_2=32+\frac{224}{3}=\frac{320}{3}\mathrm{~cm}^3
\]
故选 B.
\end{solution}
\end{problem}

\begin{problem}
已知 \(x_0\) 是函数 \(f(x) = 2^x + \frac{1}{1 - x}\) 的一个零点. 若 \(x_1 \in (1, x_0)\)，\(x_2 \in (x_0, +\infty)\)，则（\quad）

\choices
    {\(f(x_{1}) < 0, f(x_{2}) < 0\)}
    {\(f(x_{1}) < 0\)，\(f(x_{2}) > 0\)}
    {\(f(x_{1}) > 0\)，\(f(x_{2}) < 0\)}
    {\(f(x_{1}) > 0\)，\(f(x_{2}) > 0\)}

\begin{answer}
B
\end{answer}

\begin{solution}
因为 \(2^x>0\)，当 \(x<1\) 时又有 \(\frac{1}{1-x}>0\)，所以零点只能满足 \(x_0>1\). 对 \(x>1\)，有
\[
f(x)=2^x-\frac{1}{x-1}
=\frac{2^x(x-1)-1}{x-1}
\]
令 \(g(x)=2^x(x-1)\). 则
\(g'(x)=2^x\bigl((x-1)\ln2+1\bigr)>0\)，\((x>1)\)
所以 \(g\) 在 \((1,+\infty)\) 上严格递增. 由 \(f(x_0)=0\) 得
\(g(x_0)=1\). 因此，当 \(1<x_1<x_0\) 时 \(g(x_1)<1\)，从而
\(f(x_1)<0\)；当 \(x_2>x_0\) 时 \(g(x_2)>1\)，从而
\(f(x_2)>0\). 故选 B.
\end{solution}
\end{problem}

\begin{problem}
设 \(O\) 为坐标原点，\(F_1\)，\(F_2\) 是双曲线 \(\frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1\) （\(a > 0\)，\(b > 0\)）的焦点. 若在双曲线上存在点 \(P\)，满足 \(\angle F_1PF_2 = 60^{\circ}\)，\(|OP| = \sqrt{7}a\)，则该双曲线的渐近线方程为（\quad）

\choices
    {\(x \pm \sqrt{3} y = 0\)}
    {\(\sqrt{3} x \pm y = 0\)}
    {\(x \pm \sqrt{2} y = 0\)}
    {\(\sqrt{2} x \pm y = 0\)}

\begin{answer}
D
\end{answer}

\begin{solution}
设 \(PF_1=r_1\)，\(PF_2=r_2\)，双曲线半焦距为 \(c\)，则
\(c^2=a^2+b^2\). 由
\(OP=\sqrt7a\) 以及两焦点关于原点对称，得
\[
r_1^2+r_2^2=2(OP^2+c^2)=14a^2+2c^2
\]
又因双曲线的定义，
\[
|r_1-r_2|=2a
\]
故
\[
r_1r_2=\frac{r_1^2+r_2^2-4a^2}{2}=5a^2+c^2
\]
在三角形 \(F_1PF_2\) 中，
\(F_1F_2=2c\)，且 \(\angle F_1PF_2=60^{\circ}\). 由余弦定理，
\[
4c^2=r_1^2+r_2^2-2r_1r_2\cos60^{\circ}
=r_1^2+r_2^2-r_1r_2
=9a^2+c^2
\]
所以 \(c^2=3a^2\)，从而 \(b^2=c^2-a^2=2a^2\)，即
\(\frac ba=\sqrt2\). 双曲线的渐近线为
\(y=\pm\frac ba x=\pm\sqrt2x\)，即
\(\sqrt2x\pm y=0\)，故选 D.
\end{solution}
\end{problem}

\begin{problem}
函数 \(f(x) = \sin^2\left(2x - \frac{\pi}{4}\right)\) 的最小正周期是\fillinblank{}.

\begin{answer}
\(\frac{\pi}{2}\)
\end{answer}

\begin{solution}
利用恒等式 \(\sin^2t=\frac{1-\cos2t}{2}\)，有
\[
f(x)=\frac{1-\cos\left(4x-\frac{\pi}{2}\right)}{2}
\]
余弦函数的最小正周期为 \(2\pi\)，所以要求
\(4T=2\pi\)，得到 \(T=\frac{\pi}{2}\). 该周期由余弦函数的最小正周期得到，因而是最小正周期.
\end{solution}
\end{problem}

\begin{problem}
已知平面向量 \(\alpha\)，\(\beta\) 满足 \(|\alpha| = 1\)，\(|\beta| = 2\)，\(\alpha \perp (\alpha - 2\beta)\)，则 \(|2\alpha + \beta|\) 的值是\fillinblank{}.

\begin{answer}
\(\sqrt{10}\)
\end{answer}

\begin{solution}
由 \(\alpha\perp(\alpha-2\beta)\)，得
\[
\alpha\cdot(\alpha-2\beta)=0
\]
代入 \(|\alpha|=1\)，可得
\(1-2\alpha\cdot\beta=0\)，\(\alpha\cdot\beta=\frac12\).
于是
\[
|2\alpha+\beta|^2
=4|\alpha|^2+4\alpha\cdot\beta+|\beta|^2
=4+4\times\frac12+4=10
\]
长度非负，所以 \(|2\alpha+\beta|=\sqrt{10}\).
\end{solution}
\end{problem}

\begin{problem}
在如下数表中，已知每行、每列中的数都成等差数列.
那么，位于表中的第 \(n\) 行第 \(n + 1\) 列的数是\fillinblank{}.
\bitmapfigure[max width=0.36\linewidth]{img/2010/zhejiang_liberal/q14_fig1.png}

\begin{answer}
\(n^2+n\)
\end{answer}

\begin{solution}
记表中第 \(i\) 行第 \(j\) 列的数为 \(a_{ij}\). 由第一列可知
\(a_{i1}=i\)，由第二列可知 \(a_{i2}=2i\). 由于第 \(i\) 行成等差数列，该行公差为
\[
a_{i2}-a_{i1}=2i-i=i
\]
因此
\[
a_{ij}=a_{i1}+(j-1)i=i+(j-1)i=ij
\]
所以第 \(n\) 行第 \(n+1\) 列的数为
\[
a_{n,n+1}=n(n+1)=n^2+n
\]
\end{solution}
\end{problem}

\begin{problem}
若正实数 \(x\)，\(y\) 满足 \(2x + y + 6 = xy\)，则 \(xy\) 的最小值是\fillinblank{}.

\begin{answer}
\(18\)
\end{answer}

\begin{solution}
由题设
\[
xy-2x-y=6
\]
所以
\[
(x-1)(y-2)=8
\]
若 \(0<x<1\)，则 \(-1<x-1<0\)，从而
\(y-2=\frac{8}{x-1}<-8\)，即 \(y<-6\)，与 \(y>0\) 矛盾；\(x=1\) 也不满足
\((x-1)(y-2)=8\). 因此 \(x>1\)，从而 \(y-2=\frac{8}{x-1}>0\). 令
\(u=x-1>0\)，\(v=y-2>0\)，则 \(uv=8\)，且
\[
xy=(u+1)(v+2)=uv+2u+v+2=10+2u+v
\]
由均值不等式，
\[
2u+v=2u+\frac{8}{u}\geqslant8
\]
等号当且仅当 \(u=2\)，即 \(v=4\). 因此
\(xy\geqslant18\). 当 \(x=3\)，\(y=6\) 时满足原条件且 \(xy=18\)，所以最小值为 \(18\).
\end{solution}
\end{problem}

\begin{problem}
某商家一月份至五月份累计销售额达 3860 万元，预测六月份销售额为 500 万元. 七月份销售额比六月份递增 \(x\%\)，八月份销售额比七月份递增 \(x\%\)，九、十月份销售总额与七、八月份销售总额相等. 若一月至十月份销售总额至少达 7000 万元，则 \(x\) 的最小值是\fillinblank{}.

\begin{answer}
\(20\)
\end{answer}

\begin{solution}
设 \(t=1+\frac{x}{100}\). 则七月份和八月份的销售额分别为
\(500t\) 万元和 \(500t^2\) 万元，九、十月份销售总额为
\(500t+500t^2\) 万元. 因而一月至十月份的销售总额为
\[
3860+500+2(500t+500t^2)=4360+1000t+1000t^2
\]
由总额至少为 \(7000\) 万元，得
\[
25t^2+25t-66\geqslant0
\]
因 \(t>0\)，解得
\[
t\geqslant\frac65
\]
所以
\(1+\frac{x}{100}\geqslant\frac65\)，\(x\geqslant20\).
当 \(x=20\) 时恰好达到下界，故 \(x\) 的最小值为 \(20\).
\end{solution}
\end{problem}

\begin{problem}
在平行四边形 \(ABCD\) 中，\(O\) 是 \(AC\) 与 \(BD\) 的交点，\(P\)，\(Q\)，\(M\)，\(N\) 分别是线段 \(OA\)，\(OB\)，\(OC\)，\(OD\) 的中点. 在 \(A\)，\(P\)，\(M\)，\(C\) 中任取一点记为 \(E\)，在 \(B\)，\(Q\)，\(N\)，\(D\) 中任取一点记为 \(F\). 设 \(G\) 为满足向量 \(\overrightarrow{OG} = \overrightarrow{OE} + \overrightarrow{OF}\) 的点，则在上述的点 \(G\) 组成的集合中的点，落在平行四边形 \(ABCD\) 外（不含边界）的概率为\fillinblank{}.

\bitmapfigure[max width=0.44\linewidth]{img/2010/zhejiang_liberal/q17_fig1.png}

\begin{answer}
\(\frac{3}{4}\)
\end{answer}

\begin{solution}
以 \(O\) 为原点，设 \(\overrightarrow{OA}=\bs{a}\)，
\(\overrightarrow{OB}=\bs{b}\). 由于平行四边形的对角线互相平分，
\(\overrightarrow{OC}=-\bs{a}\)，\(\overrightarrow{OD}=-\bs{b}\).
所以 \(E\) 对应的系数只能是
\(1\)，\(\frac12\)，\(-\frac12\)，\(-1\)，即
\(\overrightarrow{OE}=s\bs{a}\)，其中
\(s\in\left\{1,\frac12,-\frac12,-1\right\}\). 同理
\(\overrightarrow{OF}=t\bs{b}\)，其中
\(t\in\left\{1,\frac12,-\frac12,-1\right\}\). 因而
\[
\overrightarrow{OG}=s\bs{a}+t\bs{b}
\]

在基底 \(\bs{a}\)，\(\bs{b}\) 下，平行四边形 \(ABCD\) 的四个顶点为
\((1,0)\)，\((0,1)\)，\((-1,0)\)，\((0,-1)\)，其内部及边界为
\(|s|+|t|\leqslant1\). 当且仅当
\(|s|=|t|=\frac12\) 时，\(|s|+|t|=1\)，对应 \(2\times2=4\) 个选择，所得点在边界上，不计入外部. 其余 \(16-4=12\) 个选择满足
\(|s|+|t|>1\)，所得点在平行四边形外部.

因此所求概率为
\[
\frac{12}{16}=\frac34
\]
\end{solution}
\end{problem}

\section{解答题}

\begin{problem}
在 \(\triangle ABC\) 中，角 \(A\)，\(B\)，\(C\) 所对的边分别为 \(a\)，\(b\)，\(c\). 设 \(S\) 为 \(\triangle ABC\) 的面积，满足 \(S = \frac{\sqrt{3}}{4}(a^2 + b^2 - c^2)\).

\begin{enumerate}
\item 求角 \(C\) 的大小；
\item 求 \(\sin A + \sin B\) 的最大值.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 由三角形面积公式和余弦定理，得
\(S = \frac{1}{2}ab\sin C\)，\(a^2+b^2-c^2=2ab\cos C\). 将它们代入已知条件，得到
\(\frac{1}{2}ab\sin C=\frac{\sqrt{3}}{2}ab\cos C\). 由于 \(a>0\)，\(b>0\)，且 \(0<C<\pi\)，所以 \(\sin C>0\)，从而 \(\cos C>0\). 约去 \(\frac{1}{2}ab\)，可得 \(\tan C=\sqrt{3}\)，故 \(C=\frac{\pi}{3}\).
\item 因为 \(A+B=\pi-C=\frac{2\pi}{3}\)，所以
\(\sin A+\sin B=2\sin\frac{A+B}{2}\cos\frac{A-B}{2}=\sqrt{3}\cos\frac{A-B}{2}\). 又因为 \(A>0\)，\(B>0\)，所以 \(\left|\frac{A-B}{2}\right|<\frac{\pi}{3}\)，从而 \(\cos\frac{A-B}{2}\leqslant1\). 因此 \(\sin A+\sin B\leqslant\sqrt{3}\). 当 \(A=B=\frac{\pi}{3}\) 时取等号，所以最大值为 \(\sqrt{3}\).
\end{enumerate}
\end{solution}

\begin{problem}
设 \(a_1\)，\(d\) 为实数，首项为 \(a_1\)，公差为 \(d\) 的等差数列 \(\{a_n\}\) 的前 \(n\) 项和为 \(S_n\)，满足 \(S_5S_6 + 15 = 0\).

\begin{enumerate}
\item 若 \(S_5 = 5\)，求 \(S_6\) 及 \(a_1\)；
\item 求 \(d\) 的取值范围.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 由 \(S_5S_6+15=0\) 及 \(S_5=5\)，得 \(S_6=-3\). 因此 \(a_6=S_6-S_5=-8\). 另一方面，等差数列的前 \(n\) 项和公式给出
\(S_5=5a_1+10d=5\)，即 \(a_1+2d=1\)；又 \(a_6=a_1+5d=-8\). 两式相减得 \(3d=-9\)，所以 \(d=-3\)，进而 \(a_1=7\).
\item 由 \(S_5=5a_1+10d\)，可得 \(a_1=\frac{S_5}{5}-2d\). 代入 \(S_6=6a_1+15d\)，得 \(S_6=\frac{6}{5}S_5+3d\). 于是已知条件等价于
\(S_5\left(\frac{6}{5}S_5+3d\right)+15=0\)，即
\(2S_5^2+5dS_5+25=0\). 要使实数 \(S_5\) 存在，该关于 \(S_5\) 的二次方程判别式必须满足
\(\Delta=25d^2-200\geqslant0\)，所以 \(d^2\geqslant8\)，即 \(d\leqslant-2\sqrt{2}\) 或 \(d\geqslant2\sqrt{2}\). 反之，当上述条件成立时，二次方程有实根，取该实根为 \(S_5\)，再令 \(a_1=\frac{S_5}{5}-2d\)，即可得到满足条件的等差数列，因此取值范围为 \((-\infty,-2\sqrt{2}]\cup[2\sqrt{2},+\infty)\).
\end{enumerate}
\end{solution}

\begin{problem}
如图，在平行四边形 \(ABCD\) 中，\(AB = 2BC\)，\(\angle ABC = 120^{\circ}\). \(E\) 为线段 \(AB\) 的中点，将 \(\triangle ADE\) 沿直线 \(DE\) 翻折成 \(\triangle A'DE\)，使平面 \(A'DE \perp\) 平面 \(BCD\)，\(F\) 为线段 \(A'C\) 的中点.

\begin{enumerate}
\item 求证：\(BF \parallel\) 平面 \(A'DE\)；
\item 设 \(M\) 为线段 \(DE\) 的中点，求直线 \(FM\) 与平面 \(A'DE\) 所成角的余弦值.
\end{enumerate}

\bitmapfigure[max width=0.42\linewidth]{img/2010/zhejiang_liberal/q20_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 取 \(BC=1\)，建立直角坐标系，使平面 \(BCD\) 为 \(z=0\)，并令 \(B=(0,0,0)\)，\(C=(1,0,0)\). 由 \(AB=2BC\) 及 \(\angle ABC=120^{\circ}\)，可取
\(A=(-1,\sqrt{3},0)\)，从而 \(D=(0,\sqrt{3},0)\). 于是
\(E=\left(-\frac{1}{2},\frac{\sqrt{3}}{2},0\right)\)，\(M=\left(-\frac{1}{4},\frac{3\sqrt{3}}{4},0\right)\). 由此可见 \(\triangle ADE\) 为等边三角形，且折叠后 \(A'M\perp DE\)，\(A'M=\frac{\sqrt{3}}{2}\). 因为平面 \(A'DE\) 垂直于平面 \(BCD\)，可取
\(A'=\left(-\frac{1}{4},\frac{3\sqrt{3}}{4},\frac{\sqrt{3}}{2}\right)\).

平面 \(A'DE\) 的一个法向量为 \(\bs{n}=(\sqrt{3},-1,0)\)，其方程为 \(\sqrt{3}x-y+\sqrt{3}=0\). 又 \(F\) 为 \(A'C\) 的中点，所以
\(F=\left(\frac{3}{8},\frac{3\sqrt{3}}{8},\frac{\sqrt{3}}{4}\right)\). 于是 \(\overrightarrow{BF}=\left(\frac{3}{8},\frac{3\sqrt{3}}{8},\frac{\sqrt{3}}{4}\right)\)，满足 \(\overrightarrow{BF}\cdot\bs{n}=0\). 因此直线 \(BF\) 的方向向量平行于平面 \(A'DE\)，且 \(B\) 不在该平面上，故 \(BF\parallel\) 平面 \(A'DE\).
\item 设直线 \(FM\) 与平面 \(A'DE\) 所成的角为 \(\theta\). 取直线 \(FM\) 的方向向量
\(\bs{u}=\overrightarrow{MF}=\left(\frac{5}{8},-\frac{3\sqrt{3}}{8},\frac{\sqrt{3}}{4}\right)\). 则 \(|\bs{u}|=1\)，\(|\bs{n}|=2\)，且 \(\bs{u}\cdot\bs{n}=\sqrt{3}\). 所以
\(\sin\theta=\frac{|\bs{u}\cdot\bs{n}|}{|\bs{u}|\,|\bs{n}|}=\frac{\sqrt{3}}{2}\). 由于 \(0\leqslant\theta\leqslant\frac{\pi}{2}\)，故 \(\cos\theta=\frac{1}{2}\).
\end{enumerate}
\end{solution}

\begin{problem}
已知函数 \(f(x) = (x - a)^2(x - b)\) （\(a\)，\(b \in \R\)，\(a < b\)）.

\begin{enumerate}
\item 当 \(a = 1\)，\(b = 2\) 时，求曲线 \(y = f(x)\) 在点 \((2, f(2))\) 处的切线方程；
\item 设 \(x_1\)，\(x_2\) 是 \(f(x)\) 的两个极值点，\(x_3\) 是 \(f(x)\) 的一个零点，且 \(x_3 \neq x_1\)，\(x_3 \neq x_2\). 证明：存在实数 \(x_4\)，使得 \(x_1\)，\(x_2\)，\(x_3\)，\(x_4\) 按某种顺序排列后成等差数列，并求 \(x_4\).
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 当 \(a=1\)，\(b=2\) 时，\(f(x)=(x-1)^2(x-2)\)，所以
\(f'(x)=2(x-1)(x-2)+(x-1)^2=(x-1)(3x-5)\). 又 \(f(2)=0\)，\(f'(2)=1\)，故曲线在点 \((2,0)\) 处的切线方程为 \(y-0=1\cdot(x-2)\)，即 \(y=x-2\).
\item 对一般的 \(a<b\)，有
\(f'(x)=2(x-a)(x-b)+(x-a)^2=(x-a)(3x-a-2b)\). 因此 \(f(x)\) 的两个极值点的横坐标为
\(a\) 和 \(\frac{a+2b}{3}\). 事实上，当 \(x<a\) 时 \(f'(x)>0\)，当
\(a<x<\frac{a+2b}{3}\) 时 \(f'(x)<0\)，当 \(x>\frac{a+2b}{3}\) 时
\(f'(x)>0\)，所以这两个驻点确为极值点. 而 \(f(x)=0\) 的零点为 \(a\) 和
\(b\)，其中 \(a\) 是二重零点. 由题设 \(x_3\neq x_1\) 且 \(x_3\neq x_2\)，可知
\(x_3=b\).

由于 \(a<b\)，有
\(a<\frac{2a+b}{3}<\frac{a+2b}{3}<b\)，并且相邻两数之差均为 \(\frac{b-a}{3}\). 所以按 \(a\)，\(\frac{2a+b}{3}\)，\(\frac{a+2b}{3}\)，\(b\) 的顺序排列时，四个数成等差数列，故 \(x_4=\frac{2a+b}{3}\).
\end{enumerate}
\end{solution}

\begin{problem}
已知 \(m\) 是非零实数，抛物线 \(C: y^{2} = 2px\) （\(p > 0\)） 的焦点 \(F\) 在直线 \(l: x - my - \frac{m^{2}}{2} = 0\) 上.

\begin{enumerate}
\item 若 \(m = 2\)，求抛物线 \(C\) 的方程；
\item 设直线 \(l\) 与抛物线 \(C\) 交于 \(A\)，\(B\) 两点，过 \(A\)，\(B\) 分别作抛物线 \(C\) 的准线的垂线，垂足为 \(A_{1}\)，\(B_{1}\)，\(\triangle AA_{1}F\)，\(\triangle BB_{1}F\) 的重心分别为 \(G\)，\(H\). 求证：对任意非零实数 \(m\)，抛物线 \(C\) 的准线与 \(x\) 轴的交点在以线段 \(GH\) 为直径的圆外.
\end{enumerate}

\bitmapfigure[max width=0.38\linewidth]{img/2010/zhejiang_liberal/q22_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 抛物线 \(y^2=2px\) 的焦点为 \(F\left(\frac{p}{2},0\right)\). 由于焦点在直线 \(l\) 上，代入直线方程得
\(\frac{p}{2}-\frac{m^2}{2}=0\)，所以 \(p=m^2\). 当 \(m=2\) 时，\(p=4\)，故抛物线 \(C\) 的方程为 \(y^2=8x\).
\item 由 \(p=m^2\)，可知 \(F=\left(\frac{m^2}{2},0\right)\)，抛物线的准线为 \(x=-\frac{m^2}{2}\). 设 \(A=(x_A,y_A)\)，\(B=(x_B,y_B)\). 由直线 \(l\) 得 \(x=my+\frac{m^2}{2}\)，代入抛物线方程，得到
\(y^2=2m^2\left(my+\frac{m^2}{2}\right)=2m^3y+m^4\). 因此 \(y_A\)，\(y_B\) 是方程 \(y^2-2m^3y-m^4=0\) 的两个根，从而
\(y_A+y_B=2m^3\)，\(y_Ay_B=-m^4\).

过 \(A\)，\(B\) 作准线的垂线都是水平线，所以 \(A_1=\left(-\frac{m^2}{2},y_A\right)\)，\(B_1=\left(-\frac{m^2}{2},y_B\right)\). 根据三角形重心坐标公式，得
\(G=\left(\frac{x_A}{3},\frac{2y_A}{3}\right)\)，\(H=\left(\frac{x_B}{3},\frac{2y_B}{3}\right)\). 记准线与 \(x\) 轴的交点为 \(T=\left(-\frac{m^2}{2},0\right)\). 由于 \(x_A=my_A+\frac{m^2}{2}\)，有
\(\overrightarrow{TG}=\left(\frac{m(2m+y_A)}{3},\frac{2y_A}{3}\right)\)，\(\overrightarrow{TH}=\left(\frac{m(2m+y_B)}{3},\frac{2y_B}{3}\right)\). 于是
\(\overrightarrow{TG}\cdot\overrightarrow{TH}=\frac{m^2(2m+y_A)(2m+y_B)+4y_Ay_B}{9}\). 再由根与系数的关系，得
\((2m+y_A)(2m+y_B)=4m^2+2m(y_A+y_B)+y_Ay_B=4m^2+3m^4\)，所以
\(\overrightarrow{TG}\cdot\overrightarrow{TH}=\frac{m^2(4m^2+3m^4)-4m^4}{9}=\frac{m^6}{3}>0\).

设以 \(GH\) 为直径的圆的圆心为 \(O_1\). 对任意点 \(X\)，有 \(\overrightarrow{XG}\cdot\overrightarrow{XH}=|XO_1|^2-\left(\frac{|GH|}{2}\right)^2\). 因此当该数量大于零时，点 \(X\) 在圆外. 取 \(X=T\)，由上式可知 \(T\) 在以 \(GH\) 为直径的圆外，证毕.
\end{enumerate}
\end{solution}
