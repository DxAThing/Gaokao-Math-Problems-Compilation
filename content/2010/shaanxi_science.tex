\section{单选题}

\begin{problem}
集合 \(A = \{x \mid -1 \leqslant x \leqslant 2\}\)，\(B = \{x \mid x < 1\}\)，则 \(A \cap (\complement_{\R} B) =\)（\quad）

\choices
    {\( \{x \mid x > 1\} \)}
    {\(\{x \mid x \geqslant 1\}\)}
    {\(\{x\mid 1 < x\leqslant 2\}\)}
    {\(\{x\mid 1\leqslant x\leqslant 2\}\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
由 \(B=\{x\mid x<1\}\)，可得 \(\complement_{\R}B=\{x\mid x\geqslant1\}\). 因此 \(A\cap(\complement_{\R}B)=\{x\mid1\leqslant x\leqslant2\}\)，故选 D.
\end{solution}

\begin{problem}
复数 \(z = \frac{1}{1 + \i}\) 在复平面上对应的点位于（\quad）

\choices
    {第一象限}
    {第二象限}
    {第三象限}
    {第四象限}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
分母有理化得 \(z=\frac{1-\i}{(1+\i)(1-\i)}=\frac12-\frac12\i\). 因此复数对应点的横坐标为正、纵坐标为负，位于第四象限，故选 D.
\end{solution}

\begin{problem}
对于函数 \( f(x) = 2\sin x\cos x \)，下列选项中正确的是（\quad）

\choices
    {对于 \(f(x)\) 在 \(\left(\frac{\pi}{4}, \frac{\pi}{2}\right)\) 上是递增的}
    {\(f(x)\) 的图象关于原点对称}
    {\(f(x)\) 的最小正周期为 \(2\pi\)}
    {\(f(x)\) 的最大值为 \(2\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
由 \(f(x)=\sin2x\)，得 \(f(-x)=-f(x)\)，所以函数图象关于原点对称，选项 B 正确. 在 \(\left(\frac{\pi}{4},\frac{\pi}{2}\right)\) 上，\(2x\in\left(\frac{\pi}{2},\pi\right)\)，函数 \(\sin2x\) 递减；函数的最小正周期为 \(\pi\)，最大值为 \(1\)，故其余选项均不正确.
\end{solution}

\begin{problem}
\(\left(x + \frac{a}{x}\right)^5\)（\(x\in \R\)）展开式中 \(x^{3}\) 的系数为 \(10\)，则实数 \(a\) 等于（\quad）

\choices
    {\(-1\)}
    {\(\frac{1}{2}\)}
    {\(1\)}
    {\(2\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
展开式通项中，若从 \(\frac{a}{x}\) 中取 \(k\) 次，从 \(x\) 中取 \(5-k\) 次，则幂为 \(x^{5-2k}\). 要得到 \(x^3\)，必须有 \(5-2k=3\)，所以 \(k=1\). 因而 \(x^3\) 的系数为 \(\mathrm C_5^1a=5a\). 由 \(5a=10\)，得 \(a=2\)，故选 D.
\end{solution}

\begin{problem}
已知函数 \(f(x) = \begin{cases}
2^x + 1, & x < 1,\\
x^2 + ax, & x \geqslant 1.
\end{cases}\) 若 \(f(f(0)) = 4a\)，则实数 \(a\) 等于（\quad）

\choices
    {\(\frac{1}{2}\)}
    {\(\frac{4}{5}\)}
    {\(2\)}
    {\(9\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
因为 \(0<1\)，所以 \(f(0)=2^0+1=2\). 又因为 \(2\geqslant1\)，所以 \(f(f(0))=f(2)=2^2+2a=4+2a\). 由题设 \(4+2a=4a\)，解得 \(a=2\)，故选 C.
\end{solution}

\begin{problem}
如图所示是求样本 \(x_{1}\)，\(x_{2}\)，\(\cdots\)，\(x_{10}\) 平均数 \(\overline{x}\) 的程序框图，图中空白框中应填入的内容为（\quad）

\bitmapfigure[max width=0.34\linewidth]{img/2010/shaanxi_science/q6_fig1.png}

\choices
    {\(S = S + x_{n}\)}
    {\(S = S + \frac{x_n}{n}\)}
    {\(S = S + n\)}
    {\(S = S + \frac{1}{n}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
程序开始时令 \(S=0\)，每次循环把当前输入的样本值 \(x_n\) 累加到 \(S\) 中，然后令 \(n\) 增加 \(1\). 当输入完 \(x_1\)、\(x_2\)、\(\cdots\)、\(x_{10}\) 后，必须有 \(S=x_1+x_2+\cdots+x_{10}\)，最后才能通过 \(\overline{x}=\frac{S}{n}\) 求平均数. 因此空白框应填 \(S=S+x_n\)，故选 A.
\end{solution}

若某空间几何体的三视图如图所示，则该几何体的体积是（\quad）

\bitmapfigure[max width=0.34\linewidth]{img/2010/shaanxi_science/q7_fig1.png}

    {\(\frac{2}{3}\)}

    {\(2\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{problem}
已知抛物线 \(y^2 = 2px\)（\(p > 0\)）的准线与圆 \(x^2 + y^2 - 6x - 7 = 0\) 相切，则 \(p\) 的值为（\quad）

\choices
    {\(\frac{1}{2}\)}
    {\(1\)}
    {\(2\)}
    {\(4\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
抛物线 \(y^2=2px\) 的准线为 \(x=-\frac p2\). 圆的方程可化为 \((x-3)^2+y^2=16\)，所以圆心为 \((3,0)\)，半径为 \(4\). 准线与圆相切时，圆心到准线的距离等于半径，即 \(3+\frac p2=4\). 因而 \(p=2\)，故选 C.
\end{solution}

\begin{problem}
对于数列 \(\{a_n\}\)，“\(a_{n+1} > |a_n|\)（\(n = 1\)，\(2\)，\(\cdots\)）”是“\(\{a_n\}\) 为递增数列”的（\quad）

\choices
    {必要不充分条件}
    {充分不必要条件}
    {充要条件}
    {既不充分也不必要条件}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
若对任意正整数 \(n\) 都有 \(a_{n+1}>|a_n|\)，则 \(|a_n|\geqslant a_n\)，从而 \(a_{n+1}>a_n\)，所以数列必为递增数列. 反之不成立，例如取 \(a_n=-\frac1n\)，则 \(a_{n+1}>a_n\)，数列递增，但 \(a_2=-\frac12\not>|a_1|=1\). 因此该条件是充分不必要条件，故选 B.
\end{solution}

\begin{problem}
某学校要召开学生代表大会，规定各班每 \(10\) 人推选一名代表，当各班人数除以 \(10\) 的余数大于 \(6\) 时再增选一名代表. 那么，各班可推选代表人数 \(y\) 与该班人数 \(x\) 之间的函数关系用取整函数 \(y = [x]\)（\([x]\) 表示不大于 \(x\) 的最大整数）可以表示为（\quad）

\choices
    {\(y = \left[\frac{x}{10}\right]\)}
    {\(y = \left[\frac{x + 3}{10}\right]\)}
    {\(y = \left[\frac{x + 4}{10}\right]\)}
    {\(y = \left[\frac{x + 5}{10}\right]\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
设 \(x=10k+r\)，其中 \(k\) 为非负整数，\(0\leqslant r\leqslant9\). 当 \(0\leqslant r\leqslant6\) 时，代表数为 \(k\)；当 \(7\leqslant r\leqslant9\) 时，代表数为 \(k+1\). 而 \(\left[\frac{x+3}{10}\right]=\left[k+\frac{r+3}{10}\right]\) 在前一种情形等于 \(k\)，在后一种情形等于 \(k+1\)，正好符合规定. 故选 B.
\end{solution}

\section{填空题}

\begin{problem}
已知向量 \(\bs{a} = (2, -1)\)，\(\bs{b} = (-1, m)\)，\(\bs{c} = (-1, 2)\). 若 \((\bs{a} + \bs{b}) \parallel \bs{c}\)，则 \(m = \)\fillinblank{}.
\end{problem}

\begin{answer}
\(-1\)
\end{answer}

\begin{solution}
由 \(\bs{a}+\bs{b}=(1,m-1)\). 因为 \((\bs{a}+\bs{b})\parallel\bs{c}\)，所以两向量的行列式为零，即 \(\begin{vmatrix}1&m-1\\-1&2\end{vmatrix}=2+(m-1)=m+1=0\). 因此 \(m=-1\).
\end{solution}

\begin{problem}
观察下列等式：\(1^3 + 2^3 = 3^2\)，\(1^3 + 2^3 + 3^3 = 6^2\)，\(1^3 + 2^3 + 3^3 + 4^3 = 10^2\)，\(\cdots\)，根据上述规律，第五个等式为\fillinblank{}.
\end{problem}

\begin{answer}
\(1^3 + 2^3 + 3^3 + 4^3 + 5^3 + 6^3 = 21^2\)
\end{answer}

\begin{solution}
对任意正整数 \(k\)，有
\[
\left(\frac{k(k+1)}2\right)^2-\left(\frac{(k-1)k}2\right)^2
=\left(\frac{k(k+1)}2-\frac{(k-1)k}2\right)
\left(\frac{k(k+1)}2+\frac{(k-1)k}2\right)=k\cdot k^2=k^3.
\]
从 \(k=1\) 到 \(n\) 求和，上式右端构成紧密相消，因而
\[
1^3+2^3+\cdots+n^3
=\left(\frac{n(n+1)}2\right)^2-\left(\frac{1\cdot0}2\right)^2
=\left(\frac{n(n+1)}2\right)^2.
\]
题中第一个等式对应 \(n=2\)，所以第五个等式对应 \(n=6\). 此时 \(1+2+\cdots+6=21\)，故第五个等式为 \(1^3+2^3+3^3+4^3+5^3+6^3=21^2\).
\end{solution}

\begin{problem}
从如图所示的长方形区域内任取一个点 \(M(x, y)\)，则点 \(M\) 取自阴影部分的概率为\fillinblank{}.

\bitmapfigure[max width=0.34\linewidth]{img/2010/shaanxi_science/q13_fig1.png}
\end{problem}

\begin{answer}
\(\frac{2}{3}\)
\end{answer}

\begin{solution}
由图可知，长方形区域为 \(0\leqslant x\leqslant 1\)，\(0\leqslant y\leqslant 3\)，其面积为 \(3\). 阴影部分是长方形中曲线 \(y=3x^2\) 右侧的部分，因此阴影面积为
\[
3-\int_0^1 3x^2\,\mathrm{d}x=3-\left.x^3\right|_0^1=2.
\]
所以点 \(M\) 取自阴影部分的概率为 \(\frac{2}{3}\).
\end{solution}

\begin{problem}
铁矿石 \(A\) 和 \(B\) 的含铁率 \(a\)，冶炼每万吨铁矿石的 \(\mathrm{CO}_2\) 排放量 \(b\) 及每万吨铁矿石的价格 \(c\) 如下表：

\begin{center}
\begin{tabular}{|c|c|c|c|}
\hline
 & \(a\) & \(b\)（万吨） & \(c\)（百万元） \\
\hline
\(A\) & \(50\%\) & \(1\) & \(3\) \\
\hline
\(B\) & \(70\%\) & \(0.5\) & \(6\) \\
\hline
\end{tabular}
\end{center}

某冶炼厂至少要生产 \(1.9\) 万吨铁，若要求 \(\mathrm{CO}_2\) 的排放量不超过 \(2\) 万吨，则购买铁矿石的最少费用为\fillinblank{} 百万元.
\end{problem}

\begin{answer}
15
\end{answer}

\begin{solution}
设购买铁矿石 \(A\)、\(B\) 各 \(x\)、\(y\) 万吨，则 \(x\geqslant0\)，\(y\geqslant0\)，并且 \(\frac12x+\frac7{10}y\geqslant\frac{19}{10}\)，\(x+\frac12y\leqslant2\). 购买费用为 \(3x+6y\) 百万元.

对任意满足约束条件的 \(x\)、\(y\)，有
\[
3x+6y-15=10\left(\frac12x+\frac7{10}y-\frac{19}{10}\right)+2\left(2-x-\frac12y\right)\geqslant0.
\]
所以购买费用不小于 \(15\) 百万元. 取 \(x=1\)、\(y=2\) 时，产铁量为 \(\frac12+\frac7{10}\times2=1.9\) 万吨，排放量为 \(1+\frac12\times2=2\) 万吨，满足全部条件，且费用为 \(3+6\times2=15\) 百万元. 因此最少费用为 \(15\) 百万元.
\end{solution}

\section{选做题}

\begin{problem}
不等式 \(|x + 3| - |x - 2| \geqslant 3\) 的解集为\fillinblank{}.
\end{problem}

\begin{answer}
\(\{x \mid x \geqslant 1\}\)
\end{answer}

\begin{solution}
按 \(x\) 与 \(-3\)、\(2\) 的大小规律分段讨论. 当 \(x<-3\) 时，原式等于 \(-5<3\)；当 \(-3\leqslant x<2\) 时，原式等于 \(2x+1\)，故需 \(x\geqslant1\)；当 \(x\geqslant2\) 时，原式等于 \(5\)，恒大于等于 \(3\). 合并各段可得解集为 \(\{x\mid x\geqslant1\}\).
\end{solution}

\begin{problem}
如图，已知 \(\mathrm{Rt}\triangle ABC\) 的两条直角边 \(AC\)，\(BC\) 的长分别为 \(3\,\mathrm{cm}\)，\(4\,\mathrm{cm}\)，以 \(AC\) 为直径的圆与 \(AB\) 交于点 \(D\)，则 \(\frac{BD}{DA} = \)\fillinblank{}.

\bitmapfigure[max width=0.46\linewidth]{img/2010/shaanxi_science/q15_fig1.png}
\end{problem}

\begin{answer}
\(\frac{16}{9}\)
\end{answer}

\begin{solution}
由勾股定理，\(AB=\sqrt{AC^2+BC^2}=\sqrt{3^2+4^2}=5\). 因为 \(D\) 在以 \(AC\) 为直径的圆上，所以由圆周角定理得 \(\angle ADC=90^\circ\)，即 \(CD\perp AB\). 在直角三角形 \(ABC\) 中，利用斜边上的高的射影定理，得 \(AC^2=AB\cdot AD\)，\(BC^2=AB\cdot BD\). 因而 \(AD=\frac95\)，\(BD=\frac{16}{5}\)，所以 \(\frac{BD}{DA}=\frac{16}{9}\).
\end{solution}

\begin{problem}
已知圆 \(C\) 的参数方程为 \(x = \cos \alpha\)，\(y = 1 + \sin \alpha\)（\(\alpha\) 为参数），以原点为极点，\(x\) 轴正半轴为极轴建立极坐标系. 直线 \(l\) 的极坐标方程为 \(\rho\sin\theta = 1\)，则直线 \(l\) 与圆 \(C\) 的交点的直角坐标为\fillinblank{}.
\end{problem}

\begin{answer}
\((-1,1)\)，\((1,1)\)
\end{answer}

\begin{solution}
由参数方程消去参数 \(\alpha\)，得 \(x^2+(y-1)^2=\cos^2\alpha+\sin^2\alpha=1\). 在极坐标中 \(y=\rho\sin\theta\)，所以直线 \(\rho\sin\theta=1\) 即为直线 \(y=1\). 联立圆的方程与直线方程，得 \(x^2=1\)，从而交点的直角坐标为 \((-1,1)\)，\((1,1)\).
\end{solution}

\section{解答题}

\begin{problem}
已知 \(\{a_n\}\) 是公差不为零的等差数列，\(a_1 = 1\) 且 \(a_1\)，\(a_3\)，\(a_9\) 成等比数列.

\begin{enumerate}
\item 求数列 \(\{a_n\}\) 的通项；
\item 求数列 \(\{2^{a_n}\}\) 的前 \(n\) 项和 \(S_n\).
\end{enumerate}
\end{problem}

\begin{solution}
设等差数列 \(\{a_n\}\) 的公差为 \(d\)，则 \(d\ne0\)，且 \(a_n=1+(n-1)d\). 因此 \(a_3=1+2d\)，\(a_9=1+8d\). 由 \(a_1\)，\(a_3\)，\(a_9\) 成等比数列，得
\[
(1+2d)^2=1\cdot(1+8d).
\]
化简得 \(4d^2-4d=0\)，即 \(4d(d-1)=0\). 由于 \(d\ne0\)，所以 \(d=1\)，从而
\[
a_n=1+(n-1)=n.
\]

于是 \(2^{a_n}=2^n\). 设其前 \(n\) 项和为 \(S_n\)，则
\[
S_n=2+2^2+\cdots+2^n.
\]
两边乘以 \(2\)，得 \(2S_n=2^2+2^3+\cdots+2^{n+1}\). 两式相减，得 \(S_n=2^{n+1}-2\).
所以数列 \(\{a_n\}\) 的通项为 \(a_n=n\)，数列 \(\{2^{a_n}\}\) 的前 \(n\) 项和为 \(S_n=2^{n+1}-2\).
\end{solution}

\begin{problem}
如图，\(A\)，\(B\) 是海面上位于东西方向相距 \(5(3 + \sqrt{3})\) 海里的两个观测点. 现位于 \(A\) 点北偏东 \(45^\circ\)，\(B\) 点北偏西 \(60^\circ\) 的 \(D\) 点有一艘轮船发出求救信号，位于 \(B\) 点南偏西 \(60^\circ\) 且与 \(B\) 点相距 \(20\sqrt{3}\) 海里的 \(C\) 点的救援船立即前往营救，其航行速度为 \(30\) 海里/小时，该救援船到达 \(D\) 点需要多长时间？

\bitmapfigure[max width=0.42\linewidth]{img/2010/shaanxi_science/q17_fig1.png}
\end{problem}

\begin{solution}
取东西方向为 \(x\) 轴，南北方向为 \(y\) 轴正方向，设 \(A=(0,0)\)，\(B=(L,0)\)，其中 \(L=5(3+\sqrt{3})\). 由于 \(D\) 在 \(A\) 点北偏东 \(45^\circ\) 方向上，直线 \(AD\) 的方程为 \(y=x\). 由于 \(D\) 在 \(B\) 点北偏西 \(60^\circ\) 方向上，直线 \(BD\) 与负 \(x\) 轴的夹角为 \(30^\circ\)，故其方程为 \(y=\frac{L-x}{\sqrt{3}}\). 联立得
\[
x=\frac{L-x}{\sqrt{3}}=\frac{L}{1+\sqrt{3}}=5\sqrt{3}.
\]
所以 \(D=(5\sqrt{3},5\sqrt{3})\).

从 \(B\) 点南偏西 \(60^\circ\) 方向为标准方向角 \(210^\circ\)，且 \(BC=20\sqrt{3}\)，因此
\[
\overrightarrow{BC}=20\sqrt{3}(\cos210^\circ,\sin210^\circ)=(-30,-10\sqrt{3}).
\]
从而 \(C=(L-30,-10\sqrt{3})=(5\sqrt{3}-15,-10\sqrt{3})\). 于是
\[
CD^2=\left[5\sqrt{3}-(5\sqrt{3}-15)\right]^2+\left[5\sqrt{3}-(-10\sqrt{3})\right]^2=15^2+(15\sqrt{3})^2=900,
\]
即 \(CD=30\) 海里. 救援船的航行速度为 \(30\) 海里/小时，所以到达 \(D\) 点所需时间为 \(\frac{30}{30}=1\) 小时.
\end{solution}

\begin{problem}
如图，在四棱锥 \(P - ABCD\) 中，底面 \(ABCD\) 是矩形，\(PA \perp\) 平面 \(ABCD\)，\(AP = AB = 2\)，\(BC = 2\sqrt{2}\)，\(E\)，\(F\) 分别是 \(AD\)，\(PC\) 的中点.

\begin{enumerate}
\item 证明：\(PC \perp\) 平面 \(BEF\)；
\item 求平面 \(BEF\) 与平面 \(BAP\) 夹角的大小.
\end{enumerate}

\bitmapfigure[max width=0.48\linewidth]{img/2010/shaanxi_science/q18_fig1.png}
\end{problem}

\begin{solution}
建立空间直角坐标系，取 \(A\) 为原点，令 \(AB\)、\(AD\)、\(AP\) 分别沿 \(x\)、\(y\)、\(z\) 轴正方向，则
分别有 \(A=(0,0,0)\)，\(B=(2,0,0)\)，\(D=(0,2\sqrt{2},0)\)，\(C=(2,2\sqrt{2},0)\)，\(P=(0,0,2)\).
因此 \(E=(0,\sqrt{2},0)\)，\(F=(1,\sqrt{2},1)\).

\begin{enumerate}
\item 有 \(\overrightarrow{PC}=(2,2\sqrt{2},-2)\)，\(\overrightarrow{BE}=(-2,\sqrt{2},0)\)，\(\overrightarrow{BF}=(-1,\sqrt{2},1)\).
于是 \(\overrightarrow{PC}\cdot\overrightarrow{BE}=-4+4=0\)，\(\overrightarrow{PC}\cdot\overrightarrow{BF}=-2+4-2=0\).
直线 \(BE\) 与 \(BF\) 相交于 \(B\)，且 \(BE\)、\(BF\) 都在平面 \(BEF\) 内，所以 \(PC\perp\) 平面 \(BEF\).
\item 平面 \(BAP\) 的方程为 \(y=0\)，可取其一个法向量为 \(\bs{n}_1=(0,1,0)\). 平面 \(BEF\) 的一个法向量为
\[
\bs{n}_2=\overrightarrow{BE}\times\overrightarrow{BF}=(\sqrt{2},2,-\sqrt{2}).
\]
设两平面的夹角为 \(\theta\)，则
\[
\cos\theta=\frac{|\bs{n}_1\cdot\bs{n}_2|}{|\bs{n}_1||\bs{n}_2|}=\frac{2}{\sqrt{2+4+2}}=\frac{1}{\sqrt{2}}.
\]
由于平面夹角取锐角或直角，故 \(\theta=45^\circ\).
\end{enumerate}
\end{solution}

\begin{problem}
如图，椭圆 \(C : \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\) 的顶点为 \(A_1\)，\(A_2\)，\(B_1\)，\(B_2\)，焦点为 \(F_1\)，\(F_2\)，\(|A_1B_1| = \sqrt{7}\)，\(S_{\square A_1B_1A_2B_2} = 2S_{\square B_1F_1B_2F_2}\).

\begin{enumerate}
\item 求椭圆 \(C\) 的方程；
\item 设 \(n\) 是过原点的直线，\(l\) 是与 \(n\) 垂直相交于 \(P\) 点，与椭圆相交于 \(A\)，\(B\) 两点的直线，\(\overline{OP} = 1\). 是否存在上述直线 \(l\) 使 \(\overrightarrow{AP} \cdot \overrightarrow{PB} = 1\) 成立？若存在，求出直线 \(l\) 的方程；若不存在，请说明理由.
\end{enumerate}

\bitmapfigure[max width=0.42\linewidth]{img/2010/shaanxi_science/q20_fig1.png}
\end{problem}

\begin{solution}
设椭圆的半焦距为 \(c\)，则 \(c^2=a^2-b^2\). 由椭圆顶点和焦点的位置，四边形 \(A_1B_1A_2B_2\) 的两条对角线长分别为 \(2a\)、\(2b\)，四边形 \(B_1F_1B_2F_2\) 的两条对角线长分别为 \(2b\)、\(2c\). 因此
\[
|A_1B_1|^2=a^2+b^2=7,
\]
且 \(S_{\square A_1B_1A_2B_2}=2ab\)，\(S_{\square B_1F_1B_2F_2}=2bc\).
由题设面积关系得 \(2ab=2\cdot2bc\)，所以 \(a=2c\). 结合 \(c^2=a^2-b^2\)，得 \(a^2=4(a^2-b^2)\)，即 \(b^2=\frac{3}{4}a^2\). 再由 \(a^2+b^2=7\)，得 \(a^2=4\)，\(b^2=3\).
所以椭圆 \(C\) 的方程为
\[
\frac{x^2}{4}+\frac{y^2}{3}=1.
\]

\begin{enumerate}
\item 设 \(P=(p,q)\). 由 \(\overline{OP}=1\)，得 \(p^2+q^2=1\). 取 \(\bs{e}=(-q,p)\)，则 \(\bs{e}\) 是与 \(\overrightarrow{OP}\) 垂直的单位向量，直线 \(l\) 可表示为
\[
(x,y)=(p,q)+t\bs{e}=(p-tq,q+tp).
\]
又因为
\[
\frac{p^2}{4}+\frac{q^2}{3}\leqslant\frac{p^2+q^2}{3}=\frac13<1,
\]
所以 \(P\) 在椭圆内部，\(l\) 与椭圆有两个交点. 设它们对应的参数为 \(t_1<0<t_2\)，并令 \(A=P+t_1\bs{e}\)，\(B=P+t_2\bs{e}\). 代入椭圆方程得
\[
\left(\frac{q^2}{4}+\frac{p^2}{3}\right)t^2+\frac{pq}{6}t+\left(\frac{p^2}{4}+\frac{q^2}{3}-1\right)=0.
\]
由韦达定理，
\[
t_1t_2=\frac{\frac{p^2}{4}+\frac{q^2}{3}-1}{\frac{q^2}{4}+\frac{p^2}{3}}.
\]
又因为 \(\bs{e}\) 是单位向量，有
\[
\overrightarrow{AP}\cdot\overrightarrow{PB}=(-t_1\bs{e})\cdot(t_2\bs{e})=-t_1t_2=\frac{1-\frac{p^2}{4}-\frac{q^2}{3}}{\frac{q^2}{4}+\frac{p^2}{3}}.
\]
若 \(\overrightarrow{AP}\cdot\overrightarrow{PB}=1\)，则
\[
1-\frac{p^2}{4}-\frac{q^2}{3}=\frac{q^2}{4}+\frac{p^2}{3},
\]
即
\[
1=\frac{p^2+q^2}{4}+\frac{p^2+q^2}{3}=\frac7{12},
\]
矛盾. 因此不存在满足条件的直线 \(l\).
\end{enumerate}
\end{solution}

\begin{problem}
已知函数 \(f(x) = \sqrt{x}\)，\(g(x) = a\ln x\)，\(a \in \R\).

\begin{enumerate}
\item 若曲线 \(y = f(x)\) 与曲线 \(y = g(x)\) 相交，且在交点处有共同的切线，求 \(a\) 的值和该切线方程；
\item 设函数 \(h(x) = f(x) - g(x)\)，当 \(h(x)\) 存在最小值时，求其最小值 \(\varphi(a)\) 的解析式；
\item 对第 \(2\) 问中的 \(\varphi(a)\) 和任意的 \(a > 0\)，\(b > 0\)，证明：\(\varphi'\left(\frac{a + b}{2}\right) \leqslant \frac{\varphi'(a) + \varphi'(b)}{2} \leqslant \varphi'\left(\frac{2ab}{a + b}\right)\).
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 设两曲线的交点横坐标为 \(t\)，则 \(t>0\)，并且交点处的纵坐标相等、切线斜率相等，所以 \(\sqrt{t}=a\ln t\)，且 \(\frac{1}{2\sqrt{t}}=\frac{a}{t}\).
由第二个等式得 \(a=\frac{\sqrt{t}}{2}\). 代入第一个等式，得 \(\sqrt{t}=\frac{\sqrt{t}}{2}\ln t\). 因 \(t>0\)，所以 \(\ln t=2\)，即 \(t=\e^2\)，从而 \(a=\frac{\e}{2}\).
交点为 \((\e^2,\e)\)，共同切线的斜率为 \(\frac{1}{2\e}\)，故切线方程为
\[
y-\e=\frac{1}{2\e}(x-\e^2),
\]
即 \(x-2\e y+\e^2=0\).
\item 函数 \(h\) 的定义域为 \(x>0\)，且
\[
h'(x)=\frac{1}{2\sqrt{x}}-\frac{a}{x}=\frac{\sqrt{x}-2a}{2x}.
\]
当 \(a>0\) 时，\(h'(x)<0\)（\(0<x<4a^2\)），\(h'(x)>0\)（\(x>4a^2\)），所以 \(h\) 在 \(x=4a^2\) 处取得最小值. 此时
\[
\varphi(a)=h(4a^2)=2a-a\ln(4a^2)=2a\left(1-\ln(2a)\right).
\]
当 \(a=0\) 时，\(h(x)=\sqrt{x}\)，虽有 \(h(x)\to0\)（\(x\to0^+\)），但 \(x=0\) 不在定义域内，故不存在最小值. 当 \(a<0\) 时，\(h(x)=\sqrt{x}+|a|\ln x\)，且 \(h(x)\to-\infty\)（\(x\to0^+\)），也不存在最小值. 因此 \(h(x)\) 存在最小值的条件是 \(a>0\)，此时 \(\varphi(a)=2a\left(1-\ln(2a)\right)\).
\item 由上式，在 \(a>0\) 时
\[
\varphi'(x)=-2\ln(2x).
\]
于是 \(\varphi'\left(\frac{a+b}{2}\right)=-2\ln(a+b)\)，且 \(\frac{\varphi'(a)+\varphi'(b)}{2}=-\ln(4ab)\).
\[
\varphi'\left(\frac{2ab}{a+b}\right)=-2\ln\left(\frac{4ab}{a+b}\right).
\]
由基本不等式 \((a+b)^2\geqslant4ab\)，并注意到各量均为正数，有
\[
-2\ln(a+b)\leqslant-\ln(4ab),
\]
以及
\[
-\ln(4ab)\leqslant-2\ln\left(\frac{4ab}{a+b}\right).
\]
将上述三式分别代回，即得
\[
\varphi'\left(\frac{a+b}{2}\right)\leqslant\frac{\varphi'(a)+\varphi'(b)}{2}\leqslant\varphi'\left(\frac{2ab}{a+b}\right).
\]
\end{enumerate}
\end{solution}

\begin{problem}
为了解学生身高情况，某校以 \(10\%\) 的比例对全校 \(700\) 名学生按性别进行分层抽样调查，测得身高情况的统计图如下：

\begin{enumerate}
\item 估计该校男生的人数；
\item 估计该校学生身高在 \(170 \sim 185\,\mathrm{cm}\) 之间的概率；
\item 从样本中身高在 \(165 \sim 180\,\mathrm{cm}\) 之间的女生中任选 \(2\) 人，求至少有 \(1\) 人身高在 \(170 \sim 180\,\mathrm{cm}\) 之间的概率.
\end{enumerate}

\bitmapfigure[max width=0.72\linewidth]{img/2010/shaanxi_science/q19_fig1.png}
\end{problem}

\begin{solution}
由统计图可知，男生样本在各身高区间内的频数依次为 \(2\)，\(5\)，\(14\)，\(13\)，\(4\)，\(2\)，所以男生样本数为 \(40\). 由于按 \(10\%\) 的比例抽样，估计该校男生人数为 \(\frac{40}{10\%}=400\) 人.

女生样本在各身高区间内的频数依次为 \(1\)，\(7\)，\(12\)，\(6\)，\(3\)，\(1\)，所以女生样本数为 \(30\)，样本总数为 \(40+30=70\). 身高在 \(170\sim185\,\mathrm{cm}\) 之间的学生样本数为
\[
(14+13+4)+(12+6+3)=52.
\]
因此估计该校学生身高在 \(170\sim185\,\mathrm{cm}\) 之间的概率为 \(\frac{52}{70}=\frac{26}{35}\).

女生样本中身高在 \(165\sim180\,\mathrm{cm}\) 之间的共有 \(7+12+6=25\) 人，其中身高在 \(170\sim180\,\mathrm{cm}\) 之间的有 \(12+6=18\) 人，身高在 \(165\sim170\,\mathrm{cm}\) 之间的有 \(7\) 人. 从这 \(25\) 人中任选 \(2\) 人，至少有 \(1\) 人身高在 \(170\sim180\,\mathrm{cm}\) 之间的概率为
\[
1-\frac{\mathrm C_7^2}{\mathrm C_{25}^2}=1-\frac{21}{300}=\frac{93}{100}.
\]
所以三问的结果分别为 \(400\) 人，\(\frac{26}{35}\)，\(\frac{93}{100}\).
\end{solution}
