    {\(Q \subseteq \complement_{\R} P\)}

\begin{problem}

\begin{problem}
对任意复数 \(z = x + yi\)（\(x\)，\(y \in \R\)），\(i\) 为虚数单位，则下列结论正确的是（\quad）

\choices
    {\(|z - \overline{z}| = 2y\)}
    {\(z^2 = x^2 + y^2\)}
    {\(|z - \overline{z}| \geqslant 2x\)}
    {\(|z|\leqslant |x| + |y|\)}

\begin{problem}
设 \(l\)，\(m\) 是两条不同的直线，\(\alpha\) 是一个平面，则下列命题正确的是（\quad）

\choices
    {若 \(l \perp m, m \subset \alpha\)，则 \(l \perp \alpha\)}
    {若 \(l \perp \alpha\)，\(l // m\)，则 \(m \perp \alpha\)}
    {若 \(l // \alpha\)，\(m \subset \alpha\)，则 \(l // m\)}
    {若 \(l // \alpha\)，\(m // \alpha\)，则 \(l // m\)}
\end{problem}

\begin{problem}
若实数 \(x\)，\(y\) 满足不等式组 \(\left\{ \begin{array}{l} x + 3y - 3 \geqslant 0, \\ 2x - y - 3 \leqslant 0, \\ x - my + 1 \geqslant 0, \end{array} \right.\) 且 \(x + y\) 的最大值为9，则实数 \(m =\)（\quad）

\choices
    {\(-2\)}

    {2}

\begin{problem}
设 \(F_{1}\)，\(F_{2}\) 分别为双曲线 \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 (a > 0, b > 0)\) 的左，右焦点. 若在双曲线右支上存在点 \(P\)，满足 \(|PF_{2}| = |F_{1}F_{2}|\)，且 \(F_{2}\) 到直线 \(PF_{1}\) 的距离等于双曲线的实轴长，则该双曲线的渐近线方程为（\quad）

\choices
    {\(3x \pm 4y = 0\)}
    {\(3x \pm 5y = 0\)}
    {\(4x \pm 3y = 0\)}
    {\(5x \pm 4y = 0\)}
\end{problem}

\begin{problem}

\begin{problem}
在 \(\triangle ABC\) 中，角 \(A\)，\(B\)，\(C\) 所对的边分别为 \(a\)，\(b\)，\(c\)，已知 \(\cos 2C = -\frac{1}{4}\).

\begin{enumerate}
\item 求 \(\sin C\) 的值；
\item 当 \(a = 2\)，\(2 \sin A = \sin C\) 时，求 \(b\) 及 \(c\) 的长.
\end{enumerate}
\end{problem}

\begin{problem}
如图，一个小球从 \(M\) 处投入，通过管道自上而下落到 \(A\) 或 \(B\) 或 \(C\). 已知小球从每个叉口落入左右两个管道的可能性是相等的. 某商家按上述投球方式进行促销活动，若投入的小球落到 \(A\)，\(B\)，\(C\)，则分别设为 1，2，3 等奖.

\begin{enumerate}
\item 已知获得 1，2，3 等奖的折扣率分别为 50\%，70\%，90\%. 记随机变量 \(\xi\) 为获得 \(k\) （\(k = 1\)，\(2\)，\(3\)）等奖的折扣率，求随机变量 \(\xi\) 的分布列及期望 \(E(\xi)\).
\item 若有 3 人次（投入 1 球为 1 人次）参加促销活动，记随机变量 \(\eta\) 为获得 1 等奖或 2 等奖的人次，求 \(P\{\eta = 2\}\).
\end{enumerate}

\bitmapfigure[max width=0.42\linewidth,max totalheight=6.6cm]{img/2010/zhejiang_science/q19_fig1.png}
\end{problem}

\begin{problem}

\begin{problem}
已知 \(a\) 是给定的实常数，设函数 \(f(x) = (x - a)^2 (x + b)\e^x\)，\(b \in \R\)，\(x = a\) 是 \(f(x)\) 的一个极大值点.

\begin{enumerate}
\item 求 \(b\) 的取值范围；
\item 设 \(x_{1}\)，\(x_{2}\)，\(x_{3}\) 是 \(f(x)\) 的 3 个极值点. 问是否存在实数 \(b\)，可找到 \(x_{4} \in \R\)，使得 \(x_{1}\)，\(x_{2}\)，\(x_{3}\)，\(x_{4}\) 的某种排列 \(x_{i_{1}}\)，\(x_{i_{2}}\)，\(x_{i_{3}}\)，\(x_{i_{4}}\)（其中 \(\{i_{1}, i_{2}, i_{3}, i_{4}\} = \{1, 2, 3, 4\}\)）依次成等差数列？若存在，求所有的 \(b\) 及相应的 \(x_4\)；若不存在，说明理由.
\end{enumerate}
\end{problem}
