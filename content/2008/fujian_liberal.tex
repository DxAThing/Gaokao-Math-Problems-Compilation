\begin{problem}

    {\(\{x\mid 1 < x < 3\}\)}

\section{解答题}

\begin{problem}
已知向量 \(m = (\sin A, \cos A)\)，\(n = (1, -2)\)，且 \(m \cdot n = 0\). (1) 求 \( \tan A \) 的值; (2) 求函数 \( f(x) = \cos 2x + 4 \cos A \sin x (x \in \R) \) 的值域.
\end{problem}

\begin{problem}
三人独立碰汉帝同一份密码. 已知三人各自碰出密码的概率分别为 \(\frac{1}{5}, \frac{1}{4}\); \(\frac{1}{3}\)，且他们是否破译出密码互不影响. (1) 求恰有二人破击译密码的概率; (2) 密码破破译与“密码未被破译”的概率哪个大？说明理由.
\end{problem}

\begin{problem}
如图，在四棱锥 \(P - ABCD\) 中，侧面 \(PAD \perp\) 底面 \(ABCD\)，侧棱 \(PA = PD = \sqrt{2}\)，底面 \(ABCD\) 为直角梯形，其中 \(BC // AD\)，\(AB \perp AD\)，\(AD = 2AB = 2BC = 2\)，\(O\) 为 \(AD\) 中点. (1) 求证: \(PO \perp\) 平面 \(ABCD\); (2) 求异面直线 \(PB\) 与 \(CD\) 所成角的余弦值; (3) 求点 A 到平面 PCD 的距离.
\end{problem}

\begin{problem}
已知函数 \( f(x) = x^3 + mx^2 + nx - 2 \) 的图象过点 \((-1, -6)\)，且函数 \( g(x) = f'(x) + 6x \) 的图象关于 \( y \) 轴对称. (1) 求 \(m\)、\(n\) 的值及函数 \(y = f(x)\) 的单调区间； (2) 若 \(a > 0\)，求函数 \(y = f(x)\) 在区间 \((a - 1, a + 1)\) 内的极值.
\end{problem}

\begin{problem}
如图，椭圆 \(C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0)\) 的一个焦点为 \(F(1,0)\)，且过点 \((2,0)\). (1) 求椭圆 C 的方程; (2) 若 \(AB\) 为垂直于 \(x\) 轴的动弦，直线 \(l: x = 4\) 与 \(x\) 轴交于点 \(N\)，直线 \(AP\) 与 \(BN\) 交于点 \(M\). \circled{1} 求证: 点 M 都在椭圆 C 上; \circled{2} 求 \(\triangle AMN\) 面积的最大值.
\end{problem}

\begin{problem}
已知 \(\{a_{n}\}\) 是正数组成的数列，\(a_{1} = 1\)，且点 \((\sqrt{a_{n}}, a_{n+1}) (n \in \mathbf{N}^{*})\) 在函数 \(y = x^{2} + 1\) 的图象上. (1) 求数列 \( \{a_{n}\} \) 的通项公式; (2) 若列数 \( \{b_{n}\} \) 满足 \( b_{1}=1, b_{n+1}=b_{n}+2^{a_{n}} \) ，求证： \( b_{n}\cdot b_{n+2}<b_{n+1}^{2} \)
\end{problem}
