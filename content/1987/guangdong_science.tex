\begin{problem}

在三棱台 \(A_{1}B_{1}C_{1}-ABC\) 中，侧棱 \(B_{1}B \perp\) 底面 \(ABC\)，且 \(\angle ABC = \angle AA_{1}C = \frac{\pi}{2}\)，\(AB = 2A_{1}B_{1} = 2\mathrm{cm}\).

\begin{enumerate}
\item 求证：\(BC \perp A_{1}B\)，\(BC \perp A_{1}A\)，\(A_{1}A \perp A_{1}B\)；
\item 求异面直线 \(A_{1}A\) 和 \(BC\) 的距离.
\end{enumerate}

\bitmapfigure[max width=0.5\linewidth,max totalheight=4.8cm]{img/1987/guangdong_science/q31_fig1.png}

\end{problem}

\begin{solution}
（1）因为 \(B_{1}B \perp\) 底面 \(ABC\)（题设），而 \(BC\subset\) 平面 \(ABC\)，所以 \(B_1B \perp BC\). 又 \(BC \perp AB\)（题设），且 \(AB \cap B_1B = B\)，所以 \(BC \perp\) 平面 \(BB_{1}A_{1}A\)，\(B\) 是垂足. 而 \(A_1B \subset\) 平面 \(BB_1A_1A\)，\(A_1A \subset\) 平面 \(BB_1A_1A\)，所以 \(BC \perp A_1B\)，\(BC \perp A_1A\).

其次，\(AA_1 \perp A_1C\)（题设），\(AA_1 \perp BC\)（已证），且 \(BC \cap A_1C = C\)，所以 \(AA_{1} \perp\) 平面 \(A_{1}BC\). 而 \(A_{1}B \subset\) 平面 \(A_{1}BC\)，所以 \(AA_{1} \perp A_{1}B\).

（2）依设有 \(B_{1}B \perp\) 平面 \(A_{1}B_{1}C_{1}\)，\(B_{1}A_{1} \subset\) 平面 \(A_{1}B_{1}C_{1}\)，所以 \(BB_{1} \perp B_{1}A_{1}\). 又 \(BA_{1} \perp A_{1}A\)（已证），所以 \(\angle BB_{1}A_{1}=\angle BA_{1}A=\frac{\pi}{2}\). 由棱台性质知 \(AB \parallel A_1B_1\)，所以 \(\angle B_1A_1B = \angle A_1BA\). 因此 \(\triangle A_{1}B_{1}B\sim\triangle BA_{1}A\)，从而 \(\frac{A_{1}B_{1}}{A_{1}B}=\frac{A_{1}B}{AB}\).

依设 \(AB = 2A_1B_1 = 2\mathrm{cm}\)，所以 \(A_1B_1 = 1\mathrm{cm}\). 因而 \(A_{1}B^{2}=A_{1}B_{1}\cdot AB=1\cdot2=2\)，\(A_{1}B=\sqrt{2}\mathrm{cm}\). 由（1）已证 \(A_{1}B \perp AA_{1}\)，\(A_{1}B \perp BC\)，且 \(A_{1}B \cap AA_{1} = A_{1}\)，\(A_{1}B \cap BC = B\)，所以 \(A_{1}B\) 是异面直线 \(AA_{1}\) 与 \(BC\) 的公垂线. 因此 \(A_{1}A\) 和 \(BC\) 的距离是 \(\sqrt{2}\mathrm{cm}\).
\end{solution}

\begin{problem}

已知复数 \(z = \cos \alpha + \i \sin \alpha\)，\(u = \cos \beta + \i \sin \beta\)，且 \(z + u = \frac{4}{5} + \frac{3}{5}\i\).

\begin{enumerate}
\item 求 \(\tan(\alpha+\beta)\) 的值；
\item 求证：\(z^{2}+u^{2}+zu=0\).
\end{enumerate}

\end{problem}

\begin{solution}
（1）由设可得 \(z + u = (\cos \alpha + \cos \beta) + (\sin \alpha + \sin \beta)\i = \frac{4}{5}+\frac{3}{5}\i\)，所以 \(\cos\alpha+\cos\beta=\frac{4}{5}\)，\(\sin\alpha+\sin\beta=\frac{3}{5}\). 和差化积得
\[
\begin{aligned}
2\cos\frac{\alpha-\beta}{2}\sin\frac{\alpha+\beta}{2}&=\frac{3}{5},\\
2\cos\frac{\alpha-\beta}{2}\cos\frac{\alpha+\beta}{2}&=\frac{4}{5}.
\end{aligned}
\]
两式相除，得 \(\tan\frac{\alpha+\beta}{2}=\frac{3}{4}\). 所以
\[
\tan(\alpha+\beta)=\frac{2\tan\frac{\alpha+\beta}{2}}{1-\tan^{2}\frac{\alpha+\beta}{2}}=\frac{24}{7}.
\]

（2）因为 \(\left|z + u\right| = \sqrt{\left(\frac{4}{5}\right)^2 + \left(\frac{3}{5}\right)^2} = 1\)，又
\[
z + u = 2 \cos \frac{\alpha - \beta}{2} \left( \cos \frac{\alpha + \beta}{2} + \i \sin \frac{\alpha + \beta}{2} \right),
\]
所以 \(\left|\cos \frac{\alpha - \beta}{2}\right| = \frac{1}{2}\). 又
\[
\begin{aligned}
z^{2}+u^{2}+zu
&=\left[\cos2\alpha+\cos2\beta+\cos\left(\alpha+\beta\right)\right]+\i\left[\sin2\alpha+\sin2\beta+\sin\left(\alpha+\beta\right)\right]\\
&=2\cos\left(\alpha-\beta\right)\cos\left(\alpha+\beta\right)+\cos\left(\alpha+\beta\right)\\
&\quad +\i\left[2\cos\left(\alpha-\beta\right)\sin\left(\alpha+\beta\right)+\sin\left(\alpha+\beta\right)\right]\\
&=\left[2\cos\left(\alpha-\beta\right)+1\right]\left[\cos\left(\alpha+\beta\right)+\i\sin\left(\alpha+\beta\right)\right]\\
&=\left[2\cos\left(\alpha-\beta\right)+1\right]zu.
\end{aligned}
\]
而 \(\cos(\alpha-\beta)=2\cos^{2}\frac{\alpha-\beta}{2}-1=2\left(\frac{1}{2}\right)^{2}-1=-\frac{1}{2}\)，所以 \(2\cos(\alpha-\beta)+1=0\). 故 \(z^{2}+u^{2}+zu=0\).
\end{solution}

\begin{problem}

直线 \(l\) 过抛物线 \(y^{2}=2px\left(p\neq0\right)\) 的焦点，并且与这抛物线相交于 \(A\left(x_{1},y_{1}\right)\) 和 \(B\left(x_{2},y_{2}\right)\) 两点.

\begin{enumerate}
\item 求证：\(4x_{1}x_{2}=p^{2}\)；
\item 求证：对于这抛物线的任何给定的一条弦 \(CD\)，直线 \(l\) 不是 \(CD\) 的垂直平分线.
\end{enumerate}

\end{problem}

\begin{solution}
（1）以 \(p > 0\) 为例，作图如右.

\bitmapfigure[max width=0.42\linewidth,max totalheight=4.8cm]{img/1987/guangdong_science/q33_solution_fig1.png}

抛物线 \(y^{2}=2px\) 的焦点为 \(F\left(\frac{p}{2},0\right)\). 依设 \(F \in l\)，且 \(l\) 与这抛物线有两个交点. 分两种情况讨论：

第一种情况，当 \(l \perp x\) 轴时，\(l\) 的方程为 \(x = \frac{p}{2}\)，故 \(x_1 = x_2 = \frac{p}{2}\)，所以 \(4x_1x_2 = p^2\).

第二种情况，当 \(l\) 不垂直于 \(x\) 轴时，\(l\) 的方程为 \(y = k\left(x - \frac{p}{2}\right)\)，\(k \neq 0\). 代入 \(y^2 = 2px\)，得
\[
x^2 - p\left(1 + \frac{2p}{k^2}\right)x + \frac{p^2}{4} = 0.
\]
\(x_{1}\)、\(x_{2}\) 是这方程的根，由韦达定理得 \(x_{1}x_{2}=\frac{p^{2}}{4}\)，即 \(4x_{1}x_{2}=p^{2}\). 由以上两种情况可知（1）成立。

（2）依题可设 \(C\left(\frac{c^{2}}{2p}, c\right)\)，\(D\left(\frac{d^{2}}{2p}, d\right)\)，且 \(c \neq d\). 记 \(CD\) 的垂直平分线为 \(l'\)，则 \(l'\) 的方程是
\[
\left(y - \frac{c + d}{2}\right)(c - d) + \left(x - \frac{c^{2} + d^{2}}{4p}\right)\left(\frac{c^{2}}{2p} - \frac{d^{2}}{2p}\right) = 0.
\]
因为 \(c - d \neq 0\)，可化方程为
\[
y = \frac{c + d}{8p^{2}} \left(4p^{2} + c^{2} + d^{2}\right) - \frac{c + d}{2p}x.
\]

第一种情况，当 \(F \in l'\) 时，有 \((c+d)(2p^{2}+c^{2}+d^{2})=0\). 而 \(2p^{2} + c^{2} + d^{2} \neq 0\)（因为 \(p \neq 0\)），所以 \(c + d = 0\). 这时，\(l'\) 的方程化为 \(y = 0\). 从而，\(l'\) 与抛物线 \(y^2 = 2px\) 只相交于原点. 而 \(l\) 与此抛物线有两个不同交点，因而 \(l'\) 与 \(l\) 不相重合，\(l\) 不是 \(CD\) 的垂直平分线。

第二种情况，当 \(F \notin l'\) 时，由于 \(l\) 通过 \(F\)，故 \(l\) 与 \(l'\) 也不相重合，\(l\) 不是 \(CD\) 的垂直平分线。

综上所述，（2）得证.
\end{solution}

\begin{problem}

设实数 \(a \neq 0\)，数列 \(\left\{a_n\right\}\) 是首项为 \(a\)，公比为 \(-a\) 的等比数列，记 \(b_n = a_n \lg \left|a_n\right|\)，\(n = 1, 2, \cdots\)；\(S_n = b_1 + b_2 + \cdots + b_n\)，\(n = 1, 2, \cdots\).

\begin{enumerate}
\item 求证：当 \(a \neq -1\) 时，对任意自然数 \(n\)，都有 \(S_{n} = \frac{a \lg |a|}{(1 + a)^{2}} \left[ 1 + (-1)^{n+1} (1 + n + na) a^{n} \right]\)；
\item 请问：当 \(0<a<1\) 时，是否存在自然数 \(M\)，使得对任意自然数 \(n\)，都有 \(b_{n}\leqslant b_{M}\)？证明你的结论.
\end{enumerate}

\end{problem}

\begin{solution}
（1）依设，有 \(a_{n}=a(-a)^{n-1}=(-1)^{n-1}a^{n}\). 所以 \(b_n = a_n \lg |a_n| = (-1)^{n-1}na^n \lg |a|\). 记 \(S_n = b_1 + b_2 + \cdots + b_n\)，则
\[
S_n = \left(a \lg |a| \right) \left[ 1 - 2a + 3a^2 + \cdots + (-1)^{n-1} na^{n-1} \right].
\]
又
\[
(-a) S_n = \left(a \lg |a| \right) \left[ -a + 2a^2 - 3a^3 + \cdots + (-1)^n na^n \right].
\]
两式相减，得
\[
(1 + a) S_n = \left(a \lg |a| \right) \left[ 1 - a + a^2 - a^3 + \cdots + (-1)^{n-1} a^{n-1} - (-1)^n na^n \right].
\]
因为 \(a\neq-1\)，所以
\[
\begin{aligned}
S_{n}
&=\frac{a\lg\left|a\right|}{\left(1+a\right)}\left[\frac{1-\left(-a\right)^{n}}{1-\left(-a\right)}-\left(-1\right)^{n}na^{n}\right]\\
&=\frac{a\lg\left|a\right|}{\left(1+a\right)^{2}}\left[1-\left(-a\right)^{n}-\left(-1\right)^{n}na^{n}\left(1+a\right)\right]\\
&=\frac{a\lg\left|a\right|}{\left(1+a\right)^{2}}\left[1+\left(-1\right)^{n+1}\left(1+n+na\right)a^{n}\right].
\end{aligned}
\]

（2）存在所要求的自然数 \(M\). 证明如下：因为 \(0<a<1\)，所以 \(\lg\left|a\right|=\lg a<0\). 当 \(n\) 是奇数时，\(b_{n}=(-1)^{n-1}na^{n}\lg a<0\)；当 \(n\) 是偶数时，\(b_n = (-1)^{n-1} na^n \lg a > 0\).

设 \(k\) 是自然数。因为 \(1-a^{2} \neq 0\)，所以
\[
\begin{aligned}
b_{2k+2} - b_{2k}
&=-(2k+2)a^{2k+2}\lg a+2ka^{2k}\lg a\\
&=\left(2a^{2k}\lg a\right)\left[-\left(k+1\right)a^{2}+k\right]\\
&=\left(2a^{2k}\lg a\right)\left[\left(1-a^{2}\right)k-a^{2}\right]\\
&=\left(2a^{2k}\lg a\right)\left(1-a^{2}\right)\left(k-\frac{a^{2}}{1-a^{2}}\right).
\end{aligned}
\]
因为 \(2a^{2k}\lg a<0\)，\(1-a^{2}>0\)，所以 \(\left(b_{2k+2}-b_{2k}\right)\) 与 \(\left(k-\frac{a^{2}}{1-a^{2}}\right)\) 有相反的正负符号，或者同为零.

记 \(K\) 是不大于 \(\frac{a^{2}}{1-a^{2}}\) 的最大整数，则当 \(k<K\) 时，\(\left(b_{2k+2}-b_{2k}\right)>0\)；当 \(k=K\) 时，\(\left(b_{2k+2}-b_{2k}\right)\geqslant0\)；当 \(k>K\) 时，\(\left(b_{2k+2}-b_{2k}\right)<0\). 即有 \(b_{2}<b_{4}<\cdots<b_{2K}\leqslant b_{2K+2}\)，\(b_{2K+2}>b_{2K+4}>b_{2K+6}>\cdots\). 而对任何自然数 \(k\)，又有 \(b_{2k-1} < 0 < b_{2K+2}\). 所以，取 \(M = 2K + 2\)，则对任何自然数 \(n\)，都有 \(b_n \leqslant b_M\).
\end{solution}
