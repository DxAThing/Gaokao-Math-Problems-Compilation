\section{单选题}
\begin{problem}
已知集合 \(P = \{x \mid x(x - 1) \geqslant 0\}\)，\(Q = \left\{x \mid \frac{1}{x - 1} > 0\right\}\)，则 \(P \cap Q\) 等于（\quad）

\choices
    {\( \varnothing \)}
    {\(\{x\mid x\geqslant 1\}\)}
    {\( \{x \mid x > 1\} \)}
    {\(\{x\mid x\geqslant 1 \text{\ 或\ } x < 0\}\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
由 \(x(x-1)\geqslant0\)，得 \(P=(-\infty,0]\cup[1,+\infty)\)；又因分式的分子为正，故 \(\dfrac{1}{x-1}>0\) 等价于 \(x>1\)，即 \(Q=(1,+\infty)\). 因此 \(P\cap Q=(1,+\infty)=\{x\mid x>1\}\)，选 C.
\end{solution}

\begin{problem}
函数 \( y = 4\sin \left(2x + \frac{\pi}{3}\right) + 1 \) 的最小正周期为（\quad）

\choices
    {\(\frac{\pi}{2}\)}
    {\(\pi\)}
    {\(2\pi\)}
    {\(4\pi\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
函数的正弦自变量为 \(2x+\dfrac{\pi}{3}\)，其中 \(x\) 的系数为 \(2\). 因此最小正周期为 \(\dfrac{2\pi}{|2|}=\pi\)，选 B.
\end{solution}

\begin{problem}
在各项均不为零的等差数列 \(\{a_{n}\}\) 中，若 \(a_{n + 1} - a_n^2 + a_{n - 1} = 0\)（\(n \geqslant 2\)），则 \(S_{2n - 1} - 4n =\)（\quad）

\choices
    {\(-2\)}
    {\(0\)}
    {\(1\)}
    {\(2\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
设等差数列的公差为 \(d\). 对 \(n\geqslant2\)，有 \(a_{n+1}+a_{n-1}=2a_n\)，代入题设得 \(2a_n-a_n^2=0\)，即 \(a_n(2-a_n)=0\). 由于各项均不为零，故 \(a_n=2\)（\(n\geqslant2\)）. 特别地，\(a_2=a_3=2\)，从而 \(d=0\)，并且 \(a_1=2\). 所以 \(S_{2n-1}=2(2n-1)=4n-2\)，故 \(S_{2n-1}-4n=-2\)，选 A.
\end{solution}

\begin{problem}
下列四个条件中，\(p\) 是 \(q\) 的必要不充分条件的是（\quad）

\choices
    {\(p: a > b\)，\(q: a^2 > b^2\)}
    {\(p: a > b\)，\(q: 2^{a} > 2^{b}\)}
    {\(p: ax^2 + by^2 = c\) 为双曲线，\(q: ab < 0\)}
    {\(p: ax^2 + bx + c > 0\)，\(q: \frac{c}{x^2} + \frac{b}{x} + a > 0\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
选项 A 中，\(a>b\) 不能推出 \(a^2>b^2\)，而 \(a^2>b^2\) 也不能推出 \(a>b\)，故两者均非必要充分关系. 选项 B 中，因 \(2^x\) 在 \(\R\) 上严格递增，\(a>b\) 与 \(2^a>2^b\) 等价. 选项 C 中，方程 \(ax^2+by^2=c\) 为双曲线时必有 \(ab<0\)，所以 \(p\) 是 \(q\) 的充分条件而非必要条件. 对选项 D，在 \(x\ne0\) 时，\(q\) 等价于 \(\dfrac{ax^2+bx+c}{x^2}>0\)，因 \(x^2>0\)，可推出 \(p\)；但 \(p\) 在 \(x=0\) 时可以成立而 \(q\) 无意义，所以 \(p\) 不是 \(q\) 的充分条件. 因此 \(p\) 是 \(q\) 的必要不充分条件，选 D.
\end{solution}

\begin{problem}
对于 \(\R\) 上可导的任意函数 \(f(x)\)，若满足 \((x - 1)f'(x) \geqslant 0\)，则必有（\quad）

\choices
    {\(f(0) + f(2) < 2f(1)\)}
    {\(f(0) + f(2)\leqslant 2f(1)\)}
    {\(f(0) + f(2)\geqslant 2f(1)\)}
    {\(f(0) + f(2) > 2f(1)\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
当 \(x<1\) 时，\(x-1<0\)，由 \((x-1)f'(x)\geqslant0\) 得 \(f'(x)\leqslant0\)，所以 \(f\) 在 \((-\infty,1)\) 上单调递减；当 \(x>1\) 时，得 \(f'(x)\geqslant0\)，所以 \(f\) 在 \((1,+\infty)\) 上单调递增. 因而 \(f(0)\geqslant f(1)\)，\(f(2)\geqslant f(1)\)，两式相加得 \(f(0)+f(2)\geqslant2f(1)\)，选 C.
\end{solution}

\begin{problem}
若不等式 \(x^{2} + ax + 1 \geqslant 0\) 对一切 \(x \in \left(0, \frac{1}{2}\right]\) 成立，则 \(a\) 的最小值为（\quad）

\choices
    {\(0\)}
    {\(-2\)}
    {\(-\frac{5}{2}\)}
    {\(-3\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
因为 \(x>0\)，题设不等式等价于 \(a\geqslant-\left(x+\dfrac1x\right)\) 对 \(x\in\left(0,\dfrac12\right]\) 恒成立. 令 \(g(x)=x+\dfrac1x\)，则 \(g'(x)=1-\dfrac1{x^2}<0\)（\(0<x\leqslant\dfrac12\)），所以 \(g\) 在该区间上递减，最小值为 \(g\left(\dfrac12\right)=\dfrac52\). 因而所有 \(x\) 对应的右端最大值为 \(-\dfrac52\)，即 \(a\geqslant-\dfrac52\). 取 \(a=-\dfrac52\) 时，\(x^2-\dfrac52x+1=(x-\dfrac12)(x-2)\geqslant0\) 在该区间成立，故最小值为 \(-\dfrac52\)，选 C.
\end{solution}

\begin{problem}
在 \(\left(\sqrt{x} + \frac{2}{x}\right)^n\) 的二项展开式中，若常数项为 \(60\)，则 \(n\) 等于（\quad）

\choices
    {\(3\)}
    {\(6\)}
    {\(9\)}
    {\(12\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
展开式的第 \(k+1\) 项为 \(T_{k+1}=\mathrm C_n^k(\sqrt{x})^{n-k}\left(\dfrac2x\right)^k=\mathrm C_n^k2^k x^{(n-3k)/2}\). 常数项要求 \(n-3k=0\)，即 \(n=3k\). 逐一检验选项对应的 \(k\)：当 \(n=3\) 时常数项系数为 \(\mathrm C_3^1\cdot2=6\)；当 \(n=6\) 时系数为 \(\mathrm C_6^2\cdot2^2=60\)；当 \(n=9\) 或 \(12\) 时系数分别为 \(\mathrm C_9^3\cdot2^3=672\) 和 \(\mathrm C_{12}^4\cdot2^4=7920\). 所以 \(n=6\)，选 B.
\end{solution}

\begin{problem}
袋中有 \(40\) 个小球，其中红色球 \(16\) 个，蓝色球 \(12\) 个，白色球 \(8\) 个，黄色球 \(4\) 个，从中随机抽取 \(10\) 个球作成一个样本，则这个样本恰好是按分层抽样方法得到的概率为（\quad）

\choices
    {\(\frac{\mathrm{C}_4^1\mathrm{C}_8^2\mathrm{C}_{12}^3\mathrm{C}_{16}^4}{\mathrm{C}_{40}^{10}}\)}
    {\(\frac{\mathrm{C}_4^2\mathrm{C}_8^1\mathrm{C}_{12}^3\mathrm{C}_{16}^4}{\mathrm{C}_{40}^{10}}\)}
    {\(\frac{\mathrm{C}_4^2\mathrm{C}_8^3\mathrm{C}_{12}^1\mathrm{C}_{16}^4}{\mathrm{C}_{40}^{10}}\)}
    {\(\frac{\mathrm{C}_4^1\mathrm{C}_8^3\mathrm{C}_{12}^4\mathrm{C}_{16}^2}{\mathrm{C}_{40}^{10}}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
按颜色分层时，各层抽取数应与各层总数成比例. 因为 \(10\cdot\dfrac{16}{40}=4\)，\(10\cdot\dfrac{12}{40}=3\)，\(10\cdot\dfrac{8}{40}=2\)，\(10\cdot\dfrac4{40}=1\)，所以符合分层抽样的样本须分别含红球 \(4\) 个、蓝球 \(3\) 个、白球 \(2\) 个、黄球 \(1\) 个. 全部等可能样本数为 \(\mathrm C_{40}^{10}\)，符合条件的样本数为 \(\mathrm C_{16}^4\mathrm C_{12}^3\mathrm C_8^2\mathrm C_4^1\)，故所求概率为 \(\dfrac{\mathrm C_4^1\mathrm C_8^2\mathrm C_{12}^3\mathrm C_{16}^4}{\mathrm C_{40}^{10}}\)，选 A.
\end{solution}

\begin{problem}
如果四棱锥的四条侧棱都相等，就称它为“等腰四棱锥”，四条侧棱称为它的腰. 以下 \(4\) 个命题中，假命题的是（\quad）

\choices
    {等腰四棱锥的腰与底面所成的角都相等}
    {等腰四棱锥的侧面与底面所成的二面角都相等或互补}
    {等腰四棱锥的底面四边形必存在外接圆}
    {等腰四棱锥的各顶点必在同一球面上}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
设四棱锥顶点为 \(S\)，底面为 \(ABCD\)，\(O\) 为 \(S\) 在底面上的射影. 由 \(SA=SB=SC=SD\) 及勾股定理，得 \(OA=OB=OC=OD\)，所以底面四边形存在以 \(O\) 为圆心的外接圆，命题 C 正确. 设侧棱与底面所成角为 \(\alpha\)，则 \(\sin\alpha=SO/SA\)，四条侧棱相等时四个角相等，命题 A 正确. 设底面外接圆半径为 \(R\)，在直线 \(SO\) 上取点 \(T\)，使 \(TS^2=TO^2+R^2\)，则 \(T\) 到 \(S,A,B,C,D\) 的距离相等，故各顶点共球面，命题 D 正确. 但取底面为非正方形矩形、顶点 \(S\) 在底面中心 \(O\) 的正上方时，四条侧棱仍相等，而沿矩形两组不同长度的边所成二面角不同且不互补，命题 B 错误. 因此选 B.
\end{solution}

\begin{problem}
已知等差数列 \(\{a_{n}\}\) 的前 \(n\) 项和为 \(S_{n}\)，若 \(\overrightarrow{OB} = a_{1}\overrightarrow{OA} + a_{200}\overrightarrow{OC}\)，且 \(A\)，\(B\)，\(C\) 三点共线（该直线不过点 \(O\)），则 \(S_{200}\) 等于（\quad）

\choices
    {\(100\)}
    {\(101\)}
    {\(200\)}
    {\(201\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
因 \(A,B,C\) 在不过 \(O\) 的同一直线上，存在实数 \(\lambda\) 使 \(\overrightarrow{OB}=(1-\lambda)\overrightarrow{OA}+\lambda\overrightarrow{OC}\). 比较题设表示式并利用 \(\overrightarrow{OA}\)、\(\overrightarrow{OC}\) 的线性独立性，得 \(a_1=1-\lambda\)，\(a_{200}=\lambda\)，从而 \(a_1+a_{200}=1\). 等差数列前 \(200\) 项和为 \(S_{200}=\dfrac{200(a_1+a_{200})}{2}=100\)，选 A.
\end{solution}

\begin{problem}
\(P\) 为双曲线 \(\frac{x^2}{9} -\frac{y^2}{16} = 1\) 的右支上一点，\(M\)，\(N\) 分别是圆 \((x + 5)^2 +y^2 = 4\) 和 \((x - 5)^2 +y^2 = 1\) 上的点，则 \(|PM| - |PN|\) 的最大值为（\quad）

\choices
    {\(6\)}
    {\(7\)}
    {\(8\)}
    {\(9\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
记双曲线的左、右焦点为 \(F_1=(-5,0)\)、\(F_2=(5,0)\). 对给定的 \(P\)，由三角不等式，圆 \((x+5)^2+y^2=4\) 上的点到 \(P\) 的最大距离为 \(PF_1+2\)；右支顶点为 \((3,0)\)，且 \(PF_2=\dfrac{5x}{3}-3\geqslant2>1\)，故圆 \((x-5)^2+y^2=1\) 上的点到 \(P\) 的最小距离为 \(PF_2-1\). 双曲线定义给出 \(PF_1-PF_2=2\cdot3=6\)，所以
\( |PM|-|PN|\leqslant(PF_1+2)-(PF_2-1)=6+3=9\). 取两个圆上分别实现上述最大、最小距离的点时等号成立，故最大值为 \(9\)，选 D.
\end{solution}

\section{填空题}
\begin{problem}
已知向量 \(\bs{a} = (1, \sin \theta)\)，\(\bs{b} = (1, \cos \theta)\)，则 \(\left|\bs{a} - \bs{b}\right|\) 的最大值为\fillinblank{}.
\end{problem}

\begin{answer}
\(\sqrt{2}\)
\end{answer}

\begin{solution}
由向量坐标直接计算，得 \(\left|\bs{a}-\bs{b}\right|=\sqrt{(1-1)^2+(\sin\theta-\cos\theta)^2}=\left|\sin\theta-\cos\theta\right|\). 又因为 \(\sin\theta-\cos\theta=\sqrt{2}\sin\left(\theta-\frac{\pi}{4}\right)\)，所以 \(\left|\bs{a}-\bs{b}\right|=\sqrt{2}\left|\sin\left(\theta-\frac{\pi}{4}\right)\right|\leq\sqrt{2}\). 当 \(\left|\sin\left(\theta-\frac{\pi}{4}\right)\right|=1\) 时等号成立，故最大值为 \(\sqrt{2}\).
\end{solution}

\begin{problem}
设 \( f(x) = \log_3(x + 6) \) 的反函数为 \( f^{-1}(x) \)，若 \( [f^{-1}(m) + 6]\cdot[f^{-1}(n) + 6] = 27 \)，则 \( f(m + n) = \)\fillinblank{}.
\end{problem}

\begin{answer}
2
\end{answer}

\begin{solution}
由 \(f(x)=\log_3(x+6)\)，令 \(y=\log_3(x+6)\)，则 \(x=3^y-6\)，所以 \(f^{-1}(x)=3^x-6\). 因此 \(f^{-1}(m)+6=3^m\)，\(f^{-1}(n)+6=3^n\)，题设给出 \(3^{m+n}=27=3^3\)，从而 \(m+n=3\). 所以 \(f(m+n)=f(3)=\log_3 9=2\).
\end{solution}

\begin{problem}
已知 \(F_{1}\)，\(F_{2}\) 为双曲线 \(\frac{x^{2}}{a^{2}} - \frac{y^{2}}{b^{2}} = 1\)（\(a > 0\)，\(b > 0\) 且 \(a \neq b\)）的两个焦点. \(P\) 为双曲线右支上异于顶点的任意一点，点 \(O\) 为坐标原点. 下面四个命题：

\begin{circlelist}
\item \(\triangle PF_{1}F_{2}\) 的内切圆的圆心必在直线 \(x = a\) 上；
\item \(\triangle PF_{1}F_{2}\) 的内切圆的圆心必在直线 \(x = b\) 上；
\item \(\triangle PF_{1}F_{2}\) 的内切圆的圆心必在直线 \(OP\) 上；
\item \(\triangle PF_{1}F_{2}\) 的内切圆必通过点 \((a, 0)\).
\end{circlelist}

其中真命题的代号是\fillinblank{}. （写出所有真命题的代号）
\end{problem}

\begin{answer}
A，D
\end{answer}

\begin{solution}
令 \(c=\sqrt{a^2+b^2}\)，取 \(F_1=(-c,0)\)、\(F_2=(c,0)\)，并设 \(P=(x,y)\). 由于 \(P\) 在右支上，\(x\geqslant a\)，且 \(y^2=\dfrac{b^2}{a^2}(x^2-a^2)\). 于是 \(PF_1^2=(x+c)^2+y^2=\left(\dfrac{cx}{a}+a\right)^2\)，\(PF_2^2=(x-c)^2+y^2=\left(\dfrac{cx}{a}-a\right)^2\)，从而 \(PF_1=\dfrac{cx}{a}+a\)，\(PF_2=\dfrac{cx}{a}-a\).

设 \(d_1=PF_1\)，\(d_2=PF_2\)，三角形 \(PF_1F_2\) 的内心为 \(I\). 按三角形内心的重心坐标公式，\(\overrightarrow{OI}=\dfrac{d_2\overrightarrow{OF_1}+d_1\overrightarrow{OF_2}+2c\overrightarrow{OP}}{d_1+d_2+2c}\). 因而 \(I\) 的坐标满足 \(x_I=\dfrac{-cd_2+cd_1+2cx}{d_1+d_2+2c}\)，\(y_I=\dfrac{2cy}{d_1+d_2+2c}\). 利用 \(d_1-d_2=2a\) 和 \(d_1+d_2=\dfrac{2cx}{a}\)，得 \(I=\left(a,\dfrac{ay}{x+a}\right)\).

所以内心必在直线 \(x=a\) 上，第一个命题为真；因 \(a\ne b\)，它不在直线 \(x=b\) 上，第二个命题为假. 又因 \(P\) 异于顶点，\(y\ne0\)，若 \(I\) 在直线 \(OP\) 上，则应有 \(\dfrac{y}{x+a}=\dfrac{y}{x}\)，这将推出 \(x=x+a\)，矛盾，第三个命题为假. 最后，内切圆与 \(F_1F_2\)（即 \(x\) 轴）相切，内切圆半径等于 \(I\) 到 \(x\) 轴的距离 \(\left|\dfrac{ay}{x+a}\right|\)，而点 \((a,0)\) 到 \(I\) 的距离正好相等，所以内切圆必通过 \((a,0)\)，第四个命题为真. 故选 AD.
\end{solution}

\section{解答题}
\begin{problem}
已知函数 \( f(x) = x^3 + ax^2 + bx + c \) 在 \( x = -\frac{2}{3} \) 与 \( x = 1 \) 时都取得极值.
\begin{enumerate}
\item 求 \(a\)，\(b\) 的值与函数 \( f(x) \) 的单调区间；
\item 若对 \(x \in [-1, 2]\)，不等式 \(f(x) < c^2\) 恒成立，求 \(c\) 的取值范围.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 由 \(f\) 在 \(x=-\dfrac{2}{3}\) 和 \(x=1\) 处取得极值，得 \(f'(x)=3x^2+2ax+b\) 的两个根为 \(-\dfrac{2}{3}\) 和 \(1\). 因而 \(f'(x)=3\left(x+\frac{2}{3}\right)(x-1)=3x^2-x-2\). 比较系数，得 \(a=-\frac{1}{2}\)，\(b=-2\). 当 \(x<-\dfrac{2}{3}\) 或 \(x>1\) 时，\(f'(x)>0\)；当 \(-\dfrac{2}{3}<x<1\) 时，\(f'(x)<0\). 所以 \(f(x)\) 的单调递增区间为 \(\left(-\infty,-\dfrac{2}{3}\right)\) 和 \((1,+\infty)\)，单调递减区间为 \(\left(-\dfrac{2}{3},1\right)\).
\item 由上面的单调性，\(f(x)\) 在 \([-1,2]\) 上的最大值只能在 \(-1\)，\(-\dfrac{2}{3}\)，\(1\)，\(2\) 中取得. 令 \(h(x)=x^3-\frac{1}{2}x^2-2x\)，则 \(f(x)=h(x)+c\). 逐点计算得 \(h(-1)=\frac{1}{2}\)，\(h\left(-\frac{2}{3}\right)=\frac{22}{27}\)，\(h(1)=-\frac{3}{2}\)，\(h(2)=2\)，所以 \(\max_{x\in[-1,2]}f(x)=f(2)=c+2\). 题设的严格不等式对区间内一切 \(x\) 成立，当且仅当 \(c+2<c^2\)，即 \((c-2)(c+1)>0\). 所以 \(c\) 的取值范围为 \(c\in(-\infty,-1)\cup(2,+\infty)\).
\end{enumerate}
\end{solution}

\begin{problem}
某商场举行抽奖促销互动，抽奖规则是：从装有\(9\)个白球，\(1\)个红球的箱子中每次随机地摸出一个球，记下颜色后放回，摸出一个红球可获得二等奖；摸出两个红球可获得一等奖. 现有甲，乙两位顾客，规定：甲摸一次，乙摸两次. 求：
\begin{enumerate}
\item 甲，乙两人都没有中奖的概率；
\item 甲，乙两人中至少有一人获二等奖的概率.
\end{enumerate}
\end{problem}

\begin{solution}
设一次摸到红球和白球的概率分别为 \(p=\frac{1}{10}\)，\(q=\frac{9}{10}\). 由于每次摸出后都放回，各次摸球相互独立.

\begin{enumerate}
\item 甲没有中奖，必须一次摸到白球；乙没有中奖，必须两次都摸到白球. 因此，甲、乙两人都没有中奖的概率为 \(q\cdot q^2=q^3=\left(\frac{9}{10}\right)^3=\frac{729}{1000}\).

\item 设事件 \(A\) 为甲获二等奖，事件 \(B\) 为乙获二等奖. 则 \(P(A)=p\)，因为甲只摸一次；乙恰好摸到一个红球时获二等奖，所以 \(P(B)=2pq\). 事件 \(A\cap B\) 的概率为 \(p\cdot2pq\). 因此，至少有一人获二等奖的概率为 \(P(A\cup B)=P(A)+P(B)-P(A\cap B)=p+2pq-2p^2q=\frac{1}{10}+2\cdot\frac{1}{10}\cdot\frac{9}{10}-2\cdot\left(\frac{1}{10}\right)^2\cdot\frac{9}{10}=\frac{131}{500}\).
\end{enumerate}
\end{solution}

\begin{enumerate}

\begin{solution}
\begin{enumerate}
\item 因为 \(A\) 为锐角，所以 \(\cos A=\sqrt{1-\sin^2 A}=\sqrt{1-\frac{8}{9}}=\frac{1}{3}\). 由 \(B+C=\pi-A\)，有 \(\tan\frac{B+C}{2}=\tan\left(\frac{\pi}{2}-\frac{A}{2}\right)=\cot\frac{A}{2}\). 又 \(\sin^2\frac{A}{2}=\frac{1-\cos A}{2}=\frac{1}{3}\)，\(\cot^2\frac{A}{2}=\frac{1-\sin^2(A/2)}{\sin^2(A/2)}=2\). 因此 \(\tan^2\frac{B+C}{2}+\sin^2\frac{A}{2}=2+\frac{1}{3}=\frac{7}{3}\).

\end{solution}

\begin{solution}
建立空间直角坐标系，取 \(O=(0,0,0)\)，\(A=(1,0,0)\)，\(B=(0,2,0)\)，\(C=(0,0,2)\). 因为 \(E\) 是 \(OC\) 的中点，所以 \(E=(0,0,1)\).

\begin{problem}
如图，椭圆 \(Q: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)）的右焦点为 \(F(c, 0)\)，过点 \(F\) 的一动直线 \(m\) 绕点 \(F\) 转动，并且交椭圆于 \(A\)，\(B\) 两点，\(P\) 为线段 \(AB\) 的中点.

\begin{enumerate}
\item 求点 \(P\) 的轨迹 \(H\) 的方程；
\item 在 \(Q\) 的方程中，令 \(a^2 = 1 + \cos \theta + \sin \theta\)，\(b^2 = \sin \theta\)（\(0 < \theta \leqslant \frac{\pi}{2}\)），设轨迹 \(H\) 的最高点和最低点分别为 \(M\) 和 \(N\). 当 \(\theta\) 为何值时，\(\triangle MNF\) 为一个正三角形？
\end{enumerate}

\bitmapfigure[max width=0.50\linewidth]{img/2006/jiangxi_liberal/q21_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 先考虑斜率存在的直线 \(m\)，设其斜率为 \(k\)，则 \(y=k(x-c)\). 将它代入椭圆方程，得 \(\frac{x^2}{a^2}+\frac{k^2(x-c)^2}{b^2}=1\). 化为关于 \(x\) 的二次方程后，设两个交点的横坐标为 \(x_1\)，\(x_2\)，由韦达定理得 \(x_1+x_2=\frac{2a^2k^2c}{b^2+a^2k^2}\)，所以点 \(P\) 的横坐标为 \(x_P=\frac{a^2k^2c}{b^2+a^2k^2}\). 再由 \(y_P=k(x_P-c)\)，得 \(y_P=-\frac{b^2kc}{b^2+a^2k^2}\). 于是 \(\frac{x_P}{c-x_P}=\frac{a^2k^2}{b^2}\)，且 \(k=-\frac{y_P}{c-x_P}\). 消去 \(k\)，得到 \(a^2y_P^2=b^2x_P(c-x_P)\)，整理为 \(b^2\left(x_P-\frac{c}{2}\right)^2+a^2y_P^2=\frac{b^2c^2}{4}\). 竖直直线 \(x=c\) 经过焦点时，其中点为 \((c,0)\)，也满足上式，因此点 \(P\) 的轨迹 \(H\) 的方程为 \(b^2\left(x-\frac{c}{2}\right)^2+a^2y^2=\frac{b^2c^2}{4}\).
\item 由题设，\(c^2=a^2-b^2=1+\cos\theta\). 由轨迹方程可知，\(H\) 的最高点和最低点分别为 \(M\left(\frac{c}{2},\frac{bc}{2a}\right)\)，\(N\left(\frac{c}{2},-\frac{bc}{2a}\right)\). 故 \(MN=\frac{bc}{a}\)，且 \(FM^2=FN^2=\left(\frac{c}{2}\right)^2+\left(\frac{bc}{2a}\right)^2=\frac{c^2(a^2+b^2)}{4a^2}\). 三角形 \(MNF\) 为正三角形，当且仅当 \(FM=MN\). 两边平方并利用正数条件，得 \(\frac{c^2(a^2+b^2)}{4a^2}=\frac{b^2c^2}{a^2}\)，即 \(a^2=3b^2\). 代入题设中的 \(a^2,b^2\)，得 \(1+\cos\theta+\sin\theta=3\sin\theta\)，即 \(1+\cos\theta=2\sin\theta\). 由于 \(0<\theta\leq\dfrac{\pi}{2}\)，令 \(s=\sin\theta\)，则 \(\cos\theta=2s-1\). 联立 \(s^2+\cos^2\theta=1\)，得 \(s^2+(2s-1)^2=1\)，即 \(5s^2-4s=0\). 因 \(s>0\)，所以 \(s=\dfrac45\)，进而 \(\cos\theta=\dfrac35\). 因此 \(\theta=\arctan\frac{4}{3}\).
\end{enumerate}
\end{solution}

\begin{problem}
已知各项均为正数的数列 \(\{a_{n}\}\) 满足：\(a_{1} = 3\)，且 \(\frac{2a_{n+1} - a_{n}}{2a_{n} - a_{n+1}} = a_{n}a_{n+1}\)，\(n \in \N^{*}\).
\begin{enumerate}
\item 求数列 \( \{a_{n}\} \) 的通项公式；
\item 设 \(S_{n} = a_{1}^{2} + a_{2}^{2} + \cdots + a_{n}^{2}\)，\(T_{n} = \frac{1}{a_{1}^{2}} + \frac{1}{a_{2}^{2}} + \cdots + \frac{1}{a_{n}^{2}}\)，求 \(S_{n} + T_{n}\)，并确定最小正整数 \(n\)，使 \(S_{n} + T_{n}\) 为整数.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 由题设分母不为零. 将递推关系交叉相乘，得 \(2a_{n+1}-a_n=a_na_{n+1}(2a_n-a_{n+1})\). 由于各项均为正数，除以 \(a_na_{n+1}\)，得 \(\frac{2}{a_n}-\frac{1}{a_{n+1}}=2a_n-a_{n+1}\)，即 \(a_{n+1}-\frac{1}{a_{n+1}}=2\left(a_n-\frac{1}{a_n}\right)\). 令 \(b_n=a_n-\frac{1}{a_n}\)，则 \(b_{n+1}=2b_n\). 又 \(b_1=3-\frac13=\frac83\)，所以 \(b_n=\frac83\cdot2^{n-1}=\frac{2^{n+2}}{3}\). 于是 \(a_n\) 是方程 \(a_n-\frac{1}{a_n}=\frac{2^{n+2}}{3}\) 的正根，即 \(a_n^2-\frac{2^{n+2}}{3}a_n-1=0\). 解得 \(a_n=\frac{\dfrac{2^{n+2}}{3}+\sqrt{\dfrac{2^{2n+4}}{9}+4}}{2}=\frac{2^{n+1}+\sqrt{2^{2n+2}+9}}{3}\).
\item 由 \(b_n=a_n-a_n^{-1}\)，有 \(b_n^2=a_n^2+\frac{1}{a_n^2}-2\). 因此 \(a_n^2+\frac{1}{a_n^2}=b_n^2+2=\frac{2^{2n+4}}{9}+2\). 从而 \(S_n+T_n=\sum_{k=1}^{n}\left(\frac{2^{2k+4}}{9}+2\right)=2n+\frac{16}{9}\sum_{k=1}^{n}4^k\). 利用等比数列求和公式，得 \(S_n+T_n=2n+\frac{16}{9}\cdot\frac{4(4^n-1)}{3}=2n+\frac{64(4^n-1)}{27}\). 因为 \(\gcd(64,27)=1\)，且 \(54n\) 总能被 \(27\) 整除，所以 \(S_n+T_n\) 为整数当且仅当 \(4^n\equiv1\pmod{27}\). 计算得 \(4^3=64\equiv10\pmod{27}\)，从而 \(4^9\equiv10^3\equiv1\pmod{27}\). 又 \(4\not\equiv1\pmod{27}\)，\(4^3\not\equiv1\pmod{27}\)，故 \(4\) 模 \(27\) 的乘法阶为 \(9\). 所以满足条件的最小正整数为 \(n=9\).
\end{enumerate}
\end{solution}
