\section{单选题}
\begin{problem}
已知集合 \(U = \{1, 2, 3, 4, 5, 6, 7\}\)，\(A = \{2, 4, 5, 7\}\)，\(B = \{3, 4, 5\}\)，则 \(\left(\complement_U A\right) \cup \left(\complement_U B\right) =\)（\quad）

\choices
    {\(\{1,6\}\)}
    {\(\{4,5\}\)}
    {\(\{2,3,4,5,7\}\)}
    {\(\{1,2,3,6,7\}\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
由全集分别取补集，得 \(\complement_U A=\{1,3,6\}\)，\(\complement_U B=\{1,2,6,7\}\)，所以 \(\left(\complement_U A\right)\cup\left(\complement_U B\right)=\{1,2,3,6,7\}\)，故选 D.
\end{solution}

\begin{problem}
在等差数列 \(\{a_{n}\}\) 中，若 \(a_{4} + a_{6} = 12\)，\(S_{n}\) 是数列 \(\{a_{n}\}\) 的前 \(n\) 项和，则 \(S_{9}\) 的值为（\quad）

\choices
    {\(48\)}
    {\(54\)}
    {\(60\)}
    {\(66\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
等差数列中，\(a_{4}+a_{6}=2a_{5}\)，所以 \(a_{5}=6\). 又因为 \(a_{1}+a_{9}=a_{2}+a_{8}=\cdots=a_{4}+a_{6}=2a_{5}\)，故 \(S_{9}=9a_{5}=54\)，所以选 B.
\end{solution}

\begin{problem}
过坐标原点且与圆 \(x^{2} + y^{2} - 4x + 2y + \frac{5}{2} = 0\) 相切的直线的方程为（\quad）

\choices
    {\(y = -3x\) 或 \(y = \frac{1}{3} x\)}
    {\(y = 3x\) 或 \(y = -\frac{1}{3} x\)}
    {\(y = -3x\) 或 \(y = -\frac{1}{3} x\)}
    {\(y = 3x\) 或 \(y = \frac{1}{3} x\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
圆的方程可化为 \(\left(x-2\right)^{2}+\left(y+1\right)^{2}=\frac{5}{2}\)，圆心为 \(O=(2,-1)\)，半径为 \(\sqrt{\frac{5}{2}}\). 设过原点的非竖直直线为 \(y=kx\)，则圆心到该直线的距离为 \(\frac{|2k+1|}{\sqrt{k^{2}+1}}\). 令此距离等于半径，得 \(2(2k+1)^{2}=5(k^{2}+1)\)，即 \(3k^{2}+8k-3=0\)，所以 \(k=-3\) 或 \(k=\frac{1}{3}\). 竖直直线 \(x=0\) 到圆心的距离为 \(2\)，也不等于半径，故切线为 \(y=-3x\) 或 \(y=\frac{1}{3}x\)，选 A.
\end{solution}

\begin{problem}
对于任意的直线 \(l\) 与平面 \(\alpha\)，在平面 \(\alpha\) 内必有直线 \(m\)，使 \(m\) 与 \(l\)（\quad）

\choices
    {平行}
    {相交}
    {垂直}
    {互为异面直线}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
若 \(l\subset\alpha\)，在 \(l\) 上任取一点，在平面 \(\alpha\) 内过该点作与 \(l\) 垂直的直线即可. 若 \(l\) 与 \(\alpha\) 相交且 \(l\perp\alpha\)，则在交点处任取平面 \(\alpha\) 内的一条直线 \(m\)，都有 \(m\perp l\). 若 \(l\) 与 \(\alpha\) 相交但不垂直，设 \(l\) 在 \(\alpha\) 内的射影为 \(l'\)，则过交点在 \(\alpha\) 内作 \(m\perp l'\)，由直线与平面垂直的分解关系得 \(m\perp l\). 若 \(l\parallel\alpha\)，则在 \(\alpha\) 内作一条与 \(l\) 方向垂直的直线即可. 所以总能在 \(\alpha\) 内找到与 \(l\) 垂直的直线，故选 C.
\end{solution}

\begin{problem}
若 \(\left(3\sqrt{x} - \frac{1}{\sqrt{x}}\right)^{n}\) 的展开式中各项系数之和为 64，则展开式的常数项为（\quad）

\choices
    {\(-540\)}
    {\(-162\)}
    {\(162\)}
    {\(540\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
由于根式有意义，\(x>0\). 将展开式各项的系数相加，令 \(x=1\)，得 \(\left(3-1\right)^{n}=2^{n}=64\)，所以 \(n=6\). 展开式的通项中，若取 \(r\) 个因子 \(-\frac{1}{\sqrt{x}}\)，则该项为 \(\mathrm C_{6}^{r}3^{6-r}(-1)^{r}x^{3-r}\). 常数项对应 \(3-r=0\)，即 \(r=3\)，其系数为 \(\mathrm C_{6}^{3}3^{3}(-1)^{3}=-540\)，故选 A.
\end{solution}

为了了解某地区高三学生的身体发育情况，抽查了该地区 \(100\) 名年龄为 \(17.5\) 岁至 \(18\) 岁的男生体重（\(\mathrm{kg}\)），得到频率分布直方图如下：

根据上图可得这 \(100\) 名学生中体重在 \([56.5, 64.5)\) 的学生人数是（\quad）

\choices
    {\(20\)}

\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
由直方图可读出区间 \([56.5,58.5)\)、\([58.5,60.5)\)、\([60.5,62.5)\)、\([62.5,64.5)\) 的组距均为 \(2\)，相应的频率分布直方图高度分别为 \(0.03\)、\(0.05\)、\(0.05\)、\(0.07\). 所以体重在 \([56.5,64.5)\) 内的频率为 \(2\left(0.03+0.05+0.05+0.07\right)=0.4\). 抽查人数为 \(100\)，故人数为 \(100\times0.4=40\)，选 C.

\begin{problem}
与向量 \(\bs{a} = \left(\frac{7}{2},\frac{1}{2}\right)\)，\(\bs{b} = \left(\frac{1}{2}, - \frac{7}{2}\right)\) 的夹角相等，且模为1的向量是（\quad）

\choices
    {\( \left(\frac{4}{5},-\frac{3}{5}\right) \)}
    {\(\left(\frac{4}{5}, -\frac{3}{5}\right)\) 或 \(\left(-\frac{4}{5}, \frac{3}{5}\right)\)}
    {\( \left(\frac{2\sqrt{2}}{3},-\frac{1}{3}\right) \)}
    {\(\left(\frac{2\sqrt{2}}{3}, -\frac{1}{3}\right)\) 或 \(\left(-\frac{2\sqrt{2}}{3}, \frac{1}{3}\right)\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
设所求向量为 \(\bs v=(x,y)\). 因为 \(|\bs a|=|\bs b|=\frac{5\sqrt{2}}{2}\)，且 \(|\bs v|=1\)，两夹角相等等价于 \(\bs v\cdot\bs a=\bs v\cdot\bs b\). 因而 \(\frac{7}{2}x+\frac{1}{2}y=\frac{1}{2}x-\frac{7}{2}y\)，即 \(3x+4y=0\). 再由 \(x^{2}+y^{2}=1\)，得 \((x,y)=\left(\frac45,-\frac35\right)\) 或 \(\left(-\frac45,\frac35\right)\)，故选 B.
\end{solution}

\begin{problem}
将 \(5\) 名实习教师分配到高一年级的 \(3\) 个班实习，每班至少 \(1\) 名，最多 \(2\) 名，则不同的分配方案有（\quad）

\choices
    {\(30\text{ 种}\)}
    {\(90\text{ 种}\)}
    {\(180\text{ 种}\)}
    {\(270\text{ 种}\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
每班至少 \(1\) 名、最多 \(2\) 名，而共有 \(5\) 名教师，所以三个班的人数必为 \(1\)，\(2\)，\(2\). 先选出人数为 \(1\) 的班，有 \(3\) 种选法；再从 \(5\) 名教师中选出该班的教师，有 \(5\) 种选法；从余下 \(4\) 名教师中选出一个人数为 \(2\) 的班，有 \(\mathrm C_{4}^{2}=6\) 种选法，最后两名教师进入另一个班. 因而分配方案共有 \(3\times5\times6=90\) 种，选 B.
\end{solution}

如图所示，单位圆中弧 \(\widehat{AB}\) 的长为 \(x\)，\(f(x)\) 表示弧 \(\widehat{AB}\) 与弦 \(AB\) 所围成的弓形面积的 2 倍，则函数 \(y = f(x)\) 的图象是（\quad）

\choices
    {\choicebitmap[width=0.15\paperwidth]{img/2006/chongqing_science/q9_optA.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2006/chongqing_science/q9_optB.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2006/chongqing_science/q9_optC.png}}

设弧 \(\widehat{AB}\) 所对的圆心角为 \(x\)，因为圆的半径为 \(1\)，所以扇形面积为 \(\frac{x}{2}\). 当 \(0\leqslant x\leqslant\pi\) 时，三角形 \(AOB\) 的面积为 \(\frac{\sin x}{2}\)；当 \(\pi\leqslant x\leqslant2\pi\) 时，弓形面积为大扇形面积加上 \(-\frac{\sin x}{2}\)，两种情形统一得到 \(f(x)=x-\sin x\)，其中 \(0\leqslant x\leqslant2\pi\). 于是 \(f'(x)=1-\cos x\geqslant0\)，且 \(f''(x)=\sin x\)，所以曲线在 \((0,\pi)\) 上向上弯曲，在 \((\pi,2\pi)\) 上向下弯曲，并经过 \((0,0)\)、\((\pi,\pi)\)、\((2\pi,2\pi)\). 这与图 D 相符，故选 D.
\end{solution}

\begin{problem}
若 \(a\)，\(b\)，\(c > 0\) 且 \(a(a + b + c) + bc = 4 - 2\sqrt{3}\)，则 \(2a + b + c\) 的最小值为（\quad）

\choices
    {\(\sqrt{3} - 1\)}
    {\(\sqrt{3} + 1\)}
    {\(2 \sqrt{3} + 2\)}
    {\(2 \sqrt{3} - 2\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
由条件得 \(a^{2}+ab+ac+bc=4-2\sqrt3\)，即 \((a+b)(a+c)=(\sqrt3-1)^{2}\). 因为 \(a+b>0\)、\(a+c>0\)，由均值不等式得 \(2a+b+c=(a+b)+(a+c)\geqslant2\sqrt{(a+b)(a+c)}=2\sqrt3-2\). 当 \(a+b=a+c=\sqrt3-1\)，即取任意 \(0<a<\sqrt3-1\) 且 \(b=c=\sqrt3-1-a\) 时等号成立，所以最小值为 \(2\sqrt3-2\)，选 D.
\end{solution}

\section{填空题}
\begin{problem}
复数 \(\frac{1 + 2\i}{3 + \i^3}\) 的值是\fillinblank{}.
\end{problem}

\begin{answer}
\(\frac{1}{10} + \frac{7}{10}\i\)
\end{answer}

\begin{solution}
因为 \(\i^{3}=-\i\)，所以 \(\frac{1+2\i}{3+\i^{3}}=\frac{1+2\i}{3-\i}=\frac{(1+2\i)(3+\i)}{(3-\i)(3+\i)}=\frac{1+7\i}{10}=\frac{1}{10}+\frac{7}{10}\i\).
\end{solution}

\begin{problem}
\(\displaystyle\lim_{n\to \infty}\frac{1 + 3 + \cdots + (2n - 1)}{2n^2 - n + 1} =\)\fillinblank{}.
\end{problem}

\begin{answer}
\(\frac{1}{2}\)
\end{answer}

\begin{solution}
前 \(n\) 个奇数的和为 \(n^{2}\)，因此 \(\displaystyle\lim_{n\to\infty}\frac{1+3+\cdots+(2n-1)}{2n^{2}-n+1}=\lim_{n\to\infty}\frac{n^{2}}{2n^{2}-n+1}=\lim_{n\to\infty}\frac{1}{2-\frac1n+\frac1{n^{2}}}=\frac12\).
\end{solution}

\begin{problem}
已知 \(\alpha\)，\(\beta \in \left(\frac{3\pi}{4}, \pi\right)\)，\(\sin (\alpha + \beta) = -\frac{3}{5}\)，\(\sin \left(\beta - \frac{\pi}{4}\right) = \frac{12}{13}\)，则 \(\cos \left(\alpha + \frac{\pi}{4}\right) =\)\fillinblank{}.
\end{problem}

\begin{answer}
\(-\frac{56}{65}\)
\end{answer}

\begin{solution}
由 \(\alpha\)，\(\beta\in\left(\frac{3\pi}{4},\pi\right)\)，得 \(\alpha+\beta\in\left(\frac{3\pi}{2},2\pi\right)\)，所以 \(\cos(\alpha+\beta)=\frac45\). 又 \(\beta-\frac\pi4\in\left(\frac\pi2,\frac{3\pi}{4}\right)\)，所以 \(\cos\left(\beta-\frac\pi4\right)=-\frac5{13}\). 注意到 \(\alpha+\frac\pi4=(\alpha+\beta)-\left(\beta-\frac\pi4\right)\)，故 \(\cos\left(\alpha+\frac\pi4\right)=\cos(\alpha+\beta)\cos\left(\beta-\frac\pi4\right)+\sin(\alpha+\beta)\sin\left(\beta-\frac\pi4\right)=-\frac4{13}-\frac{36}{65}=-\frac{56}{65}\).
\end{solution}

\begin{problem}
在数列 \(\{a_{n}\}\) 中，若 \(a_{1} = 1\)，\(a_{n+1} = 2a_{n} + 3\)（\(n \geqslant 1\)），则该数列的通项 \(a_{n} =\)\fillinblank{}.
\end{problem}

\begin{answer}
\(2^{n+1} - 3\)
\end{answer}

\begin{solution}
在递推式两边加上 \(3\)，得 \(a_{n+1}+3=2(a_n+3)\). 令 \(b_n=a_n+3\)，则 \(\{b_n\}\) 是首项 \(b_1=4\)、公比为 \(2\) 的等比数列，所以 \(b_n=4\cdot2^{n-1}=2^{n+1}\). 因而 \(a_n=2^{n+1}-3\). 代入 \(n=1\) 可得 \(a_1=1\)，与题设相符.
\end{solution}

\begin{problem}
设 \(a > 0\)，\(a \neq 1\)，函数 \(f(x) = a^{\lg(x^{2} - 2x + 3)}\) 有最大值，则不等式 \(\log_a(x^{2} - 5x + 7) > 0\) 的解集为\fillinblank{}.
\end{problem}

\begin{answer}
\((2,3)\)
\end{answer}

\begin{solution}
因为 \(x^{2}-2x+3=(x-1)^{2}+2\geqslant2\). 若 \(a>1\)，则 \(a^{\lg((x-1)^{2}+2)}\) 随 \((x-1)^{2}+2\) 增大而无上界，不可能有最大值；故题设只能是 \(0<a<1\). 当 \(0<a<1\) 时，\(\log_a t>0\) 等价于 \(0<t<1\)，所以 \(0<x^{2}-5x+7<1\). 其中 \(x^{2}-5x+7=(x-\frac52)^{2}+\frac34>0\)，故只需解 \(x^{2}-5x+6<0\)，即 \((x-2)(x-3)<0\). 所以解集为 \((2,3)\).
\end{solution}

\begin{problem}
已知变量 \(x\)，\(y\) 满足约束条件 \(1 \leqslant x + y \leqslant 4\)，\(-2 \leqslant x - y \leqslant 2\). 若目标函数 \(z = ax + y\)（其中 \(a > 0\)）仅在点 \((3,1)\) 处取得最大值，则 \(a\) 的取值范围为\fillinblank{}.
\end{problem}

\begin{answer}
\(a>1\)
\end{answer}

\begin{solution}
令 \(u=x+y\)、\(v=x-y\)，则可行域为矩形 \(1\leqslant u\leqslant4\)、\(-2\leqslant v\leqslant2\)，且 \(x=\frac{u+v}{2}\)、\(y=\frac{u-v}{2}\). 目标函数化为 \(z=ax+y=\frac{(a+1)u+(a-1)v}{2}\). 因为 \(a>0\)，关于 \(u\) 的系数为正，最大值必须在 \(u=4\) 处取得；要使最大值只在 \((3,1)\) 处取得，还需且只需关于 \(v\) 的系数为正，即 \(a-1>0\). 此时唯一的顶点为 \((u,v)=(4,2)\)，对应 \((x,y)=(3,1)\). 若 \(a=1\)，则整条 \(u=4\) 的边都取得最大值；若 \(0<a<1\)，最大值在 \(v=-2\) 处取得，均不符合题意. 所以 \(a>1\).
\end{solution}

\section{解答题}
\begin{problem}
设函数 \(f(x) = \sqrt{3} \cos^2 \omega x + \sin \omega x \cos \omega x + a\)（其中 \(\omega > 0\)，\(a \in \R\)），且 \(f(x)\) 的图象在 \(y\) 轴右侧的第一个最高点的横坐标为 \(\frac{\pi}{6}\).
\begin{enumerate}
\item 求 \(\omega\) 的值；
\item 如果 \(f(x)\) 在区间 \(\left[-\frac{\pi}{3}, \frac{5\pi}{6}\right]\) 上的最小值为 \(\sqrt{3}\)，求 \(a\) 的值.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 由二倍角公式，\(\sqrt3\cos^{2}\omega x+\sin\omega x\cos\omega x=\frac{\sqrt3}{2}+\frac{\sqrt3}{2}\cos2\omega x+\frac12\sin2\omega x=\frac{\sqrt3}{2}+\cos\left(2\omega x-\frac\pi6\right)\). 因而 \(f(x)=a+\frac{\sqrt3}{2}+\cos\left(2\omega x-\frac\pi6\right)\). 最高点满足 \(2\omega x-\frac\pi6=2k\pi\). 当 \(k\leqslant-1\) 时横坐标为负，故右侧第一个最高点对应 \(k=0\)，于是 \(\frac{\pi}{12\omega}=\frac\pi6\)，解得 \(\omega=\frac12\).
\item 由上问，\(f(x)=a+\frac{\sqrt3}{2}+\cos\left(x-\frac\pi6\right)\). 当 \(x\in\left[-\frac\pi3,\frac{5\pi}{6}\right]\) 时，\(x-\frac\pi6\in\left[-\frac\pi2,\frac{2\pi}{3}\right]\)，故余弦函数在该区间上的最小值为 \(-\frac12\). 因此 \(f(x)\) 的最小值为 \(a+\frac{\sqrt3}{2}-\frac12\)，由题意得 \(a+\frac{\sqrt3}{2}-\frac12=\sqrt3\)，所以 \(a=\frac{\sqrt3+1}{2}\).
\end{enumerate}
\end{solution}

某大厦的一部电梯从底层出发后只能在第 \(18\)，\(19\)，\(20\) 层可以停靠. 若该电梯在底层载有 \(5\) 位乘客，且每位乘客在这三层的每一层下电梯的概率均为 \(\frac{1}{3}\)，用 \(\xi\) 表示这 \(5\) 位乘客在第 \(20\) 层下电梯的人数，求：

\item 由二项分布的期望公式，\(E\xi=np=5\times\frac13=\frac53\).
\end{enumerate}
\end{solution}

\begin{enumerate}
\item 若 \(b^{2} > 4(a - 1)\)，讨论函数 \(f(x)\) 的单调性；
\item 若 \(b^{2} \leqslant 4(c - 1)\)，且 \(\displaystyle\lim_{x\to0}\frac{f(x) - c}{x} = 4\)，试证：\(-6 \leqslant b \leqslant 2\).
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 先求导得 \(f'(x)=\left[x^{2}+(b+2)x+b+c\right]e^{x}\). 由于 \(e^{x}>0\)，函数的单调性由二次函数 \(q(x)=x^{2}+(b+2)x+b+c\) 的符号决定. 其判别式为 \(\Delta=(b+2)^{2}-4(b+c)=b^{2}-4(c-1)\). 当 \(\Delta<0\) 时，\(q(x)>0\) 对任意 \(x\) 成立，故 \(f(x)\) 在 \(\R\) 上单调递增；当 \(\Delta=0\) 时，\(q(x)\geqslant0\)，且仅在一个点取零，故 \(f(x)\) 在 \(\R\) 上单调递增. 当 \(\Delta>0\) 时，令 \(x_{1}=\frac{-(b+2)-\sqrt{\Delta}}{2}\)、\(x_{2}=\frac{-(b+2)+\sqrt{\Delta}}{2}\)，则 \(x_{1}<x_{2}\)，且 \(q(x)>0\) 在 \((-\infty,x_{1})\cup(x_{2},+\infty)\) 上成立，\(q(x)<0\) 在 \((x_{1},x_{2})\) 上成立，所以 \(f(x)\) 在 \((-\infty,x_{1})\)、\((x_{2},+\infty)\) 上单调递增，在 \((x_{1},x_{2})\) 上单调递减. 但原 PDF 第一问写作 \(b^{2}>4(a-1)\)，题设没有定义 \(a\)，该条件不能确定 \(\Delta\)，所以在忠实原 PDF 的前提下，只能按 \(\Delta\) 的三种情形给出上述完整分类，不能擅自将题面中的 \(a\) 改为 \(c\).
\item 因为 \(f(0)=c\)，且 \(f\) 可导，所以题设极限等于 \(f'(0)=b+c\)，从而 \(b+c=4\)，即 \(c=4-b\). 结合 \(b^{2}\leqslant4(c-1)\)，得 \(b^{2}\leqslant4(3-b)\)，即 \(b^{2}+4b-12\leqslant0\). 因此 \((b+6)(b-2)\leqslant0\)，故 \(-6\leqslant b\leqslant2\).
\end{enumerate}
\end{solution}

\begin{problem}
已知定义域为 \(\R\) 的函数 \(f(x)\) 满足 \(f(f(x) - x^{2} + x) = f(x) - x^{2} + x\).
\begin{enumerate}
\item 若 \(f(2) = 3\)，求 \(f(1)\)；又若 \(f(0) = a\)，求 \(f(a)\)；
\item 设有且仅有一个实数 \(x_{0}\)，使得 \(f(x_{0}) = x_{0}\)，求函数 \(f(x)\) 的解析表达式.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 令 \(g(x)=f(x)-x^{2}+x\)，则题设为 \(f(g(x))=g(x)\). 当 \(f(2)=3\) 时，\(g(2)=3-4+2=1\)，所以 \(f(1)=1\). 当 \(f(0)=a\) 时，\(g(0)=a\)，所以 \(f(a)=a\).
\item 由 \(f(g(x))=g(x)\)，可知对任意 \(x\)，\(g(x)\) 都是 \(f\) 的不动点. 题设只有一个不动点 \(x_0\)，所以 \(g(x)=x_0\)，即 \(f(x)=x^{2}-x+x_0\). 再代入 \(f(x_0)=x_0\)，得 \(x_0^{2}=x_0\)，故 \(x_0=0\) 或 \(x_0=1\). 若 \(x_0=0\)，则 \(f(x)=x^{2}-x\)，其不动点方程为 \(x^{2}-2x=0\)，有两个不动点 \(0,2\)，不合题意；若 \(x_0=1\)，则 \(f(x)=x^{2}-x+1\)，其不动点方程为 \((x-1)^{2}=0\)，恰有一个不动点. 所以 \(f(x)=x^{2}-x+1\)（\(x\in\R\)）.
\end{enumerate}
\end{solution}

\begin{problem}
已知一列椭圆 \(C_{n}: x^{2} + \frac{y^{2}}{b_{n}^{2}} = 1\)，\(0 < b_{n} < 1\)，\(n=1\)，\(2\)，\(\cdots\). 若椭圆 \(C_{n}\) 上有一点 \(P_{n}\)，使 \(P_{n}\) 到右准线 \(l_{n}\) 的距离 \(d_{n}\) 是 \(|P_{n}F_{n}|\) 与 \(|P_{n}G_{n}|\) 的等差中项，其中 \(F_{n}\)，\(G_{n}\) 分别是 \(C_{n}\) 的左、右焦点.

\begin{enumerate}
\item 试证：\(b_{n} \leqslant \frac{\sqrt{3}}{2}\)（\(n \geqslant 1\)）；
\item 取 \(b_{n} = \frac{\sqrt{2n + 3}}{n + 2}\)，并用 \(S_{n}\) 表示 \(\triangle P_{n}F_{n}G_{n}\) 的面积. 试证：\(S_{1} < S_{2}\) 且 \(S_{n} > S_{n + 1}\)（\(n \geqslant 3\)）.
\end{enumerate}

\bitmapfigure[float=inline,max width=0.55\linewidth]{img/2006/chongqing_science/q22_fig1.png}
\end{problem}
\FloatBarrier

\begin{solution}
\begin{enumerate}
\item 记 \(e_n=\sqrt{1-b_n^{2}}\)，则椭圆的左右焦点分别为 \(F_n=(-e_n,0)\)、\(G_n=(e_n,0)\)，右准线为 \(l_n\colon x=\frac1{e_n}\). 设 \(P_n=(x_n,y_n)\). 由椭圆定义，\(|P_nF_n|+|P_nG_n|=2\)，所以题设中的等差中项为 \(1\)，即 \(d_n=1\). 又因为 \(-1\leqslant x_n\leqslant1<\frac1{e_n}\)，故 \(d_n=\frac1{e_n}-x_n\)，从而 \(x_n=\frac1{e_n}-1\). 点 \(P_n\) 存在，必须有 \(x_n\leqslant1\)，于是 \(\frac1{e_n}-1\leqslant1\)，即 \(e_n\geqslant\frac12\). 因而 \(1-b_n^{2}=e_n^{2}\geqslant\frac14\)，所以 \(b_n\leqslant\frac{\sqrt3}{2}\).
\item 由给定的 \(b_n\)，得 \(e_n=\sqrt{1-b_n^{2}}=\sqrt{1-\frac{2n+3}{(n+2)^{2}}}=\frac{n+1}{n+2}\)，所以 \(x_n=\frac1{e_n}-1=\frac1{n+1}\). 再由椭圆方程，\(y_n^{2}=b_n^{2}(1-x_n^{2})=\frac{n(2n+3)}{(n+2)(n+1)^{2}}\). 三角形 \(P_nF_nG_n\) 的底边长为 \(2e_n\)，高为 \(|y_n|\)，故 \(S_n=e_n|y_n|=\frac{\sqrt{n(2n+3)}}{(n+2)^{3/2}}\)，从而 \(S_n^{2}=\frac{n(2n+3)}{(n+2)^{3}}\). 先算得 \(S_1^{2}=\frac5{27}\)、\(S_2^{2}=\frac7{32}\)，且 \(\frac5{27}<\frac7{32}\)，所以 \(S_1<S_2\). 对实数 \(x>0\) 令 \(h(x)=\frac{x(2x+3)}{(x+2)^{3}}\)，则 \(h'(x)=\frac{-2x^{2}+2x+6}{(x+2)^{4}}=-\frac{2(x^{2}-x-3)}{(x+2)^{4}}\). 当 \(x\geqslant3\) 时，\(x^{2}-x-3>0\)，所以 \(h(x)\) 在 \([3,+\infty)\) 上递减. 因而对 \(n\geqslant3\)，有 \(S_n^{2}=h(n)>h(n+1)=S_{n+1}^{2}\). 由于面积为正，故 \(S_n>S_{n+1}\).
\end{enumerate}
\end{solution}
