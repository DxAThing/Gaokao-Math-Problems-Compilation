\section{单选题}

\begin{problem}
下列函数中，周期为 \(\frac{\pi}{2}\) 的是（\quad）

\choices
    {\(y = \sin \frac{x}{2}\)}
    {\(y = \sin 2x\)}
    {\(y = \cos \frac{x}{4}\)}
    {\(y = \cos 4x\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
对于正弦型或余弦型函数，函数 \(y=\sin kx\) 或 \(y=\cos kx\) 的最小正周期为 \(\frac{2\pi}{|k|}\). 因而四个选项中函数的最小正周期分别为 \(4\pi\)，\(\pi\)，\(8\pi\)，\(\frac{\pi}{2}\). 只有选项 D 的周期为 \(\frac{\pi}{2}\)，故选 D.
\end{solution}

\begin{problem}
已知全集 \(U = \Z\)，\(A = \{-1, 0, 1, 2\}\)，\(B = \{x \mid x^{2} = x\}\)，则 \(A \cap \complement_U B\) 为（\quad）

\choices
    {\(\{-1, 2\}\)}
    {\(\{-1, 0\}\)}
    {\(\{0, 1\}\)}
    {\(\{1, 2\}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
由 \(x^{2}=x\) 得 \(x(x-1)=0\)，所以 \(B=\{0,1\}\). 因为全集为 \(\Z\)，故 \(\complement_U B\) 是从 \(\Z\) 中去掉 \(0\)，\(1\) 后得到的集合. 从而
\[
A\cap\complement_U B=\{-1,2\}
\]
故选 A.
\end{solution}

\begin{problem}
在平面直角坐标系 \(xOy\) 中，双曲线的中心在坐标原点，焦点在 \(y\) 轴上，一条渐近线方程为 \(x - 2y = 0\)，则它的离心率为（\quad）

\choices
    {\(\sqrt{5}\)}
    {\(\frac{\sqrt{5}}{2}\)}
    {\(\sqrt{3}\)}
    {\(2\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
设双曲线的标准方程为 \(\frac{y^{2}}{a^{2}}-\frac{x^{2}}{b^{2}}=1\)，其中 \(a>0\)，\(b>0\). 其渐近线为 \(y=\pm\frac{a}{b}x\). 由渐近线 \(x-2y=0\)，即 \(y=\frac{1}{2}x\)，得 \(\frac{a}{b}=\frac{1}{2}\)，所以 \(\frac{b}{a}=2\).

双曲线的焦半距满足 \(c^{2}=a^{2}+b^{2}\)，故离心率
\[
e=\frac{c}{a}=\sqrt{1+\frac{b^{2}}{a^{2}}}=\sqrt{1+4}=\sqrt{5}
\]
故选 A.
\end{solution}

\begin{problem}
已知两条直线 \(m\)，\(n\)，两个平面 \(\alpha\)，\(\beta\)，给出下面四个命题：

\begin{circlelist}
\item \(m \parallel n\)，\(m \perp \alpha \Rightarrow n \perp \alpha\)；
\item \(\alpha \parallel \beta\)，\(m \subset \alpha\)，\(n \subset \beta \Rightarrow m \parallel n\)；
\item \(m \parallel n\)，\(m \parallel \alpha \Rightarrow n \parallel \alpha\)；
\item \(\alpha \parallel \beta\)，\(m \parallel n\)，\(m \perp \alpha \Rightarrow n \perp \beta\).
\end{circlelist}

其中正确命题的序号是（\quad）

\choices
    {\(\circled{1}\circled{3}\)}
    {\(\circled{2}\circled{4}\)}
    {\(\circled{1}\circled{4}\)}
    {\(\circled{2}\circled{3}\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
命题\(\circled{1}\)中，直线 \(m\) 与平面 \(\alpha\) 垂直，且 \(n\parallel m\)，所以 \(n\) 的方向也垂直于平面 \(\alpha\)，命题\(\circled{1}\)正确.

命题\(\circled{2}\)不正确. 两平面平行时，分别位于两平面内的两条直线的方向可以不同，例如在两个平行平面内分别取方向不同的直线，它们不一定平行.

命题\(\circled{3}\)不正确. 例如取平面 \(\alpha\) 为水平面，取一条不在 \(\alpha\) 内且平行于 \(\alpha\) 的直线 \(m\)，再取与 \(m\) 平行且位于 \(\alpha\) 内的直线 \(n\)，则 \(m\parallel n\)，但 \(n\) 不与 \(\alpha\) 平行.

命题\(\circled{4}\)中，\(\alpha\parallel\beta\)，所以两平面的法向方向相同；又因 \(m\perp\alpha\) 且 \(n\parallel m\)，故 \(n\) 的方向也垂直于平面 \(\beta\)，命题\(\circled{4}\)正确. 因此正确命题为\(\circled{1}\)\(\circled{4}\)，故选 C.
\end{solution}

\begin{problem}
函数 \(f(x) = \sin x - \sqrt{3}\cos x\)（\(x \in [-\pi, 0]\)）的单调递增区间是（\quad）

\choices
    {\(\left[-\pi, -\frac{5\pi}{6}\right]\)}
    {\(\left[-\frac{5\pi}{6}, -\frac{\pi}{6}\right]\)}
    {\(\left[-\frac{\pi}{3}, 0\right]\)}
    {\(\left[-\frac{\pi}{6}, 0\right]\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
\[
f'(x)=\cos x+\sqrt{3}\sin x=2\sin\left(x+\frac{\pi}{6}\right)
\]
当 \(x\in[-\pi,0]\) 时，只有在 \(x\in[-\frac{\pi}{6},0]\) 上有 \(f'(x)\geqslant0\)，且在其内部 \(f'(x)>0\). 因此函数在 \([-\frac{\pi}{6},0]\) 上单调递增，故选 D.
\end{solution}

\begin{problem}
设函数 \(f(x)\) 定义在实数集上，它的图象关于直线 \(x = 1\) 对称，且当 \(x \geqslant 1\) 时，\(f(x) = 3^{x} - 1\)，则有（\quad）

\choices
    {\(f\left(\frac{1}{3}\right) < f\left(\frac{3}{2}\right) < f\left(\frac{2}{3}\right)\)}
    {\(f\left(\frac{2}{3}\right) < f\left(\frac{3}{2}\right) < f\left(\frac{1}{3}\right)\)}
    {\(f\left(\frac{2}{3}\right) < f\left(\frac{1}{3}\right) < f\left(\frac{3}{2}\right)\)}
    {\(f\left(\frac{3}{2}\right) < f\left(\frac{2}{3}\right) < f\left(\frac{1}{3}\right)\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
图象关于直线 \(x=1\) 对称，所以对任意 \(x\)，有 \(f(x)=f(2-x)\). 于是
\(f\left(\frac{1}{3}\right)=f\left(\frac{5}{3}\right)=3^{5/3}-1\)，
\(f\left(\frac{2}{3}\right)=f\left(\frac{4}{3}\right)=3^{4/3}-1\)，
\(f\left(\frac{3}{2}\right)=3^{3/2}-1\).
由于 \(3^x-1\) 在 \([1,+\infty)\) 上单调递增，而 \(\frac{4}{3}<\frac{3}{2}<\frac{5}{3}\)，所以
\[
f\left(\frac{2}{3}\right)<f\left(\frac{3}{2}\right)<f\left(\frac{1}{3}\right)
\]
故选 B.
\end{solution}

\begin{problem}
若对于任意实数 \(x\)，有
\(x^{3} = a_{0} + a_{1}(x - 2) + a_{2}(x - 2)^{2} + a_{3}(x - 2)^{3}\)，则 \(a_{2}\) 的值为（\quad）

\choices
    {\(3\)}
    {\(6\)}
    {\(9\)}
    {\(12\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
令 \(u=x-2\)，则 \(x=u+2\)，从而
\[
x^{3}=(u+2)^{3}=u^{3}+6u^{2}+12u+8
\]
代回 \(u=x-2\)，得到
\[
x^{3}=8+12(x-2)+6(x-2)^{2}+(x-2)^{3}
\]
因此 \(a_{2}=6\)，故选 B.
\end{solution}

\begin{problem}
设 \(f(x) = \lg \left(\frac{2}{1 - x} + a\right)\) 是奇函数，则使 \(f(x) < 0\) 的 \(x\) 的取值范围是（\quad）

\choices
    {\((-1, 0)\)}
    {\((0, 1)\)}
    {\((-\infty, 0)\)}
    {\((-\infty, 0) \cup (1, +\infty)\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
记 \(R(x)=\frac{2}{1-x}+a=\frac{a+2-ax}{1-x}\). 由于 \(f\) 是奇函数，定义域关于原点对称，且对定义域内的 \(x\)，有 \(f(-x)=-f(x)\). 因此 \(R(x)>0\)，\(R(-x)>0\)，并且
\[
R(x)R(-x)=1
\]
于是
\[
\frac{(a+2-ax)(a+2+ax)}{1-x^{2}}=1
\]
即
\[
(a+2)^{2}-1=(a^{2}-1)x^{2}
\]
函数的定义域是由严格不等式确定的非空开集，因而包含一个非空区间；上式对该区间内的所有 \(x\) 成立，所以两边关于 \(x\) 的多项式恒等，得到 \(a^{2}=1\)，\((a+2)^{2}=1\). 联立可得 \(a=-1\). 此时
\[
f(x)=\lg\left(\frac{2}{1-x}-1\right)=\lg\left(\frac{1+x}{1-x}\right)
\]
其定义域为 \((-1,1)\). 在此定义域内，\(f(x)<0\) 等价于
\[
0<\frac{1+x}{1-x}<1
\]
因为 \(-1<x<1\) 时 \(1-x>0\)，所以不等式右半部分等价于 \(1+x<1-x\)，即 \(x<0\). 故 \(f(x)<0\) 的取值范围为 \((-1,0)\)，选 A.
\end{solution}

\begin{problem}
已知二次函数 \(f(x) = ax^{2} + bx + c\) 的导数为 \(f'(x)\)，\(f'(0) > 0\)，对于任意实数 \(x\) 都有 \(f(x) \geqslant 0\)，则 \(\frac{f(1)}{f'(0)}\) 的最小值为（\quad）

\choices
    {\(3\)}
    {\(\frac{5}{2}\)}
    {\(2\)}
    {\(\frac{3}{2}\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
由 \(f'(0)=b>0\)；若 \(a<0\)，则 \(f(x)\to-\infty\)（\(\lvert x\rvert\to\infty\)），若 \(a=0\)，则 \(f(x)=bx+c\) 在 \(x\to-\infty\) 时趋于 \(-\infty\)，均与 \(f(x)\geqslant0\) 对任意实数 \(x\) 矛盾. 因此 \(a>0\)，并且
\[
c\geqslant\frac{b^{2}}{4a}
\]
因此
\[
\frac{f(1)}{f'(0)}=\frac{a+b+c}{b}
\geqslant\frac{a+b+\frac{b^{2}}{4a}}{b}
=\frac{a}{b}+1+\frac{b}{4a}
\]
令 \(t=\frac{a}{b}>0\)，则
\[
\frac{a}{b}+\frac{b}{4a}=t+\frac{1}{4t}\geqslant1
\]
其中等号在 \(t=\frac{1}{2}\) 时成立. 所以
\[
\frac{f(1)}{f'(0)}\geqslant2
\]
取 \(a=1\)，\(b=2\)，\(c=1\) 时，\(f(x)=(x+1)^{2}\)，且比值等于 \(2\)，故最小值为 \(2\)，选 C.
\end{solution}

\begin{problem}
在平面直角坐标系 \(xOy\) 中，已知平面区域 \(A = \{(x, y) \mid x + y \leqslant 1,\text{且 }x \geqslant 0,\ y \geqslant 0\}\)，则平面区域 \(B = \{(x + y, x - y) \mid (x, y) \in A\}\) 的面积为（\quad）

\choices
    {\(2\)}
    {\(1\)}
    {\(\frac{1}{2}\)}
    {\(\frac{1}{4}\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
区域 \(A\) 是由 \(x=0\)，\(y=0\)，\(x+y=1\) 围成的三角形，其三个顶点为 \((0,0)\)，\((1,0)\)，\((0,1)\)，面积为 \(\frac{1}{2}\).

令 \(u=x+y\)，\(v=x-y\)，则
\[
\begin{pmatrix}u\\v\end{pmatrix}
=\begin{pmatrix}1&1\\1&-1\end{pmatrix}
\begin{pmatrix}x\\y\end{pmatrix}
\]
\[
\left|\det\begin{pmatrix}1&1\\1&-1\end{pmatrix}\right|=2
\]
线性变换将面积放大 \(2\) 倍，所以区域 \(B\) 的面积为 \(2\cdot\frac{1}{2}=1\)，故选 B.
\end{solution}

\begin{problem}
若 \(\cos(\alpha+\beta)=\frac{1}{5}\)，\(\cos(\alpha-\beta)=\frac{3}{5}\)，则 \(\tan\alpha\tan\beta=\)\fillinblank{}.
\end{problem}

\begin{answer}
\(\frac{1}{2}\)
\end{answer}

\begin{solution}
由和差化积公式，得
\[
\cos(\alpha+\beta)+\cos(\alpha-\beta)=2\cos\alpha\cos\beta=\frac{4}{5}
\]
以及
\[
\cos(\alpha-\beta)-\cos(\alpha+\beta)=2\sin\alpha\sin\beta=\frac{2}{5}
\]
因为 \(\cos\alpha\cos\beta=\frac{2}{5}\neq0\)，所以
\[
\tan\alpha\tan\beta
=\frac{\sin\alpha\sin\beta}{\cos\alpha\cos\beta}
=\frac{\frac{1}{5}}{\frac{2}{5}}
=\frac{1}{2}
\]
\end{solution}

\begin{problem}
某校开设 \(9\) 门课程供学生选择，其中 \(A\)，\(B\)，\(C\) 三门由于上课时间相同，学校规定，每位同学选修 \(4\) 门，共有\fillinblank{} 种不同的选修方案.（用数值作答）
\end{problem}

\begin{answer}
75
\end{answer}

\begin{solution}
由于课程 \(A\)，\(B\)，\(C\) 上课时间相同，每位同学至多选其中一门. 分两类计数：

不选 \(A\)，\(B\)，\(C\) 中的课程时，从其余 \(6\) 门课程中选 \(4\) 门，有 \(\mathrm C_6^4\) 种；恰选其中一门时，先选出这门课程，再从其余 \(6\) 门中选 \(3\) 门，有 \(\mathrm C_3^1\mathrm C_6^3\) 种. 因此方案总数为
\[
\mathrm C_6^4+\mathrm C_3^1\mathrm C_6^3=15+3\times20=75
\]
\end{solution}

\begin{problem}
已知函数 \(f(x) = x^{3} - 12x + 8\) 在区间 \([-3, 3]\) 上的最大值与最小值分别为 \(M\)，\(m\)，则 \(M - m = \)\fillinblank{}.
\end{problem}

\begin{answer}
32
\end{answer}

\begin{solution}
\[
f'(x)=3x^{2}-12=3(x-2)(x+2)
\]
在区间 \([-3,3]\) 内，函数的极值只需比较端点和驻点 \(-2,2\) 处的函数值. 逐一计算得
\(f(-3)=17\)，\(f(-2)=24\)，\(f(2)=-8\)，\(f(3)=-1\).
所以最大值 \(M=24\)，最小值 \(m=-8\)，从而
\[
M-m=24-(-8)=32
\]
\end{solution}

\begin{problem}
正三棱锥 \(P - ABC\) 高为 \(2\)，侧棱与底面 \(ABC\) 成 \(45^{\circ}\)，则点 \(A\) 到侧面 \(PBC\) 的距离为\fillinblank{}.
\end{problem}

\begin{answer}
\(\frac{6\sqrt{5}}{5}\)
\end{answer}

\begin{solution}
设正三棱锥的顶点为 \(P\)，底面中心为 \(O\)，底面边长为 \(s\). 由于 \(PO\perp\) 面 \(ABC\)，且侧棱 \(PA\) 与底面所成的角为 \(45^{\circ}\)，在直角三角形 \(PAO\) 中有 \(PO=2\)，\(\tan45^{\circ}=\frac{PO}{AO}\).
故 \(AO=2\). 对边长为 \(s\) 的正三角形，中心到顶点的距离为 \(\frac{s\sqrt{3}}{3}\)，所以 \(s=2\sqrt{3}\).

设 \(K\) 为 \(O\) 到 \(BC\) 的垂足. 正三角形的内切圆半径为 \(\frac{s\sqrt{3}}{6}=1\)，故 \(OK=1\). 因为 \(PO\perp\) 面 \(ABC\)，所以 \(PO\perp OK\)，从而
\[
PK=\sqrt{PO^{2}+OK^{2}}=\sqrt{5}
\]
于是
\[
S_{\triangle ABC}=\frac{\sqrt{3}}{4}s^{2}=3\sqrt{3}
\]
\[
V_{P-ABC}=\frac{1}{3}S_{\triangle ABC}\cdot PO=2\sqrt{3}
\]
以及
\[
S_{\triangle PBC}=\frac{1}{2}BC\cdot PK
=\frac{1}{2}\cdot2\sqrt{3}\cdot\sqrt{5}=\sqrt{15}
\]
设点 \(A\) 到平面 \(PBC\) 的距离为 \(h\). 以三角形 \(PBC\) 为底面计算体积，得
\[
V_{P-ABC}=\frac{1}{3}S_{\triangle PBC}h
\]
\[
h=\frac{3V_{P-ABC}}{S_{\triangle PBC}}
=\frac{6\sqrt{3}}{\sqrt{15}}=\frac{6\sqrt{5}}{5}
\]
\end{solution}

\begin{problem}
在平面直角坐标系 \(xOy\) 中，已知 \(\triangle ABC\) 顶点 \(A(-4, 0)\) 和 \(C(4, 0)\)，顶点 \(B\) 在椭圆 \(\frac{x^{2}}{25} + \frac{y^{2}}{9} = 1\) 上，则 \(\frac{\sin A + \sin C}{\sin B} = \)\fillinblank{}.
\end{problem}

\begin{answer}
\(\frac{5}{4}\)
\end{answer}

\begin{solution}
椭圆 \(\frac{x^{2}}{25}+\frac{y^{2}}{9}=1\) 的长半轴为 \(5\)，焦半距满足
\[
c=\sqrt{25-9}=4
\]
所以椭圆的两个焦点正是 \(A(-4,0)\) 和 \(C(4,0)\). 对椭圆上任意点 \(B\)，有
\[
AB+BC=2\times5=10
\]
在三角形 \(ABC\) 中设外接圆半径为 \(R\)，由正弦定理得 \(\sin A=\frac{BC}{2R}\)，\(\sin C=\frac{AB}{2R}\)，\(\sin B=\frac{AC}{2R}\).
又 \(AC=8\)，所以
\[
\frac{\sin A+\sin C}{\sin B}
=\frac{AB+BC}{AC}
=\frac{10}{8}=\frac{5}{4}
\]
\end{solution}

\begin{problem}
某时钟的秒针端点 \(A\) 到中心点 \(O\) 的距离为 \(5 \mathrm{~cm}\)，秒针均匀地绕点 \(O\) 旋转，当时间 \(t = 0\) 时，点 \(A\) 与钟面上标 \(12\) 的点 \(B\) 重合，将 \(A\)，\(B\) 两点的距离 \(d\)（\(\mathrm{cm}\)）表示成 \(t\)（\(\mathrm{s}\)）的函数，则 \(d = \)\fillinblank{}，其中 \(t\in[0,60]\).
\end{problem}

\begin{answer}
\(10\sin\frac{\pi t}{60}\)
\end{answer}

\begin{solution}
秒针每 \(60\) 秒转一周，所以 \(t\) 秒后半径 \(OA\) 与 \(OB\) 的夹角为
\[
\theta=\frac{2\pi}{60}t=\frac{\pi t}{30}
\]
在等腰三角形 \(AOB\) 中，作弦 \(AB\) 的垂线平分线，利用半角公式可得
\[
d=AB=2\cdot5\sin\frac{\theta}{2}
=10\sin\frac{\pi t}{60}
\]
\end{solution}

\begin{problem}
某气象站天气预报的准确率为 \(80\%\)，计算（结果保留到小数点后面第 \(2\) 位）

\begin{enumerate}
\item \(5\) 次预报中恰有 \(2\) 次准确的概率；
\item \(5\) 次预报中至少有 \(2\) 次准确的概率；
\item \(5\) 次预报中恰有 \(2\) 次准确，且其中第 \(3\) 次预报准确的概率.
\end{enumerate}
\end{problem}

\begin{solution}
设一次预报准确的概率为 \(p=0.8\)，不准确的概率为 \(1-p=0.2\)，并设 \(X\) 表示 \(5\) 次预报中准确的次数，则 \(X\) 服从二项分布.

\begin{enumerate}
\item 恰有 \(2\) 次准确时，从 \(5\) 次中选出这 \(2\) 次，故
\[
P(X=2)=\mathrm C_5^2(0.8)^2(0.2)^3=0.0512\approx0.05
\]
\item 至少有 \(2\) 次准确是“准确次数为 \(0\) 或 \(1\)”的对立事件，故
\[
P(X\geqslant2)=1-P(X=0)-P(X=1)=1-(0.2)^5-\mathrm C_5^1(0.8)(0.2)^4=0.99328\approx0.99
\]
\item 第 \(3\) 次必须准确，且其余 \(4\) 次中恰有 \(1\) 次准确，故
\[
P=\mathrm C_4^1(0.8)^2(0.2)^3=0.02048\approx0.02
\]
\end{enumerate}
\end{solution}

\item 因为 \(\overrightarrow{BE}=(0,3,1)\)，\(\overrightarrow{BF}=(3,0,2)\)，且 \(\overrightarrow{BD_{1}}=(3,3,3)=\overrightarrow{BE}+\overrightarrow{BF}\)，
所以点 \(D_{1}\) 在由点 \(B\)，\(E\)，\(F\) 确定的平面内，故 \(E\)，\(B\)，\(F\)，\(D_{1}\) 四点共面.
\item 设 \(M=(0,0,t)\). 由 \(BG=\frac{2}{3}\)，得 \(G=\left(\frac{2}{3},0,0\right)\)，从而
\(\overrightarrow{GM}=\left(-\frac{2}{3},0,t\right)\)，\(\overrightarrow{BF}=(3,0,2)\).
由 \(GM\perp BF\)，有 \(\overrightarrow{GM}\cdot\overrightarrow{BF}=-\frac{2}{3}\cdot3+2t=0\)，
解得 \(t=1\)，即 \(M=(0,0,1)\). 因而 \(\overrightarrow{EM}=(0,-3,0)\)，直线 \(EM\) 平行于 \(y\) 轴，而平面 \(BCC_{1}B_{1}\) 的方程为 \(y=0\)，所以 \(EM\perp\) 面 \(BCC_{1}B_{1}\).
\item 记平面 \(EBFD_{1}\) 为 \(\Pi\)，平面 \(BCC_{1}B_{1}\) 为 \(\Sigma\). 由 \(\overrightarrow{BE}\times\overrightarrow{BF}=(6,3,-9)=3(2,1,-3)\)，可知 \(\Pi\) 的一个法向量为 \((2,1,-3)\)，故其方程为 \(2x+y-3z=0\). 平面 \(\Sigma\) 的一个法向量为 \((0,1,0)\). 因为所求二面角取锐角，
所以 \(\cos\theta=\frac{1}{\sqrt{14}}\)，从而 \(\sin\theta=\frac{\sqrt{13}}{\sqrt{14}}\).
所以 \(\tan\theta=\sqrt{13}\).
\end{enumerate}
\end{solution}

\begin{problem}
如图，在平面直角坐标系 \(xOy\) 中，过 \(y\) 轴正方向上一点 \(C(0, c)\) 任作一直线，与抛物线 \(y = x^{2}\) 相交于 \(A\)，\(B\) 两点，一条垂直于 \(x\) 轴的直线，分别与线段 \(AB\) 和直线 \(l: y = -c\) 交于 \(P\)，\(Q\).

\begin{enumerate}
\item 若 \(\overrightarrow{OA} \cdot \overrightarrow{OB} = 2\)，求 \(c\) 的值；
\item 若 \(P\) 为线段 \(AB\) 的中点，求证：\(QA\) 为此抛物线的切线；
\item 试问第 2 小问的逆命题是否成立？说明理由.
\end{enumerate}

\bitmapfigure[max width=0.38\linewidth]{img/2007/jiangsu/q19_fig1.png}
\end{problem}

\begin{solution}
设 \(A=(u,u^{2})\)，\(B=(v,v^{2})\)，其中 \(u\neq v\). 过抛物线上两点 \(A\)，\(B\) 的直线方程为 \(y=(u+v)x-uv\). 由于该直线过 \(C=(0,c)\)，所以
\(uv=-c\).
设题设中的垂直于 \(x\) 轴的直线为 \(x=t\)，则 \(P\) 与 \(Q\) 的横坐标均为 \(t\)，且 \(Q=(t,-c)\).

\begin{enumerate}
\item
\[
\overrightarrow{OA}\cdot\overrightarrow{OB}=uv+u^{2}v^{2}=uv+(uv)^{2}=-c+c^{2}=2
\]
因此 \(c^{2}-c-2=0\)，即 \((c-2)(c+1)=0\). 由于 \(C\) 在 \(y\) 轴正方向上，\(c>0\)，所以 \(c=2\).
\item 若 \(P\) 是线段 \(AB\) 的中点，则其横坐标为 \(t=\frac{u+v}{2}\).
抛物线 \(y=x^{2}\) 在点 \(A=(u,u^{2})\) 处的切线方程为 \(y=2ux-u^{2}\). 当 \(x=t\) 时，该切线的纵坐标为
\[
2ut-u^{2}=u(u+v)-u^{2}=uv=-c
\]
所以点 \(Q=(t,-c)\) 在点 \(A\) 处的切线上，故 \(QA\) 为此抛物线的切线.
\item 逆命题成立. 设抛物线在横坐标为 \(r\) 的点处的切线为 \(y=2rx-r^{2}\). 若该切线经过抛物线上的点 \(A=(u,u^{2})\)，则
\(u^{2}=2ru-r^{2}\)，\(\Longrightarrow\)，\((u-r)^{2}=0\)
所以切点只能是 \(A\)，切线方程为 \(y=2ux-u^{2}\). 因而点 \(Q\) 在此切线上，从而
\(-c=2ut-u^{2}\).
结合 \(uv=-c\)，得 \(uv=2ut-u^{2}\). 因为 \(uv=-c<0\)，所以 \(u\neq0\)，进而 \(v=2t-u\)，即 \(t=\frac{u+v}{2}\). 这正是线段 \(AB\) 中点的横坐标；又 \(P\) 在 \(AB\) 上，所以 \(P\) 为线段 \(AB\) 的中点.
\end{enumerate}
\end{solution}

\begin{problem}
已知 \(\{a_{n}\}\) 是等差数列，\(\{b_{n}\}\) 是公比为 \(q\) 的等比数列，\(a_{1} = b_{1}\)，\(a_{2} = b_{2} \neq a_{1}\)，记 \(S_{n}\) 为数列 \(\{b_{n}\}\) 的前 \(n\) 项和.

\begin{enumerate}
\item 若 \(b_{k} = a_{m}\)（\(m\)，\(k\) 是大于 \(2\) 正整数），求证：\(S_{k-1} = (m - 1)a_{1}\)；
\item 若 \(b_{3} = a_{i}\)（\(i\) 是某一正整数），求证：\(q\) 是整数，且数列 \(\{b_{n}\}\) 中每一项都是数列 \(\{a_{n}\}\) 中的项；
\item 是否存在这样的正数 \(q\)，使等比数列 \(\{b_{n}\}\) 中有三项成等差数列？若存在，写出一个 \(q\) 的值，并加以说明；若不存在，请说明理由.
\end{enumerate}
\end{problem}

\begin{solution}
设 \(a_{1}=b_{1}=u\). 由 \(a_{2}=b_{2}=uq\neq u\)，得 \(u\neq0\)，\(q\neq1\). 等差数列的公差为
\(a_{2}-a_{1}=u(q-1)\)，
所以对任意正整数 \(n\)，\(a_{n}=u\bigl[1+(n-1)(q-1)\bigr]\)，\(b_{n}=uq^{n-1}\).

\begin{enumerate}
\item 由 \(b_{k}=a_{m}\)，得
\(uq^{k-1}=u\bigl[1+(m-1)(q-1)\bigr]\).
除以 \(u\) 后，\(q^{k-1}-1=(m-1)(q-1)\). 因而
\[
S_{k-1}=u\left(1+q+\cdots+q^{k-2}\right)=u\frac{q^{k-1}-1}{q-1}=(m-1)u=(m-1)a_{1}
\]
\item 由 \(b_{3}=a_{i}\)，得
\(uq^{2}=u\bigl[1+(i-1)(q-1)\bigr]\).
除以 \(u\) 并整理，得到 \(q^{2}-(i-1)q+(i-2)=0\)，即 \((q-1)(q-i+2)=0\).
因 \(q\neq1\)，所以 \(q=i-2\)，从而 \(q\) 是整数，且 \(q\) 只能是 \(-1\)，\(0\) 或不小于 \(2\) 的整数.

当 \(q\geqslant2\) 时，对 \(n\geqslant2\)，令
\[
j_{n}=1+\frac{q^{n-1}-1}{q-1}=1+1+q+\cdots+q^{n-2}
\]
则 \(j_{n}\) 是正整数，且
\(a_{j_{n}}=u q^{n-1}=b_{n}\).
当 \(q=0\) 时，\(b_{1}=a_{1}\)，且 \(b_{n}=0=a_{2}\)（\(n\geqslant2\)）；当 \(q=-1\) 时，奇数项 \(b_{n}=u=a_{1}\)，偶数项 \(b_{n}=-u=a_{2}\). 因此数列 \(\{b_{n}\}\) 中每一项都是数列 \(\{a_{n}\}\) 中的项.
\item 存在这样的正数 \(q\). 取
\(q=\frac{\sqrt{5}-1}{2}>0\).
则 \(q^{2}=1-q\)，从而 \(q^{3}=2q-1\)，所以 \(1+q^{3}=2q\). 因此
\(b_{1}+b_{4}=u+uq^{3}=2uq=2b_{2}\)，
即 \(b_{1}\)，\(b_{2}\)，\(b_{4}\) 三项成等差数列. 且 \(q\neq1\)，满足题设 \(a_{2}=b_{2}\neq a_{1}=b_{1}\).
\end{enumerate}
\end{solution}

\begin{problem}
已知 \(a\)，\(b\)，\(c\)，\(d\) 是不全为零的实数，函数 \(f(x) = bx^{2} + cx + d\)，\(g(x) = ax^{3} + bx^{2} + cx + d\). 方程 \(f(x) = 0\) 有实数根，且 \(f(x) = 0\) 的实数根都是 \(g(f(x)) = 0\) 的根；反之，\(g(f(x)) = 0\) 的实数根都是 \(f(x) = 0\) 的根.

\begin{enumerate}
\item 求 \(d\) 的值；
\item 若 \(a = 0\)，求 \(c\) 的取值范围；
\item 若 \(a = 1\)，\(f(1) = 0\)，求 \(c\) 的取值范围.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 设 \(x_{0}\) 是方程 \(f(x)=0\) 的一个实数根. 由题设，\(x_{0}\) 也是方程 \(g(f(x))=0\) 的根，因此
\[
0=g(f(x_{0}))=g(0)=d
\]
所以 \(d=0\).
\item 由 \(d=0\) 且 \(a=0\)，有
\(f(x)=bx^{2}+cx=x(bx+c)\)，且 \(g(x)=bx^{2}+cx=f(x)\).

先看退化情形 \(b=0\). 此时由“不全为零”知 \(c\neq0\)，且 \(f(x)=g(x)=cx\)，所以 \(g(f(x))=c^{2}x\). 两个方程的实数根都恰为 \(x=0\)，故任意 \(c\neq0\) 都满足条件.

再看 \(b\neq0\). 当 \(c=0\) 时，\(f(x)=bx^{2}\)，且 \(g(f(x))=f(f(x))=b^{3}x^{4}\)，两个方程的实数根均为 \(0\)，所以 \(c=0\) 可取. 当 \(c\neq0\) 时，\(f(x)=0\) 的根为 \(0\) 和 \(-\frac{c}{b}\)，而
\(g(f(x))=f(f(x))=0\)
还可能由 \(f(x)=-\frac{c}{b}\) 产生额外根. 该方程为
\(bx^{2}+cx+\frac{c}{b}=0\)，
其判别式为
\(\Delta=c^{2}-4c=c(c-4)\).
为了不产生额外实根，必须有 \(\Delta<0\)，即 \(0<c<4\). 因此在 \(b\neq0\) 时，\(c\in[0,4)\).

按题面条件允许 \(b=0\)，合并两种情形可得 \(c\in\R\).
\item 由 \(a=1\)，\(d=0\)，以及 \(f(1)=0\)，得 \(b+c=0\)，即 \(c=-b\). 当 \(b=0\) 时，\(c=0\)，\(f(x)\equiv0\)，而 \(g(f(x))\equiv0\)，题设条件成立.

下面设 \(b\neq0\). 此时 \(f(x)=bx(x-1)\)，\(g(y)=y\left(y^{2}+by-b\right)\).
由于 \(f(x)=0\) 的根已经必然是 \(g(f(x))=0\) 的根，所以只需保证二次方程
\(y^{2}+by-b=0\)
没有根落在 \(f\) 的值域内. 记该二次方程为 \(H(y)=0\).

当 \(b>0\) 时，\(f\) 的值域为 \(\left[-\frac{b}{4},+\infty\right)\)，而
此时 \(\Delta_H=b^{2}+4b>0\)，且 \(y_{+}=\frac{-b+\sqrt{b^{2}+4b}}{2}>0\).
所以 \(y_{+}\) 落在 \(f\) 的值域内，产生额外根，不符合题意.

当 \(-4\leqslant b<0\) 时，\(\Delta_H=b(b+4)\leqslant0\). 当 \(-4<b<0\) 时 \(H\) 无实根；当 \(b=-4\) 时 \(H\) 的唯一根为 \(2\)，而 \(f\) 的值域为 \((-\infty,1]\)，均不会产生额外根，故这一段的 \(b\) 可取.

当 \(b<-4\) 时，令 \(B=-b>4\). 此时 \(f\) 的值域为 \(\left(-\infty,\frac{B}{4}\right]\)，而 \(H\) 的较小根为
\(y_{-}=\frac{B-\sqrt{B^{2}-4B}}{2}\).
为了使两个根都不在 \(f\) 的值域内，必须有 \(y_{-}>\frac{B}{4}\). 由于两边均为正数，这等价于
\[
B>2\sqrt{B^{2}-4B}\ \Longleftrightarrow\ B^{2}>4B^{2}-16B\ \Longleftrightarrow\ B<\frac{16}{3}
\]
故此时 \(-\frac{16}{3}<b<-4\). 合并各情形并加入 \(b=0\)，得
\(-\frac{16}{3}<b\leqslant0\).
由于 \(c=-b\)，所以
\(c\in\left[0,\frac{16}{3}\right)\).
\end{enumerate}
\end{solution}
