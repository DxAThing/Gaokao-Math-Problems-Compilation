\begin{problem}
设数列 \(\{a_{n}\}\) 满足 \(a_1 + 3a_2 + 3^2 a_3 + \dots + 3^{n-1} a_n = \frac{n}{3}\)，\(n \in \mathbf{N}^*\).

\begin{enumerate}
\item 求数列 \(\{a_{n}\}\) 的通项；
\item 设 \( b_{n}=\frac{n}{a_{n}} \)，求数列 \(\{b_{n}\}\) 的前 \(n\) 项和 \( S_{n} \).
\end{enumerate}
\end{problem}

\item 求在先后两次出现的点数中有 \(5\) 的条件下，方程 \(x^{2} + bx + c = 0\) 有实根的概率.
\end{enumerate}
\end{problem}

\begin{problem}
已知椭圆 \(C\) 的中心在坐标原点，焦点在 \(x\) 轴上，椭圆 \(C\) 上的点到焦点距离的最大值为 \(3\)，最小值为 \(1\).

\begin{enumerate}
\item 求椭圆 \(C\) 的标准方程；
\item 若直线 \(l: y = kx + m\) 与椭圆 \(C\) 相交于 \(A\)，\(B\) 两点（\(A\)，\(B\) 不是左右顶点），且以 \(AB\) 为直径的圆过椭圆 \(C\) 的右顶点. 求证：直线 \(l\) 过定点，并求出该定点的坐标.
\end{enumerate}
\end{problem}

\begin{problem}
设函数 \( f(x) = x^{2} + b \ln (x + 1) \)，其中 \( b \neq 0 \).

\begin{enumerate}
\item 当 \(b > \frac{1}{2}\) 时，判断函数 \(f(x)\) 在定义域上的单调性；
\item 求函数 \( f(x) \) 的极值点；
\item 证明对任意的正整数 \(n\)，不等式 \(\ln \left(\frac{1}{n} + 1\right) > \frac{1}{n^2} - \frac{1}{n^3}\) 都成立.
\end{enumerate}
\end{problem}
