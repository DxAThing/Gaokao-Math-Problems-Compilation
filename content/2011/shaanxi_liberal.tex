\section{单选题}

\begin{problem}
设 \(\bs{a}\)，\(\bs{b}\) 是向量，命题“若 \(\bs{a} = -\bs{b}\)，则 \(|\bs{a}| = |\bs{b}|\)”的逆命题是（\quad）

\choices
    {若 \(\bs{a} \neq -\bs{b}\)，则 \(|\bs{a}| \neq |\bs{b}|\)}
    {若 \(\bs{a} = -\bs{b}\)，则 \(|\bs{a}| \neq |\bs{b}|\)}
    {若 \(|\bs{a}| \neq |\bs{b}|\)，则 \(\bs{a} \neq -\bs{b}\)}
    {若 \(|\bs{a}| = |\bs{b}|\)，则 \(\bs{a} = -\bs{b}\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
设原命题的条件为 \(P\)：\(\bs{a}=-\bs{b}\)，结论为 \(Q\)：\(|\bs{a}|=|\bs{b}|\). 逆命题就是把条件和结论互换，即由 \(Q\) 推出 \(P\)：若 \(|\bs{a}|=|\bs{b}|\)，则 \(\bs{a}=-\bs{b}\). 这正是选项 D，故选 D.
\end{solution}

\begin{problem}
设抛物线的顶点在原点，准线方程为 \(x = -2\)，则抛物线的方程是（\quad）

\choices
    {\( y^{2} = -8x \)}
    {\( y^{2} = -4x \)}
    {\( y^{2} = 8x \)}
    {\( y^{2} = 4x \)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
顶点在原点且焦点在 \(x\) 轴上的抛物线可写为 \(y^2=4px\)，其中准线方程为 \(x=-p\). 题设准线为 \(x=-2\)，所以 \(-p=-2\)，从而 \(p=2\). 因此抛物线方程为 \(y^2=8x\)，对应选项 C，故选 C.
\end{solution}

\begin{problem}
设 \(0 < a < b\)，则下列不等式中正确的是（\quad）

\choices
    {\(a < b < \sqrt{ab} < \frac{a + b}{2}\)}
    {\(a < \sqrt{ab} < \frac{a + b}{2} < b\)}
    {\(a < \sqrt{ab} < b < \frac{a + b}{2}\)}
    {\(\sqrt{ab} < a < \frac{a + b}{2} < b\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
由 \(0<a<b\)，并且平方根函数在正数上单调递增，有
\(a^2<ab<b^2\)，\(\Longrightarrow\)，\(a<\sqrt{ab}<b\)
另外，
\[
\frac{a+b}{2}-\sqrt{ab}=\frac{(\sqrt b-\sqrt a)^2}{2}>0
\]
所以 \(\sqrt{ab}<\frac{a+b}{2}\). 又因 \(a<b\)，有 \(\frac{a+b}{2}<b\). 合并得
\[
a<\sqrt{ab}<\frac{a+b}{2}<b
\]
故选 B.
\end{solution}

\begin{problem}
函数 \( y = x^{\frac{1}{3}} \) 的图象是（\quad）

\choices
    {\choicebitmap[width=0.15\paperwidth]{img/2011/shaanxi_liberal/q4_optA_clean.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2011/shaanxi_liberal/q4_optB_clean.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2011/shaanxi_liberal/q4_optC_clean.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2011/shaanxi_liberal/q4_optD_clean.png}}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
函数 \(y=x^{\frac13}\) 的定义域和值域都是 \(\R\)，且是奇函数、严格增函数，经过 \((-1,-1)\)、\((0,0)\)、\((1,1)\). 对 \(x\ne0\)，其导数为
\[
y'=\frac{1}{3x^{\frac23}}>0
\]
当 \(x\) 趋近于 \(0\) 时，\(y'\) 趋于正无穷；当 \(|x|\) 增大时，\(y'\) 变小. 因此图象在原点处较陡，在两端较平缓，并关于原点中心对称. 四个图形中只有第二个图形符合这些特征，故选 B.
\end{solution}

\begin{problem}
某几何体的三视图如图所示，则它的体积是（\quad）

\bitmapfigure[max width=0.42\linewidth]{img/2011/shaanxi_liberal/q5_fig1.png}

\choices
    {\(8 - \frac{2\pi}{3}\)}
    {\(8 - \frac{\pi}{3}\)}
    {\(8 - 2\pi\)}
    {\(\frac{2\pi}{3}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
由正视图和左视图的外轮廓可知外部是棱长为 \(2\) 的正方体；俯视图为直径 \(2\) 的圆，且正、左视图中的虚线表示从这个圆面向另一侧顶点形成的圆锥空腔. 因此该几何体的体积等于正方体体积减去圆锥体积. 正方体体积为
\[
V_{\text{方}}=2^3=8
\]
圆锥底面半径为 \(1\)，高为 \(2\)，所以
\[
V_{\text{锥}}=\frac13\pi\cdot1^2\cdot2=\frac{2\pi}{3}
\]
故几何体体积为
\[
V=8-\frac{2\pi}{3}
\]
对应选项 A，故选 A.
\end{solution}

\begin{problem}
方程 \( |x| = \cos x \) 在 \((- \infty, + \infty)\) 内（\quad）

\choices
    {没有根}
    {有且仅有一个根}
    {有且仅有两个根}
    {有无穷多个根}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
若 \(|x|=\cos x\)，则右端必须非负，且 \(|x|\leqslant1\)，故所有根都在 \([-1,1]\) 内. 先考察 \([0,1]\). 此时 \(|x|=x\)，方程化为 \(x=\cos x\). 令
\[
h(x)=x-\cos x
\]
则 \(h(0)=-1<0\)，\(h(1)=1-\cos1>0\)，所以由连续性知 \([0,1]\) 内至少有一个根；并且
\(h'(x)=1+\sin x>0\)，\((0\leqslant x\leqslant1)\)
故 \(h\) 严格递增，根至多一个. 因此 \([0,1]\) 内恰有一个根，且它不是 \(0\). 方程两边都是偶函数，所以这个正根的相反数也是根；反之，所有负根都对应于该正根. 于是方程恰有两个根，故选 C.
\end{solution}

\begin{problem}
下面的框图中，当 \(x_{1} = 6\)，\(x_{2} = 9\)，\(p = 8.5\) 时，\(x_{3}\) 等于（\quad）

\texfigure[float=inline,max width=0.52\linewidth]{img_repaint/2011/shaanxi_liberal/q7_fig1.tex}
\FloatBarrier

\choices
    {\(7\)}
    {\(8\)}
    {\(10\)}
    {\(11\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
判定框检验的条件是 \(|x_1-x_2|<|x_2-x_3|\). 若条件成立，程序输出
\[
p=\frac{x_1+x_2}{2}=\frac{6+9}{2}=7.5
\]
但题设给出 \(p=8.5\)，二者不相等，所以该条件不成立. 程序应沿“否”分支，输出
\[
p=\frac{x_2+x_3}{2}
\]
代入已知数值得
\(8.5=\frac{9+x_3}{2}\)，\(\Longrightarrow\)，\(x_3=17-9=8\)
此时 \(|x_1-x_2|=3\)，\(|x_2-x_3|=1\)，确实满足“否”分支的条件，故选 B.
\end{solution}

\begin{problem}
设集合 \(M = \{y \mid y = |\cos^2 x - \sin^2 x|, x \in \R\}\)，\(N = \left\{x \mid \left|\frac{x}{\i}\right| < 1,\ \i\text{ 为虚数单位},\ x \in \R\right\}\)，则 \(M \cap N\) 为（\quad）

\choices
    {\((0,1)\)}
    {\((0,1]\)}
    {\([0,1)\)}
    {\([0,1]\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
利用二倍角公式，
\[
\cos^2x-\sin^2x=\cos2x
\]
当 \(x\) 遍历 \(\R\) 时，\(2x\) 也遍历 \(\R\)，所以 \(|\cos2x|\) 的最小值为 \(0\)，最大值为 \(1\)，且中间各值都能取得，从而 \(M=[0,1]\). 对实数 \(x\)，虚数单位满足 \(|\i|=1\)，因此
\[
\left|\frac{x}{\i}\right|=\frac{|x|}{|\i|}=|x|
\]
于是 \(N=\{x\in\R\mid |x|<1\}=(-1,1)\). 最后
\[
M\cap N=[0,1)
\]
故选 C.
\end{solution}

\begin{problem}
设 \((x_{1}, y_{1})\)，\((x_{2}, y_{2})\)，\(\cdots\)，\((x_{n}, y_{n})\) 是变量 \(x\) 和 \(y\) 的 \(n\) 个样本点，直线 \(l\) 是由这些样本点通过最小二乘法得到的线性回归直线（如图），以下结论中正确的是（\quad）

\bitmapfigure[max width=0.36\linewidth]{img/2011/shaanxi_liberal/q9_fig1.png}

\choices
    {直线 \(l\) 过点 \((\overline{x}, \overline{y})\)}
    {\(x\) 和 \(y\) 的相关系数为直线 \(l\) 的斜率}
    {\(x\) 和 \(y\) 的相关系数在 \(0\) 到 \(1\) 之间}
    {当 \(n\) 为偶数时，分布在 \(l\) 两侧的样本点的个数一定相同}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
设最小二乘回归直线为 \(l:y=\hat a+\hat b x\). 正规方程中的截距关系为
\[
\hat a=\overline y-\hat b\,\overline x
\]
因此当 \(x=\overline x\) 时，\(l\) 上的纵坐标为 \(\hat a+\hat b\overline x=\overline y\)，即直线必过 \((\overline x,\overline y)\)，选项 A 正确. 相关系数为
\[
r=\frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}}
\]
而回归直线斜率为 \(\hat b=S_{xy}/S_{xx}\)，二者一般不相等；相关系数的取值范围是 \([-1,1]\)，不一定在 \(0\) 到 \(1\) 之间；样本点在回归直线两侧的个数也不由 \(n\) 的奇偶性决定. 因此正确结论只有 A.
\end{solution}

\begin{problem}
植树节某班 \(20\) 名同学在一段直线公路一侧植树，每人植一棵，相邻两棵树相距 \(10\text{ 米}\)，开始时需将树苗集中放置在某一树坑旁边，现将树坑从 \(1\) 到 \(20\) 依次编号，为使各位同学从各自树坑前来领取树苗所走的路程总和最小，树苗可以放置的两个最佳坑位的编号为（\quad）

\choices
    {\(1\) 和 \(20\)}
    {\(9\) 和 \(10\)}
    {\(9\) 和 \(11\)}
    {\(10\) 和 \(11\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
若把树苗放在第 \(k\) 个坑旁，所有同学取树苗所走的总路程为
\[
S_k=10\sum_{j=1}^{20}|j-k|
\]
把放置点从第 \(k\) 个坑移到第 \(k+1\) 个坑时，第 \(1\) 至第 \(k\) 个坑的同学各多走 \(10\) 米，第 \(k+1\) 至第 \(20\) 个坑的同学各少走 \(10\) 米，所以
\[
S_{k+1}-S_k=10k-10(20-k)=10(2k-20)
\]
当 \(k<10\) 时，\(S_{k+1}<S_k\)；当 \(k=10\) 时，\(S_{k+1}=S_k\)；当 \(k>10\) 时，\(S_{k+1}>S_k\). 因此总路程先减小，在第 \(10\) 个坑和第 \(11\) 个坑处相同达到最小，随后增大. 两个最佳坑位的编号为 \(10\) 和 \(11\)，故选 D.
\end{solution}

\begin{problem}
设函数 \( f(x) = \begin{cases}
\lg x, & x > 0,\\
10^x, & x \leqslant 0.
\end{cases} \) 则 \( f(f(-2)) = \)\fillinblank{}.
\end{problem}

\begin{answer}
\(-2\)
\end{answer}

\begin{solution}
因为 \(-2\leqslant0\)，第一次代入分段函数的下半段，得
\[
f(-2)=10^{-2}>0
\]
这个结果为正数，所以第二次代入时使用上半段 \(f(x)=\lg x\)，从而
\[
f(f(-2))=\lg(10^{-2})=-2
\]
\end{solution}

\begin{problem}
如图，点 \((x, y)\) 在四边形 \(ABCD\) 内部和边界上运动，那么 \(2x - y\) 的最小值为\fillinblank{}.

\bitmapfigure[max width=0.42\linewidth]{img/2011/shaanxi_liberal/q12_fig1.png}
\end{problem}

\begin{answer}
\(1\)
\end{answer}

\begin{solution}
由图可读出四边形的顶点为 \(A(1,1)\)、\(B(\sqrt3,\sqrt2)\)、\(C(\sqrt5,1)\)、\(D(1,0)\). 目标函数 \(2x-y\) 在每条边上都是关于位置参数的一次函数，所以在每条边上的最小值都在端点取得；因此只需比较四个顶点处的值：
\[
2x_A-y_A=2\cdot1-1=1
\]
\[
2x_B-y_B=2\sqrt3-\sqrt2
\]
\(2x_C-y_C=2\sqrt5-1\)，\(2x_D-y_D=2\cdot1-0=2\). 由于 \(2\sqrt3-\sqrt2=\sqrt3+(\sqrt3-\sqrt2)>\sqrt3>1\)，且 \(2\sqrt5-1>1\)，故四个值的最小值为 \(1\).
\end{solution}

\begin{problem}
观察下列等式 \(1 = 1\)，\(2 + 3 + 4 = 9\)，\(3 + 4 + 5 + 6 + 7 = 25\)，\(4 + 5 + 6 + 7 + 8 + 9 + 10 = 49\)，\(\dots\). 照此规律，第五个等式应为\fillinblank{}.
\end{problem}

\begin{answer}
\(5+6+\cdots+13=81\)
\end{answer}

\begin{solution}
第 \(n\) 个等式从 \(n\) 开始，每次加 \(1\)，共有 \(2n-1\) 项，末项为
\[
n+(2n-2)=3n-2
\]
因此第 \(n\) 个等式左边的和为
\[
\frac{n+(3n-2)}{2}(2n-1)=(2n-1)^2
\]
这与题目给出的前四个等式相符. 取 \(n=5\)，共有 \(9\) 项，末项为 \(13\)，所以第五个等式为
\[
5+6+7+8+9+10+11+12+13=81
\]
\end{solution}

\begin{problem}
设 \(n \in \N_{+}\)，一元二次方程 \(x^{2} - 4x + n = 0\) 有整数根的充要条件是 \(n=\)\fillinblank{}.
\end{problem}

\begin{answer}
\(3\) 或 \(4\)
\end{answer}

\begin{solution}
若方程有一个整数根 \(r\)，则由韦达定理，另一个根为 \(4-r\)，也是整数，记为 \(s\). 于是
\(r+s=4\)，\(rs=n\)
又因为 \(n\in\N_+\)，所以 \(rs>0\)；结合 \(r+s=4>0\)，可知 \(r\)，\(s\) 都是正整数. 正整数中和为 \(4\) 的组合只有 \((r,s)=(1,3)\)、\((2,2)\) 及交换次序的情形，因此
\[
n=rs=3\quad\text{或}\quad n=rs=4
\]
反过来，\(n=3\) 时
\[
x^2-4x+3=(x-1)(x-3)
\]
有整数根；\(n=4\) 时
\[
x^2-4x+4=(x-2)^2
\]
也有整数根. 所以充要条件为 \(n=3\) 或 \(n=4\).
\end{solution}

\section{选做题}

\begin{problem}
若不等式 \( |x+1|+|x-2|\geqslant a \) 对任意 \( x\in\R \) 恒成立，则 \(a\) 的取值范围是\fillinblank{}.
\end{problem}

\begin{answer}
\((-\infty,3]\)
\end{answer}

\begin{solution}
由三角不等式，
\[
|x+1|+|x-2|\geqslant |(x+1)-(x-2)|=3
\]
当且仅当 \(x+1\) 与 \(x-2\) 异号或其中一个为零，即 \(-1\leqslant x\leqslant2\) 时取等号. 因此左端对所有实数 \(x\) 的最小值为 \(3\). 要使
\[
|x+1|+|x-2|\geqslant a
\]
对任意 \(x\in\R\) 恒成立，必要且充分条件就是 \(a\leqslant3\). 故 \(a\) 的取值范围为 \((-\infty,3]\).
\end{solution}

\begin{problem}
如图，\( \angle B = \angle D\)，\( AE \perp BC\)，\( \angle ACD = 90^{\circ}\)，且 \(AB = 6\)，\(AC = 4\)，\(AD = 12\)，则 \(AE =\)\fillinblank{}.

\bitmapfigure[max width=0.42\linewidth]{img/2011/shaanxi_liberal/q15_fig1.png}
\end{problem}

\begin{answer}
\(2\)
\end{answer}

\begin{solution}
在直角三角形 \(ACD\) 中，\(\angle ACD=90^\circ\)，所以 \(AD\) 是斜边. 设 \(\angle ADC=\theta\)，由正弦定义有
\[
\sin\theta=\frac{AC}{AD}=\frac{4}{12}=\frac13
\]
题设 \(\angle B=\angle D\)，即 \(\angle ABC=\angle ADC=\theta\)，所以
\[
\sin\angle ABC=\frac13
\]
又因 \(AE\perp BC\)，三角形 \(ABE\) 在 \(E\) 处为直角，且 \(\angle ABE=\angle ABC\). 于是
\[
AE=AB\sin\angle ABE
=6\sin\angle ABC
=6\cdot\frac13=2
\]
故 \(AE=2\).
\end{solution}

\begin{problem}
直角坐标系 \(xOy\) 中，以原点为极点，\(x\) 轴正半轴为极轴建立极坐标系，设点 \(A\)，\(B\) 分别在曲线 \(C_1: \begin{cases}
x = 3 + \cos \theta,\\
y = \sin \theta,
\end{cases}\) （\(\theta\) 为参数）和曲线 \(C_2: \rho = 1\) 上，则 \(|AB|\) 的最小值为\fillinblank{}.
\end{problem}

\begin{answer}
\(1\)
\end{answer}

\begin{solution}
由参数方程
\[
(x-3)^2+y^2=\cos^2\theta+\sin^2\theta=1
\]
可知 \(C_1\) 是圆心为 \((3,0)\)、半径为 \(1\) 的圆. 极坐标方程 \(\rho=1\) 表示圆心为原点、半径为 \(1\) 的圆 \(C_2\). 对任意 \(A\in C_1\)，由三角不等式有
\[
|OA|\geqslant 3-1=2
\]
而任意 \(B\in C_2\) 都满足 \(|OB|=1\)，所以
\[
|AB|\geqslant\bigl||OA|-|OB|\bigr|\geqslant2-1=1
\]
取 \(\theta=\pi\)，得 \(A=(2,0)\)；再取 \(B=(1,0)\)，此时 \(|AB|=1\)，下界可以取得. 因此 \(|AB|\) 的最小值为 \(1\).
\end{solution}

\section{解答题}

\begin{problem}
如图，在 \(\triangle ABC\) 中，\(\angle ABC = 45^{\circ}\)，\(\angle BAC = 90^{\circ}\)，\(AD\) 是 \(BC\) 上的高，沿 \(AD\) 把 \(\triangle ABD\) 折起，使 \(\angle BDC = 90^{\circ}\).

\begin{enumerate}
\item 证明：平面 \(ADB \perp\) 平面 \(BDC\)；
\item 若 \(BD = 1\)，求三棱锥 \(D - ABC\) 的表面积.
\end{enumerate}

\bitmapfigure[max width=0.78\linewidth]{img/2011/shaanxi_liberal/q16_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 折叠前 \(AD\perp BC\)，而 \(DC\subset BC\)，所以 \(AD\perp DC\). 折叠沿 \(AD\) 进行，平面 \(ACD\) 保持不动，故折叠后仍有 \(AD\perp DC\). 三角形 \(ABD\) 的形状在折叠中不变，且折叠前 \(AD\perp BD\)，所以折叠后仍有 \(AD\perp BD\). 题设 \(\angle BDC=90^\circ\)，即 \(BD\perp DC\). 于是 \(DC\) 垂直于平面 \(ADB\) 内相交的两条直线 \(AD\)、\(BD\)，从而 \(DC\perp\) 平面 \(ADB\). 又因为 \(DC\subset\) 平面 \(BDC\)，平面 \(BDC\) 内含有一条垂直于平面 \(ADB\) 的直线，所以平面 \(ADB\perp\) 平面 \(BDC\).
\item 在三角形 \(ABC\) 中，\(\angle BAC=90^\circ\)、\(\angle ABC=45^\circ\)，所以 \(\angle ACB=45^\circ\)，从而 \(AB=AC\). 三角形 \(ABD\)、\(ACD\) 都是直角三角形，斜边分别为 \(AB\)、\(AC\)，且有公共直角边 \(AD\). 由斜边直角边判定，两三角形全等，故 \(BD=DC\). 由 \(BD=1\) 得 \(DC=1\). 又在直角三角形 \(ABD\) 中，\(\angle ABD=\angle ABC=45^\circ\)，所以 \(\angle BAD=45^\circ\)，从而 \(AD=BD=1\). 折叠后 \(AD\)、\(BD\)、\(DC\) 两两垂直，因此
\(AB^2=AD^2+BD^2=2\)、\(AC^2=AD^2+DC^2=2\)、\(BC^2=BD^2+DC^2=2\).
故三角形 \(ABC\) 是边长为 \(\sqrt2\) 的正三角形，其面积为
\[
S_{ABC}=\frac{\sqrt3}{4}(\sqrt2)^2=\frac{\sqrt3}{2}
\]
三个侧面 \(DAB\)、\(DBC\)、\(DCA\) 都是直角边为 \(1\)、\(1\) 的直角三角形，面积均为 \(\frac12\). 所以三棱锥的表面积为
\[
S=S_{ABC}+S_{DAB}+S_{DBC}+S_{DCA}=\frac{\sqrt3}{2}+3\cdot\frac12=\frac{3+\sqrt3}{2}
\]
\end{enumerate}
\end{solution}

\begin{problem}
设椭圆 \(C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)）过点 \((0,4)\)，离心率为 \(\frac{3}{5}\).

\begin{enumerate}
\item 求 \(C\) 的方程；
\item 求过点 \((3,0)\) 且斜率为 \(\frac{4}{5}\) 的直线被 \(C\) 所截线段的中点坐标.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 椭圆过点 \((0,4)\)，代入方程得
\[
\frac{16}{b^2}=1
\]
由于 \(b>0\)，所以 \(b=4\). 设焦半距为 \(c\)，则 \(c^2=a^2-b^2=a^2-16\). 由离心率 \(e=c/a=3/5\)，得 \(c^2=9a^2/25\)，于是
\(a^2-16=\frac{9}{25}a^2\)，\(\Longrightarrow\)，\(\frac{16}{25}a^2=16\)，\(\Longrightarrow\)，\(a^2=25\)
因为 \(a>0\)，所以 \(a=5\). 故椭圆方程为
\[
\frac{x^2}{25}+\frac{y^2}{16}=1
\]
\item 过 \((3,0)\) 且斜率为 \(4/5\) 的直线为
\[
y=\frac45(x-3)
\]
代入椭圆方程，得
\(\frac{x^2}{25}+\frac{\left(\frac45(x-3)\right)^2}{16}=1\)，\(\Longrightarrow\)，\(x^2+(x-3)^2=25\)
即
\[
x^2-3x-8=0
\]
其判别式为 \(9+32=41>0\)，所以直线与椭圆有两个交点. 设两交点横坐标为 \(x_1\)，\(x_2\)，由韦达定理 \(x_1+x_2=3\). 对应纵坐标满足 \(y_i=\frac45(x_i-3)\)，故
\[
y_1+y_2=\frac45(x_1+x_2-6)=\frac45(3-6)=-\frac{12}{5}
\]
因此截线段中点坐标为
\[
\left(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2}\right)=\left(\frac32,-\frac65\right)
\]
\end{enumerate}
\end{solution}

\begin{problem}
叙述并证明余弦定理.
\end{problem}

\begin{solution}
在三角形 \(ABC\) 中，记
\(a=|BC|\)、\(b=|CA|\)、\(c=|AB|\)，
并令 \(A=\angle BAC\)、\(B=\angle CBA\)、\(C=\angle ACB\). 余弦定理为 \(a^2=b^2+c^2-2bc\cos A\)、\(b^2=c^2+a^2-2ca\cos B\)、\(c^2=a^2+b^2-2ab\cos C\).
证明第一式. 建立直角坐标系，取 \(A\) 为原点，\(AB\) 沿 \(x\) 轴正方向，则可设
\(B=(c,0)\)，\(C=(b\cos A,b\sin A)\)
于是
\[
\begin{gathered}
a^2=|BC|^2=(b\cos A-c)^2+(b\sin A)^2\\
=b^2\cos^2A-2bc\cos A+c^2+b^2\sin^2A=b^2+c^2-2bc\cos A
\end{gathered}
\]
其中最后一步使用了 \(\sin^2A+\cos^2A=1\). 再以 \(B\) 为原点、\(BA\) 所在直线为 \(x\) 轴正方向，取
\(A=(c,0)\)，\(C=(a\cos B,a\sin B)\)
则
\[
b^2=|CA|^2=(a\cos B-c)^2+(a\sin B)^2=a^2+c^2-2ac\cos B
\]
最后以 \(C\) 为原点、\(CB\) 所在直线为 \(x\) 轴正方向，取
\(B=(a,0)\)，\(A=(b\cos C,b\sin C)\)
则
\[
c^2=|AB|^2=(b\cos C-a)^2+(b\sin C)^2=a^2+b^2-2ab\cos C
\]
三式均成立，故余弦定理得证.
\end{solution}

\begin{problem}
如图，从点 \(P_{1}(0,0)\) 作 \(x\) 轴的垂线交曲线 \(y = \e^{x}\) 于点 \(Q_{1}(0,1)\)，曲线在 \(Q_{1}\) 点处的切线与 \(x\) 轴交于点 \(P_{2}\)，再从 \(P_{2}\) 作 \(x\) 轴的垂线交曲线于点 \(Q_{2}\)，依次重复上述过程得到一系列点：\(P_{1}\)，\(Q_{1}\)；\(P_{2}\)，\(Q_{2}\)；\(\cdots\)；\(P_{n}\)，\(Q_{n}\)，记 \(P_{k}\) 点的坐标为 \((x_{k}, 0)\)（\(k = 1\)，\(2\)，\(\cdots\)，\(n\)）.

\begin{enumerate}
\item 试求 \(x_{k}\) 与 \(x_{k-1}\) 的关系（\(2 \leqslant k \leqslant n\)）；
\item 求 \( \left|P_{1}Q_{1}\right|+\left|P_{2}Q_{2}\right|+\left|P_{3}Q_{3}\right|+\cdots+\left|P_{n}Q_{n}\right| \).
\end{enumerate}

\bitmapfigure[max width=0.46\linewidth]{img/2011/shaanxi_liberal/q19_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 设 \(P_{k-1}=(x_{k-1},0)\). 因为 \(P_{k-1}\) 的垂线与曲线交于 \(Q_{k-1}\)，所以
\[
Q_{k-1}=(x_{k-1},\e^{x_{k-1}})
\]
函数 \(y=\e^x\) 的导数为 \(y'=\e^x\)，故曲线在 \(Q_{k-1}\) 处的切线方程为
\[
y-\e^{x_{k-1}}=\e^{x_{k-1}}(x-x_{k-1})
\]
该切线与 \(x\) 轴交于 \(P_k=(x_k,0)\). 代入 \(y=0\)，\(x=x_k\)，并利用 \(\e^{x_{k-1}}>0\)，得
\(-\e^{x_{k-1}}=\e^{x_{k-1}}(x_k-x_{k-1})\)，\(\Longrightarrow\)，\(x_k=x_{k-1}-1\)，\(2\leqslant k\leqslant n\)
\item 由 \(x_1=0\) 和递推关系，逐项得到
\[
x_k=x_1-(k-1)=1-k
\]
由于 \(P_kQ_k\) 是竖直线段，且 \(Q_k=(x_k,\e^{x_k})\)，所以
\[
|P_kQ_k|=\e^{x_k}=\e^{1-k}
\]
故所求和为首项 \(1\)、公比 \(\e^{-1}\) 的等比数列前 \(n\) 项和：
\[
\begin{aligned}
\sum_{k=1}^{n}|P_kQ_k|=\sum_{k=1}^{n}\e^{1-k}=1+\e^{-1}+\cdots+\e^{-(n-1)}\\
=\frac{1-\e^{-n}}{1-\e^{-1}}=\frac{\e(1-\e^{-n})}{\e-1}
\end{aligned}
\]
\end{enumerate}
\end{solution}

\begin{problem}
如图，\(A\) 地到火车站共有两条路径 \(L_{1}\) 和 \(L_{2}\)，现随机抽取 \(100\) 位从 \(A\) 地到达火车站的人进行调查，调查结果如下：

\begin{center}
\begin{tabular}{c|ccccc}
\hline
所用时间（分钟） & \(10\sim20\) & \(20\sim30\) & \(30\sim40\) & \(40\sim50\) & \(50\sim60\) \\
\hline
选择 \(L_{1}\) 的人数 & \(6\) & \(12\) & \(18\) & \(12\) & \(12\) \\
选择 \(L_{2}\) 的人数 & \(0\) & \(4\) & \(16\) & \(16\) & \(4\) \\
\hline
\end{tabular}
\end{center}

\begin{enumerate}
\item 试估计 \(40\text{ 分钟}\) 内不能赶到火车站的概率；
\item 分别求通过路径 \(L_{1}\) 和 \(L_{2}\) 所用时间落在上表中各时间段内的频率；
\item 现甲，乙两人分别有 \(40\text{ 分钟}\) 和 \(50\text{ 分钟}\) 时间用于赶往火车站，为了尽最大可能在允许的时间内赶到火车站，试通过计算说明，他们应如何选择各自的路径.
\end{enumerate}

\bitmapfigure[max width=0.44\linewidth]{img/2011/shaanxi_liberal/q20_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 调查总人数为 \(100\). 按表中分组，所用时间超过 \(40\) 分钟的人数为选择 \(L_1\) 的 \(12+12\) 人与选择 \(L_2\) 的 \(16+4\) 人，共
\[
(12+12)+(16+4)=44
\]
所以估计 \(40\) 分钟内不能赶到火车站的概率为
\[
\frac{44}{100}=0.44
\]
\item 选择路径 \(L_1\) 的人数为
\[
6+12+18+12+12=60
\]
所以 \(L_1\) 在五个时间段内的频率依次为 \(\frac6{60}=0.1\)，\(\frac{12}{60}=0.2\)，\(\frac{18}{60}=0.3\)，\(\frac{12}{60}=0.2\)，\(\frac{12}{60}=0.2\).
选择路径 \(L_2\) 的人数为
\[
0+4+16+16+4=40
\]
所以 \(L_2\) 在五个时间段内的频率依次为 \(\frac0{40}=0\)，\(\frac4{40}=0.1\)，\(\frac{16}{40}=0.4\)，\(\frac{16}{40}=0.4\)，\(\frac4{40}=0.1\).
\item 甲有 \(40\) 分钟. 若选 \(L_1\)，在允许时间内到达的人数为 \(6+12+18=36\)，估计概率为
\[
\frac{36}{60}=0.6
\]
若选 \(L_2\)，相应概率为
\[
\frac{0+4+16}{40}=\frac{20}{40}=0.5
\]
因为 \(0.6>0.5\)，甲应选择 \(L_1\). 乙有 \(50\) 分钟，选择 \(L_1\) 时的估计概率为
\[
\frac{6+12+18+12}{60}=\frac{48}{60}=0.8
\]
选择 \(L_2\) 时的估计概率为
\[
\frac{0+4+16+16}{40}=\frac{36}{40}=0.9
\]
因为 \(0.9>0.8\)，乙应选择 \(L_2\).
\end{enumerate}
\end{solution}

\begin{problem}
设 \(f(x) = \ln x\)，\(g(x) = f(x) + f'(x)\).

\begin{enumerate}
\item 求 \(g(x)\) 的单调区间和最小值；
\item 讨论 \(g(x)\) 与 \(g\left(\frac{1}{x}\right)\) 的大小关系；
\item 求 \(a\) 的取值范围，使得 \(g(a) - g(x) < \frac{1}{a}\) 对任意 \(x > 0\) 成立.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 因为 \(f(x)=\ln x\)，所以 \(f'(x)=1/x\)，从而 \(g(x)=\ln x+\frac1x\)，\(x>0\). 求导得 \(g'(x)=\frac1x-\frac1{x^2}=\frac{x-1}{x^2}\). 由于 \(x^2>0\)，当 \(0<x<1\) 时 \(g'(x)<0\)，当 \(x>1\) 时 \(g'(x)>0\). 因此 \(g(x)\) 在 \((0,1)\) 上单调递减，在 \((1,+\infty)\) 上单调递增，最小值在 \(x=1\) 处取得，且 \(g(1)=\ln1+1=1\).
\item 先计算 \(g\left(\frac1x\right)=\ln\frac1x+x=-\ln x+x\). 令 \(h(x)=g(x)-g\left(\frac1x\right)=2\ln x+\frac1x-x\). 则 \(h(1)=0\)，且 \(h'(x)=\frac2x-\frac1{x^2}-1=-\frac{(x-1)^2}{x^2}\leqslant0\). 所以 \(h\) 在 \((0,+\infty)\) 上单调递减. 由 \(h(1)=0\) 可得：当 \(0<x<1\) 时 \(h(x)>0\)，即 \(g(x)>g(1/x)\)；当 \(x=1\) 时二者相等；当 \(x>1\) 时 \(h(x)<0\)，即 \(g(x)<g(1/x)\).
\item 由第（1）问，任意 \(x>0\) 都有 \(g(x)\geqslant1\)，且 \(x=1\) 时取等号. 因此 \(g(a)-g(x)\leqslant g(a)-1\). 要使 \(g(a)-g(x)<1/a\) 对所有 \(x>0\) 成立，必要性由取 \(x=1\) 得出，充分性则由上面的上界得出，所以充要条件为 \(g(a)-1<\frac1a\). 代入 \(g(a)=\ln a+1/a\)，得到 \(\ln a+\frac1a-1<\frac1a\Longleftrightarrow \ln a<1\). 结合定义域 \(a>0\)，可得 \(0<a<\e\).
\end{enumerate}
\end{solution}
