\section{单选题}

\begin{problem}
设 \(\bs{a}\)，\(\bs{b}\) 是向量，命题“若 \(\bs{a} = -\bs{b}\)，则 \(|\bs{a}| = |\bs{b}|\)”的逆命题是（\quad）

\choices
    {若 \(\bs{a} \neq -\bs{b}\)，则 \(|\bs{a}| \neq |\bs{b}|\)}
    {若 \(\bs{a} = -\bs{b}\)，则 \(|\bs{a}| \neq |\bs{b}|\)}
    {若 \(|\bs{a}| \neq |\bs{b}|\)，则 \(\bs{a} \neq -\bs{b}\)}
    {若 \(|\bs{a}| = |\bs{b}|\)，则 \(\bs{a} = -\bs{b}\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
逆命题是将原命题的条件和结论互换，因此由 \(|\bs{a}|=|\bs{b}|\) 推出 \(\bs{a}=-\bs{b}\)，故选 D.
\end{solution}

\begin{problem}
设抛物线的顶点在原点，准线方程为 \(x = -2\)，则抛物线的方程是（\quad）

\choices
    {\( y^{2} = -8x \)}
    {\( y^{2} = -4x \)}
    {\( y^{2} = 8x \)}
    {\( y^{2} = 4x \)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
设抛物线的标准方程为 \(y^2=4px\)，其准线为 \(x=-p\). 由题意 \(-p=-2\)，得 \(p=2\)，所以抛物线方程为 \(y^2=8x\)，故选 C.
\end{solution}

\begin{problem}
设 \(0 < a < b\)，则下列不等式中正确的是（\quad）

\choices
    {\(a < b < \sqrt{ab} < \frac{a + b}{2}\)}
    {\(a < \sqrt{ab} < \frac{a + b}{2} < b\)}
    {\(a < \sqrt{ab} < b < \frac{a + b}{2}\)}
    {\(\sqrt{ab} < a < \frac{a + b}{2} < b\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
因为 \(0<a<b\)，所以由 \(a^2<ab<b^2\) 得 \(a<\sqrt{ab}<b\). 又因为 \(a<b\)，所以 \(a+b<2b\)，从而 \(\frac{a+b}{2}<b\)；由均值不等式，\(\sqrt{ab}<\frac{a+b}{2}\). 因此 \(a<\sqrt{ab}<\frac{a+b}{2}<b\)，故选 B.
\end{solution}

函数 \( y = x^{\frac{1}{3}} \) 的图象是（\quad）

\begin{problem}
某几何体的三视图如图所示，则它的体积是（\quad）

\bitmapfigure[max width=0.42\linewidth]{img/2011/shaanxi_liberal/q5_fig1.png}

\choices
    {\(8 - \frac{2\pi}{3}\)}
    {\(8 - \frac{\pi}{3}\)}
    {\(8 - 2\pi\)}
    {\(\frac{2\pi}{3}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
由三视图可知，该几何体可看作棱长为 \(2\) 的正方体去掉一个底面直径为 \(2\)、高为 \(2\) 的圆锥. 正方体体积为 \(2^3=8\)，圆锥底面半径为 \(1\)，体积为 \(\frac{1}{3}\pi\cdot1^2\cdot2=\frac{2\pi}{3}\). 所以几何体体积为 \(8-\frac{2\pi}{3}\)，故选 A.

\begin{problem}
方程 \( |x| = \cos x \) 在 \((- \infty, + \infty)\) 内（\quad）

\choices
    {没有根}
    {有且仅有一个根}
    {有且仅有两个根}
    {有无穷多个根}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
若 \(|x|=\cos x\)，则 \(|x|\leqslant1\)，所以根只能在 \([-1,1]\) 内. 当 \(x\geqslant0\) 时，方程化为 \(x=\cos x\). 令 \(h(x)=\cos x-x\)，则 \(h(0)=1>0\)，\(h(1)=\cos1-1<0\)，且 \(h'(x)=-\sin x-1<0\)，因此在 \([0,1]\) 内恰有一个根. 又因为方程两边都是偶函数，若正根为 \(x_0\)，则 \(-x_0\) 也是根；且 \(x=0\) 不是根. 所以方程有且仅有两个根，故选 C.
\end{solution}

\begin{problem}
设集合 \(M = \{y \mid y = |\cos^2 x - \sin^2 x|, x \in \R\}\)，\(N = \left\{x \mid \left|\frac{x}{\i}\right| < 1,\ \i\text{ 为虚数单位},\ x \in \R\right\}\)，则 \(M \cap N\) 为（\quad）

\choices
    {\((0,1)\)}
    {\((0,1]\)}
    {\([0,1)\)}
    {\([0,1]\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
因为 \(\cos^2x-\sin^2x=\cos2x\)，所以 \(M=\{y\mid y=|\cos2x|\}=[0,1]\). 对于实数 \(x\)，有 \(\left|\frac{x}{\i}\right|=|x|\)，故 \(N=\{x\in\R\mid |x|<1\}=(-1,1)\). 因此 \(M\cap N=[0,1)\)，故选 C.
\end{solution}

\begin{problem}
设 \((x_{1}, y_{1})\)，\((x_{2}, y_{2})\)，\(\cdots\)，\((x_{n}, y_{n})\) 是变量 \(x\) 和 \(y\) 的 \(n\) 个样本点，直线 \(l\) 是由这些样本点通过最小二乘法得到的线性回归直线（如图），以下结论中正确的是（\quad）

\bitmapfigure[max width=0.36\linewidth]{img/2011/shaanxi_liberal/q9_fig1.png}

\choices
    {直线 \(l\) 过点 \((\overline{x}, \overline{y})\)}
    {\(x\) 和 \(y\) 的相关系数为直线 \(l\) 的斜率}
    {\(x\) 和 \(y\) 的相关系数在 \(0\) 到 \(1\) 之间}
    {当 \(n\) 为偶数时，分布在 \(l\) 两侧的样本点的个数一定相同}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
设线性回归直线为 \(y=\hat a+\hat b x\). 最小二乘法的正规方程给出 \(\overline y=\hat a+\hat b\,\overline x\)，所以直线 \(l\) 必过点 \((\overline x,\overline y)\). 相关系数还含有两个变量的标准差，通常不等于回归直线斜率；它可以为负，也不一定落在 \((0,1)\) 内；样本点在直线两侧的个数也不由 \(n\) 的奇偶性决定. 因此正确结论是 A.
\end{solution}

\begin{problem}
植树节某班 \(20\) 名同学在一段直线公路一侧植树，每人植一棵，相邻两棵树相距 \(10\text{ 米}\)，开始时需将树苗集中放置在某一树坑旁边，现将树坑从 \(1\) 到 \(20\) 依次编号，为使各位同学从各自树坑前来领取树苗所走的路程总和最小，树苗可以放置的两个最佳坑位的编号为（\quad）

\choices
    {\(1\) 和 \(20\)}
    {\(9\) 和 \(10\)}
    {\(9\) 和 \(11\)}
    {\(10\) 和 \(11\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
设树苗放在第 \(k\) 个坑旁，则总路程为 \(10\sum_{j=1}^{20}|j-k|\). 当放置点从第 \(k\) 个坑移到第 \(k+1\) 个坑时，左侧的 \(k\) 棵树距离各减少 \(10\)，右侧的 \(20-k\) 棵树距离各增加 \(10\)，总路程的变化量为 \(10(20-k-k)=10(20-2k)\). 因此当 \(k<10\) 时总路程减少，当 \(k=10\) 时不变，当 \(k>10\) 时增加，最小值在第 \(10\) 和第 \(11\) 个坑处取得，故选 D.
\end{solution}

\section{填空题}

\begin{problem}
设函数 \( f(x) = \begin{cases}
\lg x, & x > 0,\\
10^x, & x \leqslant 0.
\end{cases} \) 则 \( f(f(-2)) = \)\fillinblank{}.
\end{problem}

\begin{answer}
\(-2\)
\end{answer}

\begin{solution}
因为 \(-2\leqslant0\)，所以 \(f(-2)=10^{-2}>0\). 因而再次使用 \(f(x)=\lg x\)，得到 \(f(f(-2))=\lg(10^{-2})=-2\).
\end{solution}

\begin{problem}
如图，点 \((x, y)\) 在四边形 \(ABCD\) 内部和边界上运动，那么 \(2x - y\) 的最小值为\fillinblank{}.

\bitmapfigure[max width=0.42\linewidth]{img/2011/shaanxi_liberal/q12_fig1.png}
\end{problem}

\begin{answer}
\(1\)
\end{answer}

\begin{solution}
目标函数 \(2x-y\) 是线性函数，在四边形的每条边上的最小值都在边的端点取到，因此只需计算四个顶点处的值. 由图中顶点 \(A(1,1)\)，\(B(\sqrt3,\sqrt2)\)，\(C(\sqrt5,1)\)，\(D(1,0)\)，可得 \(2x-y\) 在四点处分别为 \(1\)，\(2\sqrt3-\sqrt2\)，\(2\sqrt5-1\)，\(2\). 其中最小值为 \(1\).

\begin{problem}
观察下列等式 \(1 = 1\)，\(2 + 3 + 4 = 9\)，\(3 + 4 + 5 + 6 + 7 = 25\)，\(4 + 5 + 6 + 7 + 8 + 9 + 10 = 49\)，\(\dots\). 照此规律，第五个等式应为\fillinblank{}.
\end{problem}

\begin{answer}
\(5+6+\cdots+13=81\)
\end{answer}

\begin{solution}
第一个等式有 \(1\) 项，第二个等式有 \(3\) 项，第三个等式有 \(5\) 项，第四个等式有 \(7\) 项；每个等式的项数依次为连续的奇数，且和分别是这些奇数的平方. 所以第五个等式有 \(9\) 项，从 \(5\) 开始到 \(13\) 结束，其和为 \(\frac{(5+13)\times9}{2}=81\). 因此第五个等式为 \(5+6+\cdots+13=81\).
\end{solution}

\begin{problem}
设 \(n \in \N_{+}\)，一元二次方程 \(x^{2} - 4x + n = 0\) 有整数根的充要条件是 \(n=\)\fillinblank{}.
\end{problem}

\begin{answer}
\(3\) 或 \(4\)
\end{answer}

\begin{solution}
设方程的两个整数根为 \(r\)，\(s\). 由韦达定理，\(r+s=4\)，\(rs=n\). 因为 \(n\in\N_+\)，且 \(r+s=4\)，两根只能为 \(1,3\)，\(2,2\) 或交换次序的情形，所以 \(n=3\) 或 \(n=4\). 反过来，\(n=3\) 时方程为 \((x-1)(x-3)=0\)，\(n=4\) 时方程为 \((x-2)^2=0\)，均有整数根. 因此充要条件是 \(n=3\) 或 \(n=4\).
\end{solution}

\section{选做题}

\begin{problem}
若不等式 \( |x+1|+|x-2|\geqslant a \) 对任意 \( x\in\R \) 恒成立，则 \(a\) 的取值范围是\fillinblank{}.
\end{problem}

\begin{answer}
\((-\infty,3]\)
\end{answer}

\begin{solution}
\(|x+1|+|x-2|\) 表示数轴上点 \(x\) 到点 \(-1\) 和点 \(2\) 的距离之和. 由两点间距离不等式，\(|x+1|+|x-2|\geqslant3\)，且当 \(-1\leqslant x\leqslant2\) 时等号成立. 因而不等式对任意 \(x\in\R\) 恒成立，当且仅当 \(a\leqslant3\)，所以 \(a\) 的取值范围为 \((-\infty,3]\).
\end{solution}

\begin{problem}
如图，\( \angle B = \angle D\)，\( AE \perp BC\)，\( \angle ACD = 90^{\circ}\)，且 \(AB = 6\)，\(AC = 4\)，\(AD = 12\)，则 \(AE =\)\fillinblank{}.

\bitmapfigure[max width=0.42\linewidth]{img/2011/shaanxi_liberal/q15_fig1.png}
\end{problem}

\begin{answer}
\(2\)
\end{answer}

\begin{solution}
在直角三角形 \(ACD\) 中，\(\angle ACD=90^{\circ}\)，所以 \(AD\) 是斜边. 设 \(\angle ADC=\theta\)，则由正弦定义，\(\sin\theta=\frac{AC}{AD}=\frac{4}{12}=\frac13\). 题设 \(\angle B=\angle D\)，故 \(\sin\angle ABC=\frac13\). 又因为 \(AE\perp BC\)，在直角三角形 \(ABE\) 中，\(AE=AB\sin\angle ABE=AB\sin\angle ABC=6\times\frac13=2\).
\end{solution}

\begin{problem}
直角坐标系 \(xOy\) 中，以原点为极点，\(x\) 轴正半轴为极轴建立极坐标系，设点 \(A\)，\(B\) 分别在曲线 \(C_1: \begin{cases}
x = 3 + \cos \theta,\\
y = \sin \theta,
\end{cases}\) （\(\theta\) 为参数）和曲线 \(C_2: \rho = 1\) 上，则 \(|AB|\) 的最小值为\fillinblank{}.
\end{problem}

\begin{answer}
\(1\)
\end{answer}

\begin{solution}
参数方程 \(x=3+\cos\theta\)，\(y=\sin\theta\) 表示以 \((3,0)\) 为圆心、半径为 \(1\) 的圆，曲线 \(C_2\colon\rho=1\) 表示以原点为圆心、半径为 \(1\) 的圆. 对任意 \(A\in C_1\)，有 \(|OA|\geqslant3-1=2\)，而 \(|OB|=1\). 由三角形三边关系，\(|AB|\geqslant|OA|-|OB|\geqslant1\). 当 \(A=(2,0)\)（取 \(\theta=\pi\)），\(B=(1,0)\) 时等号成立，所以 \(|AB|\) 的最小值为 \(1\).
\end{solution}

\section{解答题}

\begin{problem}
如图，在 \(\triangle ABC\) 中，\(\angle ABC = 45^{\circ}\)，\(\angle BAC = 90^{\circ}\)，\(AD\) 是 \(BC\) 上的高，沿 \(AD\) 把 \(\triangle ABD\) 折起，使 \(\angle BDC = 90^{\circ}\).

\begin{enumerate}
\item 证明：平面 \(ADB \perp\) 平面 \(BDC\)；
\item 若 \(BD = 1\)，求三棱锥 \(D - ABC\) 的表面积.
\end{enumerate}

\bitmapfigure[max width=0.78\linewidth]{img/2011/shaanxi_liberal/q16_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 折叠前，\(AD\perp BC\)，而 \(DC\) 在直线 \(BC\) 上，所以 \(AD\perp DC\). 折叠沿着 \(AD\) 进行，平面 \(ACD\) 不动，故折叠后仍有 \(AD\perp DC\)；三角形 \(ABD\) 的形状不变，又因为 \(AD\perp BD\)，折叠后仍有 \(AD\perp BD\). 题设 \(\angle BDC=90^{\circ}\)，所以 \(BD\perp DC\). 因此直线 \(DC\) 垂直于平面 \(ADB\) 内相交的两条直线 \(AD\)，\(BD\)，从而 \(DC\perp\) 平面 \(ADB\). 由于 \(DC\) 在平面 \(BDC\) 内，所以平面 \(ADB\perp\) 平面 \(BDC\).
\item 在三角形 \(ABC\) 中，\(\angle BAC=90^{\circ}\)，\(\angle ABC=45^{\circ}\)，故 \(\angle ACB=45^{\circ}\)，从而 \(AB=AC\). 在直角三角形 \(ABD\) 和 \(ACD\) 中，斜边 \(AB=AC\)，且有公共直角边 \(AD\)，所以 \(BD=DC\). 由 \(BD=1\) 得 \(DC=1\). 又因为三角形 \(ABD\) 中 \(\angle ADB=90^{\circ}\)，\(\angle ABD=\angle ABC=45^{\circ}\)，所以 \(\angle BAD=45^{\circ}\)，从而 \(AD=BD=1\). 折叠后，\(AD\)，\(BD\)，\(DC\) 两两垂直，故 \(AB^2=AD^2+BD^2=2\)，\(AC^2=AD^2+DC^2=2\)，\(BC^2=BD^2+DC^2=2\). 所以三角形 \(ABC\) 为边长 \(\sqrt2\) 的正三角形，面积为 \(\frac{\sqrt3}{4}(\sqrt2)^2=\frac{\sqrt3}{2}\). 三个侧面 \(DAB\)，\(DBC\)，\(DCA\) 都是直角边长为 \(1\)，\(1\) 的直角三角形，面积均为 \(\frac12\). 因而三棱锥 \(D-ABC\) 的表面积为 \(\frac{\sqrt3}{2}+3\times\frac12=\frac{3+\sqrt3}{2}\).
\end{enumerate}
\end{solution}

\begin{problem}
设椭圆 \(C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)）过点 \((0,4)\)，离心率为 \(\frac{3}{5}\).

\begin{enumerate}
\item 求 \(C\) 的方程；
\item 求过点 \((3,0)\) 且斜率为 \(\frac{4}{5}\) 的直线被 \(C\) 所截线段的中点坐标.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 因为椭圆过点 \((0,4)\)，代入方程得 \(\frac{16}{b^2}=1\)，所以 \(b=4\). 设焦半距为 \(c\)，则 \(c^2=a^2-b^2\)，且由离心率条件 \(\frac{c}{a}=\frac35\) 得 \(c^2=\frac{9}{25}a^2\). 因而 \(a^2-16=\frac{9}{25}a^2\)，即 \(\frac{16}{25}a^2=16\)，所以 \(a=5\). 所求椭圆方程为 \(\frac{x^2}{25}+\frac{y^2}{16}=1\).
\item 直线方程为 \(y=\frac45(x-3)\). 代入椭圆方程，得 \(\frac{x^2}{25}+\frac{(\frac45(x-3))^2}{16}=1\)，即 \(x^2+(x-3)^2=25\)，整理得 \(x^2-3x-8=0\). 设交点的横坐标为 \(x_1\)，\(x_2\)，则 \(x_1+x_2=3\). 对应纵坐标满足 \(y_i=\frac45(x_i-3)\)，所以 \(y_1+y_2=\frac45(x_1+x_2-6)=-\frac{12}{5}\). 因此截线段的中点坐标为 \(\left(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2}\right)=\left(\frac32,-\frac65\right)\).
\end{enumerate}
\end{solution}

\begin{problem}
叙述并证明余弦定理.
\end{problem}

\begin{solution}
在三角形 \(ABC\) 中，设 \(a=|BC|\)，\(b=|CA|\)，\(c=|AB|\)，则余弦定理为 \(a^2=b^2+c^2-2bc\cos A\)，以及循环得到的两个类似结论 \(b^2=c^2+a^2-2ca\cos B\)，\(c^2=a^2+b^2-2ab\cos C\). 证明如下：建立直角坐标系，取 \(A\) 为原点，\(AB\) 沿 \(x\) 轴正方向，则可设 \(B=(c,0)\)，\(C=(b\cos A,b\sin A)\). 因此 \(a^2=|BC|^2=(b\cos A-c)^2+(b\sin A)^2=b^2\cos^2A-2bc\cos A+c^2+b^2\sin^2A=b^2+c^2-2bc\cos A\). 对顶点 \(B\)，\(C\) 循环使用同样的推导，即得另外两个公式，余弦定理得证.
\end{solution}

如图，从点 \(P_{1}(0,0)\) 作 \(x\) 轴的垂线交曲线 \(y = \e^{x}\) 于点 \(Q_{1}(0,1)\)，曲线在 \(Q_{1}\) 点处的切线与 \(x\) 轴交于点 \(P_{2}\)，再从 \(P_{2}\) 作 \(x\) 轴的垂线交曲线于点 \(Q_{2}\)，依次重复上述过程得到一系列点：\(P_{1}\)，\(Q_{1}\)；\(P_{2}\)，\(Q_{2}\)；\(\cdots\)；\(P_{n}\)，\(Q_{n}\)，记 \(P_{k}\) 点的坐标为 \((x_{k}, 0)\)（\(k = 1\)，\(2\)，\(\cdots\)，\(n\)）.

\begin{solution}
\begin{enumerate}
\item 设 \(P_{k-1}=(x_{k-1},0)\)，则 \(Q_{k-1}=(x_{k-1},\e^{x_{k-1}})\). 曲线 \(y=\e^x\) 在 \(Q_{k-1}\) 处的切线斜率为 \(\e^{x_{k-1}}\)，切线方程为 \(y-\e^{x_{k-1}}=\e^{x_{k-1}}(x-x_{k-1})\). 令 \(y=0\) 求其与 \(x\) 轴的交点，得 \(-\e^{x_{k-1}}=\e^{x_{k-1}}(x_k-x_{k-1})\)，从而 \(x_k=x_{k-1}-1\)，其中 \(2\leqslant k\leqslant n\).
\item 由 \(x_1=0\) 及递推关系，得 \(x_k=1-k\). 因为 \(P_kQ_k\) 垂直于 \(x\) 轴，所以 \(|P_kQ_k|=\e^{x_k}=\e^{1-k}\). 因而 \(|P_1Q_1|+|P_2Q_2|+\cdots+|P_nQ_n|=\sum_{k=1}^{n}\e^{1-k}=1+\e^{-1}+\cdots+\e^{-(n-1)}=\frac{1-\e^{-n}}{1-\e^{-1}}=\frac{\e(1-\e^{-n})}{\e-1}\).
\end{enumerate}
\end{solution}

\begin{problem}
如图，\(A\) 地到火车站共有两条路径 \(L_{1}\) 和 \(L_{2}\)，现随机抽取 \(100\) 位从 \(A\) 地到达火车站的人进行调查，调查结果如下：

\begin{center}
\begin{tabular}{c|ccccc}
\hline
所用时间（分钟） & \(10\sim20\) & \(20\sim30\) & \(30\sim40\) & \(40\sim50\) & \(50\sim60\) \\
\hline
选择 \(L_{1}\) 的人数 & \(6\) & \(12\) & \(18\) & \(12\) & \(12\) \\
选择 \(L_{2}\) 的人数 & \(0\) & \(4\) & \(16\) & \(16\) & \(4\) \\
\hline
\end{tabular}
\end{center}

\begin{enumerate}
\item 试估计 \(40\text{ 分钟}\) 内不能赶到火车站的概率；
\item 分别求通过路径 \(L_{1}\) 和 \(L_{2}\) 所用时间落在上表中各时间段内的频率；
\item 现甲，乙两人分别有 \(40\text{ 分钟}\) 和 \(50\text{ 分钟}\) 时间用于赶往火车站，为了尽最大可能在允许的时间内赶到火车站，试通过计算说明，他们应如何选择各自的路径.
\end{enumerate}

\bitmapfigure[max width=0.44\linewidth]{img/2011/shaanxi_liberal/q20_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 调查总人数为 \(100\)，所用时间超过 \(40\) 分钟的人数为 \((12+12)+(16+4)=44\). 因此估计 \(40\) 分钟内不能赶到火车站的概率为 \(\frac{44}{100}=0.44\).
\item 选择路径 \(L_1\) 的共有 \(6+12+18+12+12=60\) 人，所以各时间段内的频率依次为 \(\frac6{60}=0.1\)，\(\frac{12}{60}=0.2\)，\(\frac{18}{60}=0.3\)，\(\frac{12}{60}=0.2\)，\(\frac{12}{60}=0.2\). 选择路径 \(L_2\) 的共有 \(0+4+16+16+4=40\) 人，所以各时间段内的频率依次为 \(\frac0{40}=0\)，\(\frac4{40}=0.1\)，\(\frac{16}{40}=0.4\)，\(\frac{16}{40}=0.4\)，\(\frac4{40}=0.1\).
\item 甲有 \(40\) 分钟，选择 \(L_1\) 时在允许时间内到达的频率为 \(\frac{6+12+18}{60}=0.6\)，选择 \(L_2\) 时为 \(\frac{0+4+16}{40}=0.5\)，所以甲应选择 \(L_1\). 乙有 \(50\) 分钟，选择 \(L_1\) 时在允许时间内到达的频率为 \(\frac{6+12+18+12}{60}=0.8\)，选择 \(L_2\) 时为 \(\frac{0+4+16+16}{40}=0.9\)，所以乙应选择 \(L_2\).
\end{enumerate}
\end{solution}

\begin{problem}
设 \(f(x) = \ln x\)，\(g(x) = f(x) + f'(x)\).

\begin{enumerate}
\item 求 \(g(x)\) 的单调区间和最小值；
\item 讨论 \(g(x)\) 与 \(g\left(\frac{1}{x}\right)\) 的大小关系；
\item 求 \(a\) 的取值范围，使得 \(g(a) - g(x) < \frac{1}{a}\) 对任意 \(x > 0\) 成立.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 由 \(g(x)=\ln x+\frac1x\)，得 \(g'(x)=\frac1x-\frac1{x^2}=\frac{x-1}{x^2}\). 当 \(0<x<1\) 时，\(g'(x)<0\)，所以 \(g(x)\) 在 \((0,1)\) 上单调递减；当 \(x>1\) 时，\(g'(x)>0\)，所以 \(g(x)\) 在 \((1,+\infty)\) 上单调递增. 因此最小值在 \(x=1\) 处取得，且 \(g(1)=1\).
\item 令 \(h(x)=g(x)-g\left(\frac1x\right)=2\ln x+\frac1x-x\). 则 \(h(1)=0\)，且 \(h'(x)=\frac2x-\frac1{x^2}-1=-\frac{(x-1)^2}{x^2}\leqslant0\). 所以 \(h(x)>0\) 当 \(0<x<1\)，\(h(1)=0\)，\(h(x)<0\) 当 \(x>1\). 即当 \(0<x<1\) 时 \(g(x)>g\left(\frac1x\right)\)，当 \(x=1\) 时二者相等，当 \(x>1\) 时 \(g(x)<g\left(\frac1x\right)\).
\item 由第（1）问，\(g(x)\geqslant1\)，且当 \(x=1\) 时取等号. 因而对任意 \(x>0\)，都有 \(g(a)-g(x)\leqslant g(a)-1\). 所求不等式对任意 \(x>0\) 成立，当且仅当在 \(x=1\) 时也成立，即 \(g(a)-1<\frac1a\). 代入 \(g(a)=\ln a+\frac1a\)，得 \(\ln a<1\). 结合定义域 \(a>0\)，可得 \(0<a<\e\).
\end{enumerate}
\end{solution}
