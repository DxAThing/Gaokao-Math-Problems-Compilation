\section{解答题}
\begin{problem}
解方程：\(4^{x} - 2^{x + 2} - 12 = 0\).
\end{problem}

\begin{solution}
令 \(t = 2^{x}\)，则 \(t > 0\)，原方程化为
\[
t^{2} - 4t - 12 = 0
\]
即 \((t - 6)(t + 2) = 0\). 因为 \(t > 0\)，所以 \(t = 6\)，从而
\[
x = \log_{2}6
\]
故原方程的解为 \(x = \log_{2}6\).
\end{solution}

\begin{problem}
已知 \(\alpha\) 为锐角，且 \(\tan \alpha = \frac{1}{2}\)，求 \(\frac{\sin 2\alpha \cos \alpha - \sin \alpha}{\sin 2\alpha \cos 2\alpha}\) 的值.
\end{problem}

\begin{solution}
由 \(\alpha\) 为锐角且 \(\tan\alpha = \frac{1}{2}\)，得
\[
\sin\alpha = \frac{1}{\sqrt{5}},\qquad \cos\alpha = \frac{2}{\sqrt{5}},\qquad \cos 2\alpha = \frac{1 - \tan^{2}\alpha}{1 + \tan^{2}\alpha} = \frac{3}{5} \ne 0
\]
又
\[
\sin 2\alpha\cos\alpha - \sin\alpha
= 2\sin\alpha\cos^{2}\alpha - \sin\alpha
= \sin\alpha\left(2\cos^{2}\alpha - 1\right)
= \sin\alpha\cos 2\alpha
\]
因此原式
\[
= \frac{\sin\alpha\cos 2\alpha}{\sin 2\alpha\cos 2\alpha}
= \frac{\sin\alpha}{\sin 2\alpha}
= \frac{1}{2\cos\alpha}
= \frac{\sqrt{5}}{4}
\]
\end{solution}

\begin{problem}
设数列 \(\{a_{n}\}\) 是公差不为零的等差数列，\(S_n\) 是数列 \(\{a_{n}\}\) 的前 \(n\) 项和，且 \(S_{1}^{2} = 9S_2\)，\(S_4 = 4S_2\)，求数列 \(\{a_{n}\}\) 的通项公式.
\end{problem}

\begin{solution}
设 \(a_{1} = a\)，公差为 \(d\)，则 \(d \ne 0\)，且
\[
S_{1} = a\quad S_{2} = 2a + d\quad S_{4} = 4a + 6d
\]
由 \(S_{4} = 4S_{2}\)，得
\[
4a + 6d = 4(2a + d)
\]
所以 \(d = 2a\). 因为 \(d \ne 0\)，故 \(a \ne 0\). 再由 \(S_{1}^{2} = 9S_{2}\)，得
\[
a^{2} = 9(2a + d) = 9(2a + 2a) = 36a
\]
于是 \(a = 36\)，从而 \(d = 72\). 因此数列的通项公式为
\[
a_{n} = a + (n - 1)d = 36 + 72(n - 1) = 72n - 36
\]
\end{solution}

\begin{problem}
某村计划建造一个室内面积为 \(800 \mathrm{~m}^{2}\) 的矩形蔬菜温室. 在温室内，沿左、右两侧与后侧内墙各保留 \(1 \mathrm{~m}\) 宽的通道，沿前侧内墙保留 \(3 \mathrm{~m}\) 宽的空地. 当矩形温室的边长各为多少时，蔬菜的种植面积最大，最大种植面积是多少？
\end{problem}

\begin{solution}
设矩形温室沿前、后墙方向的边长为 \(x\mathrm{~m}\)，沿左、右墙方向的边长为 \(y\mathrm{~m}\)，则
\[
xy = 800\quad x > 2\quad y > 4
\]
蔬菜的种植区域在前、后墙方向的长度为 \(x - 2\)，在左、右墙方向的长度为 \(y - 4\)，所以种植面积
\[
T = (x - 2)(y - 4)
\]
由 \(y = \frac{800}{x}\)，得 \(2 < x < 200\)，且
\[
T = (x - 2)\left(\frac{800}{x} - 4\right) = 808 - 4x - \frac{1600}{x}
\]
整理得
\[
T = 648 - \frac{4(x - 20)^{2}}{x} \leqslant 648
\]
当且仅当 \(x = 20\) 时等号成立，此时 \(y = \frac{800}{20} = 40\). 因此，当矩形温室的边长为 \(20\mathrm{~m}\) 和 \(40\mathrm{~m}\) 时，蔬菜的种植面积最大，最大种植面积为 \(648\mathrm{~m}^{2}\).
\end{solution}

\begin{problem}
三棱锥 \(P - ABC\) 中，侧面 \(PAC\) 与底面 \(ABC\) 垂直，\(PA = PB = PC = 3\).
\begin{enumerate}
\item 求证：\(AB \perp BC\)；
\item 设 \(AB = BC = 2\sqrt{3}\)，求 \(AC\) 与平面 \(PBC\) 所成角的大小.
\end{enumerate}

\bitmapfigure[max width=0.42\linewidth]{img/2004/national_paper_3_liberal/q21_fig1.png}
\end{problem}

\begin{solution}
设 \(O\) 为 \(AC\) 的中点. 因为 \(PA = PC\)，所以在等腰三角形 \(PAC\) 中，\(PO \perp AC\). 又因为平面 \(PAC \perp\) 平面 \(ABC\)，且两平面的交线为 \(AC\)，故由二面角的性质得 \(PO \perp\) 平面 \(ABC\).

于是三角形 \(POA\)，\(POB\)，\(POC\) 均为直角三角形. 由 \(PA = PB = PC\) 得
\[
OA^{2} = PA^{2} - PO^{2} = PB^{2} - PO^{2} = OB^{2}\quad OC^{2} = PC^{2} - PO^{2} = OA^{2}
\]
所以 \(OA = OB = OC\). 又 \(O\) 是 \(AC\) 的中点，故 \(AC\) 是三角形 \(ABC\) 的外接圆直径，从而 \(\angle ABC = 90^{\circ}\)，即 \(AB \perp BC\).

在第（2）问中，建立空间直角坐标系，使
\[
B = (0,0,0)\quad A = (2\sqrt{3},0,0)\quad C = (0,2\sqrt{3},0)
\]
此时 \(O = (\sqrt{3},\sqrt{3},0)\). 由 \(PA = 3\) 及 \(OA^{2} = 6\)，得
\[
PO^{2} = PA^{2} - OA^{2} = 9 - 6 = 3
\]
由于 \(PO \perp\) 平面 \(ABC\)，不妨取 \(P = (\sqrt{3},\sqrt{3},\sqrt{3})\)，另一侧的对称情形所得角度相同.

平面 \(PBC\) 上的三个点都满足 \(x-z = 0\)，所以平面 \(PBC\) 的一个法向量为 \(\bs{n} = (1,0,-1)\). 直线 \(AC\) 的一个方向向量为 \(\bs{v} = (-2\sqrt{3},2\sqrt{3},0)\). 设直线 \(AC\) 与平面 \(PBC\) 所成的角为 \(\theta\)，则
\[
\sin\theta = \frac{|\bs{v}\cdot\bs{n}|}{|\bs{v}|\,|\bs{n}|} = \frac{2\sqrt{3}}{2\sqrt{6}\cdot\sqrt{2}} = \frac{1}{2}
\]
因此 \(\theta = 30^{\circ}\).
\end{solution}

\begin{problem}
设椭圆 \(\frac{x^2}{m+1} + y^2 = 1\) 的两个焦点是 \(F_{1}(-c,0)\) 与 \(F_{2}(c,0)\)（\(c > 0\)），且椭圆上存在一点 \(P\)，使得直线 \(PF_{1}\) 与 \(PF_{2}\) 垂直.
\begin{enumerate}
\item 求实数 \(m\) 的取值范围；
\item 设 \(L\) 是相应于焦点 \(F_{2}\) 的准线，直线 \(PF_{2}\) 与 \(L\) 相交于点 \(Q\). 若 \(\left|\frac{QF_2}{PF_2}\right| = 2 - \sqrt{3}\)，求直线 \(PF_{2}\) 的方程.
\end{enumerate}
\end{problem}

\begin{solution}
设 \(P = (x,y)\). 由题意，椭圆的长半轴平方为 \(m + 1\)，短半轴平方为 \(1\)，又焦点在 \(x\) 轴上且 \(c > 0\)，故
\[
m > 0\quad c^{2} = (m + 1) - 1 = m
\]
由 \(PF_{1} \perp PF_{2}\)，得
\[
(x + c,y)\cdot(x - c,y) = x^{2} + y^{2} - c^{2} = 0
\]
即 \(x^{2} + y^{2} = m\). 与椭圆方程联立，消去 \(y^{2}\) 得
\[
\frac{x^{2}}{m + 1} + m - x^{2} = 1
\]
所以
\[
x^{2} = \frac{m^{2} - 1}{m}\quad y^{2} = m - x^{2} = \frac{1}{m}
\]
由于 \(m > 0\)，要使 \(x\) 为实数，必须且只需 \(m^{2} - 1 \geqslant 0\)，即 \(m \geqslant 1\). 对任意 \(m \geqslant 1\)，取上述平方关系对应的实数 \(x,y\)，即可得到满足条件的点 \(P\)，故实数 \(m\) 的取值范围为 \([1,+\infty)\).

相应于焦点 \(F_{2}\) 的准线为 \(L\)，其方程为
\[
x = \frac{m + 1}{c} = \frac{m + 1}{\sqrt{m}}
\]
由 \(x^{2} = m - \frac{1}{m} < m = c^{2}\)，可知 \(x < c\). 设准线与直线 \(PF_{2}\) 的交点为 \(Q\)，则 \(Q\) 在 \(F_{2}\) 的右侧，且同一直线上的距离之比等于相应横坐标差之比，因此
\[
\left|\frac{QF_{2}}{PF_{2}}\right| = \frac{\dfrac{m + 1}{\sqrt{m}} - \sqrt{m}}{\sqrt{m} - x} = \frac{1}{m - \sqrt{m}x}
\]
由题设比值为 \(2 - \sqrt{3}\)，得
\[
m - \sqrt{m}x = \frac{1}{2 - \sqrt{3}} = 2 + \sqrt{3}
\]
从而
\[
x = \frac{m - (2 + \sqrt{3})}{\sqrt{m}}
\]
将其代入 \(x^{2} = \frac{m^{2} - 1}{m}\)，得
\[
\bigl(m - (2 + \sqrt{3})\bigr)^{2} = m^{2} - 1
\]
整理得
\[
2(2 + \sqrt{3})m = (2 + \sqrt{3})^{2} + 1 = 4(2 + \sqrt{3}),
\]
所以 \(m = 2\). 此时
\[
c = \sqrt{2}\quad x = -\sqrt{\frac{3}{2}}\quad y = \pm\frac{1}{\sqrt{2}}
\]
直线 \(PF_{2}\) 的斜率为
\[
\frac{y}{x - \sqrt{2}} = \pm(\sqrt{3} - 2) = \mp(2 - \sqrt{3})
\]
故直线 \(PF_{2}\) 的方程为
\[
y = \pm(2 - \sqrt{3})(x - \sqrt{2})
\]
\end{solution}
