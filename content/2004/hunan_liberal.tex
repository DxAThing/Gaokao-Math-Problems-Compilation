\section{单选题}
\begin{problem}
函数 \( y = \lg \left(1 - \frac{1}{x}\right) \) 的定义域为（\quad）

\choices
    {\(\{x\mid x < 0\}\)}
    {\(\{x\mid x > 1\}\)}
    {\(\{x\mid 0 < x < 1\}\)}
    {\(\{x\mid x < 0\text{或} x > 1\}\)}
\end{problem}

\begin{problem}
设直线 \(ax + by + c = 0\) 的倾斜角为 \(\alpha\)，且 \(\sin \alpha + \cos \alpha = 0\)，则 \(a, b\) 满足（\quad）

\choices
    {\(a + b = 1\)}
    {\(a - b = 1\)}
    {\(a + b = 0\)}
    {\(a - b = 0\)}
\end{problem}

\begin{problem}
设 \( f^{-1}(x) \) 是函数 \( f(x) = \sqrt{x} \) 的反函数，则下列不等式中恒成立的是（\quad）

\choices
    {\(f^{-1}(x)\leqslant 2x - 1\)}
    {\(f^{-1}(x)\leqslant 2x + 1\)}
    {\(f^{-1}(x)\geqslant 2x - 1\)}
    {\(f^{-1}(x)\geqslant 2x + 1\)}
\end{problem}

\begin{problem}
如果双曲线 \(\frac{x^2}{3} - \frac{y^2}{12} = 1\) 上一点 \(P\) 到右焦点的距离等于 \(\sqrt{13}\)，那么点 \(P\) 到右准线的距离是（\quad）

\choices
    {\( \frac{13}{3} \)}
    {13}
    {5}
    {\( \frac{5}{13} \)}
\end{problem}

\begin{problem}
把正方形 \(ABCD\) 沿对角线 \(AC\) 折起，当以 \(A, B, C, D\) 四点为顶点的三棱锥体积最大时，直线 \(BD\) 和平面 \(ABC\) 所成的角的大小为（\quad）

\choices
    {90}
    {60}
    {45}
    {30}
\end{problem}

\begin{problem}
某公司在甲、乙、丙、丁四个地区分别有 150 个、120 个、180 个、150 个销售点，需完成以下两项调查：

\begin{circlelist}
\item 从这 600 个销售点中抽取一个容量为 100 的样本；
\item 在丙地区中有 20 个特大型销售点，要从中抽取 7 个调查其销售收入和售后服务情况。
\end{circlelist}

则完成上述两项调查宜采用的抽样方法依次是（\quad）

\choices
    {分层抽样，系统抽样法}
    {分层抽样法，简单随机抽样法}
    {系统抽样法，分层抽样法}
    {简单随机抽样，分层抽样法}
\end{problem}

\begin{problem}
若 \( f(x) = -x^{2} + 2ax \) 与 \( g(x) = \frac{a}{x + 1} \) 在区间[1,2]上都是减函数，则 \( a \) 的值范围是（\quad）

\choices
    {\((-1,0)\cup (0,1)\)}

\begin{problem}
已知向量 \(\bs{a} = (\cos \theta, \sin \theta)\)，向量 \(\bs{b} = (\sqrt{3}, -1)\)，则 \(\left|2\bs{a} - \bs{b}\right|\) 的最大值，最小值分别是（\quad）

\begin{problem}
农民收入由工资性收入和其它收入两部分构成. 2003年某地区农民人均收入为3150元(其中工资性收入为1800元，其它收入为1350元)，预计该地区自2004年起的5年内，农民的工资性收入将以每年6\%的年增长率增长，其它收入每年增加160元. 根据以上数据，2008年该地区农民人均收入介于（\quad）

\choices
    {4200 元 \textasciitilde{} 4400 元}
    {4400 元 \textasciitilde{} 4600 元}
    {4600 元 \textasciitilde{} 4800 元}
    {4800 元 \textasciitilde{} 5000 元}
\end{problem}

\begin{problem}
设集合 \(U = \{(x, y) \mid x \in \R, y \in \R\}\)，\(A = \{(x, y) \mid 2x - y + m > 0\}\)，\(B = \{(x, y) \mid x + y - n \leqslant 0\}\)，那么点 \(P(2,3) \in A \cap (\complement_U B)\) 的充要条件是（\quad）

\choices
    {\(m > -1, n < 5\)}
    {\(m < -1, n < 5\)}
    {\(m > -1, n > 5\)}
    {\(m < -1, n > 5\)}
\end{problem}

\section{解答题}
\begin{problem}

\end{problem}

\begin{problem}
如图，在底面是菱形的四棱锥 \(P - ABCD\) 中，\(\angle ABC = 60^{\circ}\)，\(PA = AC = a\)，\(PB = PD = \sqrt{2} a\)，点 \(E\) 是 \(PD\) 的中点. (1) 证明: \(PA \perp\) 平面 \(ABCD, PB\parallel\) 平面 \(EAC\); (2) 求以 AC 为棱，EAC 与 DAC 为面的二面角 \( \theta \) 的正切值.
\end{problem}

\begin{problem}
甲、乙、丙三台机床各自独立地加工同一种零件，已知甲机床加工的零件是一等品而乙机床加工的零件不是一等品的概率为 \(\frac{1}{4}\)，乙机床加工的零件是一等品而丙机床加工的零件不是一等品的概率为 \(\frac{1}{12}\)，甲、丙两台机床加工的零件都是一等品的概率为 \(\frac{2}{9}\). (1) 分别求甲、乙、丙三台机床各自加工零件是一等品的概率; (2) 从甲、乙、丙加工的零件中各取一个检验，求至少有一个一等品的概率.
\end{problem}

\begin{problem}
已知数列 \(\{a_{n}\}\) 是首项为 \(a\) 且公比 \(q\) 不等于1的等比数列，\(S_{n}\) 是其前 \(n\) 项的和，且 \(a_{1}, 2a_{7}, 3a_{4}\) 成等差数列. (1) 证明： \( 12S_{3} \) ， \( S_{6} \) ， \( S_{12}-S_{6} \) 成等比数列； (2) 求和 \( T_{n}=a_{1}+2a_{4}+3a_{7}+\cdots+n a_{3n-2} \)
\end{problem}

\begin{problem}
如图，已知曲线 \(C_1: y = x^3 (x \geqslant 0)\) 与曲线 \(C_2: y = -2x^3 + 3x (x \geqslant 0)\) 交于 \(O, A\)，直线 \(x = t (0 < t < 1)\) 与曲线 \(C_1, C_2\) 分别交于 \(B, D\). (1) 写出四边形 ABOD 的面积 S 与 t 的函数关系式 S = f(t); (2) 讨论 \(f(t)\) 的单调性，并求 \(f(t)\) 的最大值.
\end{problem}

\begin{problem}
如图，过抛物线 \(x^{2} = 4y\) 的对称轴上任一点 \(P(0, m) (m > 0)\) 作直线与抛物线交于 \(A\)、\(B\) 两点，点 \(Q\) 是点 \(P\) 关于原点的对称点. (1) 设点 \(P\) 分有向线段 \(\overrightarrow{AB}\) 所成的比为 \(\lambda\). 证明: \(\overrightarrow{QP} \perp (\overrightarrow{QA} - \lambda \overrightarrow{QB})\); (2) 设直线 \(AB\) 的方程是 \(x - 2y + 12 = 0\)，过 \(A, B\) 两点的圆 \(C\) 与抛物线在点 \(A\) 处有共同的切线，求圆 \(C\) 的方程.
\end{problem}
