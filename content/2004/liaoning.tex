\begin{problem}
设全集 \(U = \R\).

\begin{enumerate}
\item 解关于 \(x\) 的不等式 \(|x - 1| + a - 1 > 0\ (a \in \R)\)；
\item 记 \(A\) 为（1）中不等式的解集，集合 \(B = \left\{x \mid \sin \left( \pi x - \frac{\pi}{3} \right) + \sqrt{3} \cos \left( \pi x - \frac{\pi}{3} \right) = 0 \right\}\)，若 \((\complement_U A) \cap B\) 恰有 3 个元素，求 \(a\) 的取值范围.

\begin{problem}
甲方是一农场，乙方是一工厂，由于乙方生产须占用甲方的资源，因此甲方有权向乙方索赔以弥补经济损失并获得一定净收入，在乙方不赔付甲方的情况下，乙方的年利润 \(x\)（元）与年产量 \(t\)（吨）满足函数关系 \(x = 2000\sqrt{t}\). 若乙方每生产一吨产品必须赔付甲方 \(s\) 元（以下称 \(s\) 为赔付价格）.

\begin{enumerate}
\item 将乙方的年利润 \(w\)（元）表示为年产量 \(t\)（吨）的函数，并求出乙方获得最大利润的年产量；
\item 甲方每年受乙方生产影响的经济损失金额 \(y = 0.002t^2\)（元），在乙方按照获得最大利润的产量进行生产的前提下，甲方要在索赔中获得最大净收入，应向乙方要求的赔付价格 \(s\) 是多少.
\end{enumerate}
\end{problem}

\begin{problem}
已知函数 \(f(x)=ax-\frac{3}{2}x^{2}\) 的最大值不大于 \(\frac{1}{6}\)，又当 \(x \in \left[\frac{1}{4}, \frac{1}{2}\right]\) 时，

\(f(x) \ge \frac{1}{8}\).

\begin{enumerate}
\item 求 \(a\) 的值；
\item 设 \(0 < a_1 < \frac{1}{2}\)，\(a_{n+1} = f(a_n)\)，\(n \in \N^*\). 证明 \(a_n < \frac{1}{n+1}\).
\end{enumerate}
\end{problem}

\begin{problem}
已知函数 \(f(x) = \ln(\e^x + a)\)（\(a > 0\)）.

\begin{enumerate}
\item 求函数 \(y = f(x)\) 的反函数 \(y = f^{-1}(x)\) 及 \(f(x)\) 的导数 \(f'(x)\)；
\item 假设对任意 \(x \in [\ln(3a), \ln(4a)]\)，不等式 \(|m - f^{-1}(x)| + \ln(f'(x)) < 0\) 成立，求实数 \(m\) 的取值范围.
\end{enumerate}
\end{problem}
