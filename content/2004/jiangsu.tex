\section{单选题}
\begin{problem}
设集合 \(P = \{1, 2, 3, 4\}\)，\(Q = \{x \mid |x| \leqslant 2, x \in \R\}\)，则 \(P \cap Q\) 等于（\(\quad\)）

\choices
    {\(\{1, 2\}\)}
    {\(\{3,4\}\)}
    {\( \{1\} \)}
    {\(\{-2, -1, 0, 1, 2\}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
由 \(Q=\{x\mid |x|\leqslant2,x\in\R\}\)，可知 \(Q\) 中属于集合 \(P=\{1,2,3,4\}\) 的元素只有 \(1\) 和 \(2\). 因此 \(P\cap Q=\{1,2\}\)，故选 A.
\end{solution}

\begin{problem}
函数 \(y = 2\cos^2 x + 1\)（\(x \in \R\)）的最小正周期为（\(\quad\)）

\choices
    {\( \frac{\pi}{2} \)}
    {\(\pi\)}
    {\(2\pi\)}
    {\(4\pi\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
利用降幂公式，\(y=2\cos^2x+1=1+\cos2x+1=\cos2x+2\). 函数 \(\cos2x\) 的最小正周期为 \(\pi\)，所以原函数的最小正周期也是 \(\pi\)，故选 B.
\end{solution}

\begin{problem}
从 \(4\) 名男生和 \(3\) 名女生中选出 \(4\) 人参加某个座谈会，若这 \(4\) 人中必须既有男生又有女生，则不同的选法共有（\(\quad\)）

\choices
    {\(140\) 种}
    {\(120\) 种}
    {\(35\) 种}
    {\(34\) 种}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
按男生人数分类计数. 选 \(1\) 名男生和 \(3\) 名女生有 \(\mathrm C_4^1\mathrm C_3^3\) 种，选 \(2\) 名男生和 \(2\) 名女生有 \(\mathrm C_4^2\mathrm C_3^2\) 种，选 \(3\) 名男生和 \(1\) 名女生有 \(\mathrm C_4^3\mathrm C_3^1\) 种. 因此不同的选法共有 \(\mathrm C_4^1\mathrm C_3^3+\mathrm C_4^2\mathrm C_3^2+\mathrm C_4^3\mathrm C_3^1=4+18+12=34\) 种，故选 D.
\end{solution}

\begin{problem}
一平面截一球得到直径是 \(6 \mathrm{~cm}\) 的圆面，球心到这个平面的距离是 \(4 \mathrm{~cm}\)，则该球的体积是（\(\quad\)）

\choices
    {\(\frac{100\pi}{3} \mathrm{~cm}^{3}\)}
    {\(\frac{208\pi}{3} \mathrm{~cm}^{3}\)}
    {\(\frac{500\pi}{3} \mathrm{~cm}^{3}\)}
    {\(\frac{416\sqrt{3}\pi}{3} \mathrm{~cm}^{3}\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
设球的半径为 \(R\). 截面圆的半径为 \(3\mathrm{~cm}\)，球心到截面的距离为 \(4\mathrm{~cm}\)，由球心、截面圆心和截面圆上任一点构成直角三角形，得 \(R^2=3^2+4^2=25\)，所以 \(R=5\mathrm{~cm}\). 故球的体积为 \(\dfrac43\pi R^3=\dfrac43\pi\cdot5^3=\dfrac{500\pi}{3}\mathrm{~cm}^3\)，选 C.
\end{solution}

\begin{problem}
若双曲线 \(\frac{x^2}{8} - \frac{y^2}{b^2} = 1\) 的一条准线与抛物线 \(y^2 = 8x\) 的准线重合，则双曲线离心率为（\(\quad\)）

\choices
    {\(\sqrt{2}\)}
    {\(2 \sqrt{2}\)}
    {\(4\)}
    {\(4\sqrt{2}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
双曲线的实半轴长为 \(a=\sqrt8=2\sqrt2\)，其准线方程为 \(x=\pm\dfrac{a}{e}\). 抛物线 \(y^2=8x\) 的准线为 \(x=-2\). 由题意，双曲线的一条准线与此直线重合，所以 \(\dfrac{a}{e}=2\)，从而 \(e=\dfrac{a}{2}=\sqrt2\)，故选 A.
\end{solution}

\begin{problem}
某校为了了解学生的课外阅读情况，随机调查了 \(50\) 名学生，得到他们在某一天各自课外阅读所用时间的数据. 结果用下面的条形图表示. 根据条形图可得这 \(50\) 名学生这一天平均每人的课外阅读时间为（\(\quad\)）

    {\(0.6\text{ 小时}\)}
    {\(0.9\text{ 小时}\)}
    {\(1.0\text{ 小时}\)}
    {\(1.5\text{ 小时}\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
从条形图读得阅读时间为 \(0\)，\(0.5\)，\(1\)，\(1.5\)，\(2\) 小时的学生人数分别为 \(5\)，\(20\)，\(10\)，\(10\)，\(5\)，总人数为 \(50\). 所以平均阅读时间为

\begin{problem}
\((2x + \sqrt{x})^4\) 的展开式中 \(x^3\) 的系数是（\(\quad\)）

\choices
    {\(6\)}
    {\(12\)}
    {\(24\)}
    {\(48\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
在 \((2x+\sqrt{x})^4\) 的展开式中，若取 \(j\) 个因子 \(\sqrt{x}\)，则相应项的次数为 \(4-j+\dfrac j2=4-\dfrac j2\). 令其等于 \(3\)，得 \(j=2\). 因此 \(x^3\) 的系数为 \(\mathrm C_4^2\cdot2^{4-2}=6\cdot4=24\)，故选 C.
\end{solution}

\begin{problem}
若函数 \(y = \log_a (x + b)\)（\(a > 0\)，\(a \neq 1\)）的图象过两点 \((-1,0)\) 和 \((0,1)\)，则（\(\quad\)）

\choices
    {\(a = 2\)，\(b = 2\)}
    {\(a = \sqrt{2}\)，\(b = 2\)}
    {\(a = 2\)，\(b = 1\)}
    {\(a = \sqrt{2}\)，\(b = \sqrt{2}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
将点 \((-1,0)\) 代入得 \(\log_a(b-1)=0\)，所以 \(b-1=1\)，即 \(b=2\). 再将点 \((0,1)\) 代入得 \(\log_a2=1\)，从而 \(a=2\). 故选 A.
\end{solution}

\begin{problem}
将一颗质地均匀的骰子（它是一种各面上分别标有点数 \(1\)，\(2\)，\(3\)，\(4\)，\(5\)，\(6\) 的正方体玩具）先后抛掷 \(3\) 次，至少出现一次 \(6\) 点向上的概率是（\(\quad\)）

\choices
    {\( \frac{5}{216} \)}
    {\( \frac{25}{216} \)}
    {\( \frac{31}{216} \)}
    {\( \frac{91}{216} \)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
每次抛掷不出现 \(6\) 点的概率为 \(\dfrac56\)，连续抛掷 \(3\) 次都不出现 \(6\) 点的概率为 \(\left(\dfrac56\right)^3\). 因此至少出现一次 \(6\) 点向上的概率为
\[
1-\left(\frac56\right)^3=1-\frac{125}{216}=\frac{91}{216},
\]
故选 D.
\end{solution}

\begin{problem}
函数 \( f(x) = x^3 - 3x + 1 \) 在闭区间 \([-3, 0]\) 上的最大值，最小值分别是（\(\quad\)）

\choices
    {\(1\)，\(-1\)}
    {\(1\)，\(-17\)}
    {\(3\)，\(-17\)}
    {\(9\)，\(-19\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
令 \(f(x)=x^3-3x+1\)，则 \(f'(x)=3x^2-3=3(x-1)(x+1)\). 在区间 \([-3,0]\) 内的临界点为 \(x=-1\). 计算端点和临界点处的函数值，得 \(f(-3)=-17\)，\(f(-1)=3\)，\(f(0)=1\). 所以最大值为 \(3\)，最小值为 \(-17\)，故选 C.
\end{solution}

\begin{problem}
设 \(k > 1\)，\(f(x) = k(x - 1)\)（\(x \in \R\)）. 在平面直角坐标系 \(xOy\) 中，函数 \(y = f(x)\) 的图象与 \(x\) 轴交于 \(A\) 点，它的反函数 \(y = f^{-1}(x)\) 的图象与 \(y\) 轴交于 \(B\) 点，并且这两个函数的图象交于 \(P\) 点. 已知四边形 \(OAPB\) 的面积是\(3\)，则 \(k\) 等于（\(\quad\)）

\choices
    {\(3\)}
    {\(\frac{3}{2}\)}
    {\( \frac{4}{3} \)}
    {\(\frac{6}{5}\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
直线 \(y=k(x-1)\) 与 \(x\) 轴交于 \(A=(1,0)\)，其反函数为 \(y=\dfrac{x}{k}+1\)，与 \(y\) 轴交于 \(B=(0,1)\). 联立两条函数图象的方程，得交点
\[
k(x-1)=\frac{x}{k}+1.
\]
解得 \(P=\left(\frac{k}{k-1},\frac{k}{k-1}\right)\).
记 \(t=\dfrac{k}{k-1}\). 四边形 \(OAPB\) 的顶点依次为 \(O=(0,0)\)，\(A=(1,0)\)，\(P=(t,t)\)，\(B=(0,1)\)，其面积为 \(t\). 由题意 \(\dfrac{k}{k-1}=3\)，解得 \(k=\dfrac32\)，故选 B.
\end{solution}

\begin{problem}
设函数 \(f(x) = -\frac{x}{1 + |x|}\)（\(x \in \R\)），区间 \(M = [a, b]\)（\(a < b\)），集合 \(N = \{y \mid y = f(x), x \in M\}\)，则使 \(M = N\) 成立的实数对 \((a, b)\) 有（\(\quad\)）

\choices
    {\(0\) 个}
    {\(1\) 个}
    {\(2\) 个}
    {无数多个}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
函数 \(f(x)=-\dfrac{x}{1+|x|}\) 在 \(\R\) 上连续且严格递减，所以
\(f([a,b])=[f(b),f(a)]\). 若 \(M=N\)，则必须有 \(a=f(b)\)，\(b=f(a)\). 由于 \(a<b\)，这两个等式又说明 \(a<0<b\). 令 \(u=-a>0\)，\(v=b>0\)，则
\[
u=\frac{v}{1+v},\qquad v=\frac{u}{1+u}.
\]
将第二式代入第一式，得 \(u=\dfrac{u}{1+2u}\)，这与 \(u>0\) 矛盾. 因此不存在满足条件的实数对 \((a,b)\)，共有 \(0\) 个，故选 A.
\end{solution}

\section{填空题}
\begin{problem}
二次函数 \(y = ax^{2} + bx + c\)（\(x \in \R\)）的部分对应值如下表：

\begin{center}
\begin{tabular}{|c|c|c|c|c|c|c|c|c|}
\hline
\(x\) & \(-3\) & \(-2\) & \(-1\) & \(0\) & \(1\) & \(2\) & \(3\) & \(4\) \\
\hline
\(y\) & \(6\) & \(0\) & \(-4\) & \(-6\) & \(-6\) & \(-4\) & \(0\) & \(6\) \\
\hline
\end{tabular}
\end{center}

则不等式 \(ax^2 + bx + c > 0\) 的解集是\fillinblank{}.
\end{problem}

\begin{answer}
\(\left\{x \mid x < -2 \text{ 或 } x > 3\right\}\)
\end{answer}

\begin{solution}
由表中 \(y(-2)=y(3)=0\)，二次函数可写为 \(y=a(x+2)(x-3)\). 又由 \(y(0)=-6\) 得 \(-6a=-6\)，所以 \(a=1\). 因此原不等式化为 \((x+2)(x-3)>0\)，其解集为 \(x<-2\) 或 \(x>3\)，即 \(\left\{x\mid x<-2\text{ 或 }x>3\right\}\).
\end{solution}

\begin{problem}
以点 \((1,2)\) 为圆心，与直线 \(4x+3y-35=0\) 相切的圆的方程是\fillinblank{}.
\end{problem}

\begin{answer}
\((x-1)^2+(y-2)^2=25\)
\end{answer}

\begin{solution}
圆心为 \((1,2)\)，圆心到直线 \(4x+3y-35=0\) 的距离就是半径，故
\[
r=\frac{|4\times1+3\times2-35|}{\sqrt{4^2+3^2}}=\frac{25}{5}=5.
\]
因此圆的方程为 \((x-1)^2+(y-2)^2=25\).
\end{solution}

\begin{problem}
设数列 \(\{a_{n}\}\) 的前 \(n\) 项和为 \(S_{n}\)，且 \(S_{n} = \frac{a_{1}(3^{n} - 1)}{2}\)（对于所有 \(n \geqslant 1\)），且 \(a_{4} = 54\)，则 \(a_{1}\) 的数值是\fillinblank{}.
\end{problem}

\begin{answer}
\(2\)
\end{answer}

\begin{solution}
由前 \(n\) 项和的关系，对于 \(n\geqslant2\)，有
\[
a_n=S_n-S_{n-1}=\frac{a_1(3^n-1)-a_1(3^{n-1}-1)}2=a_1 3^{n-1}.
\]
该式对 \(n=1\) 也成立，因此 \(a_4=27a_1=54\)，解得 \(a_1=2\).
\end{solution}

\begin{problem}
平面向量 \(\bs{a}\)，\(\bs{b}\) 中，已知 \(\bs{a} = (4, -3)\)，\(\left|\bs{b}\right| = 1\)，且 \(\bs{a} \cdot \bs{b} = 5\)，则向量 \(\bs{b} =\fillinblank{}\).
\end{problem}

\begin{answer}
\(\left(\frac{4}{5}, -\frac{3}{5}\right)\)
\end{answer}

\begin{solution}
设 \(\bs b=(x,y)\). 因为 \(|\bs a|=\sqrt{4^2+(-3)^2}=5\)，且
\(\bs a\cdot\bs b=5=|\bs a|\,|\bs b|\)，所以柯西不等式取等号，\(\bs b\) 与 \(\bs a\) 同向. 又 \(|\bs b|=1\)，故 \(\bs b=\dfrac{\bs a}{|\bs a|}=\left(\dfrac45,-\dfrac35\right)\).
\end{solution}

\section{解答题}
\begin{problem}
已知 \(0 < \alpha < \frac{\pi}{2}\)，\(\tan \frac{\alpha}{2} + \cot \frac{\alpha}{2} = \frac{5}{2}\)，求 \(\sin \left( \alpha - \frac{\pi}{3} \right)\) 的值.
\end{problem}

\begin{solution}
令 \(t=\tan\dfrac{\alpha}{2}\). 因为 \(0<\dfrac\alpha2<\dfrac\pi4\)，所以 \(0<t<1\)，且题设给出
\[
t+\frac1t=\frac52,\qquad 2t^2-5t+2=0,\qquad (2t-1)(t-2)=0.
\]
结合 \(0<t<1\)，得 \(t=\dfrac12\). 于是
\[
\sin\alpha=\frac{2t}{1+t^2}=\frac45,\qquad \cos\alpha=\frac{1-t^2}{1+t^2}=\frac35.
\]
所以
\[
\sin\left(\alpha-\frac\pi3\right)=\sin\alpha\cos\frac\pi3-\cos\alpha\sin\frac\pi3=\frac25-\frac{3\sqrt3}{10}=\frac{4-3\sqrt3}{10}.
\]
\end{solution}

\begin{problem}
在棱长为 \(4\) 的正方体 \(ABCD - A_{1}B_{1}C_{1}D_{1}\) 中，\(O\) 是正方形 \(A_{1}B_{1}C_{1}D_{1}\) 的中心，点 \(P\) 在棱 \(CC_{1}\) 上，且 \(CC_{1} = 4CP\). 求：

\begin{enumerate}
\item 直线 \(AP\) 与平面 \(BCC_{1}B_{1}\) 所成的角的大小（结果用反三角函数值表示）；
\item 设 \(O\) 点在平面 \(D_{1}AP\) 上的射影是 \(H\)，求证：\(D_{1}H \perp AP\)；
\item 求点 \(P\) 到平面 \(ABD_{1}\) 的距离.
\end{enumerate}

\bitmapfigure[max width=0.42\linewidth]{img/2004/jiangsu/q18_fig1.png}
\end{problem}

\begin{solution}
建立空间直角坐标系，取
\[
A=(0,0,0),\quad B=(4,0,0),\quad C=(4,4,0),\quad D=(0,4,0),
\]
以及
\[
A_1=(0,0,4),\quad B_1=(4,0,4),\quad C_1=(4,4,4),\quad D_1=(0,4,4).
\]
由 \(CC_1=4CP\) 得 \(CP=1\)，所以 \(P=(4,4,1)\)，而正方形 \(A_1B_1C_1D_1\) 的中心为 \(O=(2,2,4)\).

\begin{enumerate}
\item 直线 \(AP\) 的方向向量可取 \(\overrightarrow{AP}=(4,4,1)\)，平面 \(BCC_1B_1\) 的一个法向量为 \(\bs n=(1,0,0)\). 设直线 \(AP\) 与该平面所成的角为 \(\theta\)，则
\[
\sin\theta=\frac{|\overrightarrow{AP}\cdot\bs n|}{|\overrightarrow{AP}|\,|\bs n|}=\frac4{\sqrt{4^2+4^2+1^2}}=\frac4{\sqrt{33}}.
\]
因此 \(\theta=\arcsin\dfrac4{\sqrt{33}}\).

\item 平面 \(D_1AP\) 经过原点 \(A\)，且 \(\overrightarrow{AD_1}=(0,4,4)\)，\(\overrightarrow{AP}=(4,4,1)\). 取其法向量
\[
\bs n=\overrightarrow{AD_1}\times\overrightarrow{AP}=(-12,16,-16),
\]
故平面 \(D_1AP\) 的方程为 \(-3x+4y-4z=0\). 由于 \(H\) 是 \(O\) 在此平面上的射影，利用正交投影公式得
\[
H=O-\frac{\bs n\cdot O}{|\bs n|^2}\bs n=O+\frac{14}{41}(-3,4,-4)=\left(\frac{40}{41},\frac{138}{41},\frac{108}{41}\right).
\]
于是
\[
\overrightarrow{D_1H}=\left(\frac{40}{41},-\frac{26}{41},-\frac{56}{41}\right),\qquad \overrightarrow{AP}\cdot\overrightarrow{D_1H}=\frac{160-104-56}{41}=0.
\]
又 \(D_1H\) 在平面 \(D_1AP\) 内，所以 \(D_1H\perp AP\).

\item 由 \(\overrightarrow{AB}=(4,0,0)\)，\(\overrightarrow{AD_1}=(0,4,4)\)，可取平面 \(ABD_1\) 的法向量为
\[
\overrightarrow{AB}\times\overrightarrow{AD_1}=(0,-16,16).
\]
因此平面 \(ABD_1\) 的方程为 \(z-y=0\). 点 \(P=(4,4,1)\) 到该平面的距离为
\[
\frac{|1-4|}{\sqrt{(-1)^2+1^2}}=\frac3{\sqrt2}=\frac{3\sqrt2}{2}.
\]
\end{enumerate}
\end{solution}

\begin{problem}
制定投资计划时，不仅要考虑可能获得的盈利，而且要考虑可能出现的亏损. 某投资人打算投资甲、乙两个项目. 根据预测，甲、乙项目可能的最大盈利率分别为 \(100\%\) 和 \(50\%\)，可能的最大亏损分别为 \(30\%\) 和 \(10\%\). 投资人计划投资金额不超过 \(10\text{ 万元}\). 要求确保可能的资金亏损不超过 \(1.8\text{ 万元}\). 问投资人对甲、乙两个项目各投资多少万元，才能使可能的盈利最大.
\end{problem}

\begin{solution}
设投资甲、乙两个项目的金额分别为 \(x\) 万元和 \(y\) 万元，则 \(x\geqslant0\)，\(y\geqslant0\)，并且投资总额和最大亏损分别给出
\[
x+y\leqslant10,\qquad 0.3x+0.1y\leqslant1.8.
\]
将第二个不等式乘以 \(10\)，可得约束条件 \(3x+y\leqslant18\). 可能获得的盈利为
\[
z=x+0.5y.
\]
可行域的顶点为 \((0,0)\)，\((0,10)\)，\((6,0)\) 以及两条边界直线 \(x+y=10\)，\(3x+y=18\) 的交点 \((4,6)\). 在这些顶点处，盈利分别为 \(0\)，\(5\)，\(6\)，\(7\) 万元. 因此最大盈利为 \(7\) 万元，在 \((x,y)=(4,6)\) 时取得.

所以投资人应投资甲项目 \(4\) 万元，乙项目 \(6\) 万元.
\end{solution}

\begin{problem}
设无穷等差数列 \(\{a_{n}\}\) 的前 \(n\) 项和为 \(S_{n}\).

\begin{enumerate}
\item 若首项 \(a_1 = \frac{3}{2}\)，公差 \(d = 1\)，求满足 \(S_{k^2} = (S_k)^2\) 的正整数 \(k\)；
\item 求所有的无穷等差数列 \(\{a_{n}\}\)，使得对于一切正整数 \(k\) 都有 \(S_{k^2} = (S_k)^2\) 成立.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 当 \(a_1=\dfrac32\)，\(d=1\) 时，等差数列前 \(n\) 项和为
\[
S_n=\frac n2\bigl(2a_1+(n-1)d\bigr)=\frac{n(n+2)}2.
\]
因此题设条件化为
\[
\frac{k^2(k^2+2)}2=\left(\frac{k(k+2)}2\right)^2.
\]
因为 \(k\) 是正整数，可以约去 \(\dfrac{k^2}{4}\)，得 \(2(k^2+2)=(k+2)^2\)，即 \(k^2-4k=0\). 所以 \(k=0\) 或 \(k=4\)，结合 \(k>0\)，得 \(k=4\).

\item 设等差数列的首项为 \(A\)，公差为 \(D\)，则
\[
S_n=\frac n2\bigl(2A+(n-1)D\bigr).
\]
对于任意正整数 \(k\)，代入题设等式并约去 \(\dfrac{k^2}{4}\)，得
\[
2\bigl(2A+(k^2-1)D\bigr)=\bigl(2A+(k-1)D\bigr)^2.
\]
这是关于 \(k\) 的恒等式. 比较两边关于 \(k\) 的系数，得到
\[
D(D-2)=0,\qquad 2D(2A-D)=0,\qquad 4A-2D=(2A-D)^2.
\]
若 \(D=0\)，则最后一个等式给出 \(A=A^2\)，所以 \(A=0\) 或 \(A=1\). 这得到两个常数数列：\(a_n=0\) 和 \(a_n=1\).

若 \(D=2\)，由第二个等式得 \(A=1\)，且第三个等式自动成立. 这得到数列 \(a_n=1+2(n-1)=2n-1\). 直接验证时，\(S_n=n^2\)，故 \(S_{k^2}=k^4=(S_k)^2\).

所以所有符合条件的无穷等差数列为 \(a_n=0\)，\(a_n=1\)，以及 \(a_n=2n-1\).
\end{enumerate}
\end{solution}

\begin{problem}
已知椭圆的中心在原点，离心率为 \(\frac{1}{2}\). 一个焦点是 \(F(-m,0)\)（\(m\) 是大于 \(0\) 的常数）.

\begin{enumerate}
\item 求椭圆的方程；
\item 设 \(Q\) 是椭圆上的一点，且过点 \(F\)，\(Q\) 的直线 \(l\) 与 \(y\) 轴交于点 \(M\). 若 \(\left|MQ\right| = 2\left|QF\right|\)，求直线 \(l\) 的斜率.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 设椭圆的长半轴为 \(a\)，短半轴为 \(b\)，焦半距为 \(c\). 由焦点 \(F(-m,0)\) 知 \(c=m\)，又离心率为 \(\dfrac12\)，所以 \(\dfrac ca=\dfrac12\)，即 \(a=2m\). 于是
\[
b^2=a^2-c^2=4m^2-m^2=3m^2.
\]
故椭圆方程为 \(\dfrac{x^2}{4m^2}+\dfrac{y^2}{3m^2}=1\).

\item 设直线 \(l\) 的斜率为 \(q\)，用参数表示直线上的点为 \((-m+t,qt)\)，其中 \(t=0\) 对应焦点 \(F\). 直线与 \(y\) 轴交于 \(M=(0,qm)\)，所以
\[
|QF|=|t|\sqrt{1+q^2},\qquad |MQ|=|m-t|\sqrt{1+q^2}.
\]
由 \(|MQ|=2|QF|\)，令 \(u=\dfrac tm\)，得 \(|1-u|=2|u|\)，从而
\[
(1-u)^2=4u^2,\qquad 3u^2+2u-1=0,\qquad u=\frac13\text{ 或 }u=-1.
\]
另一方面，点 \(Q=(-m+t,qt)\) 在椭圆上，代入椭圆方程并用 \(t=um\)，得
\[
\frac{(u-1)^2}{4}+\frac{q^2u^2}{3}=1.
\]
当 \(u=\dfrac13\) 时，得 \(q^2=24\)，所以 \(q=\pm2\sqrt6\)；当 \(u=-1\) 时，得 \(q=0\).

因此直线 \(l\) 的斜率为 \(0\)，\(2\sqrt6\) 或 \(-2\sqrt6\).
\end{enumerate}
\end{solution}

\begin{problem}
已知函数 \(f(x)\)（\(x \in \R\)）满足下列条件：对任意的实数 \(x_1\)，\(x_2\) 都有 \(\lambda(x_1 - x_2)^2 \leqslant (x_1 - x_2)[f(x_1) - f(x_2)]\) 和 \(|f(x_1) - f(x_2)| \leqslant |x_1 - x_2|\). 其中 \(\lambda\) 是大于\(0\)的常数. 设实数 \(a_0\)，\(a\)，\(b\) 满足 \(f(a_0) = 0\) 和 \(b = a - \lambda f(a)\).

\begin{enumerate}
\item 证明：\(\lambda \leqslant 1\)，并且不存在 \(b_0 \neq a_0\)，使得 \(f(b_0) = 0\)；
\item 证明：\((b - a_0)^2\leqslant (1 - \lambda^2)(a - a_0)^2\)；
\item 证明：\([f(b)]^{2}\leqslant(1-\lambda^{2})[f(a)]^{2}\).
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 对任意 \(x_1\ne x_2\)，由两组条件分别得到
\[
\lambda|x_1-x_2|^2\leqslant (x_1-x_2)\bigl(f(x_1)-f(x_2)\bigr)\leqslant |x_1-x_2|^2.
\]
因而 \(\lambda\leqslant1\). 又若存在 \(b_0\ne a_0\) 使得 \(f(b_0)=0=f(a_0)\)，则第一组条件给出 \(\lambda(b_0-a_0)^2\leqslant0\)，这与 \(\lambda>0\) 及 \(b_0\ne a_0\) 矛盾. 因此不存在这样的 \(b_0\).

\item 因为 \(f(a_0)=0\)，且 \(b=a-\lambda f(a)\)，所以
\[
b-a_0=a-a_0-\lambda f(a).
\]
取 \(x_1=a\)，\(x_2=a_0\)，则 \((a-a_0)f(a)\geqslant\lambda(a-a_0)^2\)，且 \(f(a)^2\leqslant(a-a_0)^2\). 于是展开得
\[
(b-a_0)^2=(a-a_0)^2-2\lambda(a-a_0)f(a)+\lambda^2[f(a)]^2.
\]
由上述两个不等式，
\[
(b-a_0)^2\leqslant(a-a_0)^2-2\lambda^2(a-a_0)^2+\lambda^2(a-a_0)^2=(1-\lambda^2)(a-a_0)^2.
\]

\item 令 \(u=f(a)\)，\(v=f(b)-f(a)\). 由 \(b-a=-\lambda u\)，并在第一组条件中取 \(x_1=b\)，\(x_2=a\)，可得
\[
\lambda(b-a)^2\leqslant(b-a)v,\qquad |v|\leqslant|b-a|.
\]
因此 \(uv\leqslant-\lambda^2u^2\)，且 \(v^2\leqslant\lambda^2u^2\). 从而
\[
[f(b)]^2=(u+v)^2=u^2+2uv+v^2\leqslant u^2-2\lambda^2u^2+\lambda^2u^2=(1-\lambda^2)u^2.
\]
代回 \(u=f(a)\)，即得 \([f(b)]^2\leqslant(1-\lambda^2)[f(a)]^2\).
\end{enumerate}
\end{solution}
