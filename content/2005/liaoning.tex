\section{单选题}
\begin{problem}
复数 \(z = \frac{-1 + \i}{1 + \i} - 1\) 在复平面内，\(z\) 所对应的点在（\quad）

\choices
    {第一象限}
    {第二象限}
    {第三象限}
    {第四象限}

\begin{answer}
B
\end{answer}

\begin{solution}
有
\(\frac{-1+\i}{1+\i}=\frac{(-1+\i)(1-\i)}{(1+\i)(1-\i)}=\i\)，
所以 \(z=\i-1=-1+\i\). 该复数的实部为负，虚部为正，故它所对应的点在第二象限，选 B.
\end{solution}
\end{problem}

\begin{problem}
极限 \(\displaystyle\lim_{x \to x_0} f(x)\) 存在是函数 \(f(x)\) 在点 \(x = x_0\) 处连续的（\quad）

\choices
    {充分而不必要的条件}
    {必要而不充分的条件}
    {充要条件}
    {既不充分也不必要的条件}

\begin{answer}
B
\end{answer}

\begin{solution}
若函数 \(f(x)\) 在 \(x_0\) 处连续，则由连续性的定义可知 \(\displaystyle\lim_{x\to x_0}f(x)=f(x_0)\)，因此极限存在是连续的必要条件. 但极限存在不一定连续，例如令 \(f(x)=1\)（\(x\ne x_0\)），\(f(x_0)=0\)，则极限存在而函数在 \(x_0\) 处不连续. 因此极限存在是必要而不充分的条件，选 B.
\end{solution}
\end{problem}

\begin{problem}
设袋中有 \(80\) 个红球，\(20\) 个白球，若从袋中任取 \(10\) 个球，则其中恰有 \(6\) 个红球的概率为（\quad）

\choices
    {\(\frac{\mathrm C_{80}^{4}\cdot \mathrm C_{10}^{6}}{\mathrm C_{100}^{10}}\)}
    {\(\frac{\mathrm C_{80}^{6}\cdot \mathrm C_{10}^{4}}{\mathrm C_{100}^{10}}\)}
    {\(\frac{\mathrm C_{80}^{4}\cdot \mathrm C_{20}^{6}}{\mathrm C_{100}^{10}}\)}
    {\(\frac{\mathrm C_{80}^{6}\cdot \mathrm C_{20}^{4}}{\mathrm C_{100}^{10}}\)}

\begin{answer}
D
\end{answer}

\begin{solution}
从 \(100\) 个球中任取 \(10\) 个球的取法数为 \(\mathrm C_{100}^{10}\). 恰有 \(6\) 个红球时，需从 \(80\) 个红球中取 \(6\) 个，并从 \(20\) 个白球中取 \(4\) 个，故所求概率为
\(\dfrac{\mathrm C_{80}^{6}\mathrm C_{20}^{4}}{\mathrm C_{100}^{10}}\)，
对应选项 D.
\end{solution}
\end{problem}

\begin{problem}
已知 \(m\)，\(n\) 是两条不重合的直线，\(\alpha\)，\(\beta\)，\(\gamma\) 是三个两两不重合的平面，给出下列四个命题：

\begin{circlelist}
\item 若 \(m \perp \alpha\)，\(m \perp \beta\)，则 \(\alpha \parallel \beta\)；
\item 若 \(\alpha \perp \gamma\)，\(\beta \perp \alpha\)，则 \(\alpha \parallel \beta\)；
\item 若 \(m \subset \alpha\)，\(n \subset \beta\)，\(m \parallel n\)，则 \(\alpha \parallel \beta\)；
\item 若 \(m\)，\(n\) 是异面直线，\(m \subset \alpha\)，\(m \parallel \beta\)，\(n \subset \beta\)，\(n \parallel \alpha\)，则 \(\alpha \parallel \beta\).
\end{circlelist}

其中真命题是（\quad）

\choices
    {\circled{1}和\circled{2}}
    {\circled{1}和\circled{3}}
    {\circled{3}和\circled{4}}
    {\circled{1}和\circled{4}}

\begin{answer}
D
\end{answer}

\begin{solution}
命题\(\circled{1}\)正确：同一直线垂直于两个平面时，这两个平面的法线方向均与该直线平行；又因两平面不重合，所以 \(\alpha\parallel\beta\).

命题\(\circled{2}\)不正确. 例如取 \(\alpha:z=0\)、\(\gamma:x=0\)、\(\beta:y=0\)，则 \(\alpha\perp\gamma\)、\(\beta\perp\alpha\)，但 \(\alpha\) 与 \(\beta\) 相交.

命题\(\circled{3}\)不正确. 例如在 \(\alpha:z=0\) 内取 \(m\) 为 \(x\) 轴，在 \(\beta:y=1\) 内取与 \(m\) 平行的直线 \(n\)，则 \(m\parallel n\)，但 \(\alpha\) 与 \(\beta\) 不平行.

命题\(\circled{4}\)正确. 若 \(\alpha\) 与 \(\beta\) 相交，设交线为 \(l\). 由 \(m\subset\alpha\) 且 \(m\parallel\beta\)，得 \(m\parallel l\)；由 \(n\subset\beta\) 且 \(n\parallel\alpha\)，得 \(n\parallel l\). 于是 \(m\parallel n\)，这与 \(m\)，\(n\) 为异面直线矛盾，所以 \(\alpha\parallel\beta\). 因此真命题是\(\circled{1}\)和\(\circled{4}\)，选 D.
\end{solution}
\end{problem}

\begin{problem}
函数 \(y = \ln \left(x + \sqrt{x^2 + 1}\right)\) 的反函数是（\quad）

\choices
    {\(y = \frac{\e^x + \e^{-x}}{2}\)}
    {\(y = -\frac{\e^x + \e^{-x}}{2}\)}
    {\(y = \frac{\e^x - \e^{-x}}{2}\)}
    {\(y = -\frac{\e^x - \e^{-x}}{2}\)}

\begin{answer}
C
\end{answer}

\begin{solution}
设原函数的函数值为 \(y\)，则 \(\e^y=x+\sqrt{x^2+1}\). 由于 \((x+\sqrt{x^2+1})(\sqrt{x^2+1}-x)=1\)，有 \(\e^{-y}=\sqrt{x^2+1}-x\).
两式相减得 \(2x=\e^y-\e^{-y}\)，即 \(x=\dfrac{\e^y-\e^{-y}}2\). 交换 \(x\)，\(y\)，反函数为 \(y=\dfrac{\e^x-\e^{-x}}2\)，选 C.
\end{solution}
\end{problem}

\begin{problem}
若 \(\log_{2a}\frac{1 + a^2}{1 + a} < 0\)，则 \(a\) 的取值范围是（\quad）

\choices
    {\(\left(\frac{1}{2}, +\infty\right)\)}
    {\((1, +\infty)\)}
    {\(\left(\frac{1}{2}, 1\right)\)}
    {\(\left(0, \frac{1}{2}\right)\)}

\begin{answer}
C
\end{answer}

\begin{solution}
对数有意义要求 \(a>0\) 且 \(2a\ne1\). 当 \(a>\frac12\) 时，底数 \(2a>1\)，要使对数小于零，必须有 \(0<\dfrac{1+a^2}{1+a}<1\).
因 \(a>0\)，前一个不等式自动成立；后一个不等式等价于 \(a^2<a\)，即 \(0<a<1\). 因而得到 \(\frac12<a<1\).

当 \(0<a<\frac12\) 时，\(0<2a<1\)，对数小于零要求真数大于 \(1\)，即 \(a^2>a\)，这与 \(0<a<\frac12\) 矛盾. 故取值范围为 \(\left(\frac12,1\right)\)，选 C.
\end{solution}
\end{problem}

\begin{problem}
在 \(\R\) 上定义运算 \(\otimes\)：\(x \otimes y = x(1 - y)\). 若不等式 \((x - a) \otimes (x + a) < 1\) 对任意实数 \(x\) 成立，则（\quad）

\choices
    {\(-1 < a < 1\)}
    {\(0 < a < 2\)}
    {\(-\frac{1}{2} < a < \frac{3}{2}\)}
    {\(-\frac{3}{2} < a < \frac{1}{2}\)}

\begin{answer}
C
\end{answer}

\begin{solution}
由运算定义，
\((x-a)\otimes(x+a)=(x-a)(1-x-a)=-x^2+x+a^2-a\).
因此题设不等式对任意实数 \(x\) 成立，等价于
\(-x^2+x+a^2-a<1\) 对任意 \(x\in\R\).
左侧关于 \(x\) 的最大值在 \(x=\frac12\) 处取得，最大值为 \(\frac14+a^2-a\). 所以
\[
\frac14+a^2-a<1
\Longleftrightarrow
a^2-a-\frac34<0
\Longleftrightarrow
-\frac12<a<\frac32
\]
故选 C.
\end{solution}
\end{problem}

\begin{problem}
若钝角三角形三内角的度数成等差数列，且最大边长与最小边长的比值为 \(m\)，则 \(m\) 的范围是（\quad）

\choices
    {\((1,2)\)}
    {\((2, +\infty)\)}
    {\([3, +\infty)\)}
    {\((3, +\infty)\)}

\begin{answer}
B
\end{answer}

\begin{solution}
设三个内角依次为 \(\frac\pi3-t\)、\(\frac\pi3\)、\(\frac\pi3+t\). 因三角形为钝角三角形，最大角满足 \(\frac\pi3+t>\frac\pi2\)，又必须小于 \(\frac{2\pi}3\)，故
\(\frac\pi6<t<\frac\pi3\).
由正弦定理，最大边与最小边的比值为
\(m=\dfrac{\sin(\frac\pi3+t)}{\sin(\frac\pi3-t)}\).
对 \(m\) 求导得
\(m'(t)=\dfrac{\sin\left(\frac{2\pi}{3}\right)}{\sin^2\left(\frac\pi3-t\right)}>0\).
当 \(t\to\frac\pi6+\) 时，\(m\to\frac1{1/2}=2\)；当 \(t\to\frac\pi3-\) 时，分母趋于 \(0^+\)，故 \(m\to+\infty\). 因而 \(m\in(2,+\infty)\)，选 B.
\end{solution}
\end{problem}

\begin{problem}
若直线 \(2x - y + c = 0\) 按向量 \(\bs{a} = (1, -1)\) 平移后与圆 \(x^{2} + y^{2} = 5\) 相切，则 \(c\) 的值为（\quad）

\choices
    {\(8\) 或 \(-2\)}
    {\(6\) 或 \(-4\)}
    {\(4\) 或 \(-6\)}
    {\(2\) 或 \(-8\)}

\begin{answer}
A
\end{answer}

\begin{solution}
平移后直线上的点 \((x,y)\) 对应于原直线上的点 \((x-1,y+1)\)，所以平移后的直线方程为
\(2(x-1)-(y+1)+c=0\)，
即 \(2x-y+c-3=0\). 该直线与圆 \(x^2+y^2=5\) 相切，当且仅当原点到直线的距离等于圆半径 \(\sqrt5\)，即
\(\frac{|c-3|}{\sqrt5}=\sqrt5\).
所以 \(|c-3|=5\)，得 \(c=8\) 或 \(c=-2\)，选 A.
\end{solution}
\end{problem}

\begin{problem}
已知 \(y = f(x)\) 是定义在 \(\R\) 上的单调函数，实数 \(x_{1} \neq x_{2}\)，\(\lambda \neq -1\)，
\(\alpha = \frac{x_{1} + \lambda x_{2}}{1 + \lambda}\)，\(\beta = \frac{x_{2} + \lambda x_{1}}{1 + \lambda}\).
若 \( |f(x_{1}) - f(x_{2})| < |f(\alpha) - f(\beta)| \)，则（\quad）

\choices
    {\(\lambda < 0\)}
    {\(\lambda = 0\)}
    {\(0 < \lambda < 1\)}
    {\(\lambda \geqslant 1\)}

\begin{answer}
A
\end{answer}

\begin{solution}
不妨设 \(x_1<x_2\). 若 \(\lambda\geqslant0\)，则
有 \(\alpha=\frac1{1+\lambda}x_1+\frac\lambda{1+\lambda}x_2\)，\(\beta=\frac\lambda{1+\lambda}x_1+\frac1{1+\lambda}x_2\)，
所以 \(\alpha\)，\(\beta\in[x_1,x_2]\). 因 \(f\) 单调，区间 \([\alpha,\beta]\) 上的函数值差的绝对值不超过区间 \([x_1,x_2]\) 上端点函数值差，即
\(|f(\alpha)-f(\beta)|\leqslant|f(x_1)-f(x_2)|\)，
与题设矛盾. 因此必须有 \(\lambda<0\)，选 A.
\end{solution}
\end{problem}

\begin{problem}
已知双曲线的中心在原点，离心率为 \(\sqrt{3}\). 若它的一条准线与抛物线 \(y^{2} = 4x\) 的准线重合，则该双曲线与抛物线 \(y^{2} = 4x\) 的交点到原点的距离是（\quad）

\choices
    {\(2\sqrt{3}+\sqrt{6}\)}
    {\(\sqrt{21}\)}
    {\(18+12\sqrt{2}\)}
    {\(21\)}

\begin{answer}
B
\end{answer}

\begin{solution}
抛物线 \(y^2=4x\) 的焦点为 \((1,0)\)，准线为 \(x=-1\). 双曲线的一条准线与其重合，故双曲线为横轴型，设其方程为
\(\frac{x^2}{a^2}-\frac{y^2}{b^2}=1\)，且 \(c^2=a^2+b^2\)，\(\frac ca=\sqrt3\).
双曲线准线为 \(x=\pm\frac ae\)，由 \(\frac ae=1\) 得 \(a=\sqrt3\)，进而 \(c=3\)、\(b^2=6\). 与抛物线联立：
\[
\frac{x^2}{3}-\frac{4x}{6}=1
\Longleftrightarrow
x^2-2x-3=0
\]
解得 \(x=3\) 或 \(x=-1\)，抛物线要求 \(x\geqslant0\)，故交点的横坐标为 \(3\)，且 \(y^2=12\). 交点到原点的距离为
\[
\sqrt{x^2+y^2}=\sqrt{9+12}=\sqrt{21}
\]
选 B.
\end{solution}
\end{problem}

\section{填空题}
\begin{problem}
\(\left(x^{\frac{1}{2}} - 2x^{-\frac{1}{2}}\right)^{n}\) 的展开式中常数项是\fillinblank{}.

\begin{answer}
若 \(n=2k\)（\(k\) 为非负整数），常数项为 \((-2)^k\mathrm C_{2k}^{k}\)；若 \(n\) 为奇数，则无常数项.
\end{answer}

\begin{solution}
展开式的第 \(k+1\) 项为
\[
\mathrm C_n^k\left(x^{\frac{1}{2}}\right)^{n-k}\left(-2x^{-\frac{1}{2}}\right)^k
=\mathrm C_n^k(-2)^k x^{\frac{n-2k}{2}}
\]
要得到常数项，必须有 \(\frac{n-2k}{2}=0\)，即 \(k=\frac n2\). 因此，只有当 \(n=2k\) 为偶数时才有常数项，其系数为 \((-2)^k\mathrm C_{2k}^{k}\)；当 \(n\) 为奇数时不存在满足条件的整数 \(k\)，所以没有常数项.
\end{solution}
\end{problem}

\begin{problem}
如图，正方体的棱长为 \(1\)，\(C\)，\(D\) 分别是两条棱的中点，\(A\)，\(B\)，\(M\) 是顶点，那么点 \(M\) 到截面 \(ABCD\) 的距离是\fillinblank{}.

\bitmapfigure[width=0.42\linewidth]{img/2005/liaoning/q14_fig1.png}

\begin{answer}
\(\frac{2}{3}\)
\end{answer}

\begin{solution}
建立直角坐标系，取 \(A=(0,0,0)\)，令 \(AM\) 方向、底面内从后向前的方向和竖直向上方向分别为三个坐标轴方向，则 \(M=(1,0,0)\)，\(B=(1,1,0)\)，\(D=\left(\frac12,0,1\right)\)，\(C=\left(1,\frac12,1\right)\).
平面 \(ABCD\) 内有
\(\overrightarrow{AB}=(1,1,0)\)，\(\overrightarrow{AD}=\left(\frac12,0,1\right)\).
其法向量可取
\(\overrightarrow{AB}\times\overrightarrow{AD}=\left(1,-1,-\frac12\right)\)，
所以平面 \(ABCD\) 的方程为 \(2x-2y-z=0\). 因而点 \(M\) 到该平面的距离为
\[
\frac{|2\cdot1-2\cdot0-0|}{\sqrt{2^2+(-2)^2+(-1)^2}}
=\frac23
\]
\end{solution}
\end{problem}

\begin{problem}
用 \(1\)，\(2\)，\(3\)，\(4\)，\(5\)，\(6\)，\(7\)，\(8\) 组成没有重复数字的八位数，要求 \(1\) 和 \(2\) 相邻，\(3\) 与 \(4\) 相邻，\(5\) 与 \(6\) 相邻，而 \(7\) 与 \(8\) 不相邻，这样的八位数共有\fillinblank{}个.（用数字作答）

\begin{answer}
576
\end{answer}

\begin{solution}
把相邻的 \(1,2\)、\(3,4\)、\(5,6\) 分别看作三个整体，每个整体内部都有 \(2\) 种排列方式. 先不考虑 \(7,8\) 相邻的限制，五个对象 \((12)\)，\((34)\)，\((56)\)，\(7\)，\(8\)
的排列数为 \(5!\)，故共有 \(5!\cdot2^3\) 种.

其中 \(7,8\) 相邻时，把 \(7,8\) 再看作一个整体，该整体有 \(2\) 种内部排列，四个对象的排列数为 \(4!\cdot2^4\). 因而满足题意的八位数共有
\(5!\cdot2^3-4!\cdot2^4=960-384=576\) 个.
\end{solution}
\end{problem}

\begin{problem}
\(\omega\) 是正实数. 设 \(S_{\omega} = \{\theta \mid f(x) = \cos[\omega(x + \theta)] \text{ 是奇函数}\}\)，若对每个实数 \(a\)，\(S_{\omega} \cap (a, a + 1)\) 的元素不超过 \(2\) 个，且有 \(a\) 使 \(S_{\omega} \cap (a, a + 1)\) 含 \(2\) 个元素，则 \(\omega\) 的取值范围是\fillinblank{}.

\begin{answer}
\(\left(\pi, 2\pi\right]\)
\end{answer}

\begin{solution}
由 \(f(x)=\cos[\omega(x+\theta)]\) 为奇函数，先令 \(x=0\)，得到 \(\cos(\omega\theta)=0\). 反过来，若 \(\cos(\omega\theta)=0\)，则
\(\cos[\omega(-x+\theta)]=-\cos[\omega(x+\theta)]\)，
所以
\[
S_{\omega}=\left\{\frac{\frac{\pi}{2}+k\pi}{\omega}\mid k\in\Z\right\}
\]
相邻两个元素的距离为 \(d=\frac{\pi}{\omega}\). 任意长度为 \(1\) 的开区间中元素不超过两个，当且仅当 \(2d\geqslant1\)；存在某个这样的开区间含有两个元素，当且仅当 \(d<1\). 因而
\(\frac12\leqslant\frac{\pi}{\omega}<1\)，
即 \(\pi<\omega\leqslant2\pi\).
\end{solution}
\end{problem}

\section{解答题}
\begin{problem}
已知三棱锥 \(P-ABC\) 中，\(E\)，\(F\) 分别是 \(AC\)，\(AB\) 的中点，\(\triangle ABC\)，\(\triangle PEF\) 都是正三角形，\(PF \perp AB\).

\begin{enumerate}
\item 证明：\(PC \perp\) 平面 \(PAB\)；
\item 求二面角 \(P-AB-C\) 的平面角的余弦值；
\item 若点 \(P\)，\(A\)，\(B\)，\(C\) 在一个表面积为 \(12\pi\) 的球面上，求 \(\triangle ABC\) 的边长.
\end{enumerate}

\bitmapfigure[width=0.45\linewidth]{img/2005/liaoning/q17_fig1.png}

\begin{solution}
\begin{enumerate}
\item 设正三角形 \(ABC\) 的边长为 \(a\). 由 \(E\) 是 \(AC\) 的中点，且 \(\triangle PEF\) 与 \(\triangle ABC\) 都是正三角形，有
\(PE=EF=\frac a2\)，\(AE=CE=\frac a2\).
因此 \(E\) 到 \(A\)，\(C\)，\(P\) 三点的距离相等，\(E\) 是 \(\triangle APC\) 外接圆的圆心，而 \(AC\) 是该圆的直径，从而 \(\angle APC=90^\circ\)，即 \(AP\perp PC\).

又因为 \(F\) 是正三角形 \(ABC\) 的边 \(AB\) 的中点，所以 \(CF\perp AB\)；题设给出 \(PF\perp AB\). 直线 \(PF\)，\(CF\) 在平面 \(PFC\) 内相交，故 \(AB\perp\) 平面 \(PFC\)，从而 \(PC\perp AB\). 直线 \(AP\)，\(AB\) 是平面 \(PAB\) 内相交的两条直线，且 \(PC\) 同时垂直于它们，所以 \(PC\perp\) 平面 \(PAB\).

\item 因为 \(PF\perp AB\)，\(CF\perp AB\)，所以 \(\angle PFC\) 是二面角 \(P-AB-C\) 的平面角. 又
\(PF=AF=\frac a2\)，\(PF\perp AF\)
故在直角三角形 \(PAF\) 中，
\(PA^2=PF^2+AF^2=\frac{a^2}{2}\).
由第（1）问，\(\triangle APC\) 在 \(P\) 处直角，所以
\[
PC^2=AC^2-PA^2=a^2-\frac{a^2}{2}=\frac{a^2}{2}
\]
正三角形的中线给出 \(CF=\frac{\sqrt3}{2}a\). 在 \(\triangle PFC\) 中应用余弦定理，得
\[
\cos\angle PFC
=\frac{PF^2+CF^2-PC^2}{2PF\cdot CF}
=\frac{\frac{a^2}{4}+\frac{3a^2}{4}-\frac{a^2}{2}}{2\cdot\frac a2\cdot\frac{\sqrt3 a}{2}}
=\frac{\sqrt3}{3}
\]

\item 由 \(BF=AF=\frac a2\) 且 \(PF\perp AB\)，同理可得
\(PB^2=PF^2+BF^2=\frac{a^2}{2}\).
于是 \(PA=PB=PC=\frac{a}{\sqrt2}\). 又
\(PA^2+PB^2=a^2=AB^2\)，

\begin{solution}
\begin{enumerate}
\item 设图中十字形的横、纵两个长方形的长边均为 \(y\)，短边均为 \(x\). 两个长方形的公共部分是边长为 \(x\) 的正方形，所以十字形面积为
\(S=2xy-x^2\).
由图中半径方向形成的直角三角形及圆的直径为 \(1\)，有 \(x=\cos\theta\)，\(y=\sin\theta\). 条件 \(y>x>0\) 给出 \(\frac\pi4<\theta<\frac\pi2\)，故
\(S(\theta)=2\sin\theta\cos\theta-\cos^2\theta\).

\item 对上式求导，得
\(S'(\theta)=2\cos2\theta+\sin2\theta\).
在 \(\frac\pi4<\theta<\frac\pi2\) 内，令 \(S'(\theta)=0\)，则
\(2\cos2\theta+\sin2\theta=0\).

\(\theta=\frac\pi4+\frac12\arccos\frac2{\sqrt5}\).
此时
\[
S=\sin2\theta-\cos^2\theta
=\frac2{\sqrt5}-\frac{1+\cos2\theta}{2}
=\frac2{\sqrt5}-\frac{1-\frac1{\sqrt5}}2
=\frac{\sqrt5-1}{2}
\]
区间端点不属于定义域；当 \(\theta\to\frac\pi4+\) 和 \(\theta\to\frac\pi2-\) 时，面积分别趋于 \(\frac12\) 和 \(0\)，均小于上述驻点处的面积. 又上述驻点唯一且导数由正变负，所以该值为最大面积.
\end{enumerate}
\end{solution}

\begin{problem}
已知函数 \(f(x) = \frac{x+3}{x+1}\)（\(x \ne -1\)）. 设数列 \(\{a_n\}\) 满足 \(a_1 = 1\)，\(a_{n+1} = f(a_n)\)，数列 \(\{b_n\}\) 满足 \(b_n = |a_n - \sqrt{3}|\)，\(S_n = b_1 + b_2 + \cdots + b_n\)（\(n \in \mathbf{N}^*\)）.

\begin{enumerate}
\item 用数学归纳法证明：\(b_n \leqslant \frac{\sqrt{3} - 1}{2^{n-1}}\)；
\item 证明：\(S_n < \frac{2\sqrt{3}}{3}\).
\end{enumerate}

\begin{solution}
\begin{enumerate}
\item 记 \(r=\sqrt3\). 由于
\[
a_{n+1}=\frac{a_n+3}{a_n+1}=1+\frac2{a_n+1}
\]
且 \(a_1=1\)，可归纳得到 \(a_n\geqslant1\) 对一切正整数 \(n\) 成立. 另外，
\(a_{n+1}-r=\dfrac{(1-r)(a_n-r)}{a_n+1}\)，
所以
\[
b_{n+1}=\frac{r-1}{a_n+1}b_n\leqslant\frac{r-1}{2}b_n<\frac12b_n
\]

下面用数学归纳法证明 \(b_n\leqslant\frac{r-1}{2^{n-1}}\). 当 \(n=1\) 时，\(b_1=|1-r|=r-1\)，结论成立. 假设当 \(n=k\) 时结论成立，则
\[
b_{k+1}<\frac12b_k\leqslant\frac12\cdot\frac{r-1}{2^{k-1}}=\frac{r-1}{2^k}
\]
因此结论对 \(k+1\) 也成立，故对一切正整数 \(n\) 成立.

\item 先算得 \(a_2=f(1)=2\). 又因为 \(f(x)=\frac{x+3}{x+1}\) 在 \([\frac53,2]\) 上递减，且
\(f(2)=\frac53\)，\(f\left(\frac53\right)=\frac74\)，
所以由归纳法可得 \(\frac53\leqslant a_n\leqslant2\) 对一切 \(n\geqslant2\) 成立. 对 \(n\geqslant2\)，有
\[
b_{n+1}=\frac{r-1}{a_n+1}b_n\leqslant\frac{3(r-1)}8b_n<\frac13b_n
\]
其中最后一个不等式由 \(\sqrt3<\frac{17}{9}\) 得到. 因而
\(S_n<b_1+b_2\left(1+\frac13+\frac1{3^2}+\cdots\right)\).
又 \(b_1=r-1\)，\(b_2=|2-r|=2-r\)，所以
\(S_n<r-1+\frac32(2-r)=2-\frac r2\).
最后，\(\sqrt3>\frac{12}{7}\)，从而
\(2-\frac r2<\frac{2r}{3}\).
故 \(S_n<\frac{2\sqrt3}{3}\).
\end{enumerate}
\end{solution}
\end{problem}

已知椭圆 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)）的左，右焦点分别是 \(F_1(-c, 0)\)，\(F_2(c, 0)\)，\(Q\) 是椭圆外的动点. 满足 \(\left|\overrightarrow{F_1Q}\right| = 2a\). 点 \(P\) 是线段 \(F_1Q\) 与该椭圆的交点，点 \(T\) 在线段 \(F_2Q\) 上，并且满足 \(\overrightarrow{PT} \cdot \overrightarrow{TF_2} = 0\)，\(\left|\overrightarrow{F_2T}\right| \neq 0\).

\begin{enumerate}
\item 设 \(x\) 为点 \(P\) 的横坐标，证明：\(\left|\overrightarrow{F_1P}\right| = a + \frac{c}{a}x\)；
\item 求点 \(T\) 的轨迹 \(C\) 的方程；
\item 试问：在点 \(T\) 的轨迹 \(C\) 上，是否存在点 \(M\)，使 \(\triangle F_1MF_2\) 的面积 \(S = b^2\). 若存在，求 \(\angle F_1MF_2\) 的正切值；若不存在，请说明理由.
\end{enumerate}

\begin{solution}
\begin{enumerate}
\item 设 \(P=(x,y)\). 由椭圆方程及 \(a^2=b^2+c^2\)，有
\[
\left|\overrightarrow{F_1P}\right|^2=(x+c)^2+y^2=(x+c)^2+b^2\left(1-\frac{x^2}{a^2}\right)
\]
又因 \(a^2=b^2+c^2\)，所以
\[
\left|\overrightarrow{F_1P}\right|^2=a^2+2cx+\frac{c^2}{a^2}x^2=\left(a+\frac ca x\right)^2
\]
椭圆上 \(-a\leqslant x\leqslant a\)，而 \(a+\frac ca x\geqslant a-c>0\)，故
\(\left|\overrightarrow{F_1P}\right|=a+\frac ca x\).

\item 由椭圆的定义，\(PF_1+PF_2=2a\). 又题设 \(F_1Q=2a\)，且 \(P\) 在线段 \(F_1Q\) 上，所以
\[
PQ=F_1Q-F_1P=2a-PF_1=PF_2
\]
若 \(P\ne T\)，则因 \(\left|\overrightarrow{F_2T}\right|\ne0\) 且 \(\overrightarrow{PT}\cdot\overrightarrow{TF_2}=0\)，有 \(PT\perp TF_2\). 在等腰三角形 \(QPF_2\) 中，\(PT\) 是底边 \(QF_2\) 上的高，所以 \(T\) 是 \(QF_2\) 的中点. 若 \(P=T\)，则 \(P\) 在 \(QF_2\) 上，且 \(PQ=PF_2\)，所以 \(P=T\) 仍是 \(QF_2\) 的中点. 因而无论哪种情形，\(T\) 都是 \(QF_2\) 的中点.

设 \(T=(u,v)\)，\(Q=(X,Y)\). 因为 \(T\) 是 \(QF_2\) 的中点，
\(u=\frac{X+c}{2}\)，\(v=\frac Y2\).
而 \(F_1Q=2a\) 给出 \((X+c)^2+Y^2=4a^2\)，于是
\[
u^2+v^2=\frac{(X+c)^2+Y^2}{4}=a^2
\]
因此点 \(T\) 的轨迹包含在圆 \(x^2+y^2=a^2\) 上.

反过来，任取圆 \(u^2+v^2=a^2\) 上的点 \(T=(u,v)\)，令 \(Q=(2u-c,2v)\). 则 \(F_1Q=2a\). 又因为椭圆包含在圆 \(x^2+y^2\leqslant a^2\) 内，且 \(F_1\) 到该圆内任一点的距离不超过 \(a+c<2a\)，所以 \(Q\) 在椭圆外；而 \(F_1\) 在椭圆内部，故线段 \(F_1Q\) 与椭圆相交于一点 \(P\). 由前面的等式 \(PQ=PF_2\)，三角形 \(QPF_2\) 为等腰三角形，且 \(T\) 是其底边 \(QF_2\) 的中点，因此 \(T\) 满足题设条件. 另外，\(|F_2T|\ne0\)，因为 \(|F_2|=c<a=|OT|\). 所以圆上每一点都能取得，轨迹方程为
\(C:\ x^2+y^2=a^2\).

\item 设 \(M=(x_0,y_0)\) 在轨迹 \(C\) 上. 三角形 \(F_1MF_2\) 的底边为 \(2c\)，故
\(S=\frac12\cdot2c\cdot|y_0|=c|y_0|\). 条件 \(S=b^2\) 等价于 \(|y_0|=\frac{b^2}{c}\). 因为 \(M\in C\) 时 \(|y_0|\leqslant a\)，所以存在这样的点 \(M\) 的充要条件是 \(a\geqslant\frac{b^2}{c}\).
若 \(a<\frac{b^2}{c}\)，则圆 \(C\) 上任意点的三角形面积都小于 \(b^2\)，不存在这样的点 \(M\). 当 \(a\geqslant\frac{b^2}{c}\) 时，取圆 \(C\) 上满足 \(|y_0|=\frac{b^2}{c}\) 的点 \(M\)，下面求其角度.

\[
\overrightarrow{MF_1}\cdot\overrightarrow{MF_2}
=(-c-x_0,-y_0)\cdot(c-x_0,-y_0)
=x_0^2+y_0^2-c^2
=a^2-c^2=b^2
\]
另一方面，\(\overrightarrow{MF_1}\) 与 \(\overrightarrow{MF_2}\) 的夹角就是 \(\angle F_1MF_2\)，所以
\[
\tan\angle F_1MF_2
=\frac{2S}{\overrightarrow{MF_1}\cdot\overrightarrow{MF_2}}
=\frac{2b^2}{b^2}=2
\]
\end{enumerate}
\end{solution}

\begin{problem}
函数 \(y = f(x)\) 在区间 \((0, +\infty)\) 内可导，导函数 \(f'(x)\) 是减函数，且 \(f'(x) > 0\). 设 \(x_0 \in (0, +\infty)\)，\(y = kx + m\) 是曲线 \(y = f(x)\) 在点 \((x_0, f(x_0))\) 处的切线方程，并设函数 \(g(x) = kx + m\).

\begin{enumerate}
\item 用 \(x_0\)，\(f(x_0)\)，\(f'(x_0)\) 表示 \(m\)；
\item 证明：当 \(x_0 \in (0, +\infty)\)，\(g(x) \geqslant f(x)\)；
\item 若关于 \(x\) 的不等式 \(x^{2} + 1 \geqslant ax + b \geqslant \frac{3}{2}x^{\frac{2}{3}}\) 在 \([0, +\infty)\) 上恒成立. 其中 \(a\)，\(b\) 为实数，求 \(b\) 的取值范围及 \(a\) 与 \(b\) 所满足的关系.
\end{enumerate}

\begin{solution}
\begin{enumerate}
\item 切线斜率为 \(k=f'(x_0)\)，又切线经过 \((x_0,f(x_0))\)，所以
\(f(x_0)=kx_0+m=f'(x_0)x_0+m\)，
从而 \(m=f(x_0)-x_0f'(x_0)\).

\item 当 \(x>x_0\) 时，由拉格朗日中值定理，存在 \(\xi\in(x_0,x)\)，使得
\(f(x)-f(x_0)=f'(\xi)(x-x_0)\).
由于 \(f'\) 是减函数，\(f'(\xi)\leqslant f'(x_0)\)，故
\(f(x)-f(x_0)\leqslant f'(x_0)(x-x_0)=g(x)-f(x_0)\).
于是 \(f(x)\leqslant g(x)\). 当 \(0<x<x_0\) 时，仍由中值定理存在 \(\xi\in(x,x_0)\)，且 \(f'(\xi)\geqslant f'(x_0)\). 因为 \(x-x_0<0\)，所以
\(f(x)-f(x_0)=f'(\xi)(x-x_0)\leqslant f'(x_0)(x-x_0)=g(x)-f(x_0)\).
因此对任意 \(x>0\)，都有 \(g(x)\geqslant f(x)\).

\item 要使下方不等式对所有 \(x\geqslant0\) 成立，先注意到 \(a\) 必须为正数；否则当 \(x\to+\infty\) 时，\(ax+b\) 不可能始终不小于 \(\frac32x^{2/3}\). 由 \(x=0\) 处的下方不等式还知 \(b\geqslant0\). 对函数 \(h(x)=\frac32x^{2/3}\)（\(x>0\)），有
\(h'(x)=x^{-1/3}\)，\(h''(x)=-\frac13x^{-4/3}<0\)，所以 \(h'(x)\) 是减函数. 斜率为 \(a>0\) 的切线接触点满足 \(x_0^{-1/3}=a\)，即 \(x_0=a^{-3}\)，该切线的截距为
\[
h(x_0)-ax_0=\frac32a^{-2}-a\cdot a^{-3}=\frac1{2a^2}
\]
由第（2）问，切线在曲线 \(y=h(x)\) 的上方；反过来，函数 \(h(x)-ax\) 在 \(x>0\) 上的导数为 \(x^{-1/3}-a\)，先正后负，故其最大值也在 \(x=a^{-3}\) 处取得；并且在 \(x=0\) 处该函数值为 \(0\). 所以
\(ax+b\geqslant\frac32x^{2/3}\)（\(x\geqslant0\)）当且仅当 \(b\geqslant\frac1{2a^2}\).

上方不等式等价于
\(x^2-ax+1-b\geqslant0\)（\(x\geqslant0\)）.
由 \(x=0\) 处的上方不等式得 \(b\leqslant1\). 因为 \(a>0\)，左侧二次函数在非负半轴上的最小值出现在 \(x=\frac a2\)，所以这又等价于
\(1-b-\frac{a^2}{4}\geqslant0\)，即 \(a\leqslant2\sqrt{1-b}\).
综合两侧条件，得到
\(\frac1{\sqrt{2b}}\leqslant a\leqslant2\sqrt{1-b}\).
要使这个区间非空，必须且只需
\(\frac1{\sqrt{2b}}\leqslant2\sqrt{1-b}\Longleftrightarrow 8b(1-b)\geqslant1\)，
即
\(\frac{2-\sqrt2}{4}\leqslant b\leqslant\frac{2+\sqrt2}{4}\).
\end{enumerate}
\end{solution}
\end{problem}
