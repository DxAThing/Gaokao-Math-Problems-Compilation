\section{单选题}
\begin{problem}
设 \(P\)，\(Q\) 为两个非空实数集合，定义集合 \(P + Q = \{a + b \mid a \in P, b \in Q\}\)，若 \(P = \{0, 2, 5\}\)，\(Q = \{1, 2, 6\}\)，则 \(P + Q\) 中元素的个数是（\quad）

\choices
    {\(9\)}
    {\(8\)}
    {\(7\)}
    {\(6\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
逐一计算两集合中元素的和，得到
\[
P+Q=\{1,2,6,3,4,8,6,7,11\}=\{1,2,3,4,6,7,8,11\}.
\]
因此，集合 \(P+Q\) 中有 \(8\) 个元素，故选 B.
\end{solution}

\begin{problem}
对任意实数 \(a\)，\(b\)，\(c\) 给出下列命题：

\begin{circlelist}
\item “\(a = b\)”是“\(ac = bc\)”充要条件；
\item “\(a + 5\) 是无理数”是“\(a\) 是无理数”的充要条件；
\item “\(a > b\)”是“\(a^{2} > b^{2}\)”的充分条件；
\item “\(a < 5\)”是“\(a < 3\)”的必要条件.
\end{circlelist}

其中真命题的个数是（\quad）

\choices
    {\(1\)}
    {\(2\)}
    {\(3\)}
    {\(4\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
命题\(\circled{1}\)中，\(a=b\) 能推出 \(ac=bc\)，但当 \(c=0\) 时，\(ac=bc\) 不能推出 \(a=b\)，所以命题\(\circled{1}\)不是真命题.

命题\(\circled{2}\)中，整数 \(5\) 是有理数，因此 \(a\) 为无理数当且仅当 \(a+5\) 为无理数，命题\(\circled{2}\)是真命题.

命题\(\circled{3}\)不成立. 例如取 \(a=0\)，\(b=-1\)，虽然 \(a>b\)，但 \(a^2<b^2\)，所以 \(a>b\) 不是 \(a^2>b^2\) 的充分条件.

命题\(\circled{4}\)中，\(a<3\) 一定能推出 \(a<5\)，所以 \(a<5\) 是 \(a<3\) 的必要条件，命题\(\circled{4}\)是真命题.

真命题共有 \(2\) 个，故选 B.
\end{solution}

\begin{problem}
\(\frac{\left(1 - \i\right)\left(1 + 2\i\right)}{1 + \i} =\)（\quad）

\choices
    {\(-2 - \i\)}
    {\(-2 + \i\)}
    {\(2 - \i\)}
    {\(2 + \i\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
先计算分子，得
\[
\left(1-\i\right)\left(1+2\i\right)=1+2\i-\i-2\i^2=3+\i.
\]
所以
\[
\frac{\left(1-\i\right)\left(1+2\i\right)}{1+\i}=\frac{3+\i}{1+\i}=\frac{\left(3+\i\right)\left(1-\i\right)}{\left(1+\i\right)\left(1-\i\right)}=\frac{4-2\i}{2}=2-\i.
\]
故选 C.
\end{solution}

\begin{problem}
函数 \( y = \e^{|\ln x|} - |x - 1| \) 的图象大致是（\quad）

\choices
    {\choicebitmap[width=0.15\paperwidth]{img/2005/hubei_science/q4_optA_clean.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2005/hubei_science/q4_optB_clean.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2005/hubei_science/q4_optC_clean.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2005/hubei_science/q4_optD_clean.png}}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
函数的定义域为 \(x>0\). 当 \(0<x<1\) 时，\(|\ln x|=-\ln x\)，\(|x-1|=1-x\)，因此
\[
y=\e^{-\ln x}-(1-x)=\frac{1}{x}+x-1.
\]
此时 \(y'=1-\frac{1}{x^2}<0\)，函数从左向右递减，并且当 \(x\to0^+\) 时，\(y\to+\infty\). 当 \(x\geqslant1\) 时，\(|\ln x|=\ln x\)，\(|x-1|=x-1\)，所以 \(y=x-(x-1)=1\). 因而图象在 \(x=1\) 处取值 \(1\)，右侧为水平射线，左侧从上方递减到 \((1,1)\)，故选 D.
\end{solution}

\begin{problem}
双曲线 \(\frac{x^2}{m} - \frac{y^2}{n} = 1\)（\(mn \neq 0\)）离心率为 \(2\)，有一个焦点与抛物线 \(y^2 = 4x\) 的焦点重合，则 \(mn\) 的值为（\quad）

\choices
    {\( \frac{3}{16} \)}
    {\( \frac{3}{8} \)}
    {\( \frac{16}{3} \)}
    {\( \frac{8}{3} \)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
将双曲线写成标准形式，其半实轴平方为 \(m\)，半虚轴平方为 \(n\)，焦半距平方为 \(m+n\). 因此离心率满足
\[
e^2=\frac{m+n}{m}=4,
\]
从而 \(n=3m\). 抛物线 \(y^2=4x\) 的焦点为 \((1,0)\)，而双曲线的焦点为 \(\left(\pm\sqrt{m+n},0\right)\)，故 \(m+n=1\). 于是 \(4m=1\)，\(m=\frac14\)，\(n=\frac34\)，所以
\[
mn=\frac14\cdot\frac34=\frac{3}{16}.
\]
故选 A.
\end{solution}

\begin{problem}
在 \( y = 2^x \)，\( y = \log_{2} x \)，\( y = x^2 \)，\( y = \cos 2x \) 这四个函数中，当 \( 0 < x_1 < x_2 < 1 \) 时，使 \( f\left(\frac{x_1 + x_2}{2}\right) > \frac{f(x_1) + f(x_2)}{2} \) 恒成立的函数的个数是（\quad）

\choices
    {\(0\)}
    {\(1\)}
    {\(2\)}
    {\(3\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
对二阶导数进行判断. 对于 \(y=2^x\)，有 \(y''=(\ln2)^2 2^x>0\)，所以它在 \((0,1)\) 上为凸函数，不满足题中的不等式. 对于 \(y=\log_2x\)，有
\[
y''=-\frac{1}{x^2\ln2}<0,
\]
所以它在 \((0,1)\) 上严格凹，恒满足题中的不等式. 对于 \(y=x^2\)，有 \(y''=2>0\)，不满足题中的不等式.

对于 \(y=\cos2x\)，有 \(y''=-4\cos2x\). 当 \(\frac{\pi}{4}<x<1\) 时，\(\cos2x<0\)，从而 \(y''>0\)，函数在该小区间上为凸函数，不能对所有 \(0<x_1<x_2<1\) 满足严格凹函数的中点不等式. 因此只有 \(y=\log_2x\) 满足条件，函数的个数为 \(1\)，故选 B.
\end{solution}

\begin{problem}
若 \(\sin \alpha + \cos \alpha = \tan \alpha\)（\(0 < \alpha < \frac{\pi}{2}\)），则 \(\alpha \in\)（\quad）

\choices
    {\(\left(0, \frac{\pi}{6}\right)\)}
    {\(\left(\frac{\pi}{6}, \frac{\pi}{4}\right)\)}
    {\(\left(\frac{\pi}{4}, \frac{\pi}{3}\right)\)}
    {\(\left(\frac{\pi}{3}, \frac{\pi}{2}\right)\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
令
\[
h(\alpha)=\tan\alpha-\sin\alpha-\cos\alpha.
\]
在 \(0<\alpha<\frac{\pi}{2}\) 内，
\[
h'(\alpha)=\sec^2\alpha-\cos\alpha+\sin\alpha>1-\cos\alpha+\sin\alpha>0,
\]
所以 \(h\) 严格递增. 又 \(h\left(\frac{\pi}{4}\right)=1-\sqrt2<0\)，
\(h\left(\frac{\pi}{3}\right)=\sqrt3-\frac{\sqrt3+1}{2}>0\).
由连续性，方程 \(h(\alpha)=0\) 的解唯一，且位于 \(\left(\frac{\pi}{4},\frac{\pi}{3}\right)\) 内. 故选 C.
\end{solution}

\begin{problem}
若 \(\displaystyle\lim_{x\to 1}\left(\frac{a}{1 - x} - \frac{b}{1 - x^2}\right) = 1\)，则常数 \(a\)，\(b\) 的值为（\quad）

\choices
    {\(a = -2\)，\(b = 4\)}
    {\(a = 2\)，\(b = -4\)}
    {\(a = -2\)，\(b = -4\)}
    {\(a = 2\)，\(b = 4\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
将式子通分，得
\[
\frac{a}{1-x}-\frac{b}{1-x^2}=\frac{a(1+x)-b}{(1-x)(1+x)}.
\]
要使 \(x\to1\) 时极限为有限值，分子在 \(x=1\) 时必须为零，即 \(2a-b=0\)，所以 \(b=2a\). 代入后，
\[
\frac{a(1+x)-2a}{(1-x)(1+x)}=-\frac{a}{1+x},
\]
故极限为 \(-\frac{a}{2}=1\)，从而 \(a=-2\)，\(b=-4\). 故选 C.
\end{solution}

\begin{problem}
若 \(0 < x < \frac{\pi}{2}\)，则 \(2x\) 与 \(3\sin x\) 的大小关系（\quad）

\choices
    {\(2x > 3\sin x\)}
    {\(2x < 3\sin x\)}
    {\(2x = 3\sin x\)}
    {与 \(x\) 的取值有关}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
令 \(h(x)=2x-3\sin x\)，并把它连续延拓到 \(x=0\). 则 \(h(0)=0\)，且
\[
h'(x)=2-3\cos x.
\]
当 \(x\) 为充分接近 \(0\) 的正数时，\(h'(x)<0\)，所以 \(h(x)<0\)，即 \(2x<3\sin x\). 另一方面，\(h\left(\frac{\pi}{2}\right)=\pi-3>0\)，由连续性可知在充分接近 \(\frac{\pi}{2}\) 的区间内有 \(h(x)>0\)，即 \(2x>3\sin x\). 因此两者的大小关系随 \(x\) 的取值而变，故选 D.
\end{solution}

\begin{problem}
如图，在三棱柱 \(ABC - A'B'C'\) 中，点 \(E\)，\(F\)，\(H\)，\(K\) 分别为 \(AC'\)，\(CB'\)，\(A'B\)，\(B'C'\) 的中点，\(G\) 为 \(\triangle ABC\) 的重心. 从 \(K\)，\(H\)，\(G\)，\(B'\) 中取一点作为 \(P\)，使得该棱柱恰有 \(2\) 条棱与平面 \(PEF\) 平行，则 \(P\) 为（\quad）

\bitmapfigure[max width=0.58\linewidth]{img/2005/hubei_science/q10_fig1.png}

\choices
    {\(K\)}
    {\(H\)}
    {\(G\)}
    {\(B^{\prime}\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
取仿射坐标 \(A=(0,0,0)\)，\(B=(1,0,0)\)，\(C=(0,1,0)\)，\(A'=(0,0,1)\).
于是 \(B'=(1,0,1)\)，\(C'=(0,1,1)\)，\(E=\left(0,\frac12,\frac12\right)\)，\(F=\left(\frac12,\frac12,\frac12\right)\)，
并且 \(H=\left(\frac12,0,\frac12\right)\)，\(K=\left(\frac12,\frac12,1\right)\)，\(G=\left(\frac13,\frac13,0\right)\). 由于 \(EF\) 平行于 \(x\) 轴，平面 \(PEF\) 的一个方向始终是 \((1,0,0)\)，对应棱 \(AB\) 和 \(A'B'\).

当 \(P=K\) 时，平面方程为 \(y=\frac12\)，与 \(x\) 轴方向平行的棱以及三条侧棱均与该平面无公共点，共有 \(5\) 条，不合题意. 当 \(P=H\) 时，平面方程为 \(z=\frac12\)，六条底面棱均与该平面平行，共有 \(6\) 条，也不合题意.

当 \(P=G\) 时，由 \(E\)，\(F\)，\(G\) 三点可得平面方程为 \(3y-z=1\). 棱 \(AB\) 和 \(A'B'\) 的方向满足 \(3\Delta y-\Delta z=0\)，且它们分别位于 \(3y-z=0\) 和 \(3y-z=-1\) 上，所以恰有这 \(2\) 条棱与平面平行；其余各棱的方向均不满足该方向条件.

当 \(P=B'\) 时，平面方程为 \(y+z=1\). 棱 \(AB\) 与该平面平行，但棱 \(A'B'\) 在该平面内，棱 \(BB'\) 与该平面相交，其余各棱的方向也不平行于该平面，故不满足恰有 \(2\) 条棱的条件. 所以 \(P=G\)，故选 C.
\end{solution}

\begin{problem}
某初级中学有学生 \(270\text{ 人}\)，其中一年级 \(108\text{ 人}\)，二、三年级各 \(81\text{ 人}\). 现要利用抽样方法抽取 \(10\text{ 人}\) 参加某项调查，考虑选用简单随机抽样，分层抽样和系统抽样三种方案，使用简单随机抽样和分层抽样时，将学生按一、二、三年级依次统一编号为 \(1\)，\(2\)，…，\(270\)；使用系统抽样时，将学生统一随机编号为 \(1\)，\(2\)，…，\(270\)，并将整个编号依次分为 \(10\) 段. 如果抽得号码有下列四种情况：

\begin{circlelist}
\item \(7, 34, 61, 88, 115, 142, 169, 196, 223, 250\)；
\item \(5, 9, 100, 107, 111, 121, 180, 195, 200, 265\)；
\item \(11, 38, 65, 92, 119, 146, 173, 200, 227, 254\)；
\item \(30, 57, 84, 111, 138, 165, 192, 219, 246, 270\).
\end{circlelist}

关于上述样本的下列结论中，正确的是（\quad）

\choices
    {\(\circled{2}\)，\(\circled{3}\)都不能为系统抽样}
    {\(\circled{2}\)，\(\circled{4}\)都不能为分层抽样}
    {\(\circled{1}\)，\(\circled{4}\)都可能为系统抽样}
    {\(\circled{1}\)，\(\circled{3}\)都可能为分层抽样}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
系统抽样时每段有 \(270\div10=27\) 个号码，所以样本号码应为
\[
r, r+27, r+2\times27, \dots, r+9\times27
\]
的形式，其中 \(1\leqslant r\leqslant27\). 因此样本\(\circled{1}\)对应 \(r=7\)，样本\(\circled{3}\)对应 \(r=11\)，二者都可能是系统抽样；样本\(\circled{2}\)和样本\(\circled{4}\)不具有这种等差结构.

分层抽样按年级人数比例抽取，三个年级应分别抽取 \(10\times\frac{108}{270}=4\)，\(10\times\frac{81}{270}=3\)，\(10\times\frac{81}{270}=3\) 人. 样本\(\circled{1}\)和样本\(\circled{3}\)在三个年级中均分别含有 \(4\)，\(3\)，\(3\) 人，所以二者都可能是分层抽样. 样本\(\circled{4}\)在三个年级中分别含有 \(3\)，\(4\)，\(3\) 人，不可能是分层抽样.

因此正确结论是“\(\circled{1}\)，\(\circled{3}\)都可能为分层抽样”，故选 D.
\end{solution}

\begin{problem}
以平行六面体 \(ABCD - A'B'C'D'\) 的任意三个顶点为顶点作三角形，从中随机取出两个三角形，则这两个三角形不共面的概率 \(p\) 为（\quad）

\choices
    {\(\frac{367}{385}\)}
    {\(\frac{376}{385}\)}
    {\(\frac{192}{385}\)}
    {\(\frac{18}{385}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
用仿射坐标把平行六面体的八个顶点表示为立方体的八个顶点. 仿射变换保持共线、共面关系，因此只需统计立方体顶点的情形.

八个顶点中任取三个作三角形，共有 \(\mathrm C_8^3=56\) 个三角形，从中任取两个共有 \(\mathrm C_{56}^2=1540\) 种取法. 逐一考察 \(x,y,z\in\{0,1\}\) 可知，含有 \(4\) 个立方体顶点的平面为 \(x=0\)，\(x=1\)，\(y=0\)，\(y=1\)，\(z=0\)，\(z=1\)，\(x=y\)，\(x+y=1\)，\(y=z\)，\(y+z=1\)，\(x=z\)，\(x+z=1\).
前 \(6\) 个是面所在的平面，后 \(6\) 个是对角平面；除此之外的平面至多含有 \(3\) 个顶点.

每个含有 \(4\) 个顶点的平面内可作 \(\mathrm C_4^3=4\) 个三角形，因此其中任取两个三角形共有 \(\mathrm C_4^2=6\) 对. 不同的四点共面平面不会重复计算同一对三角形，所以共面的三角形对数为 \(12\times6=72\). 因而两个三角形不共面的概率为
\[
p=\frac{\mathrm C_{56}^2-72}{\mathrm C_{56}^2}=\frac{1540-72}{1540}=\frac{1468}{1540}=\frac{367}{385}.
\]
故选 A.
\end{solution}

\section{填空题}
\begin{problem}
已知向量 \(\bs{a} = (-2, 2)\)，\(\bs{b} = (5, k)\). 若 \(|\bs{a} + \bs{b}|\) 不超过 \(5\)，则 \(k\) 的取值范围是\fillinblank{}.
\end{problem}

\begin{answer}
\([-6,2]\)
\end{answer}

\begin{solution}
由
\[
\bs{a}+\bs{b}=(3,k+2)
\]
以及 \(\lvert\bs{a}+\bs{b}\rvert\leqslant5\)，得
\[
\sqrt{3^2+(k+2)^2}\leqslant5.
\]
两边平方并整理，得到 \((k+2)^2\leqslant16\)，所以 \(-4\leqslant k+2\leqslant4\)，即 \(-6\leqslant k\leqslant2\). 因此填 \([-6,2]\).
\end{solution}

\begin{problem}
\(\left(\frac{x}{2} + \frac{1}{x} + \sqrt{2}\right)^5\) 的展开式中整理后的常数项为\fillinblank{}.
\end{problem}

\begin{answer}
\(\dfrac{63\sqrt{2}}{2}\)
\end{answer}

\begin{solution}
设从三项 \(\frac{x}{2}\)，\(\frac1x\)，\(\sqrt2\) 中分别取了 \(r\)，\(s\)，\(t\) 次. 常数项的幂次条件为 \(r-s=0\)，又 \(r+s+t=5\)，所以 \(r=s=k\)，且 \(k=0,1,2\). 因而常数项为
\[
(\sqrt2)^5+\frac{5!}{1!1!3!}\left(\frac{x}{2}\right)\left(\frac1x\right)(\sqrt2)^3+\frac{5!}{2!2!1!}\left(\frac{x}{2}\right)^2\left(\frac1x\right)^2\sqrt2
\]
\[
=4\sqrt2+20\sqrt2+\frac{15}{2}\sqrt2=\frac{63\sqrt2}{2}.
\]
因此填 \(\dfrac{63\sqrt2}{2}\).
\end{solution}

\begin{problem}
设等比数列 \(\{a_{n}\}\) 的公比为 \(q\)，前 \(n\) 项和为 \(S_{n}\)，若 \(S_{n+1}\)，\(S_{n}\)，\(S_{n+2}\) 成等差数列，则 \(q\) 的值为\fillinblank{}.
\end{problem}

\begin{answer}
\(-2\)
\end{answer}

\begin{solution}
因为 \(S_{n+1}\)，\(S_n\)，\(S_{n+2}\) 成等差数列，所以
\[
2S_n=S_{n+1}+S_{n+2}.
\]
又 \(S_{n+1}=S_n+a_{n+1}\)，\(S_{n+2}=S_n+a_{n+1}+a_{n+2}\)，代入可得 \(2a_{n+1}+a_{n+2}=0\). 由等比数列的定义，\(a_{n+2}=q a_{n+1}\)，且 \(a_{n+1}\neq0\)，所以 \(2+q=0\)，即 \(q=-2\).
\end{solution}

\begin{problem}
某实验室需购某种化工原料 \(106\text{ 千克}\)，现在市场上该原料有两种包装，一种是每袋 \(35\text{ 千克}\)，价格为 \(140\text{ 元}\)；另一种是每袋 \(24\text{ 千克}\)，价格为 \(120\text{ 元}\). 在满足需要的条件下，最少要花费\fillinblank{}\(\text{ 元}\).
\end{problem}

\begin{answer}
\(500\)
\end{answer}

\begin{solution}
设购买 \(35\text{ 千克}\) 包装和 \(24\text{ 千克}\) 包装的袋数分别为非负整数 \(x\)，\(y\)，则需满足 \(35x+24y\geqslant106\)，总费用为 \(140x+120y\).

分别讨论 \(x\) 的取值：当 \(x=0\) 时，至少需 \(y=5\)，费用为 \(600\) 元；当 \(x=1\) 时，至少需 \(y=3\)，费用为 \(500\) 元；当 \(x=2\) 时，至少需 \(y=2\)，费用为 \(520\) 元；当 \(x=3\) 时，至少需 \(y=1\)，费用为 \(540\) 元；当 \(x\geqslant4\) 时，费用至少为 \(4\times140=560\) 元.

其中 \(x=1\)，\(y=3\) 时购买总量为 \(35+3\times24=107\text{ 千克}\)，满足需要且费用为 \(500\) 元，并且这是上述各情形中的最小值. 因此填 \(500\).
\end{solution}

\section{解答题}
\begin{problem}
已知向量 \(\bs{a} = (x^2, x + 1)\)，\(\bs{b} = (1 - x, t)\). 若函数 \(f(x) = \bs{a} \cdot \bs{b}\) 在区间 \((-1, 1)\) 上是增函数，求 \(t\) 的取值范围.
\end{problem}

\begin{solution}
由点积定义，
\[
f(x)=\bs{a}\cdot\bs{b}=x^{2}(1-x)+t(x+1)=-x^{3}+x^{2}+tx+t.
\]
因此
\[
f'(x)=-3x^{2}+2x+t.
\]
令 \(g(x)=-3x^{2}+2x\). 因为 \(g\) 在闭区间 \([-1,1]\) 上为开口向下的二次函数，所以其最小值在端点取得，而 \(g(-1)=-5\)，\(g(1)=-1\)，故 \(g(x)\geqslant-5\). 当 \(t\geqslant5\) 时，对于任意 \(x\in(-1,1)\)，有 \(f'(x)>0\)，从而 \(f(x)\) 在 \((-1,1)\) 上是增函数. 反之，若 \(t<5\)，则 \(f'(-1)=t-5<0\)，由连续性知在 \(-1\) 右侧的某个区间内仍有 \(f'(x)<0\)，不可能在整个 \((-1,1)\) 上为增函数. 因此
\[
t\geqslant5.
\]
\end{solution}

\begin{problem}
在 \(\triangle ABC\) 中，已知 \(AB = \frac{4\sqrt{6}}{3}\)，\(\cos B = \frac{\sqrt{6}}{6}\)，\(AC\) 边上的中线 \(BD = \sqrt{5}\)，求 \(\sin A\) 的值.
\end{problem}

\begin{solution}
设 \(BC=a\)，\(CA=c_1\)，并记 \(AB=c=\dfrac{4\sqrt{6}}{3}\). 以 \(B\) 为起点，则中点 \(D\) 满足 \(2\overrightarrow{BD}=\overrightarrow{BA}+\overrightarrow{BC}\)，所以
\[
4BD^{2}=AB^{2}+BC^{2}+2AB\cdot BC\cos B.
\]
代入已知条件，得
\[
20=\frac{32}{3}+a^{2}+2\cdot\frac{4\sqrt{6}}{3}\cdot a\cdot\frac{\sqrt{6}}{6}=\frac{32}{3}+a^{2}+\frac{8a}{3}.
\]
整理得 \(3a^{2}+8a-28=0\). 因为 \(a>0\)，所以 \(a=2\). 再由余弦定理，
\[
c_1^{2}=a^{2}+c^{2}-2ac\cos B=4+\frac{32}{3}-\frac{16}{3}=\frac{28}{3},
\]
故 \(c_1=\dfrac{2\sqrt{21}}{3}\). 又
\[
\sin B=\sqrt{1-\cos^{2}B}=\sqrt{1-\frac{1}{6}}=\frac{\sqrt{30}}{6}.
\]
由同一个三角形的面积可得 \(\dfrac12 ac\sin B=\dfrac12 c_1c\sin A\)，于是
\[
\sin A=\frac{a\sin B}{c_1}=\frac{2\cdot\frac{\sqrt{30}}{6}}{\frac{2\sqrt{21}}{3}}=\frac{\sqrt{70}}{14}.
\]
\end{solution}

\begin{problem}
某地最近出台一项机动车驾照考试规定：每位考试者一年之内最多有 \(4\) 次参加考试的机会，一旦某次考试通过，即可领取驾照，不再参加以后的考试，否则就一直等到第 \(4\) 次为止. 如果李明决定参加驾照考试，设他每次参加考试通过的概率依次为 \(0.6\)，\(0.7\)，\(0.8\)，\(0.9\)，求在一年内李明参加驾照考试次数 \(\xi\) 的分布列和 \(\xi\) 的期望，并求李明在一年内领到驾照的概率.
\end{problem}

\begin{solution}
第一次通过的概率为 \(0.6\)，因此 \(P(\xi=1)=0.6\). 要参加第二次考试，第一次必须未通过，且第二次通过，所以 \(P(\xi=2)=0.4\times0.7=0.28\). 同理，
\[
P(\xi=3)=0.4\times0.3\times0.8=0.096.
\]
参加第四次考试的概率是前三次均未通过，故
\[
P(\xi=4)=0.4\times0.3\times0.2=0.024.
\]
所以 \(\xi\) 的分布列为 \(P(\xi=1)=0.6\)，\(P(\xi=2)=0.28\)，\(P(\xi=3)=0.096\)，\(P(\xi=4)=0.024\). 其期望为
\[
E\xi=1\times0.6+2\times0.28+3\times0.096+4\times0.024=1.544.
\]
一年内未领到驾照当且仅当四次考试均未通过，因此一年内领到驾照的概率为
\[
1-0.4\times0.3\times0.2\times0.1=0.9976.
\]
\end{solution}

\begin{problem}
如图，在四棱锥 \(P - ABCD\) 中，底面 \(ABCD\) 为矩形，侧棱 \(PA \perp\) 底面 \(ABCD\)，\(AB = \sqrt{3}\)，\(BC = 1\)，\(PA = 2\)，\(E\) 为 \(PD\) 的中点.

\begin{enumerate}
\item 求直线 \(AC\) 与 \(PB\) 所成角的余弦值；
\item 在侧面 \(PAB\) 内找一点 \(N\)，使 \(NE \perp\) 面 \(PAC\)，并求出 \(N\) 点到 \(AB\) 和 \(AP\) 的距离.
\end{enumerate}

\begin{solution}
建立如下一直角坐标系：取 \(A\) 为原点，令 \(AB\) 在 \(x\) 轴正向，\(AD\) 在 \(y\) 轴正向，\(AP\) 在 \(z\) 轴正向，则 \(A=(0,0,0)\)，\(B=(\sqrt{3},0,0)\)，\(D=(0,1,0)\)，\(C=(\sqrt{3},1,0)\)，\(P=(0,0,2)\).
由于 \(E\) 是 \(PD\) 的中点，所以 \(E=\left(0,\dfrac12,1\right)\).

\begin{enumerate}
\item \(\overrightarrow{AC}=(\sqrt{3},1,0)\)，\(\overrightarrow{PB}=(\sqrt{3},0,-2)\)，从而
\[
\cos\angle(AC,PB)=\frac{\overrightarrow{AC}\cdot\overrightarrow{PB}}{|\overrightarrow{AC}|\,|\overrightarrow{PB}|}=\frac{3}{2\sqrt{7}}.
\]

\item 设 \(N=(x,0,z)\)，因为 \(N\) 在侧面 \(PAB\) 内. 平面 \(PAC\) 的一个法向量为 \(\bs{n}=(1,-\sqrt{3},0)\)，因为 \(\bs{n}\cdot\overrightarrow{AP}=\bs{n}\cdot\overrightarrow{AC}=0\). 又
\[
\overrightarrow{NE}=\left(-x,\frac12,1-z\right).
\]
条件 \(NE\perp\) 面 \(PAC\) 表明 \(\overrightarrow{NE}\) 与 \(\bs{n}\) 平行，于是 \(z=1\)，且
\[
\left(-x,\frac12,0\right)=\mu(1,-\sqrt{3},0).

\begin{problem}
设 \(A\)，\(B\) 是椭圆 \(3x^{2} + y^{2} = \lambda\) 上的两点，点 \(N(1,3)\) 是线段 \(AB\) 的中点，线段 \(AB\) 的垂直平分线与椭圆相交于 \(C\)，\(D\) 两点.

\begin{enumerate}
\item 确定 \(\lambda\) 的取值范围，并求直线 \(AB\) 的方程；
\item 试判断是否存在这样的 \(\lambda\)，使得 \(A\)，\(B\)，\(C\)，\(D\) 四点在同一个圆上，并说明理由.
\end{enumerate}
\end{problem}

\begin{solution}
设 \(\overrightarrow{NA}=(u,v)\)，则 \(\overrightarrow{NB}=(-u,-v)\)，即 \(A=(1+u,3+v)\)，\(B=(1-u,3-v)\). 因为 \(A\)，\(B\) 都在椭圆上，分别代入 \(3x^{2}+y^{2}=\lambda\) 并相减，得
\[
12u+12v=0,
\]
所以 \(v=-u\). 再将 \(A\) 代入椭圆方程，得
\[
\lambda=3(1+u)^{2}+(3-u)^{2}=12+4u^{2}.
\]
由于 \(A\)，\(B\) 是两个不同的点，\(u\neq0\)，故 \(\lambda>12\). 同时，\(AB\) 的方向向量为 \((1,-1)\)，且经过 \(N(1,3)\)，所以
\[
AB:\ x+y-4=0.
\]

线段 \(AB\) 的垂直平分线经过 \(N\)，方向与 \((1,-1)\) 垂直，故其方程为 \(y=x+2\). 设它与椭圆的交点为 \(C=(s_1,s_1+2)\)，\(D=(s_2,s_2+2)\)，则
\[
4s^{2}+4s+4=\lambda,
\]
从而 \(s_1+s_2=-1\)，\(s_1s_2=1-\frac{\lambda}{4}\).
将该二次方程除以 \(4\)，得 \(s^2+s+1-\frac{\lambda}{4}=0\)，其判别式为 \(\lambda-3>0\)，所以确有两个交点 \(C,D\). 在两条相交直线 \(AB\) 和 \(CD\) 上分别计算以 \(N\) 为端点的有向线段乘积：
\[
\overline{NA}\,\overline{NB}=-2u^{2},
\]
而
\[
\overline{NC}\,\overline{ND}=2(s_1-1)(s_2-1)=2\left(s_1s_2-s_1-s_2+1\right)=6-\frac{\lambda}{2}=-2u^{2}.
\]
两乘积相等，根据相交弦定理的逆定理，四点 \(A\)，\(B\)，\(C\)，\(D\) 共圆. 因此存在这样的 \(\lambda\)，并且对所有 \(\lambda>12\)，四点均共圆.
\end{solution}

\begin{problem}
已知不等式 \(\frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n} > \frac{1}{2}\left[\log_{2} n\right]\)，其中 \(n\) 为大于 \(2\) 的整数，\([\log_{2} n]\) 表示不超过 \(\log_{2} n\) 的最大整数. 设数列 \(\{a_n\}\) 的各项为正，且满足 \(a_1 = b\)（\(b > 0\)），\(a_n \leqslant \frac{n a_{n-1}}{n + a_{n-1}}\)，\(n = 2\)，\(3\)，\(4\)，\(\dots\).

\begin{enumerate}
\item 证明： \(a_{n} < \frac{2b}{2 + b[\log_{2} n]}\)，\(n = 3\)，\(4\)，\(5\)，\(\dots\)；
\item 猜测数列 \(\{a_{n}\}\) 是否有极限？如果有，写出极限的值（不必证明）；
\item 试确定一个正整数 \(N\)，使得当 \(n > N\) 时，对任意 \(b > 0\)，都有 \(a_{n} < \frac{1}{5}\).
\end{enumerate}
\end{problem}

\begin{solution}
令 \(S_n=\dfrac12+\dfrac13+\dots+\dfrac1n\)，并令 \(L_n=\left[\log_{2}n\right]\). 由数列各项为正以及递推不等式，取倒数可得
\[
\frac1{a_n}\geqslant\frac{n+a_{n-1}}{na_{n-1}}=\frac1{a_{n-1}}+\frac1n.
\]
连续使用这个不等式，得到
\[
\frac1{a_n}\geqslant\frac1b+S_n.
\]

\begin{enumerate}
\item 题设给出 \(S_n>\dfrac12L_n\)，所以
\[
a_n\leqslant\frac{1}{\frac1b+S_n}<\frac{1}{\frac1b+\frac12L_n}=\frac{2b}{2+bL_n}.
\]
即 \(a_n<\frac{2b}{2+b\left[\log_{2}n\right]}\)，其中 \(n=3,4,5,\dots\).

\item 由 \(a_n\leqslant\dfrac{na_{n-1}}{n+a_{n-1}}<a_{n-1}\)，数列 \(\{a_n\}\) 为正且递减，因而有极限. 另一方面，上一问的上界随 \(n\) 趋于无穷大而趋于 \(0\)，故
\[
\lim_{n\to\infty}a_n=0.
\]

\item 取 \(N=1023\). 当 \(n>N\) 时，\(n\geqslant1024=2^{10}\)，从而 \(L_n\geqslant10\). 因此
\[
a_n<\frac{2b}{2+bL_n}\leqslant\frac{2b}{2+10b}<\frac15,
\]
其中最后一个不等式等价于 \(10b<2+10b\)，对任意 \(b>0\) 均成立. 所以可取
\[
N=1023.
\]
\end{enumerate}
\end{solution}
