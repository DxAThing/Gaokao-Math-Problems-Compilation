\section{单选题}
\begin{problem}
设集合 \(A = \{1, 2\}\)，\(B = \{1, 2, 3\}\)，\(C = \{2, 3, 4\}\)，则 \(\left(A \cap B\right) \cup C =\)（\quad）

\choices
    {\(\{1,2,3\}\)}
    {\(\{1,2,4\}\)}
    {\(\{2,3,4\}\)}
    {\(\{1,2,3,4\}\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
因为 \(A\subset B\)，所以 \(A\cap B=A=\{1,2\}\). 从而

\(\left(A\cap B\right)\cup C=\{1,2\}\cup\{2,3,4\}=\{1,2,3,4\}\)，故选 D.
\end{solution}

\begin{problem}
函数 \(y = 2^{1 - x} + 3\)（\(x \in \R\)）的反函数的解析表达式为（\quad）

\choices
    {\(y=\log_{2}\frac{2}{x - 3}\)}
    {\(y=\log_{2}\frac{x - 3}{2}\)}
    {\(y=\log_{2}\frac{3 - x}{2}\)}
    {\(y=\log_{2}\frac{2}{3 - x}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
由 \(y=2^{1-x}+3\)，得 \(y-3=2^{1-x}>0\)，所以

\(\log_{2}(y-3)=1-x\)，即 \(x=1-\log_{2}(y-3)=\log_{2}\dfrac{2}{y-3}\). 交换 \(x\)，\(y\)，得到反函数为 \(y=\log_{2}\dfrac{2}{x-3}\)，故选 A.
\end{solution}

\begin{problem}
在各项都为正数的等比数列 \(\{a_{n}\}\) 中，首项 \(a_1 = 3\)，前三项和为 \(21\)，则 \(a_3 + a_4 + a_5 =\)（\quad）

\choices
    {\(33\)}
    {\(72\)}
    {\(84\)}
    {\(189\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
设等比数列的公比为 \(q\). 由前三项和得 \(3(1+q+q^{2})=21\)，即 \(q^{2}+q-6=0\)，所以 \(q=2\) 或 \(q=-3\). 由于各项均为正数，\(q=2\). 因此

\(a_{3}+a_{4}+a_{5}=3q^{2}+3q^{3}+3q^{4}=12+24+48=84\)，故选 C.
\end{solution}

\begin{problem}
在正三棱柱 \(ABC-A_{1}B_{1}C_{1}\) 中，若 \(AB = 2\)，\(AA_{1} = 1\)，则点 \(A\) 到平面 \(A_{1}BC\) 的距离为（\quad）

\choices
    {\(\frac{\sqrt{3}}{4}\)}
    {\(\frac{\sqrt{3}}{2}\)}
    {\(\frac{3\sqrt{3}}{4}\)}
    {\(\sqrt{3}\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
建立直角坐标系，取 \(A=(0,0,0)\)，\(B=(2,0,0)\)，\(C=(1,\sqrt{3},0)\)，\(A_{1}=(0,0,1)\). 则

\(\overrightarrow{A_{1}B}=(2,0,-1)\)，\(\overrightarrow{A_{1}C}=(1,\sqrt{3},-1)\)，平面 \(A_{1}BC\) 的一个法向量为

\(\overrightarrow{A_{1}B}\times\overrightarrow{A_{1}C}=(\sqrt{3},1,2\sqrt{3})\).

因此点 \(A\) 到该平面的距离为

\(\dfrac{\left|\overrightarrow{A_{1}A}\cdot(\sqrt{3},1,2\sqrt{3})\right|}{\sqrt{3+1+12}}=\dfrac{2\sqrt{3}}{4}=\dfrac{\sqrt{3}}{2}\)，故选 B.
\end{solution}

\begin{problem}
\(\triangle ABC\) 中，\(\angle A = \frac{\pi}{3}\)，\(BC = 3\)，则 \(\triangle ABC\) 的周长为（\quad）

\choices
    {\(4\sqrt{3}\sin \left(B + \frac{\pi}{3}\right) + 3\)}
    {\(4\sqrt{3}\sin \left(B + \frac{\pi}{6}\right) + 3\)}
    {\(6\sin \left(B + \frac{\pi}{3}\right) + 3\)}
    {\(6\sin \left(B + \frac{\pi}{6}\right) + 3\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
在 \(\triangle ABC\) 中，记 \(BC\)，\(CA\)，\(AB\) 分别为 \(a\)，\(b\)，\(c\). 由正弦定理和 \(A=\dfrac{\pi}{3}\)，\(a=3\)，得

\(b=\dfrac{3\sin B}{\sin(\pi/3)}=2\sqrt{3}\sin B\)，且 \(C=\dfrac{2\pi}{3}-B\)，所以

\(c=\dfrac{3\sin C}{\sin(\pi/3)}=2\sqrt{3}\sin\left(B+\dfrac{\pi}{3}\right)\).

从而三角形的周长为

\(b+c+3=2\sqrt{3}\left[\sin B+\sin\left(B+\dfrac{\pi}{3}\right)\right]+3=6\sin\left(B+\dfrac{\pi}{6}\right)+3\)，故选 D.
\end{solution}

\begin{problem}
抛物线 \(y = 4x^{2}\) 上的一点 \(M\) 到焦点的距离为 \(1\)，则点 \(M\) 的纵坐标是（\quad）

\choices
    {\(\frac{17}{16}\)}
    {\(\frac{15}{16}\)}
    {\(\frac{7}{8}\)}
    {\(0\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
抛物线方程可写为 \(x^{2}=\dfrac14y=4py\)，所以 \(p=\dfrac1{16}\)，焦点为 \(\left(0,\dfrac1{16}\right)\)，准线为 \(y=-\dfrac1{16}\). 设 \(M=(x,y)\)，由抛物线定义，点 \(M\) 到焦点的距离等于其到准线的距离. 又 \(y=4x^{2}\geqslant0\)，故

\(1=y+\dfrac1{16}\)，从而 \(y=\dfrac{15}{16}\)，故选 B.
\end{solution}

\begin{problem}
在一次歌手大奖赛上，七位评委为歌手打出的分数如下：\(9.4\)，\(8.4\)，\(9.4\)，\(9.9\)，\(9.6\)，\(9.4\)，\(9.7\). 去掉一个最高分和一个最低分后，所剩数据的平均值和方差分别为（\quad）

\choices
    {\(9.4, 0.484\)}
    {\(9.4, 0.016\)}
    {\(9.5, 0.04\)}
    {\(9.5, 0.016\)}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
去掉最高分 \(9.9\) 和最低分 \(8.4\) 后，剩下的数据为 \(9.4\)，\(9.4\)，\(9.4\)，\(9.6\)，\(9.7\). 它们的平均值为

\(\overline{x}=\dfrac{3\times9.4+9.6+9.7}{5}=9.5\).

方差为

\(\dfrac{3(9.4-9.5)^{2}+(9.6-9.5)^{2}+(9.7-9.5)^{2}}{5}=\dfrac{3\times0.01+0.01+0.04}{5}=0.016\).

故选 D.
\end{solution}

\begin{problem}
设 \(\alpha\)，\(\beta\)，\(\gamma\) 为两两不重合的平面，\(l\)，\(m\)，\(n\) 为两两不重合的直线，给出下列四个命题：
\begin{circlelist}
\item 若 \(\alpha \perp \gamma\)，\(\beta \perp \gamma\)，则 \(\alpha \parallel \beta\)；
\item 若 \(m \subset \alpha\)，\(n \subset \alpha\)，\(m \parallel \beta\)，\(n \parallel \beta\)，则 \(\alpha \parallel \beta\)；
\item 若 \(\alpha \parallel \beta\)，\(l \subset \alpha\)，则 \(l \parallel \beta\)；
\item 若 \(\alpha \cap \beta = l\)，\(\beta \cap \gamma = m\)，\(\gamma \cap \alpha = n\)，\(l \parallel \gamma\)，则 \(m \parallel n\).
\end{circlelist}
其中真命题的个数是（\quad）

\choices
    {\(1\)}
    {\(2\)}
    {\(3\)}
    {\(4\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
命题\(\circled{1}\)不成立. 例如取 \(\gamma\) 为水平面，取两个相交的竖直平面 \(\alpha\)，\(\beta\)，则 \(\alpha\perp\gamma\)，\(\beta\perp\gamma\)，但 \(\alpha\) 与 \(\beta\) 相交.

命题\(\circled{2}\)也不成立. 例如取 \(\alpha\) 为平面 \(z=0\)，\(\beta\) 为平面 \(y=0\)，在 \(\alpha\) 内取两条互不重合且分别位于 \(y=1\)，\(y=2\) 的 \(x\) 轴平行直线 \(m\)，\(n\). 则 \(m\parallel\beta\)，\(n\parallel\beta\)，但 \(\alpha\) 与 \(\beta\) 相交.

命题\(\circled{3}\)成立. 因为 \(\alpha\parallel\beta\)，所以 \(\alpha\) 内任一直线都不与 \(\beta\) 相交，故 \(l\parallel\beta\).

命题\(\circled{4}\)成立. 直线 \(l\) 在平面 \(\alpha\) 内且 \(l\parallel\gamma\)，而 \(\alpha\cap\gamma=n\)，所以由平面内一条直线平行于相交平面的判定，得 \(l\parallel n\). 同理，\(l\subset\beta\)，且 \(\beta\cap\gamma=m\)，所以 \(l\parallel m\). 因而 \(m\parallel n\).

真命题有两个，故选 B.
\end{solution}

\begin{problem}
设 \(k = 1\)，\(2\)，\(3\)，\(4\)，\(5\)，则 \((x + 2)^5\) 的展开式中 \(x^k\) 的系数不可能是（\quad）

\choices
    {\(10\)}
    {\(40\)}
    {\(50\)}
    {\(80\)}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solution}
由二项式定理，\(x^{k}\) 的系数为 \(\mathrm C_{5}^{k}2^{5-k}\). 当 \(k=1\)，\(2\)，\(3\)，\(4\)，\(5\) 时，这些系数依次为

\(\mathrm C_{5}^{1}2^{4}=80\)，\(\mathrm C_{5}^{2}2^{3}=80\)，\(\mathrm C_{5}^{3}2^{2}=40\)，\(\mathrm C_{5}^{4}2=10\)，\(\mathrm C_{5}^{5}=1\).

所以 \(10\)，\(40\)，\(80\) 都可能，而 \(50\) 不可能，故选 C.
\end{solution}

\begin{problem}
若 \(\sin \left(\frac{\pi}{6} - \alpha\right) = \frac{1}{3}\)，则 \(\cos \left(\frac{2\pi}{3} + 2\alpha\right) =\)（\quad）

\choices
    {\(\displaystyle -\frac{7}{9}\)}
    {\(\displaystyle -\frac{1}{3}\)}
    {\(\displaystyle \frac{1}{3}\)}
    {\(\displaystyle \frac{7}{9}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
令 \(t=\dfrac{\pi}{6}-\alpha\)，则 \(\sin t=\dfrac13\)，且

\(\dfrac{2\pi}{3}+2\alpha=\dfrac{2\pi}{3}+2\left(\dfrac{\pi}{6}-t\right)=\pi-2t\).

因此

\(\cos\left(\dfrac{2\pi}{3}+2\alpha\right)=\cos(\pi-2t)=-\cos2t=-\left(1-2\sin^{2}t\right)=-1+\dfrac{2}{9}=-\dfrac79\).

故选 A.
\end{solution}

\begin{problem}
点 \(P(-3,1)\) 在椭圆 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)）的左准线上. 过点 \(P\) 且方向为 \(\bs{a} = (2,-5)\) 的光线，经直线 \(y = -2\) 反射后通过椭圆的左焦点，则这个椭圆的离心率为（\quad）

\choices
    {\(\frac{\sqrt{3}}{3}\)}
    {\(\frac{1}{3}\)}
    {\(\frac{\sqrt{2}}{2}\)}
    {\(\frac{1}{2}\)}
\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
设椭圆的离心率为 \(e\)，焦距的一半为 \(c\)，则左准线为 \(x=-\dfrac{a}{e}\). 由于 \(P(-3,1)\) 在左准线上，故 \(\dfrac{a}{e}=3\)，从而 \(a=3e\)，\(c=ae=3e^{2}\).

入射光线的方向向量为 \((2,-5)\). 它与直线 \(y=-2\) 的交点为

\(Q=(-3,1)+\dfrac35(2,-5)=\left(-\dfrac95,-2\right)\).

关于水平直线 \(y=-2\) 反射后，方向向量变为 \((2,5)\). 由 \(Q\) 沿此方向上升 \(2\) 个单位，横坐标增加 \(\dfrac45\)，所以反射光线通过点 \((-1,0)\). 该点是椭圆左焦点 \((-c,0)\)，故 \(c=1\). 因而 \(3e^{2}=1\)，即 \(e=\dfrac{\sqrt3}{3}\)，故选 A.
\end{solution}

\begin{problem}
四棱锥的 \(8\) 条棱代表 \(8\) 种不同的化工产品，有公共点的两条棱代表的化工产品放在同一仓库是危险的，没有公共顶点的两条棱所代表的化工产品放在同一仓库是安全的，现打算用编号为 \(\circled{1}\)，\(\circled{2}\)，\(\circled{3}\)，\(\circled{4}\) 的 \(4\) 个仓库存放这 \(8\) 种化工产品，那么安全存放的不同方法种数为（\quad）

\choices
    {\(96\)}
    {\(48\)}
    {\(24\)}
    {\(0\)}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
设四棱锥的底面顶点为 \(A\)，\(B\)，\(C\)，\(D\)，顶点为 \(S\). 四条侧棱 \(SA\)，\(SB\)，\(SC\)，\(SD\) 两两有公共顶点 \(S\)，所以每个安全仓库都必须由一条侧棱和一条底面棱组成.

底面棱与侧棱的安全配对只有

\(AB\) 可与 \(SC\)，\(SD\) 配对；\(BC\) 可与 \(SD\)，\(SA\) 配对；\(CD\) 可与 \(SA\)，\(SB\) 配对；\(DA\) 可与 \(SB\)，\(SC\) 配对.

将四条底面棱和四条侧棱全部配成安全对，只有以下两种配法：

\(AB\text{-}SC\)，\(BC\text{-}SD\)，\(CD\text{-}SA\)，\(DA\text{-}SB\)；

\(AB\text{-}SD\)，\(BC\text{-}SA\)，\(CD\text{-}SB\)，\(DA\text{-}SC\).

每种配法得到的四个安全对再分别放入编号为 \(\circled{1}\)，\(\circled{2}\)，\(\circled{3}\)，\(\circled{4}\) 的仓库，有 \(4!\) 种放法. 所以总数为 \(2\times4!=48\)，故选 B.
\end{solution}

\section{填空题}
\begin{problem}
命题“若 \(a > b\)，则 \(2^a > 2^b - 1\)”的否命题为\fillinblank{}.
\end{problem}

\begin{answer}
若 \(a\leqslant b\)，则 \(2^a\leqslant2^b-1\)
\end{answer}

\begin{solution}
原命题是“若 \(p\)，则 \(q\)”的形式，其中 \(p\) 为 \(a>b\)，\(q\) 为 \(2^a>2^b-1\). 对条件和结论分别取否定，得 \(\lnot p\) 为 \(a\leqslant b\)，\(\lnot q\) 为 \(2^a\leqslant2^b-1\). 因此原命题的否命题为“若 \(a\leqslant b\)，则 \(2^a\leqslant2^b-1\)”.
\end{solution}

\begin{problem}
曲线 \(y = x^{3} + x + 1\) 在点 \((1,3)\) 处的切线方程是\fillinblank{}.
\end{problem}

\begin{answer}
\(4x-y-1=0\)
\end{answer}

\begin{solution}
设 \(f(x)=x^{3}+x+1\)，则 \(f'(x)=3x^{2}+1\)，所以曲线在 \(x=1\) 处的切线斜率为 \(f'(1)=4\). 由点斜式，切线方程为 \(y-3=4(x-1)\)，整理得 \(4x-y-1=0\).
\end{solution}

\begin{problem}
函数 \(y = \sqrt{\log_{0.5}(4x^2 - 3x)}\) 的定义域为\fillinblank{}.
\end{problem}

\begin{answer}
\(\left[-\frac{1}{4},0\right)\cup\left(\frac{3}{4},1\right]\)
\end{answer}

\begin{solution}
要使根式有意义，必须有 \(\log_{0.5}(4x^{2}-3x)\geqslant0\). 因为底数 \(0.5\in(0,1)\)，所以这等价于

\(0<4x^{2}-3x\leqslant1\).

先解 \(4x^{2}-3x>0\)，得 \(x<0\) 或 \(x>\dfrac34\). 再解 \(4x^{2}-3x\leqslant1\)，即 \(4x^{2}-3x-1\leqslant0\)，得 \(-\dfrac14\leqslant x\leqslant1\). 两者取交集，函数定义域为 \(\left[-\dfrac14,0\right)\cup\left(\dfrac34,1\right]\).
\end{solution}

\begin{problem}
若 \(3^{a} = 0.618\)，\(a \in [k,k+1), k \in \Z\)，则 \(k =\)\fillinblank{}.
\end{problem}

\begin{answer}
\(-1\)
\end{answer}

\begin{solution}
因为 \(3^{-1}=\dfrac13<0.618<1=3^{0}\)，且 \(3^{x}\) 在 \(\R\) 上单调递增，所以 \(-1<a<0\). 因此唯一满足 \(a\in[k,k+1)\) 且 \(k\in\Z\) 的整数为 \(k=-1\).
\end{solution}

\begin{problem}
已知 \(a\)，\(b\) 为常数，若 \(f(x) = x^{2} + 4x + 3\)，\(f(ax + b) = x^{2} + 10x + 24\)，则 \(5a - b =\)\fillinblank{}.
\end{problem}

\begin{answer}
\(2\)
\end{answer}

\begin{solution}
将 \(ax+b\) 代入 \(f\)，得

\(f(ax+b)=(ax+b)^{2}+4(ax+b)+3=a^{2}x^{2}+(2ab+4a)x+(b^{2}+4b+3)\).

比较系数，得到 \(a^{2}=1\)，\(2a(b+2)=10\)，以及 \(b^{2}+4b+3=24\). 当 \(a=1\) 时，\(b=3\)；当 \(a=-1\) 时，\(b=-7\). 这两组值均满足常数项条件，且分别有 \(5a-b=5-3=2\) 与 \(5a-b=-5+7=2\). 所以所求值为 \(2\).
\end{solution}

\begin{problem}
在 \(\triangle ABC\) 中，\(O\) 为中线 \(AM\) 上的一个动点，若 \(AM = 2\)，则 \(\overrightarrow{OA} \cdot (\overrightarrow{OB} + \overrightarrow{OC})\) 的最小值是\fillinblank{}.
\end{problem}

\begin{answer}
\(-2\)
\end{answer}

\begin{solution}
取 \(M\) 为原点，设 \(\overrightarrow{MA}=\bs{u}\)，\(\overrightarrow{MB}=\bs{v}\)，则 \(\overrightarrow{MC}=-\bs{v}\)，且 \(|\bs{u}|=AM=2\). 设 \(O\) 在线段 \(AM\) 上，\(\overrightarrow{MO}=t\bs{u}\)，其中 \(0\leqslant t\leqslant1\). 则

\(\overrightarrow{OA}=(1-t)\bs{u}\)，\(\overrightarrow{OB}=\bs{v}-t\bs{u}\)，\(\overrightarrow{OC}=-\bs{v}-t\bs{u}\).

所以

\(\overrightarrow{OA}\cdot(\overrightarrow{OB}+\overrightarrow{OC})=(1-t)\bs{u}\cdot(-2t\bs{u})=-2t(1-t)|\bs{u}|^{2}=-8t(1-t)\).

因为 \(t(1-t)\leqslant\dfrac14\)，等号在 \(t=\dfrac12\) 时成立，故所求最小值为 \(-8\times\dfrac14=-2\).
\end{solution}

如图，圆 \(O_{1}\) 与圆 \(O_{2}\) 的半径都是 \(1\)，\(O_{1}O_{2} = 4\)，过动点 \(P\) 分别作圆 \(O_{1}\)，圆 \(O_{2}\) 的切线 \(PM\)，\(PN\)（\(M\)，\(N\) 分别为切点），使得 \(PM = \sqrt{2}PN\). 试建立适当的坐标系，并求动点 \(P\) 的轨迹方程.

取 \(O_{1}O_{2}\) 的中点 \(O\) 为原点，\(O_{1}O_{2}\) 所在直线为 \(x\) 轴，建立平面直角坐标系，则 \(O_{1}=(-2,0)\)，\(O_{2}=(2,0)\). 设 \(P=(x,y)\)，由切线长定理得

\((x+2)^{2}+y^{2}-1=2\left[(x-2)^{2}+y^{2}-1\right]\).

\((x-6)^{2}+y^{2}=33\).

所以动点 \(P\) 的轨迹方程为 \((x-6)^{2}+y^{2}=33\).

\begin{problem}
甲，乙两人各射击一次，击中目标的概率分别是 \(\frac{2}{3}\) 和 \(\frac{3}{4}\). 假设两人射击是否击中目标，相互之间没有影响；每次射击是否击中目标，相互之间没有影响.
\begin{enumerate}
\item 求甲射击 \(4\) 次，至少 \(1\) 次未击中目标的概率；
\item 求两人各射击 \(4\) 次，甲恰好击中目标 \(2\) 次且乙恰好击中目标 \(3\) 次的概率；
\item 假设某人连续 \(2\) 次未击中目标，则停止射击. 问：乙恰好射击 \(5\) 次后，被中止射击的概率是多少？
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 甲每次击中的概率为 \(\dfrac23\)，四次全部击中的概率为 \(\left(\dfrac23\right)^{4}\). 因此至少一次未击中的概率为
\(\displaystyle 1-\left(\dfrac23\right)^{4}=\dfrac{65}{81}\).
\item 甲恰好击中 \(2\) 次的概率为
\(\displaystyle \mathrm C_{4}^{2}\left(\dfrac23\right)^{2}\left(\dfrac13\right)^{2}=\dfrac{8}{27}\).
乙恰好击中 \(3\) 次的概率为
\(\displaystyle \mathrm C_{4}^{3}\left(\dfrac34\right)^{3}\left(\dfrac14\right)=\dfrac{27}{64}\).
由于两人的射击相互独立，所求概率为
\(\displaystyle \dfrac{8}{27}\cdot\dfrac{27}{64}=\dfrac18\).
\item 乙恰好射击 \(5\) 次后停止，必须第 \(4\)，\(5\) 次连续未击中，且前两次不能都未击中，并且第 \(3\) 次必须击中，否则会在第 \(3\) 或第 \(4\) 次前停止. 因此所求概率为
\(\displaystyle \left[1-\left(\dfrac14\right)^{2}\right]\cdot\dfrac34\cdot\dfrac14\cdot\dfrac14=\dfrac{45}{1024}\).
\end{enumerate}
\end{solution}

\begin{problem}
如图，在五棱锥 \(S-ABCDE\) 中，\(SA \perp\) 底面 \(ABCDE\)，\(SA = AB = AE = 2\)，\(BC = DE = \sqrt{3}\)，\(\angle BAE = \angle BCD = \angle CDE = 120^{\circ}\).
\begin{enumerate}
\item 求异面直线 \(CD\) 与 \(SB\) 所成的角（用反三角函数值表示）；
\item 证明：\(BC \perp\) 平面 \(SAB\)；
\item 用反三角函数值表示二面角 \(B-SC-D\) 的大小（本小问不必写出解答过程）.
\end{enumerate}

\bitmapfigure[max width=0.42\linewidth]{img/2005/jiangsu/q21_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 延长 \(BC\)，\(ED\)，使二者相交于 \(F\). 因为 \(CF\) 是 \(CB\) 的延长线，\(DF\) 是 \(DE\) 的延长线，所以
\(\angle DCF=180^{\circ}-\angle BCD=60^{\circ}\)，\(\angle CDF=180^{\circ}-\angle CDE=60^{\circ}\). 从而 \(\triangle CDF\) 为正三角形，\(CF=DF=\sqrt3\).

又 \(BC=DE=\sqrt3\)，所以 \(BF=EF=2\sqrt3\). 在 \(\triangle ABE\) 中，\(AB=AE=2\)，\(\angle BAE=120^{\circ}\)，由余弦定理得 \(BE=2\sqrt3\). 因而 \(\triangle BFE\) 也是正三角形，于是 \(BE\parallel CD\).

所以异面直线 \(CD\) 与 \(SB\) 所成的角等于直线 \(BE\) 与 \(SB\) 所成的锐角 \(\angle SBE\). 由 \(SA\perp\) 底面，得 \(SB=SE=2\sqrt2\)，从而
\(\displaystyle \cos\angle SBE=\frac{SB^{2}+BE^{2}-SE^{2}}{2SB\cdot BE}=\frac{8+12-8}{2\cdot2\sqrt2\cdot2\sqrt3}=\frac{\sqrt6}{4}\).

故所求角为 \(\displaystyle \arccos\frac{\sqrt6}{4}\).
\item 由 \(AB=AE\) 及 \(\angle BAE=120^{\circ}\)，得 \(\angle ABE=30^{\circ}\). 又 \(BF\) 与 \(BC\) 同向，且 \(\triangle BFE\) 为正三角形，所以 \(\angle EBC=\angle FBE=60^{\circ}\). 因此 \(\angle ABC=30^{\circ}+60^{\circ}=90^{\circ}\)，即 \(BC\perp AB\).

又 \(SA\perp\) 底面 \(ABCDE\)，且 \(BC\) 在底面内，所以 \(BC\perp SA\). 直线 \(AB\)，\(SA\) 是平面 \(SAB\) 内相交的两条直线，故 \(BC\perp\) 平面 \(SAB\).
\item 取底面为 \(z=0\) 平面，令 \(r=\sqrt3\)，建立直角坐标系
\(A=(0,0,0)\)，\(S=(0,0,2)\)，\(B=(2,0,0)\)，\(C=(2,r,0)\)，\(D=\left(\dfrac12,\dfrac{3r}{2},0\right)\)，\(E=(-1,r,0)\). 这些坐标满足题设中的长度和角度条件.

取平面 \(BSC\) 和平面 \(DSC\) 的法向量
\(\bs{n}_{1}=\overrightarrow{SC}\times\overrightarrow{SB}=(-2r,0,-2r)\)，
\(\bs{n}_{2}=\overrightarrow{SC}\times\overrightarrow{SD}=\left(r,3,\dfrac{5r}{2}\right)\). 则

\(\displaystyle \bs{n}_{1}\cdot\bs{n}_{2}=-21,\quad |\bs{n}_{1}|=2\sqrt6,\quad |\bs{n}_{2}|=\frac{\sqrt{123}}{2}\).

设二面角 \(B-SC-D\) 的大小为 \(\theta\)，则
\(\displaystyle \cos\theta=\frac{\bs{n}_{1}\cdot\bs{n}_{2}}{|\bs{n}_{1}||\bs{n}_{2}|}=-\frac{21}{3\sqrt{82}}=-\frac{7\sqrt{82}}{82}\). 因而
\(\displaystyle \theta=\arccos\left(-\frac{7\sqrt{82}}{82}\right)=\pi-\arccos\frac{7\sqrt{82}}{82}\).
\end{enumerate}
\end{solution}

\begin{problem}
已知 \(a \in \R\)，函数 \(f(x) = x^2 |x - a|\).
\begin{enumerate}
\item 当 \(a = 2\) 时，求 \(f(x) = x\) 使成立的 \(x\) 的集合；
\item 求函数 \(y = f(x)\) 在区间 \([1,2]\) 上的最小值.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 当 \(x<2\) 时，\(|x-2|=2-x\)，方程 \(f(x)=x\) 化为
\(x^{2}(2-x)=x\)，即 \(x\left[x(2-x)-1\right]=0\). 因而 \(x=0\) 或 \((x-1)^{2}=0\)，得 \(x=0\)，\(1\).

当 \(x\geqslant2\) 时，\(|x-2|=x-2\)，方程化为 \(x^{2}(x-2)=x\). 因为此时 \(x\neq0\)，所以 \(x^{2}-2x-1=0\)，得 \(x=1+\sqrt2\) 或 \(1-\sqrt2\)，其中只有 \(1+\sqrt2\geqslant2\). 所以所求解集为 \(\{0,1,1+\sqrt2\}\).
\item 设区间 \([1,2]\) 上的最小值为 \(m\). 分情况讨论.

当 \(a\leqslant1\) 时，\(x-a\geqslant0\)，所以 \(f(x)=x^{3}-ax^{2}\)，且
\(f'(x)=x(3x-2a)\geqslant3-2a>0\)（\(1\leqslant x\leqslant2\)）. 因而 \(f\) 在 \([1,2]\) 上递增，\(m=f(1)=1-a\).

当 \(1<a\leqslant2\) 时，\(a\in[1,2]\)，且 \(f(a)=0\)，又 \(f(x)\geqslant0\)，所以 \(m=0\).

当 \(a>2\) 时，\(x-a<0\)，所以 \(f(x)=ax^{2}-x^{3}\)，且 \(f'(x)=x(2a-3x)\). 若 \(a\geqslant3\)，则 \(2a-3x\geqslant2a-6\geqslant0\)，函数在 \([1,2]\) 上递增，\(m=f(1)=a-1\).

若 \(2<a<3\)，则临界点 \(x=\dfrac{2a}{3}\in(1,2)\)，函数在 \(\left[1,\dfrac{2a}{3}\right]\) 上递增，在 \(\left[\dfrac{2a}{3},2\right]\) 上递减，因此最小值取在端点 \(1\) 或 \(2\) 处. 计算得 \(f(1)=a-1\)，\(f(2)=4(a-2)\)，且
\(4(a-2)\leqslant a-1\) 等价于 \(a\leqslant\dfrac73\).

综上，所求最小值为
\examdisplaycases{m =}{
1-a, & a\leqslant 1,\\
0, & 1<a\leqslant 2,\\
4(a-2), & 2<a\leqslant \dfrac{7}{3},\\
a-1, & a>\dfrac{7}{3}.
}
\end{enumerate}
\end{solution}

\begin{problem}
设数列 \(\{a_{n}\}\) 的前 \(n\) 项和为 \(S_{n}\)，已知 \(a_1 = 1\)，\(a_2 = 6\)，\(a_3 = 11\)，且 \((5n - 8)S_{n+1} - (5n + 2)S_n = An + B\)，\(n = 1\)，\(2\)，\(3\)，\(\cdots\)，其中 \(A\)，\(B\) 为常数.
\begin{enumerate}
\item 求 \(A\) 与 \(B\) 的值；
\item 证明数列 \(\{a_{n}\}\) 为等差数列；
\item 证明不等式 \(\sqrt{5a_{mn}} - \sqrt{a_m a_n} > 1\) 对任何正整数 \(m\)，\(n\) 都成立.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 由 \(S_{1}=a_{1}=1\)，\(S_{2}=a_{1}+a_{2}=7\)，\(S_{3}=a_{1}+a_{2}+a_{3}=18\). 将 \(n=1\)，\(2\) 分别代入题设等式，得

\(-3S_{2}-7S_{1}=A+B\)，\(2S_{3}-12S_{2}=2A+B\)，即 \(A+B=-28\)，\(2A+B=-48\). 解得 \(A=-20\)，\(B=-8\).
\item 由上一问，题设关系为
\((5n-8)S_{n+1}-(5n+2)S_{n}=-20n-8\). 将 \(n\) 换成 \(n+1\)，再与原式相减，得

\((5n-3)S_{n+2}-(10n-1)S_{n+1}+(5n+2)S_{n}=-20\). 再将 \(n\) 换成 \(n+1\)，并与上式相减，得到

\((5n+2)S_{n+3}-(15n+6)S_{n+2}+(15n+6)S_{n+1}-(5n+2)S_{n}=0\).

利用 \(a_{n+1}=S_{n+1}-S_{n}\)，上式化为
\((5n+2)a_{n+3}-2(5n+2)a_{n+2}+(5n+2)a_{n+1}=0\). 因为 \(5n+2\neq0\)，所以
\(a_{n+3}-2a_{n+2}+a_{n+1}=0\)，即 \(a_{n+3}-a_{n+2}=a_{n+2}-a_{n+1}\).

又 \(a_{2}-a_{1}=5\)，\(a_{3}-a_{2}=5\)，故数列 \(\{a_{n}\}\) 为等差数列，公差为 \(5\)，从而 \(a_{n}=1+5(n-1)=5n-4\).
\item 由上一问，\(a_{mn}=5mn-4\)，\(a_{m}=5m-4>0\)，\(a_{n}=5n-4>0\). 记
\(X=5a_{mn}=25mn-20\)，\(Y=a_{m}a_{n}=25mn-20m-20n+16\). 则

\(X-Y-1=20m+20n-37\).

由基本不等式 \(2\sqrt{Y}\leqslant a_{m}+a_{n}=5m+5n-8\)，以及 \(m,n\) 为正整数，得
\(2\sqrt{Y}\leqslant5m+5n-8<20m+20n-37=X-Y-1\)，其中最后一个不等式等价于 \(15m+15n>29\)，显然成立.

于是 \(X>Y+1+2\sqrt{Y}=(\sqrt{Y}+1)^{2}\). 因为 \(X,Y\geqslant0\)，开平方得 \(\sqrt{X}-\sqrt{Y}>1\)，即
\(\sqrt{5a_{mn}}-\sqrt{a_{m}a_{n}}>1\). 不等式对任意正整数 \(m\)，\(n\) 都成立.
\end{enumerate}
\end{solution}
