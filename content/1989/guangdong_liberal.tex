\section{解答题}

\begin{problem}

设 \(f(x) = a^{x - 1}\)，其中常数 \(a > 0\).

\begin{enumerate}
\item 如果 \(\{x_n\}\) 是等差数列，求证：\(\{f(x_n)\}\) 是等比数列；
\item 如果 \(a = 4\)，解方程 \(4f(x) + f(-x) - 1 = 0\).
\end{enumerate}

\end{problem}

\begin{solution}
（1）设等差数列 \(\{x_n\}\) 的公差为 \(d\). 因为 \(a > 0\)，所以 \(f(x_n) = a^{x_n - 1} \neq 0\). 当 \(n \geqslant 2\) 时，\(\frac{f(x_n)}{f(x_{n-1})} = \frac{a^{x_n - 1}}{a^{x_{n-1} - 1}} = a^d\). 因为 \(a^d\) 是不等于 0 的常数，所以 \(\{f(x_n)\}\) 是等比数列.

（2）当 \(a = 4\) 时，方程化为 \(4^x + 4^{-x - 1} - 1 = 0\). 令 \(4^x = y\)，则原方程化为 \(y + \frac{1}{4y} - 1 = 0\). 解得 \(y = \frac{1}{2}\)，所以 \(x = -\frac{1}{2}\).
\end{solution}

\begin{problem}

如图，在平面 \(\beta\) 内有 \(\triangle ABO\)，在平面 \(\beta\) 外有点 \(S\)，斜线 \(SA \perp AO\)，\(SB \perp BO\)，且斜线段 \(SA\) 和 \(SB\) 在 \(\beta\) 内的射影是等长的线段.

\begin{enumerate}
\item 求证：\(AO = BO\)；
\item 又设点 \(S\) 与平面 \(\beta\) 的距离为 \(3\mathrm{~cm}\)，且 \(AO \perp BO\)，\(AB = 4\mathrm{~cm}\)，求线段 \(SO\) 的长.
\end{enumerate}

\bitmapfigure[max width=0.42\linewidth]{img/1989/guangdong_liberal/q2_fig1.png}

\end{problem}

\begin{solution}
（1）如图，作 \(SD \perp \beta\) 于 \(D\)，连结 \(AD\)，\(BD\). 由已知 \(AD = BD\)，所以 \(SA = SB\). 因此 \(\mathrm{Rt}\triangle SAO \cong \mathrm{Rt}\triangle SBO\)，故 \(AO = BO\).

\bitmapfigure[max width=0.42\linewidth]{img/1989/guangdong_liberal/q2_solution_fig1.png}

（2）由三垂线定理的逆定理，可知 \(\angle DAO = \angle DBO = 90^\circ\). 又 \(\angle AOB = 90^\circ\)，且 \(AO = BO\)，所以四边形 \(AOBD\) 是正方形，因此 \(OD = AB = 4\mathrm{~cm}\). 又 \(SD = 3\mathrm{~cm}\)，所以 \(SO = \sqrt{3^2 + 4^2} = 5\mathrm{~cm}\).
\end{solution}

\begin{problem}

已知复数 \(z = 1 - 2\i\)，其中 \(\i\) 是虚数单位.

\begin{enumerate}
\item 求 \(\frac{2}{z + \i} - \overline{(z + 1)}\) 的值，并把该值表示成三角形式；
\item 求适合不等式 \(\log_{0.5}\left|\frac{az - \i}{\sqrt{a + 1}}\right| \leqslant \frac{1}{2}\) 的实数 \(a\) 的取值范围.
\end{enumerate}

\end{problem}

\begin{solution}
（1）因为 \(z = 1 - 2\i\)，所以
\[
\begin{gathered}
\frac{2}{z + \i} - \overline{(z + 1)}=\frac{2}{1 - \i} - \overline{(2 - 2\i)}=1 + \i - (2 + 2\i),\\
\frac{2}{z + \i} - \overline{(z + 1)}=-1 - \i.
\end{gathered}
\]
将其表示成三角形式，得 \(-1 - \i = \sqrt{2}\left(\cos \frac{5\pi}{4} + \i \sin \frac{5\pi}{4}\right)\).

（2）因为 \(z = 1 - 2\i\)，所以 \(|az - \i| = \sqrt{5a^2 + 4a + 1}\). 由已知不等式可得
\[
\left\{
\begin{aligned}
\frac{\sqrt{5a^2 + 4a + 1}}{\sqrt{a + 1}} &\geqslant \sqrt{\frac{1}{2}},\\
a + 1 &> 0,\\
\frac{\sqrt{5a^2 + 4a + 1}}{\sqrt{a + 1}} &> 0.
\end{aligned}
\right.
\]
由 \(a+1>0\)，不等式第一项两边平方，得 \(10a^2+7a+1\geqslant0\)，即 \(a\leqslant-\frac{1}{2}\) 或 \(a\geqslant-\frac{1}{5}\). 因此 \(a\) 的取值范围为 \(\left(-1,-\frac{1}{2}\right]\cup\left[-\frac{1}{5},+\infty\right)\).
\end{solution}

\begin{problem}

设圆 \(O\) 的方程为 \(x^2 - 2x\cos \theta + y^2 + 2(1 + 2\sin \theta)y = 0\)，其中 \(0\leqslant\theta<2\pi\).

\begin{enumerate}
\item 当 \(\theta\) 变化时，求圆 \(O\) 的圆心轨迹的普通方程，并画出轨迹的草图；
\item 如果又有圆 \(S\)：\(x^2 + y^2 + 2y = 0\)，求 \(\theta\) 的值，使得圆 \(O\) 与圆 \(S\) 的公共弦的长度取最大值（请把满足条件的 \(\theta\) 的值都求出来）.
\end{enumerate}
\end{problem}

\begin{solution}
（1）圆 \(O\) 的圆心为 \(C(\cos\theta,-1-2\sin\theta)\). 令圆心坐标为 \((x,y)\)，消去 \(\theta\) 得 \(x^2+\frac{(y+1)^2}{4}=1\)，即 \(4x^2+(y+1)^2=4\). 因此圆心轨迹是中心为 \((0,-1)\)、半轴长分别为 \(1\) 和 \(2\) 的椭圆.

（2）两圆方程相减，得公共弦所在直线 \(x\cos\theta-2y\sin\theta=0\). 圆 \(S\) 的圆心为 \(S_0(0,-1)\)，半径为 \(1\)，圆心到该直线的距离为
\[
p=\frac{2|\sin\theta|}{\sqrt{\cos^2\theta+4\sin^2\theta}}=\frac{2|\sin\theta|}{\sqrt{1+3\sin^2\theta}}
\]
故公共弦长为
\[
L=2\sqrt{1-p^2}=\frac{2|\cos\theta|}{\sqrt{1+3\sin^2\theta}}
\]
当且仅当 \(\sin\theta=0\) 时，\(L\) 取得最大值 \(2\). 由 \(0\leqslant\theta<2\pi\)，得 \(\theta=0\) 或 \(\pi\).
\end{solution}
