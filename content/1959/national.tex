\begin{problem}
已知 \(\lg 2=0.3010\)，\(\lg 7=0.8451\)，求 \(\lg 35\).
\end{problem}

\begin{solution}
\[\lg 35=\lg \frac{10\times 7}{2}=\lg 10+\lg 7-\lg 2=1+0.8451-0.3010=1.5441\]
\end{solution}

\begin{problem}
化简 \(\frac{\left( 1-\i \right)^3}{1+\i}\).
\end{problem}

\begin{solution}
【法一】
\[\frac{\left( 1-\i \right)^3}{1+\i}=\frac{\left( 1-\i \right)^4}{2}=\frac{1-4\i+6\i^2-4\i^3+\i^4}{2}=\frac{1-4\i-6+4\i+1}{2}=-2\]

【法二】
\[\frac{\left( 1-\i \right)^3}{1+\i}=\frac{1-3\i+3\i^2-\i^3}{1+\i}=\frac{1-3\i-3+\i}{1+\i}=\frac{-2-2\i}{1+\i}=-2\]
\end{solution}

\begin{problem}
解不等式：\(2x^2+5x<3\).
\end{problem}

\begin{solution}
【法一】
\(2x^2+5x<3\). 移项，得 \(2x^2+5x-3<0\)，\(\left( 2x-1 \right)\left( x+3 \right)<0\).
因为两个数的积是负数，必须并且只须这两个数中一个是正数，一个是负数，所以从这个不等式可以得出下面两个不等式组：
\[
\begin{cases}
2x-1>0\\
x+3<0
\end{cases}
\]
或
\[
\begin{cases}
2x-1<0\\
x+3>0
\end{cases}
\]
第一个不等式组没有解，第二个不等式组的解是 \(-3<x<\frac{1}{2}\). 所以原不等式的解是 \(-3<x<\frac{1}{2}\).

【法二】
\(2x^2+5x<3\). 移项，得 \(2x^2+5x-3<0\). 不等式两边都乘以 \(-1\)，得 \(-2x^2-5x+3>0\). 因为 \(\Delta=\left( -5 \right)^2-4\times \left( -2 \right)\times 3>0\)，二次三项式 \(-2x^2-5x+3\) 的根是 \(-3\) 和 \(\frac{1}{2}\). 当 \(-3<x<\frac{1}{2}\) 的时候，\(-2x^2-5x+3\) 和 \(-2\) 异号. 因此，原不等式的解是 \(-3<x<\frac{1}{2}\).
\end{solution}

\begin{problem}
求 \(\cos 165^\circ\) 的值.
\end{problem}

\begin{solution}
【法一】
\[\cos 165^\circ=\cos \left( 180^\circ-15^\circ \right)=-\cos 15^\circ=-\cos \left( 45^\circ-30^\circ \right)\]
\[\cos 165^\circ=-\left( \cos 45^\circ \cos 30^\circ+\sin 45^\circ \sin 30^\circ \right)=-\left( \frac{1}{\sqrt{2}}\cdot \frac{\sqrt{3}}{2}+\frac{1}{\sqrt{2}}\cdot \frac{1}{2} \right)=-\frac{\sqrt{6}+\sqrt{2}}{4}\]

【法二】
\[\cos 165^\circ=\cos \left( 180^\circ-15^\circ \right)=-\cos 15^\circ=-\cos \frac{30^\circ}{2}\]
\[\cos 165^\circ=-\sqrt{\frac{1+\cos 30^\circ}{2}}=-\sqrt{\frac{1+\frac{\sqrt{3}}{2}}{2}}=-\frac{\sqrt{6}+\sqrt{2}}{4}\]
\end{solution}

\begin{problem}
一直圆台上底的面积为 \(25\pi \mathrm{~cm}^2\)，下底的直径为 \(20 \mathrm{~cm}\)，母线长为 \(10 \mathrm{~cm}\). 求这直圆台的侧面积.
\end{problem}

\begin{solution}
圆台侧面积 \(S=\pi L\left( R+r \right)\)，其中 \(L\) 为母线，\(r\)，\(R\) 分别为上，下底的半径. 上底面积为 \(\pi r^2=25\pi \mathrm{~cm}^2\)，所以 \(r=5 \mathrm{~cm}\). 下底半径 \(R=\frac{20}{2} \mathrm{~cm}=10 \mathrm{~cm}\). 母线 \(L=10 \mathrm{~cm}\). 所以这圆台侧面积
\[S=\pi L\left( R+r \right)=\pi\cdot 10\cdot \left( 10+5 \right)=150\pi \mathrm{~cm}^2\]
\end{solution}

\begin{problem}
有三条不在同一平面内的平行线 \(a\)，\(b\) 和 \(c\). 在线 \(a\) 上取一固定线段 \(AB\)，在线 \(c\)，\(b\) 上各任取一点 C 和 D. 求证：不论 C 和 D 取在 \(c\)，\(b\) 的什么位置上，四面体 \(ABCD\) 的体积总是不变的.

\bitmapfigure[max width=0.34\linewidth,trim=0 0.35cm 0 0.1cm,clip]{img/1959/national/q1_fig1.png}
\end{problem}

\begin{solution}
\(\triangle ABD\) 当四面体 \(ABCD\) 的底（如图），作底上的高 \(CO\).
因为 \(a\parallel b\)，所以无论 \(D\) 在 \(b\) 上什么位置，\(\triangle ABD\) 的面积总不变.
又因为 \(a\parallel b\)，所以 \(a\)，\(b\) 决定一平面. 因为 \(c\parallel a\)，\(c\parallel b\)，所以 \(c\) 平行于 \(a\)，\(b\) 所决定的平面.
所以无论 \(C\) 点在 \(c\) 的什么位置，高 \(CO\) 的高度总不变.
四面体的体积等于 \(\frac{1}{3}\times\) 高 \(\times\) 底面积，因之，无论 \(C\)，\(D\) 在 \(c\)，\(b\) 上什么位置，其体积总不变.
\end{solution}

\begin{problem}
三个数成等差数列，前两个数的和的三倍等于第三个数的二倍；如果第二个数减去 \(2\)（仍当作第二项），三个数就成等比数列. 求原来的三个数.

\end{problem}

\begin{solution}
设成等差数列的三个数是 \(x-y\)，\(x\)，\(x+y\)，依据题中条件，列出方程组：
\[
\begin{cases}
3\left[ \left( x-y \right)+x \right]=2\left( x+y \right)\\
\left( x-2 \right)^2=\left( x-y \right)\left( x+y \right)
\end{cases}
\]
化简以上两式，得：
\[
\begin{cases}
4x=5y\\
y^2-4x+4=0
\end{cases}
\]
将 \(4x=5y\) 代入 \(y^2-4x+4=0\)，得 \(y^2-5y+4=0\)，\(\left( y-1 \right)\left( y-4 \right)=0\). 故 \(y_1=1\)，\(y_2=4\). 将 \(y_1\) 与 \(y_2\) 的值代入 \(4x=5y\)，得 \(x_1=\frac{5}{4}\)，\(x_2=5\). 故 \(x_1=\frac{5}{4}\)，\(y_1=1\)；\(x_2=5\)，\(y_2=4\). 又 \(x_1-y_1=\frac{1}{4}\)，\(x_1+y_1=\frac{9}{4}\)；\(x_2-y_2=1\)，\(x_2+y_2=9\). 答：所求的三个数是 \(\frac{1}{4}\)，\(\frac{5}{4}\)，\(\frac{9}{4}\) 或 \(1\)，\(5\)，\(9\).
\end{solution}

\begin{problem}
设有 \(\triangle ABC\)，已知 \(\angle B=60^\circ\)，\(AC\) 边长为 \(4\)，面积为 \(\sqrt{3}\). 求 \(AB\) 及 \(BC\) 两边之长.

\end{problem}

\begin{solution}
设 \(AB\) 及 \(BC\) 两边之长为 \(x\) 及 \(y\)，则有 \(x^2+y^2-2xy\cos 60^\circ=4^2\)，\(\frac{1}{2}xy\sin 60^\circ=\sqrt{3}\). 代入 \(\cos 60^\circ\) 及 \(\sin 60^\circ\) 的值，得到 \(x^2+y^2-xy=16\)，\(xy=4\). 化简，得到 \(x^2+y^2=20\)，\(2xy=8\). 两式相加，得 \(\left( x+y \right)^2=28\)；两式相减，得 \(\left( x-y \right)^2=12\). 由此得 \(x+y=2\sqrt{7}\)，\(x-y=\pm 2\sqrt{3}\). 所以 \(x=\sqrt{7}\pm \sqrt{3}\)，\(y=\sqrt{7}\mp \sqrt{3}\). 答：\(AB\) 之长为 \(\sqrt{7}\pm \sqrt{3}\)，\(BC\) 之长为 \(\sqrt{7}\mp \sqrt{3}\).
\solutionfigure{\bitmapfigure[max width=0.34\linewidth]{img/1959/national/q3_solution_fig1.png}}
\end{solution}

\begin{problem}
\(A\)，\(B\)，\(C\) 是直线 \(L\) 上三点，\(P\) 是这直线外一点. 已知 \(AB=BC=a\)，\(\angle APB=90^\circ\)，\(\angle BPC=45^\circ\). 试求：

\begin{enumerate}
\item \(\angle PBA\) 的正弦，余弦，正切；
\item 线段 \(PB\) 的长；
\item \(P\) 点到直线 \(L\) 的距离.
\end{enumerate}

\end{problem}

\begin{solution}
【法一】令 \(\angle PBA=\theta\)，\(PB=x\)，\(P\) 点到直线 \(L\) 的距离为 \(h\). 由 \(\triangle APB\) 知 \(x=a\cos \theta\). 由 \(\triangle BPC\) 知 \(\frac{a}{\sin 45^\circ}=\frac{x}{\sin \left( \theta-45^\circ \right)}\). 由这两式消去 \(x\)，得 \(\frac{a}{\sin 45^\circ}=\frac{a\cos \theta}{\sin \left( \theta-45^\circ \right)}\). 于是 \(\sqrt{2}\left( \sin \theta \cos 45^\circ-\cos \theta \sin 45^\circ \right)=\cos \theta\)，所以 \(\sin \theta-\cos \theta=\cos \theta\)，即 \(\sin \theta=2\cos \theta\). 故 \(\tan \theta=2\). \(\theta\) 是锐角，所以 \(\sin \theta=\frac{2}{\sqrt{5}}\)，\(\cos \theta=\frac{1}{\sqrt{5}}\). 于是 \(x=a\cos \theta=\frac{a}{\sqrt{5}}\)，\(h=x\sin \theta=\frac{2}{5}a\).

答：（1）\(\angle PBA\) 的正弦，余弦及正切分别是 \(\frac{2}{\sqrt{5}}\)，\(\frac{1}{\sqrt{5}}\)，\(2\).
（2）\(PB\) 的长是 \(\frac{a}{\sqrt{5}}\).
（3）\(P\) 到 \(L\) 的距离为 \(\frac{2}{5}a\).

【法二】由 \(\frac{a}{\sin 45^\circ}=\frac{x}{\sin \left( \theta-45^\circ \right)}\) 得
\[x=\frac{a\sin \left( \theta-45^\circ \right)}{\sin 45^\circ}=a\sqrt{2}\left( \sin \theta \cos 45^\circ-\cos \theta \sin 45^\circ \right)=a\sin \theta-a\cos \theta\]
由 \(x=a\cos \theta\)，并因 \(\theta\) 是锐角，得 \(\sin \theta=\frac{\sqrt{a^2-x^2}}{a}\). 将这两式代入上式，得 \(x=\sqrt{a^2-x^2}-x\). 由此得 \(5x^2=a^2\)，\(x=\frac{a}{\sqrt{5}}\). 于是 \(\cos \theta=\frac{x}{a}=\frac{1}{\sqrt{5}}\)，\(\sin \theta=\frac{2}{\sqrt{5}}\)，\(\tan \theta=2\)，\(h=x\sin \theta=\frac{2}{5}a\).
\solutionfigure{\bitmapfigure[max width=0.36\linewidth]{img/1959/national/q4_solution_fig1.png}}
\end{solution}

\begin{problem}
延长圆 \(O\) 的两弦 \(AB\)，\(CD\) 交于圆外一点 \(E\)，过 \(E\) 点作 \(DA\) 的平行线交 \(CB\) 的延长线于点 \(F\)，自 \(F\) 点作圆 \(O\) 的切线 \(FG\). 求证 \(FG=FE\).

\bitmapfigure[max width=0.42\linewidth,trim=0 0.45cm 0 0.15cm,clip]{img/1959/national/q5_fig1.png}

\end{problem}

\begin{solution}
因为 \(EF\parallel DA\)，所以 \(\angle FEB=\angle BAD\). 而 \(\angle BAD=\angle BCD\)，所以 \(\angle FEB=\angle BCD\). 又 \(\angle EFB=\angle EFC\)，所以 \(\triangle EFB\sim \triangle CFE\).
因此，\(FE:FC=FB:FE\)，即 \(FE^2=FB\cdot FC\).
因为 \(FG\) 是圆 \(O\) 的切线，\(FBC\) 是圆 \(O\) 的割线，所以 \(FG^2=FB\cdot FC\).
因此 \(FG^2=FE^2\)，即 \(FG=FE\).
\solutionfigure{\bitmapfigure[max width=0.42\linewidth,trim=0 0.45cm 0 0.15cm,clip]{img/1959/national/q5_solution_fig1.png}}
\end{solution}
