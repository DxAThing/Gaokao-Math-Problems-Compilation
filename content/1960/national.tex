\chapter{1960年全国卷}

\begin{problem}
\begin{enumerate}
\item
解方程 \(\sqrt{2x^{2}-5}-\sqrt{5x-7}=0\). （限定在实数范围内）

\item
有 \(5\) 组篮球队，每组 \(6\) 队. 首先每组中各队进行单循环比赛（即每两队比赛一次），然后各组的冠军再进行单循环比赛. 问先后共比赛多少次？

\item
求证等比数列的各项的对数组成等差数列. （这里所说的等比数列的各项都是正数）

\item
求使等式 \(\sqrt{1-\sin^{2}\frac{x}{2}}=\cos\frac{x}{2}\) 成立的 \(x\) 值的范围. （\(x\) 是 \(0^{\circ}\) 到 \(720^{\circ}\) 的角）

\item
如图，用钢珠测量机件上一小孔的直径. 所用钢珠的中心是 \(O\)，直径是 \(12\text{ 毫米}\). 将钢珠放在这小孔上，测得钢珠上端 \(D\) 到机件平面的距离 \(CD\) 是 \(9\text{ 毫米}\). 求这小孔的直径 \(AB\) 的长.

\begingroup
\def\theprobnum{5}%
\bitmapfigure[max width=0.34\linewidth]{img/1960/national/q5_fig1.png}
\endgroup

\item
四棱锥 \(P-ABCD\) 的底面是一正方形. \(PA\) 与底面垂直. 已知 \(PA\) 是 \(3\text{ 厘米}\)，\(P\) 点到 \(BC\) 的距离是 \(5\text{ 厘米}\). 求 \(PC\) 的长.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item
由 \(\sqrt{2x^{2}-5}-\sqrt{5x-7}=0\)，得 \(\sqrt{2x^{2}-5}=\sqrt{5x-7}\)，所以 \(2x^{2}-5=5x-7\). 整理得 \(2x^{2}-5x+2=0\)，即 \((2x-1)(x-2)=0\)，所以 \(x=\frac12\) 或 \(2\). 因为 \(x=\frac12\) 使原方程无意义，舍去，所以 \(x=2\).

\item
\[
5\mathrm C_6^2+\mathrm C_5^2=5\times\frac{6\cdot5}{1\cdot2}+\frac{5\cdot4}{1\cdot2}=75+10=85
\]
答：共比赛 \(85\) 次.

\item
设等比数列为 \(a\)，\(aq\)，\(aq^2\)，\(\ldots\)，\(aq^{n-1}\). 则各项的对数依次为 \(\log a\)，\(\log(aq)\)，\(\log(aq^2)\)，\(\ldots\)，\(\log(aq^{n-1})\)，即 \(\log a\)，\(\log a+\log q\)，\(\log a+2\log q\)，\(\ldots\)，\(\log a+(n-1)\log q\). 因此，上面的数列是以 \(\log a\) 为首项，\(\log q\) 为公差的等差数列.

\item
根据算术根的定义，\(\cos\frac{x}{2}\ge0\). 所以，\(0^{\circ}\le\frac{x}{2}\le90^{\circ}\) 和 \(270^{\circ}\le\frac{x}{2}\le360^{\circ}\)，即 \(0^{\circ}\le x\le180^{\circ}\) 和 \(540^{\circ}\le x\le720^{\circ}\).

\item
解法一：设 \(AB\) 为 \(x\text{ 毫米}\)，则 \(AC=\frac{x}{2}\text{ 毫米}\). 又直径 \(DE=12\text{ 毫米}\)，\(CD=9\text{ 毫米}\)，所以 \(CE=12-9=3\text{ 毫米}\). 因为 \(AC^{2}=DC\cdot CE\)，所以 \(\left(\frac{x}{2}\right)^2=9\times3\)，从而 \(x^{2}=9\times3\times4\)，所以 \(x=6\sqrt3\)（取正值）. 答：小孔的直径是 \(6\sqrt3\text{ 毫米}\).

解法二：设 \(AB\) 为 \(x\text{ 毫米}\)，则 \(AC=\frac{x}{2}\text{ 毫米}\). 又 \(CD=9\text{ 毫米}\)，半径 \(OD=6\text{ 毫米}\)，所以 \(OC=9-6=3\text{ 毫米}\). 连结 \(OA\)，则 \(OA=6\text{ 毫米}\). 在直角三角形 \(OAC\) 中，\(OA^{2}=OC^{2}+AC^{2}\)，即 \(6^{2}=3^{2}+\left(\frac{x}{2}\right)^2\)，所以 \(\frac{x^{2}}{4}=27\)，从而 \(x=6\sqrt3\)（取正值）. 答：小孔的直径是 \(6\sqrt3\text{ 毫米}\).

\item
因为 \(PA\perp\) 平面 \(ABCD\)，又 \(AB\perp BC\)，所以 \(PB=5\text{ 厘米}\). 又 \(PA=3\text{ 厘米}\)，因此 \(AB=BC=4\text{ 厘米}\). 所以
\[
PC=\sqrt{PB^{2}+BC^{2}}=\sqrt{5^{2}+4^{2}}=\sqrt{41}
\]
答：\(PC\) 是 \(\sqrt{41}\text{ 厘米}\).
\end{enumerate}
\solutionfigure{\bitmapfigure[max width=0.34\linewidth]{img/1960/national/q6_solution_fig1.png}}
\end{solution}

\begin{problem}
有一直圆柱，高是 \(20\text{ 厘米}\)，底面半径是 \(5\text{ 厘米}\). 它的一个内接长方体的体积是 \(800\text{ 立方厘米}\). 求这长方体的底面的长和宽.
\end{problem}

\begin{solution}
设底面的长和宽分别是 \(x\) 厘米和 \(y\) 厘米，则
\[
\begin{cases}
x^{2}+y^{2}=10^{2},\\
20xy=800
\end{cases}
\]
方程组可变形为
\[
\begin{cases}
x^{2}+y^{2}=100,\\
2xy=80
\end{cases}
\]
解这个方程组，得 \((x+y)^{2}=180\)，所以 \(x+y=6\sqrt5\). 其中只取正值. 又 \((x-y)^{2}=20\)，所以 \(x-y=\pm2\sqrt5\).

分别解下面的两个方程组：
\[
\begin{cases}
x+y=6\sqrt5,\\
x-y=2\sqrt5
\end{cases}
\qquad
\begin{cases}
x+y=6\sqrt5,\\
x-y=-2\sqrt5
\end{cases}
\]
就得出
\[
\begin{cases}
x_1=4\sqrt5,\\
y_1=2\sqrt5
\end{cases}
\qquad
\begin{cases}
x_2=2\sqrt5,\\
y_2=4\sqrt5
\end{cases}
\]
答：底面的长和宽分别是 \(4\sqrt5\text{ 厘米}\) 和 \(2\sqrt5\text{ 厘米}\).
\end{solution}

\begin{problem}
从一船上看到在它的南 \(30^{\circ}\) 东的海面上有一灯塔. 船以 \(30\text{ 浬/小时}\) 的速度向正东南方向航行半小时后，看到这个灯塔在船的正西方. 问这时船与灯塔的距离是多少？（精确到 \(0.1\text{ 浬}\)）
\end{problem}

\begin{solution}
解法一：如图，\(A\) 是原来船的位置，\(B\) 是灯塔，\(C\) 是航行半小时后船的位置. \(AC=30\times\frac12=15\text{ 浬}\)，\(\angle BAC=45^{\circ}-30^{\circ}=15^{\circ}\)，\(\angle ABC=120^{\circ}\).
\[
\begin{gathered}
BC=\frac{AC\cdot\sin15^{\circ}}{\sin120^{\circ}}=\frac{15(\sin45^{\circ}\cos30^{\circ}-\cos45^{\circ}\sin30^{\circ})}{\sin60^{\circ}},\\
BC=\frac{5\sqrt2(3-\sqrt3)}{2}\approx4.5
\end{gathered}
\]
答：船与灯塔的距离是 \(4.5\text{ 浬}\).
\solutionfigure{\bitmapfigure[max width=0.34\linewidth]{img/1960/national/q3_solution_fig1.png}}

解法二：如图，过 \(A\) 引 \(CB\) 的垂线，与 \(CB\) 的延长线交于 \(D\) 点. \(AC=30\times\frac12=15\text{ 浬}\). 在 \(\triangle ADC\) 中，\(DA=DC=AC\sin45^{\circ}=\frac{15\sqrt2}{2}\). 在 \(\triangle ADB\) 中，\(DB=DA\tan30^{\circ}=\frac{15\sqrt2}{2}\times\frac{\sqrt3}{3}=\frac{5\sqrt6}{2}\). 所以 \(BC=DC-DB=\frac{15\sqrt2}{2}-\frac{5\sqrt6}{2}=\frac{5(3\sqrt2-\sqrt6)}{2}\approx4.5\). 答：船与灯塔的距离是 \(4.5\text{ 浬}\).
\end{solution}

\begin{problem}
要在墙上开一矩形的大玻璃窗，周长限定为 \(6\text{ 米}\).

\begin{enumerate}
\item 求以矩形的一条边长 \(x\) 表示窗户的面积 \(y\) 的函数式.
\item 求这函数图象的顶点的坐标，对称轴的方程.
\item 画出这函数的图象，并求出 \(x\) 的允许值的范围.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item
\(y=(3-x)x=-x^{2}+3x\).

\item
\(y=-\left(x^{2}-3x+\frac94\right)+\frac94=-\left(x-\frac32\right)^{2}+\frac94\). 顶点的坐标 \(\left(\frac32,\frac94\right)\)，对称轴的方程 \(x=\frac32\).

\item
\(-x^{2}+3x=0\)，\(x_1=0\)，\(x_2=3\). \(x\) 的允许值的范围：\(0<x<3\).
\end{enumerate}

\end{solution}

\section{选作题}

\begin{problem}
已知方程 \(2x^{2}-x\cdot4\sin\theta+3\cos\theta=0\) 的两个根相等，且 \(\theta\) 为锐角，求 \(\theta\) 和这个方程的两个根.
\end{problem}

\begin{solution}
\(\Delta=16\sin^{2}\theta-24\cos\theta=0\)，即 \(2\sin^{2}\theta-3\cos\theta=0\). 由 \(\sin^{2}\theta=1-\cos^{2}\theta\)，该方程可变形为 \(2\cos^{2}\theta+3\cos\theta-2=0\)，即 \((2\cos\theta-1)(\cos\theta+2)=0\).

\(\cos\theta+2=0\)，无解.

由 \(2\cos\theta-1=0\)，得 \(\cos\theta=\frac12\). 因为 \(\theta\) 为锐角，所以 \(\theta=60^{\circ}\). 所以 \(x=\frac{4\sin60^{\circ}}{4}=\sin60^{\circ}=\frac{\sqrt3}{2}\). 答：\(\theta\) 是 \(60^{\circ}\)，方程的两个根都是 \(\frac{\sqrt3}{2}\).
\end{solution}

\begin{problem}
\(a\) 是什么实数的时候，下列方程组的解是正数：
\(
\begin{cases}
2x+ay=4,\\
x+4y=8
\end{cases}
\)
\end{problem}

\begin{solution}
记题干中的两式分别为第一式，第二式. 由第二式乘 \(2\) 减第一式，得 \((8-a)y=12\). 当 \(a\neq8\) 时，\(y=\frac{12}{8-a}\). 把 \(y=\frac{12}{8-a}\) 代入第二式中，得 \(x=\frac{16-8a}{8-a}=\frac{8(2-a)}{8-a}\). 要使 \(y\) 是正数，必须并且只须 \(8-a>0\). 由此要使 \(x\) 是正数，必须并且只须 \(2-a>0\). 解不等式组
\[
\begin{cases}
8-a>0,\\
2-a>0
\end{cases}
\]
得 \(a<2\). 因此，当 \(a<2\) 的时候，原方程组的解是正数.
\end{solution}
