\begin{problem}
解方程 \( \frac{7}{2x+6}-\frac{3}{4}=\frac{5}{x+3} \)  解：将方程两边同乘以 \( 4(x+3) \) \[ 1 4 - 3 (x + 3) = 2 0 \] \[ - 3 (x + 3) = 6 \] \[ x + 3 = - 2 \] \[ x = - 5. \] 将 \(x = -5\) 代入原方程 左边 \(= \frac{7}{-10 + 6} -\frac{3}{4} = -\frac{5}{2}\)， 右边 \(= -\frac{5}{-5 + 3} = -\frac{5}{2}\) 左边 \(=\) 右边 因此 \(x=-5\) 为方程的根. 

\end{problem}

\begin{problem}
已知 \(AB\)，\(AC\) 是 \( \odot O \) 的切线，\(B\)，\(C\) 是切点，\( \angle BAC = 120^{\circ} \)，\(AO=10\mathrm{cm}\)，求 \( \odot O \) 的半径和切线 \(AB\) 的长. 解：\( \angle BAO=\frac{1}{2}\angle BAC=60^{\circ} \)（园外一点 \(A\) 与园心的联线平分过这点的两条切线间的夹角）连 \(OB\)，则 \(OB\perp AB\)（过切点的半径垂直于切线）. 因此半径 \( r = OA \cdot \sin 60^{\circ} = 10 \times \frac{\sqrt{3}}{2} = 5 \sqrt{3} \). \(AB = OA \cdot \cos 60^{\circ} = 10 \times \frac{1}{2} = 5\). 

\end{problem}

\begin{problem}
在直角 \(\triangle ABC\) 中，\(\angle C=90^\circ\)，\(CD\perp AB\). 求证 \(\frac{CD}{AD}=\frac{BD}{CD}\). 证：因为 \(\angle A\) 与 \(\angle B\) 互余，\(\angle A\) 与 \(\angle 2\) 互余， \[ \text{所以} \angle B = \angle 2. \angle B D C = \angle A D C = 9 0 ^{\circ} (C D \perp A B) \] \[ \triangle A D C \sim \triangle B D C (a, a) \] 因此 \( \frac{CD}{BD}=\frac{AD}{CD} \)（相似形对应边成比例）故 \(\frac{\mathrm{CD}}{\mathrm{AD}} = \frac{\mathrm{BD}}{\mathrm{CD}}\)（更比定理）

\end{problem}

\begin{problem}
甲、乙两个车间按计划每月共生产450件产品，粉碎“四人帮”之后，在工业学大庆运动的推动下，甲车间完成了计划的 \(120\%\) ，乙车间完成了计划的 \(110\%\) ，两车间共生产515件产品，问甲、乙两车间原计划各生产多少件产品？ 解：设甲车间原计划生产 \(x\) 件产品，乙车间原计划生产 \(450-x\) 件产品，则 \[ x \cdot 120 \% + (450 - x) \cdot 110 \% = 515 \]

\[ 1 2 x + 4 9 5 0 - 1 1 x = 5 1 5 0 \] \[ x = 2 0 0, 4 5 0 - 2 0 0 = 2 5 0. \] 答：甲车间原生产200件产品， 乙车间原生产250件产品. 

\end{problem}

\begin{problem}
在 \(\triangle ABC\) 中，已知 \(\angle A=120^\circ\)，\(\angle B=45^\circ\)，\(AC=6\mathrm{cm}\). 求 \(BC\) 的长. 解： \(\frac{\mathrm{BC}}{\sin 120^{\circ}} = \frac{\mathrm{AC}}{\sin 45^{\circ}}\) \[ \mathrm{BC} = \frac {\mathrm{AC}}{\sin 4 5 ^{\circ}} \cdot \sin 1 2 0 ^{\circ} \] \[ = \frac {6}{\frac {\sqrt {2}}{2}} \cdot \cos 3 0 ^{\circ} \] \[ = \frac {1 2}{\sqrt {2}} \cdot \frac {\sqrt {3}}{2} = 3 \sqrt {6} (\mathrm{cm}) \]

\end{problem}

\begin{problem}
求函数 \( y = -x^{2} - 2x + 3 \) 的最大值. 因为 \(a<0\)，因此 \(y\) 有最大值. 解：当 \( x = -\frac{b}{2a} \) 时，\(y\) 有最大值. 即 \( x = -\frac{-2}{-2} = -1 \) 时，\(y=4\) 为最大值. 
\end{problem}
