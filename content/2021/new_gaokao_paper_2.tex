\section{单选题}

\begin{problem}
复数 \(\frac{2-\i}{1-3\i}\) 在复平面内对应的点所在的象限为（\quad）

\choices
    {第一象限}
    {第二象限}
    {第三象限}
    {第四象限}

\end{problem}

\begin{answer}
A
\end{answer}

\begin{solution}
由 \(\frac{2-\i}{1-3\i}=\frac{\left( 2-\i \right)\left( 1+3\i \right)}{10}=\frac{5+5\i}{10}=\frac{1+\i}{2}\)，所以该复数对应的点为 \(\left( \frac12,\frac12 \right)\)，该点在第一象限，故选 A.
\end{solution}

\begin{problem}
抛物线 \(y^2=2px\left( p>0 \right)\) 的焦点到直线 \(y=x+1\) 的距离为 \(\sqrt2\)，则 \(p=\)（\quad）

\choices
    {\(1\)}
    {\(2\)}
    {\(2\sqrt2\)}
    {\(4\)}

\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
抛物线的焦点坐标为 \(\left( \frac p2,0 \right)\)，其到直线 \(x-y+1=0\) 的距离为 \(d=\frac{\left| \frac p2-0+1 \right|}{\sqrt{1+1}}=\sqrt2\). 解得 \(p=2\)（\(p=-6\) 舍去），故选 B.
\end{solution}
\begin{problem}
北斗三号全球卫星导航系统是我国航天事业的重要成果. 在卫星导航系统中，地球静止同步卫星的轨道位于地球赤道所在平面，轨道高度为 \(36000\text{ km}\)（轨道高度是指卫星到地球表面的距离）. 将地球看作是一个球心为 \(O\)，半径 \(r\) 为 \(6400\text{ km}\) 的球，其上点 \(A\) 的纬度是指 \(OA\) 与赤道平面所成角的度数. 地球表面上能直接观测到一颗地球静止同步轨道卫星点的纬度最大值为 \(\alpha\)，记卫星信号覆盖地球表面的表面积为 \(S=2\pi r^2\left( 1-\cos \alpha \right)\)（单位：\(\text{km}^2\)），则 \(S\) 占地球表面积的百分比约为（\quad）

\choices

\end{problem}

\begin{answer}
C
\end{answer}

\begin{problem}
某物理量的测量结果服从正态分布 \(N\left( 10,\sigma^2 \right)\)，下列结论中不正确的是（\quad）

\choices
    {\(\sigma\) 越小，该物理量在一次测量中在 \(\left( 9.9,10.1 \right)\) 的概率越大}
    {\(\sigma\) 越小，该物理量在一次测量中大于 \(10\) 的概率为 \(0.5\)}
    {\(\sigma\) 越小，该物理量在一次测量中小于 \(9.99\) 与大于 \(10.01\) 的概率相等}
    {\(\sigma\) 越小，该物理量在一次测量中落在 \(\left( 9.9,10.2 \right)\) 与落在 \(\left( 10,10.3 \right)\) 的概率相等}

\end{problem}

\begin{answer}
D
\end{answer}

\begin{solution}
对于 A，\(\sigma^2\) 为数据的方差，所以 \(\sigma\) 越小，数据在 \(\mu=10\) 附近越集中，所以测量结果落在 \(\left( 9.9,10.1 \right)\) 内的概率越大，故 A 正确.

对于 B，由正态分布密度曲线的对称性可知该物理量一次测量大于 \(10\) 的概率为 \(0.5\)，故 B 正确.

对于 C，由正态分布密度曲线的对称性可知该物理量一次测量结果大于 \(10.01\) 的概率与小于 \(9.99\) 的概率相等，故 C 正确.

对于 D，因为该物理量一次测量结果落在 \(\left( 9.9,10.0 \right)\) 的概率与落在 \(\left( 10.2,10.3 \right)\) 的概率不同，所以一次测量结果落在 \(\left( 9.9,10.2 \right)\) 的概率与落在 \(\left( 10,10.3 \right)\) 的概率不同，故 D 错误.
\end{solution}

\begin{problem}
已知函数 \(f\left( x \right)\) 的定义域为 \(\R\)，\(f\left( x+2 \right)\) 为偶函数，\(f\left( 2x+1 \right)\) 为奇函数，则（\quad）

\choices
    {\(f\left( -\frac12 \right)=0\)}
    {\(f\left( -1 \right)=0\)}
    {\(f\left( 2 \right)=0\)}
    {\(f\left( 4 \right)=0\)}

\end{problem}

\begin{answer}
B
\end{answer}

\begin{solution}
因为函数 \(f\left( x+2 \right)\) 为偶函数，则 \(f\left( 2+x \right)=f\left( 2-x \right)\)，可得 \(f\left( x+3 \right)=f\left( 1-x \right)\). 因为函数 \(f\left( 2x+1 \right)\) 为奇函数，则 \(f\left( 1-2x \right)=-f\left( 2x+1 \right)\)，所以 \(f\left( 1-x \right)=-f\left( x+1 \right)\). 因此 \(f\left( x+3 \right)=-f\left( x+1 \right)=f\left( x-1 \right)\)，即 \(f\left( x \right)=f\left( x+4 \right)\).
故函数 \(f\left( x \right)\) 是以 \(4\) 为周期的周期函数.

又因为函数 \(F\left( x \right)=f\left( 2x+1 \right)\) 为奇函数，所以 \(F\left( 0 \right)=f\left( 1 \right)=0\). 故 \(f\left( -1 \right)=-f\left( 1 \right)=0\)，其它三个选项未知，故选 B.
\end{solution}

如图，在正方体中，\(O\) 为底面的中心，\(P\) 为所在棱的中点，\(M\)，\(N\) 为正方体的顶点. 则满足 \(MN\perp OP\) 的是（\quad）

\end{problem}

\begin{answer}
BC
\end{answer}

\begin{solution}
设正方体的棱长为 \(2\).

对于 A，如图（1）所示，连接 \(AC\)，则 \(MN//AC\)，故 \(\angle POC\)（或其补角）为异面直线 \(OP\)，\(MN\) 所成的角.

在直角三角形 \(OPC\) 中，\(OC=\sqrt2\)，\(CP=1\)，故
	\(\tan \angle POC=\frac1{\sqrt2}=\frac{\sqrt2}{2}\)，
故 \(MN\perp OP\) 不成立，所以 A 错误.

对于 B，如图（2）所示，取 \(NT\) 的中点为 \(Q\)，连接 \(PQ\)，\(OQ\)，则 \(OQ\perp NT\)，\(PQ\perp MN\).

又 \(MN\subset \text{平面 }SNTM\)，且 \(OQ\perp MN\)，而 \(OQ\cap PQ=Q\)，所以 \(MN\perp \text{平面 }OPQ\)，而 \(PO\subset \text{平面 }OPQ\)，故 \(MN\perp OP\)，所以 B 正确.

对于 C，如图（3）所示，连接 \(BD\)，则 \(BD//MN\). 由 B 的判断可得 \(OP\perp BD\)，故 \(OP\perp MN\)，所以 C 正确.

对于 D，如图（4）所示，取 \(AD\) 的中点 \(Q\)，\(AB\) 的中点 \(K\)，连接 \(AC\)，\(PQ\)，\(OQ\)，\(PK\)，\(OK\).

则 \(AC//MN\)，因为 \(DP=PC\)，故 \(PQ//AC\)，从而 \(PQ//MN\)，所以 \(\angle QPO\) 或其补角为异面直线 \(PO\)，\(MN\) 所成的角.

因为正方体的棱长为 \(2\)，故
\(PQ=\frac12 AC=\sqrt2\)，\(OQ=\sqrt{AO^2+AQ^2}=\sqrt3\)，\(PO=\sqrt{PK^2+OK^2}=\sqrt5\).
由 \(QO^2<PQ^2+OP^2\) 可知 \(\angle QPO\) 不是直角，故 \(PO\) 与 \(MN\) 不垂直，所以 D 错误. 故选 BC.
\end{solution}
\begin{problem}
已知直线 \(l:ax+by-r^2=0\) 与圆 \(C:x^2+y^2=r^2\)，点 \(A\left( a,b \right)\)，则下列说法正确的是（\quad）

\choices
    {若点 \(A\) 在圆 \(C\) 上，则直线 \(l\) 与圆 \(C\) 相切}
    {若点 \(A\) 在圆 \(C\) 内，则直线 \(l\) 与圆 \(C\) 相离}
    {若点 \(A\) 在圆 \(C\) 外，则直线 \(l\) 与圆 \(C\) 相离}
    {若点 \(A\) 在直线 \(l\) 上，则直线 \(l\) 与圆 \(C\) 相切}

\end{problem}

\begin{answer}
ABD
\end{answer}

\begin{solution}
圆心 \(\left( 0,0 \right)\) 到直线 \(l\) 的距离为
\(d=\frac{r^2}{\sqrt{a^2+b^2}}\).

若点 \(A\left( a,b \right)\) 在圆 \(C\) 上，则 \(a^2+b^2=r^2\)，所以
\(d=\frac{r^2}{\sqrt{a^2+b^2}}=r\)，
则直线 \(l\) 与圆 \(C\) 相切，所以 A 正确.

若点 \(A\left( a,b \right)\) 在圆 \(C\) 内，则 \(a^2+b^2<r^2\)，所以
\(d=\frac{r^2}{\sqrt{a^2+b^2}}>r\)，
则直线 \(l\) 与圆 \(C\) 相离，所以 B 正确.

若点 \(A\left( a,b \right)\) 在圆 \(C\) 外，则 \(a^2+b^2>r^2\)，所以
\(d=\frac{r^2}{\sqrt{a^2+b^2}}<r\)，
则直线 \(l\) 与圆 \(C\) 相交，所以 C 错误.

若点 \(A\left( a,b \right)\) 在直线 \(l\) 上，则
\(a^2+b^2-r^2=0\)，
即 \(a^2+b^2=r^2\)，所以
\(d=\frac{r^2}{\sqrt{a^2+b^2}}=r\)，
直线 \(l\) 与圆 \(C\) 相切，所以 D 正确. 故选 ABD.
\end{solution}
\begin{problem}
设正整数 \(n=a_0\cdot 2^0+a_1\cdot 2^1+\cdots +a_k\cdot 2^k\)，其中 \(a_i\in \{0,1\}\)，记 \(\omega\left( n \right)=a_0+a_1+\cdots +a_k\). 则（\quad）

\choices
    {\(\omega\left( 2n \right)=\omega\left( n \right)\)}
    {\(\omega\left( 2n+3 \right)=\omega\left( n \right)+1\)}
    {\(\omega\left( 8n+5 \right)=\omega\left( 4n+3 \right)\)}
    {\(\omega\left( 2^n-1 \right)=n\)}

\end{problem}

\begin{answer}
ACD
\end{answer}

\begin{solution}
对于 A 选项，\(\omega\left( n \right)=a_0+a_1+\cdots +a_k\)，而
\(2n=a_0\cdot 2^1+a_1\cdot 2^2+\cdots +a_k\cdot 2^{k+1}\)，
所以
\(\omega\left( 2n \right)=a_0+a_1+\cdots +a_k=\omega\left( n \right)\)，
故 A 正确.

对于 B 选项，取 \(n=2\)，则
\(2n+3=7=1\cdot 2^0+1\cdot 2^1+1\cdot 2^2\)，
故 \(\omega\left( 7 \right)=3\)，而 \(\omega\left( 2 \right)=1\)，所以 \(\omega\left( 7 \right)\ne \omega\left( 2 \right)+1\)，故 B 错误.

对于 C 选项，
\(8n+5=1\cdot 2^0+1\cdot 2^2+a_0\cdot 2^3+a_1\cdot 2^4+\cdots +a_k\cdot 2^{k+3}\)，
所以
\(\omega\left( 8n+5 \right)=2+a_0+a_1+\cdots +a_k\).
又
\(4n+3=1\cdot 2^0+1\cdot 2^1+a_0\cdot 2^2+a_1\cdot 2^3+\cdots +a_k\cdot 2^{k+2}\)，
所以
\(\omega\left( 4n+3 \right)=2+a_0+a_1+\cdots +a_k\).
因此
\(\omega\left( 8n+5 \right)=\omega\left( 4n+3 \right)\)，
故 C 正确.

对于 D 选项，
\(2^n-1=2^0+2^1+\cdots +2^{n-1}\)，
故
\(\omega\left( 2^n-1 \right)=n\)，
所以 D 正确. 故选 ACD.
\end{solution}
\section{填空题}

\begin{problem}
已知双曲线 \(\frac{x^2}{a^2}-\frac{y^2}{b^2}=1\left( a>0,b>0 \right)\) 的离心率为 \(2\)，则该双曲线的渐近线方程为\fillinblank{}.

\end{problem}

\begin{answer}
\(y=\pm \sqrt3 x\)
\end{answer}

\begin{solution}
因为双曲线 \(\frac{x^2}{a^2}-\frac{y^2}{b^2}=1\left( a>0,b>0 \right)\) 的离心率为 \(2\)，所以
\(e=\sqrt{\frac{c^2}{a^2}}=\sqrt{\frac{a^2+b^2}{a^2}}=2\)，
从而
\(\frac{b^2}{a^2}=3\).
因此该双曲线的渐近线方程为
\(y=\pm \frac ba x=\pm \sqrt3 x\).
故答案为 \(y=\pm \sqrt3 x\).
\end{solution}
\begin{problem}
写出一个同时具有下列性质 \(\circled{1}\)\(\circled{2}\)\(\circled{3}\) 的函数 \(f\left( x \right)\)：\fillinblank{}.

\(\circled{1}\) \(f\left( x_1x_2 \right)=f\left( x_1 \right)f\left( x_2 \right)\)；\ \(\circled{2}\) 当 \(x\in \left( 0,+\infty \right)\) 时，\(f'\left( x \right)>0\)；\ \(\circled{3}\) \(f'\left( x \right)\) 是奇函数.

\end{problem}

\begin{answer}
\(f\left( x \right)=x^4\)（答案不唯一，\(f\left( x \right)=x^{2n}\left( n\in \N^* \right)\) 均满足）
\end{answer}

\begin{solution}
取 \(f\left( x \right)=x^4\)，则
\(f\left( x_1x_2 \right)=\left( x_1x_2 \right)^4=x_1^4x_2^4=f\left( x_1 \right)f\left( x_2 \right)\)，
满足 \(\circled{1}\).

又
\(f'\left( x \right)=4x^3\)，
当 \(x>0\) 时有 \(f'\left( x \right)>0\)，满足 \(\circled{2}\).

并且
\(f'\left( -x \right)=-4x^3=-f'\left( x \right)\)，
故 \(f'\left( x \right)\) 是奇函数，满足 \(\circled{3}\).

故答案可取 \(f\left( x \right)=x^4\).
\end{solution}
\begin{problem}
已知向量 \(\bs a+\bs b+\bs c=\bs 0\)，\(\left| \bs a \right|=1\)，\(\left| \bs b \right|=\left| \bs c \right|=2\)，则 \(\bs a\cdot \bs b+\bs b\cdot \bs c+\bs c\cdot \bs a=\fillinblank{}\).

\end{problem}

\begin{answer}
\(-\frac92\)
\end{answer}

\begin{solution}
由已知可得
\(\left( \bs a+\bs b+\bs c \right)^2=0\)，
所以
\(\left| \bs a \right|^2+\left| \bs b \right|^2+\left| \bs c \right|^2+2\left( \bs a\cdot \bs b+\bs b\cdot \bs c+\bs c\cdot \bs a \right)=0\).
代入 \(\left| \bs a \right|=1\)，\(\left| \bs b \right|=\left| \bs c \right|=2\)，得
\(1^2+2^2+2^2+2\left( \bs a\cdot \bs b+\bs b\cdot \bs c+\bs c\cdot \bs a \right)=0\)，
即
\(9+2\left( \bs a\cdot \bs b+\bs b\cdot \bs c+\bs c\cdot \bs a \right)=0\).
因此
\(\bs a\cdot \bs b+\bs b\cdot \bs c+\bs c\cdot \bs a=-\frac92\).
故答案为 \(-\frac92\).
\end{solution}
\begin{problem}
已知函数 \(f\left( x \right)=\left| \e^x-1 \right|\)，\(x_1<0\)，\(x_2>0\)，函数 \(f\left( x \right)\) 的图象在点 \(A\left( x_1,f\left( x_1 \right) \right)\) 和点 \(B\left( x_2,f\left( x_2 \right) \right)\) 的两条切线互相垂直，且分别交 \(y\) 轴于 \(M\)，\(N\) 两点，则 \(\frac{\left| AM \right|}{\left| BN \right|}\) 取值范围是\fillinblank{}.

\end{problem}

\begin{answer}
\(\left( 0,1 \right)\)
\end{answer}

\begin{solution}
由题意，
\examdisplaychain{
f\left( x \right)=\left| \e^x-1 \right|
&=
\begin{cases}
1-\e^x,\quad x<0,\\
\e^x-1,\quad x\ge 0,
\end{cases}\\
f'\left( x \right)
&=
\begin{cases}
-\e^x,\quad x<0,\\
\e^x,\quad x>0.
\end{cases}
}
所以点 \(A\left( x_1,1-\e^{x_1} \right)\) 和点 \(B\left( x_2,\e^{x_2}-1 \right)\) 处切线的斜率分别为
\(k_{AM}=-\e^{x_1}\)，\(k_{BN}=\e^{x_2}\).
由两条切线互相垂直，得
\(-\e^{x_1}\cdot \e^{x_2}=-1\)，
所以
\(x_1+x_2=0\).

直线 \(AM\) 的方程为
\(y-1+\e^{x_1}=-\e^{x_1}\left( x-x_1 \right)\)，
令 \(x=0\)，得
\(M\left( 0,\e^{x_1}x_1-\e^{x_1}+1 \right)\).
故
	\(\left| AM \right|=\sqrt{x_1^2+\left( \e^{x_1}x_1 \right)^2}
	=\sqrt{1+\e^{2x_1}}\cdot \left| x_1 \right|\).
直线 \(BN\) 的方程为
\(y-\e^{x_2}+1=\e^{x_2}\left( x-x_2 \right)\)，
令 \(x=0\)，得
\(N\left( 0,-\e^{x_2}x_2+\e^{x_2}-1 \right)\).
故
	\(\left| BN \right|=\sqrt{x_2^2+\left( \e^{x_2}x_2 \right)^2}
	=\sqrt{1+\e^{2x_2}}\cdot \left| x_2 \right|\).
因此
\(\frac{\left| AM \right|}{\left| BN \right|}

\end{enumerate}

\end{problem}

\begin{solution}
（1）由题意，椭圆半焦距
\(c=\sqrt2\)，
且
\(e=\frac ca=\frac{\sqrt6}{3}\)，
所以
\(a=\sqrt3\).
又
\(b^2=a^2-c^2=1\)，
所以椭圆方程为
\(\frac{x^2}{3}+y^2=1\).

（2）由（1）得，曲线为
\(x^2+y^2=1\left( x>0 \right)\).

若 \(M\)，\(N\)，\(F\) 三点共线，可设直线
\(MN:y=k\left( x-\sqrt2 \right)\)，
即
\(kx-y-\sqrt2 k=0\).
由直线 \(MN\) 与曲线 \(x^2+y^2=1\left( x>0 \right)\) 相切可得
\(\frac{\left| \sqrt2 k \right|}{\sqrt{k^2+1}}=1\)，
解得
\(k=\pm 1\).

联立 \(\begin{cases}
y=\pm \left( x-\sqrt2 \right),\\
\frac{x^2}{3}+y^2=1,
\end{cases}\)
可得
\(4x^2-6\sqrt2 x+3=0\)，
所以
\(x_1+x_2=\frac{3\sqrt2}{2}\)，\(x_1x_2=\frac34\).
因此
\(\left| MN \right|
=\sqrt{1+1}\cdot \sqrt{\left( x_1+x_2 \right)^2-4x_1x_2}
=\sqrt3\).
所以必要性成立.

充分性：设直线
\(MN:y=kx+b\)，\(kb<0\)，
即
\(kx-y+b=0\).
由直线 \(MN\) 与曲线 \(x^2+y^2=1\left( x>0 \right)\) 相切可得
\(\frac{\left| b \right|}{\sqrt{k^2+1}}=1\)，

\(b^2=k^2+1\).

联立 \(\begin{cases}
y=kx+b,\\
\frac{x^2}{3}+y^2=1,
\end{cases}\)
可得
\(\left( 1+3k^2 \right)x^2+6kbx+3b^2-3=0\).
所以
\(x_1+x_2=-\frac{6kb}{1+3k^2}\)，\(x_1x_2=\frac{3b^2-3}{1+3k^2}\).
从而
\(\left| MN \right|
=\sqrt{1+k^2}\cdot \sqrt{\left( x_1+x_2 \right)^2-4x_1x_2}
=\sqrt{1+k^2}\cdot \sqrt{\left( \frac{-6kb}{1+3k^2} \right)^2-4\cdot \frac{3b^2-3}{1+3k^2}}\).
由 \(\left| MN \right|=\sqrt3\) 及 \(b^2=k^2+1\)，得
\(\sqrt{1+k^2}\cdot \frac{\sqrt{24k^2}}{1+3k^2}=\sqrt3\).
化简得
\(3\left( k^2-1 \right)^2=0\)，
所以
\(k=\pm 1\).
又由 \(b^2=k^2+1\) 且 \(kb<0\)，得 \(\begin{cases}
k=1,\\
b=-\sqrt2,
\end{cases}\qquad \text{或} \qquad \begin{cases}
k=-1,\\
b=\sqrt2.
\end{cases}\)
所以直线
\(MN:y=x-\sqrt2\)或\(y=-x+\sqrt2\).
两种情形下直线 \(MN\) 都经过点 \(F\left( \sqrt2,0 \right)\)，故 \(M\)，\(N\)，\(F\) 三点共线.

综上，\(M\)，\(N\)，\(F\) 三点共线的充要条件是 \(\left| MN \right|=\sqrt3\).
\end{solution}
\begin{problem}
一种微生物群体可以经过自身繁殖不断生存下来，设一个这种微生物为第 \(0\) 代，经过一次繁殖后为第 \(1\) 代，再经过一次繁殖后为第 \(2\) 代……，该微生物每代繁殖的个数是相互独立的且有相同的分布列，设 \(X\) 表示 \(1\) 个微生物个体繁殖下一代的个数，\(P\left( X=i \right)=p_i\left( i=0,1,2,3 \right)\).

\begin{enumerate}
\item 已知 \(p_0=0.4\)，\(p_1=0.3\)，\(p_2=0.2\)，\(p_3=0.1\)，求 \(E\left( X \right)\)；
\item 设 \(p\) 表示该种微生物经过多代繁殖后临近灭绝的概率，\(p\) 是关于 \(x\) 的方程 \(p_0+p_1x+p_2x^2+p_3x^3=x\) 的一个最小正实根，求证：当 \(E\left( X \right)\le 1\) 时，\(p=1\)；当 \(E\left( X \right)>1\) 时，\(p<1\)；
\item 根据你的理解说明（2）问结论的实际含义.
\end{enumerate}

\end{problem}

\begin{solution}
（1）
\(E\left( X \right)=0\times 0.4+1\times 0.3+2\times 0.2+3\times 0.1=1\).

（2）设
\(f\left( x \right)=p_3x^3+p_2x^2+\left( p_1-1 \right)x+p_0\).
因为
\(p_3+p_2+p_1+p_0=1\)，
故
\(f\left( x \right)=p_3x^3+p_2x^2-\left( p_2+p_0+p_3 \right)x+p_0\).

若 \(E\left( X \right)\le 1\)，则
\(p_1+2p_2+3p_3\le 1\)，
故
\(p_2+2p_3\le p_0\).
又
\(f'\left( x \right)=3p_3x^2+2p_2x-\left( p_2+p_0+p_3 \right)\).
因为
\(f'\left( 0 \right)=-\left( p_2+p_0+p_3 \right)<0\)，\(f'\left( 1 \right)=p_2+2p_3-p_0\le 0\)，
故 \(f'\left( x \right)\) 有两个不同零点 \(x_1,x_2\)，且
\(x_1<0<1\le x_2\).

\(x\in \left( -\infty,x_1 \right)\cup \left( x_2,+\infty \right)\)
时，\(f'\left( x \right)>0\)；当
\(x\in \left( x_1,x_2 \right)\)
时，\(f'\left( x \right)<0\).

因此 \(f\left( x \right)\) 在 \(\left( -\infty,x_1 \right)\)，\(\left( x_2,+\infty \right)\) 上为增函数，在 \(\left( x_1,x_2 \right)\) 上为减函数.

若 \(x_2=1\)，因为 \(f\left( x \right)\) 在 \(\left( x_2,+\infty \right)\) 上为增函数且 \(f\left( 1 \right)=0\)，而当
\(x\in \left( 0,x_2 \right)\)
时，\(f\left( x \right)\) 在 \(\left( x_1,x_2 \right)\) 上为减函数，故
\(f\left( x \right)>f\left( x_2 \right)=f\left( 1 \right)=0\)，
所以 \(1\) 为 \(p_0+p_1x+p_2x^2+p_3x^3=x\) 的一个最小正实根.

若 \(x_2>1\)，因为 \(f\left( 1 \right)=0\) 且在 \(\left( 0,x_2 \right)\) 上为减函数，所以 \(1\) 仍为 \(p_0+p_1x+p_2x^2+p_3x^3=x\) 的一个最小正实根.

\(p_1+2p_2+3p_3>1\)，

\(p_2+2p_3>p_0\).

\(f'\left( 0 \right)=-\left( p_2+p_0+p_3 \right)<0\)，\(f'\left( 1 \right)=p_2+2p_3-p_0>0\)，
故 \(f'\left( x \right)\) 有两个不同零点 \(x_3,x_4\)，且
\(x_3<0<x_4<1\).
并且当
\(x\in \left( -\infty,x_3 \right)\cup \left( x_4,+\infty \right)\)
时，\(f'\left( x \right)>0\)；当
\(x\in \left( x_3,x_4 \right)\)
时，\(f'\left( x \right)<0\).

因此 \(f\left( x \right)\) 在 \(\left( -\infty,x_3 \right)\)，\(\left( x_4,+\infty \right)\) 上为增函数，在 \(\left( x_3,x_4 \right)\) 上为减函数.

又因为
\(f\left( 1 \right)=0\)，
所以
\(f\left( x_4 \right)<0\).
再由
\(f\left( 0 \right)=p_0>0\)，
可知 \(f\left( x \right)\) 在 \(\left( 0,x_4 \right)\) 存在一个零点 \(p\)，且
\(p<1\).

\(p<1\).

\begin{enumerate}
\item 讨论 \(f\left( x \right)\) 的单调性；

当 \(a>\frac12\) 时，若 \(x\in \left( -\infty,0 \right)\)，则 \(f'\left( x \right)>0\)，\(f\left( x \right)\) 单调递增；若 \(x\in \left( 0,\ln \left( 2a \right) \right)\)，则 \(f'\left( x \right)<0\)，\(f\left( x \right)\) 单调递减；若 \(x\in \left( \ln \left( 2a \right),+\infty \right)\)，则 \(f'\left( x \right)>0\)，\(f\left( x \right)\) 单调递增.

\(\frac12<a\le \frac{\e^2}{2}\)，

\(f\left( 0 \right)=b-1>0\).

\(\frac12<a\le \frac{\e^2}{2}\)，

\(1<2a\le \e^2\)，

\(f\left( \ln \left( 2a \right) \right)
\le 2a\left[ \ln \left( 2a \right)-1 \right]-a\left[ \ln \left( 2a \right) \right]^2+2a

由于
\(0<a<\frac12\)，

\(0<2a<1\)，
故
\(a\ln \left( 2a \right)\left[ 2-\ln \left( 2a \right) \right]<0\).
