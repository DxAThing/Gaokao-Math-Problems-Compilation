\begin{problem}
在 \(\triangle ABC\) 中，内角 \(A, B, C\) 的对边分别为 \(a, b, c\). 已知 \(\cos A = \frac{2}{3}\)，\(\sin B = \sqrt{5} \cos C\).
\begin{enumerate}
\item 求 \(\tan C\) 的值；
\item 若 \(a = \sqrt{2}\)，求 \(\triangle ABC\) 的面积.
\end{enumerate}
\end{problem}

\begin{problem}
已知箱中装有 4 个白球和 5 个黑球，且规定：取出一个白球得 2 分，取出一个黑球得 1 分. 现从该箱中任取 (无放回，且每球取到的机会均等) 3 个球，记随机变量 X 为取出此 3 球所得分数之和.
\begin{enumerate}
\item 求 \(X\) 的分布列；
\item 求 \(E(X)\).
\end{enumerate}
\end{problem}

\begin{problem}
已知 \(a > 0, b \in \R\)，函数 \(f(x) = 4ax^3 - 2bx - a + b\).
\begin{enumerate}
\item 证明：当 \(0 \leqslant x \leqslant 1\) 时，\circled{1} 函数 \(f(x)\) 的最大值为 \(|2a-b|+a\)；\circled{2} \(f(x)+|2a-b|+a\geqslant0\)；
\item 若 \(-1 \leqslant f(x) \leqslant 1\) 对 \(x \in [0,1]\) 恒成立，求 \(a+b\) 的取值范围.
\end{enumerate}
\end{problem}
