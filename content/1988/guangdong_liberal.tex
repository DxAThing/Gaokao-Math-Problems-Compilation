\begin{problem}

设复数 \(z = -\sqrt{6} + \sqrt{2}\i\)，记 \(u = \left(\frac{4}{z}\right)^3\).
\begin{enumerate}[label={（\arabic*）},itemsep=0.2em]
\item 求 \(|u|\) 和 \(\arg u\) 的值；
\item 求实数 \(x\) 和 \(y\)，使 \(\frac{x}{z} + \frac{y}{u} = z + 2u\).
\end{enumerate}

\end{problem}

\begin{solution}
（1）因为 \(|z| = \sqrt{6 + 2} = 2\sqrt{2}\)，所以
\[
|u| = \left(\frac{4}{|z|}\right)^3 = \left(\frac{4}{2\sqrt{2}}\right)^3 = 2\sqrt{2}
\]
又复数 \(z\) 所对应的点在第二象限，设 \(z\) 的辐角主值为 \(\theta\)，则 \(\cos \theta = -\frac{\sqrt{6}}{2\sqrt{2}} = -\frac{\sqrt{3}}{2}\)，所以 \(\theta = \frac{5\pi}{6}\). 因此 \(u\) 的辐角为 \(-\frac{5\pi}{6} \times 3 + 2k\pi\)（其中 \(k \in \Z\)），由 \(0 \leqslant -\frac{15\pi}{6} + 2k\pi < 2\pi\)，得 \(u\) 的辐角主值是 \(\frac{3\pi}{2}\).

（1）的另一种解法如下：因为
\[
z = 2\sqrt{2}\left(-\frac{\sqrt{3}}{2} + \frac{1}{2}\i\right)
= 2\sqrt{2}\left(\cos \frac{5\pi}{6} + \i \sin \frac{5\pi}{6}\right)
\]
所以
\[
\frac{4}{z} = \sqrt{2}\left(\cos \frac{7\pi}{6} + \i \sin \frac{7\pi}{6}\right)
\]
从而
\[
u = \left(\frac{4}{z}\right)^3 = 2\sqrt{2}\left(\cos \frac{3\pi}{2} + \i \sin \frac{3\pi}{2}\right)
\]
因此 \(|u| = 2\sqrt{2}\)，\(\arg u = \frac{3\pi}{2}\).

（2）由（1）知 \(u = -2\sqrt{2}\i\). 代入 \(\frac{x}{z} + \frac{y}{u} = z + 2u\)，有
\[
\frac{x}{8}\left(-\sqrt{6} - \sqrt{2}\i\right) + \frac{y\i}{2\sqrt{2}}
= \left(-\sqrt{6} + \sqrt{2}\i\right) - 4\sqrt{2}\i
\]
整理得
\[
-\frac{\sqrt{6}}{8}x + \left(\frac{y}{2\sqrt{2}} - \frac{\sqrt{2}x}{8}\right)\i
= -\sqrt{6} - 3\sqrt{2}\i
\]
所以
\[
-\frac{\sqrt{6}}{8}x = -\sqrt{6}, \qquad
\frac{y}{2\sqrt{2}} - \frac{\sqrt{2}x}{8} = -3\sqrt{2}
\]
解得 \(x = 8\)，\(y = -8\).

（2）的另一种解法如下：由（1）知 \(u = -2\sqrt{2}\i\)，所以 \(\bar{u} = -u\). 由
\[
\frac{x}{z} + \frac{y}{u} = z + 2u \circled{1}
\]
两边取共轭，得
\[
\frac{x}{\bar{z}} - \frac{y}{u} = \bar{z} - 2u \circled{2}
\]
\(\circled{1} + \circled{2}\) 得
\[
x\left(\frac{1}{z} + \frac{1}{\bar{z}}\right) = z + \bar{z}
\]
所以 \(x = z\bar{z} = |z|^2 = 8\). \(\circled{1} - \circled{2}\) 得
\[
x\left(\frac{1}{z} - \frac{1}{\bar{z}}\right) + \frac{2y}{u} = (z - \bar{z}) + 4u
\]
即
\[
(\bar{z} - z) + \frac{2y}{u} = (z - \bar{z}) + 4u
\]
所以
\[
y = u(z - \bar{z}) + 2u^2 = -2\sqrt{2}\i \cdot 2\sqrt{2}\i - 2 \cdot 8 = -8
\]
\end{solution}

\begin{problem}

如图，在四棱锥 \(P - ABCD\) 中，\(PA \perp\) 底面 \(ABCD\)，\(PD \perp DC\)，\(DC \parallel\) 侧面 \(PAB\).

\begin{enumerate}[label={（\arabic*）},itemsep=0.2em]
\item 求证：\(DA \perp AB\)；
\item 又设 \(PB = PC\)，且 \(DC = PA = 3\mathrm{cm}\)，\(DA = 4\mathrm{cm}\)，求这个四棱锥的体积.
\end{enumerate}

\bitmapfigure[max width=0.44\linewidth,max totalheight=4.8cm]{img/1988/guangdong_liberal/q2_fig1.png}
\end{problem}

\begin{solution}
（1）依设 \(PA \perp\) 底面 \(ABCD\)，\(A\) 是垂足，因此 \(DA\) 是斜线 \(PD\) 在底面 \(ABCD\) 上的射影. 由题设 \(PD \perp DC\)，而 \(DC \subset\) 底面 \(ABCD\)，因此 \(DA \perp DC\)（三垂线定理的逆定理）. 又由题设 \(DC \parallel\) 侧面 \(PAB\)，而且过 \(DC\) 的平面 \(ABCD\) 和侧面 \(PAB\) 交于 \(AB\)，所以 \(DC \parallel AB\). 因此 \(AB \perp DA\).

（2）依设 \(PA \perp\) 底面 \(ABCD\)，而 \(DA \subset\) 底面 \(ABCD\)，\(AB \subset\) 底面 \(ABCD\)，所以 \(PA \perp DA\)，\(PA \perp AB\). 又由题设 \(PD \perp DC\)，因此 \(\triangle PAD\)、\(\triangle PDC\)、\(\triangle PAB\) 都是直角三角形，所以
\[
PD = \sqrt{PA^2 + DA^2} = \sqrt{3^2 + 4^2} = 5\mathrm{cm}
\]
\[
PC = \sqrt{PD^2 + DC^2} = \sqrt{5^2 + 3^2} = \sqrt{34}\mathrm{cm}
\]
又由题设 \(PB = PC\)，所以
\[
AB = \sqrt{PB^2 - PA^2} = \sqrt{34 - 9} = 5\mathrm{cm}
\]
在四边形 \(ABCD\) 中，因为 \(DC \parallel AB\)，\(DA \perp AB\)，且 \(AB \neq DC\)，因此 \(ABCD\) 是直角梯形，所以
\[
S_{ABCD} = \frac{1}{2}(AB + DC)\cdot DA = \frac{1}{2} \cdot 8 \cdot 4 = 16\mathrm{cm}^2
\]
故
\[
V = \frac{1}{3}S_{ABCD}\cdot PA = \frac{1}{3} \cdot 16 \cdot 3 = 16\mathrm{cm}^3
\]

（2）的另一种解法如下：连结 \(AC\). 因为 \(PA \perp\) 底面 \(ABCD\)，\(A\) 是垂足，因此 \(AC\)、\(AB\) 分别是斜线 \(PC\)、\(PB\) 在底面 \(ABCD\) 上的射影. 依题设 \(PB = PC\)，因此 \(AC = AB\)（相等的斜线段的射影相等）. 又由（1）已证 \(DC \perp DA\)，因此 \(\triangle ADC\) 是直角三角形，所以
\[
AC = \sqrt{DA^2 + DC^2} = \sqrt{4^2 + 3^2} = 5\mathrm{cm}
\]
因而 \(AB = 5\mathrm{cm}\)，以下同解法一，可得这个四棱锥的体积是 \(16\mathrm{cm}^3\).
\end{solution}

\begin{problem}

设数列 \(\{a_n\}\) 的前 \(n\) 项和 \(S_n = \frac{\pi}{3}n^2 + c\)，式中 \(c\) 是常数，\(n = 1, 2, \dots\). （1）如果 \(c \neq 0\)，求证：\(\{a_n\}\) 不是等差数列；（2）如果 \(c = 0\)，求证：对任意大于 1 的自然数 \(n\)，和数 \(\cos^2(a_{n-1}) + \cos^2(a_n) + \cos^2(a_{n+1})\) 是一个与 \(n\) 无关的常数，并求出这个常数值.

\end{problem}

\begin{solution}
（1）[证法一] 因为 \(a_1 = S_1 = \frac{\pi}{3} + c\). 当 \(n \geqslant 2\) 时，
\[
a_n = S_n - S_{n-1}
= \left(\frac{\pi}{3}n^2 + c\right) - \left[\frac{\pi}{3}(n - 1)^2 + c\right]
= \frac{\pi}{3}(2n - 1)
\]
因此当 \(n \geqslant 3\) 时，
\[
a_n - a_{n-1} = \frac{\pi}{3}(2n - 1) - \frac{\pi}{3}(2n - 3) = \frac{2\pi}{3}
\]
但
\[
a_2 - a_1 = \pi - \left(\frac{\pi}{3} + c\right) = \frac{2\pi}{3} - c
\]
依题设 \(c \neq 0\)，所以 \(a_2 - a_1 \neq a_3 - a_2\)，因此 \(\{a_n\}\) 不是等差数列. 

（1）[证法二] 因为 \(a_1 = S_1 = \frac{\pi}{3} + c\)，又 \(S_2 = \frac{4\pi}{3} + c = a_1 + a_2\)，所以 \(a_2 = \pi\). 又 \(S_3 = 3\pi + c = a_1 + a_2 + a_3\)，所以 \(a_3 = \frac{5\pi}{3}\). 因此
\[
a_3 - a_2 = \frac{2\pi}{3}, \qquad a_2 - a_1 = \frac{2\pi}{3} - c
\]
依题设 \(c \neq 0\)，所以 \(a_3 - a_2 \neq a_2 - a_1\)，因此 \(\{a_n\}\) 不是等差数列. 

（2）[证法一] 因为 \(c = 0\)，所以 \(a_1 = S_1 = \frac{\pi}{3}\). 当 \(n \geqslant 2\) 时，
\[
a_n = S_n - S_{n-1}
= \frac{\pi}{3}n^2 - \frac{\pi}{3}(n - 1)^2
= \frac{\pi}{3}(2n - 1)
\]
因此对任意自然数 \(n\)，有 \(a_n = \frac{\pi}{3}(2n - 1)\). 当 \(n \geqslant 2\) 时，
\[
a_{n-1} = \frac{\pi}{3}(2n - 3), \qquad a_{n+1} = \frac{\pi}{3}(2n + 1)
\]
于是
\[
\cos^2 a_{n-1} + \cos^2 a_n + \cos^2 a_{n+1}
= \frac{3}{2} + \frac{1}{2}\cos \frac{2\pi}{3}(2n - 1)
\]
\[
+ \frac{1}{2}\left[\cos \frac{2\pi}{3}(2n - 3) + \cos \frac{2\pi}{3}(2n + 1)\right]
= \frac{3}{2}
\]
因此，当 \(n \geqslant 2\) 时，\(\cos^2 a_{n-1} + \cos^2 a_n + \cos^2 a_{n+1}\) 与 \(n\) 无关，且等于常数 \(\frac{3}{2}\).

（2）[证法二] 因为 \(c = 0\)，所以 \(a_1 = \frac{\pi}{3}\). 对任意自然数 \(n\)，有 \(a_n = \frac{\pi}{3}(2n - 1)\). 当 \(n \geqslant 2\) 时，
\[
a_{n-1} = a_n - \frac{2\pi}{3}, \qquad a_{n+1} = a_n + \frac{2\pi}{3}
\]
于是
\[
\cos a_{n-1} = -\frac{1}{2}\cos a_n + \frac{\sqrt{3}}{2}\sin a_n
\]
\[
\cos a_{n+1} = -\frac{1}{2}\cos a_n - \frac{\sqrt{3}}{2}\sin a_n
\]
所以
\[
\cos^2 a_{n-1} + \cos^2 a_n + \cos^2 a_{n+1}
= \frac{3}{2}\left(\cos^2 a_n + \sin^2 a_n\right)
= \frac{3}{2}
\]

（2）[证法三] 当 \(n = 2\) 时，
\[
\cos^2 a_1 + \cos^2 a_2 + \cos^2 a_3
= \cos^2 \frac{\pi}{3} + \cos^2 \pi + \cos^2 \frac{5\pi}{3}
= \frac{3}{2}
\]
下面用数学归纳法证明：对于 \(n \geqslant 2\) 的任意自然数，
\[
\cos^2 a_{n-1} + \cos^2 a_n + \cos^2 a_{n+1} = \frac{3}{2}
\]
设当 \(n = k \geqslant 2\) 时结论成立，则当 \(n = k + 1\) 时，因为 \(a_{k+2} = a_{k-1} + 2\pi\)，所以
\[
\cos^2 a_k + \cos^2 a_{k+1} + \cos^2 a_{k+2}
= \cos^2 a_{k-1} + \cos^2 a_k + \cos^2 a_{k+1}
= \frac{3}{2}
\]
故结论对一切 \(n \geqslant 2\) 成立，且常数值为 \(\frac{3}{2}\).
\end{solution}

\begin{problem}

设 \(k\) 和 \(r\) 是实数，且 \(r > 0\)，使得直线 \(y = kx + 1\) 既与圆 \(x^2 + y^2 = r^2\) 相切，又与双曲线 \(x^2 - y^2 = r^2\) 有两个交点. 求证：\(\frac{1}{r^2} - k^2 = 1\)，且 \(|k| \neq 1\)；试问：直线 \(y = kx + 1\) 能否经过双曲线 \(x^2 - y^2 = r^2\) 的焦点？为什么？

\end{problem}

\begin{solution}
（1）[证法一] 因为直线 \(y = kx + 1\) 与圆 \(x^2 + y^2 = r^2\) 相切，所以
\[
\frac{|-1|}{\sqrt{1 + k^2}} = r
\]
两边平方，得
\[
\frac{1}{1 + k^2} = r^2
\]
由于 \(r^2 \neq 0\)，因此
\[
1 + k^2 = \frac{1}{r^2}
\]
故
\[
\frac{1}{r^2} - k^2 = 1
\]
又由题设直线 \(y = kx + 1\) 与双曲线 \(x^2 - y^2 = r^2\) 有两个交点，所以方程
\[
x^2 - (kx + 1)^2 = r^2
\]
化简为
\[
(1 - k^2)x^2 - 2kx - (1 + r^2) = 0
\]
有两个不同实根，于是 \(1 - k^2 \neq 0\)，即 \(|k| \neq 1\).

（1）[证法二] 由直线 \(y = kx + 1\) 与圆 \(x^2 + y^2 = r^2\) 相切，可得方程
\[
(1 + k^2)x^2 + 2kx + 1 - r^2 = 0
\]
只有一个解，所以它的判别式为 0，即
\[
4k^2 - 4(1 + k^2)(1 - r^2) = 0
\]
从而
\[
4k^2r^2 + 4r^2 - 4 = 0
\]
于是
\[
\frac{1}{r^2} - k^2 = 1
\]
若 \(k = 1\)，则直线 \(y = x + 1\) 与双曲线 \(x^2 - y^2 = r^2\) 联立后只有一个交点，与题设矛盾；同理 \(k \neq -1\). 所以 \(|k| \neq 1\).

（2）[证法一] 双曲线 \(x^2 - y^2 = r^2\) 的焦点为 \(F_1(-\sqrt{2}r,0)\) 和 \(F_2(\sqrt{2}r,0)\). 如果直线 \(y = kx + 1\) 经过 \(F_1\)，那么
\[
-\sqrt{2}rk + 1 = 0
\]
即 \(\frac{1}{r} = \sqrt{2}k\). 又由（1）已证
\[
\frac{1}{r^2} - k^2 = 1
\]
所以 \((\sqrt{2}k)^2 - k^2 = 1\)，得 \(k^2 = 1\)，这与 \(|k| \neq 1\) 矛盾. 因此，直线 \(y = kx + 1\) 不可能通过左焦点 \(F_1\). 同理也不可能通过右焦点 \(F_2\).

（2）[证法二] 由（1）知 \(\frac{1}{r^2} - k^2 = 1\)，又 \(r > 0\)，得
\[
r = \frac{1}{\sqrt{1 + k^2}}
\]
故双曲线的焦点为
\[
F_1\left(-\sqrt{\frac{2}{1 + k^2}},0\right), \qquad
F_2\left(\sqrt{\frac{2}{1 + k^2}},0\right)
\]
如果 \(F_1\) 在直线 \(y = kx + 1\) 上，则
\[
-k\sqrt{\frac{2}{1 + k^2}} + 1 = 0
\]
于是 \(\frac{2}{1 + k^2} = \frac{1}{k^2}\)，得 \(k^2 = 1\)，与 \(|k| \neq 1\) 矛盾. 所以 \(F_1\)、\(F_2\) 都不在题设直线上.
\end{solution}
