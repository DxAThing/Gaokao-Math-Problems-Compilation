\section{单选题}

\begin{problem}
若集合 \(P = \{x \mid 2 \leqslant x < 4\}\)，\(Q = \{x \mid x \geqslant 3\}\)，则 \(P \cap Q\) 等于（\quad）

\choices
    {\(\{x \mid 3 \leqslant x < 4\}\)}
    {\(\{x \mid 3 < x < 4\}\)}
    {\(\{x \mid 2 \leqslant x < 3\}\)}
    {\(\{x \mid 2 \leqslant x \leqslant 3\}\)}

\begin{answer}
A
\end{answer}

\begin{solution}
由 \(x\in P\cap Q\) 得 \(2\leqslant x<4\) 且 \(x\geqslant 3\)，所以 \(3\leqslant x<4\). 因此选 A.
\end{solution}
\end{problem}

\begin{problem}
复数 \((3 + 2\i)\i\) 等于（\quad）

\choices
    {\(-2 - 3\i\)}
    {\(-2 + 3\i\)}
    {\(2 - 3\i\)}
    {\(2 + 3\i\)}

\begin{answer}
B
\end{answer}

\begin{solution}
因为 \(\i^2=-1\)，所以 \((3+2\i)\i=3\i+2\i^2=-2+3\i\). 因此选 B.
\end{solution}
\end{problem}

\begin{problem}
以边长为 \(1\) 的正方形的一边所在直线为旋转轴，将该正方形旋转一周所得圆柱的侧面积等于（\quad）

\choices
    {\(2\pi\)}
    {\(\pi\)}
    {2}
    {1}

\begin{answer}
A
\end{answer}

\begin{solution}
正方形绕其中一边旋转一周所得圆柱的底面半径为 \(1\)，高为 \(1\)，所以其侧面积为 \(2\pi rh=2\pi\). 因此选 A.
\end{solution}
\end{problem}

\begin{problem}
阅读如图所示的程序框图，运行相应的程序，输出的 \(n\) 的值为（\quad）

\bitmapfigure[max width=0.42\linewidth]{img/2014/fujian_liberal/q4_fig1.png}

\choices
    {1}
    {2}
    {3}
    {4}

\begin{answer}
B
\end{answer}

\begin{solution}
程序开始时 \(n=1\). 执行一次 \(n=n+1\) 后，\(n=2\)，此时 \(2^n=2^2=4\)，不满足 \(2^n>n^2\)，程序输出 \(n=2\). 因此选 B.
\end{solution}
\end{problem}

\begin{problem}
命题“\(\forall x \in [0, +\infty)\)，\(x^3 + x \geqslant 0\)”的否定是（\quad）

\choices
    {\(\forall x \in (-\infty, 0), x^3 + x < 0\)}
    {\(\forall x \in (-\infty, 0)\)，\(x^3 + x \geqslant 0\)}
    {\(\exists x_0 \in [0, +\infty)\)，\(x_0^3 + x_0 < 0\)}
    {\(\exists x_0 \in [0, +\infty)\)，\(x_0^3 + x_0 \geqslant 0\)}

\begin{answer}
C
\end{answer}

\begin{solution}
否定全称命题时，将全称量词改为存在量词，并将不等式 \(x^3+x\geqslant 0\) 改为 \(x^3+x<0\)，定义域保持不变. 因此否定为“存在 \(x_0\in[0,+\infty)\)，使 \(x_0^3+x_0<0\)”，选 C.
\end{solution}
\end{problem}

\begin{problem}
已知直线 \(l\) 过圆 \(x^{2} + (y - 3)^{2} = 4\) 的圆心，且与直线 \(x + y + 1 = 0\) 垂直，则 \(l\) 的方程是（\quad）

\choices
    {\(x + y - 2 = 0\)}
    {\(x - y + 2 = 0\)}
    {\(x + y - 3 = 0\)}
    {\(x - y + 3 = 0\)}

\begin{answer}
D
\end{answer}

\begin{solution}
圆 \(x^2+(y-3)^2=4\) 的圆心为 \((0,3)\). 直线 \(x+y+1=0\) 的斜率为 \(-1\)，所以与它垂直的直线斜率为 \(1\). 过 \((0,3)\) 的直线 \(l\) 为 \(y-3=x\)，即 \(x-y+3=0\). 因此选 D.
\end{solution}
\end{problem}

\begin{problem}
将函数 \( y = \sin x \) 的图象向左平移 \( \frac{\pi}{2} \) 个单位，得到函数 \( y = f(x) \) 的函数图象，则下列说法正确的是（\quad）

\choices
    {\(y = f(x)\) 是奇函数}
    {\(y = f(x)\) 的周期是 \(\pi\)}
    {\(y = f(x)\) 的图象关于直线 \(x = \frac{\pi}{2}\) 对称}
    {\(y = f(x)\) 的图象关于点 \(\left(-\frac{\pi}{2},0\right)\) 对称}

\begin{answer}
D
\end{answer}

\begin{solution}
图象向左平移 \(\frac{\pi}{2}\) 个单位后，\(f(x)=\sin\left(x+\frac{\pi}{2}\right)=\cos x\). 函数 \(\cos x\) 是偶函数，最小正周期为 \(2\pi\)，且图象关于直线 \(x=0\) 对称，故 A、B、C 均不正确. 又 \(f(-\pi-x)=\cos(-\pi-x)=-\cos x=-f(x)\)，所以图象关于点 \(\left(-\frac{\pi}{2},0\right)\) 对称. 因此选 D.
\end{solution}
\end{problem}

\begin{problem}
若函数 \( y = \log_a x \)（\(a > 0\)，且 \(a \neq 1\)）的图象如图所示，则下列函数图象正确的是（\quad）

\bitmapfigure[max width=0.34\linewidth]{img/2014/fujian_liberal/q8_fig1.png}

\choices
    {\choicebitmap[width=0.15\paperwidth]{img/2014/fujian_liberal/q8_choice_a.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2014/fujian_liberal/q8_choice_b.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2014/fujian_liberal/q8_choice_c.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2014/fujian_liberal/q8_choice_d.png}}

\begin{answer}
B
\end{answer}

\begin{solution}
原图象经过点 \((3,1)\)，故 \(\log_a3=1\)，从而 \(a=3\). 因此四个选项中的函数依次为 \(y=3^{-x}\)、\(y=x^3\)、\(y=(-x)^3=-x^3\) 和 \(y=\log_3(-x)\). 函数 \(y=3^{-x}\) 在 \(\R\) 上递减，函数 \(y=-x^3\) 也在 \(\R\) 上递减，均与对应图象的增减性不符；函数 \(y=\log_3(-x)\) 的定义域为 \((-\infty,0)\)，且在其定义域上递减. 而 \(y=x^3\) 在 \(\R\) 上递增且经过 \((1,1)\)，与选项 B 的图象相符. 因此选 B.
\end{solution}
\end{problem}

\begin{problem}
要制作一个容积为 \(4 \mathrm{~m}^{3}\)，高为 \(1 \mathrm{~m}\) 的无盖长方体容器，已知该容器的底面造价是每平方米 20 元，侧面造价是每平方米 10 元，则该容器的最低总造价是（\quad）

\choices
    {\(80\text{ 元}\)}
    {\(120\text{ 元}\)}
    {\(160\text{ 元}\)}
    {\(240\text{ 元}\)}

\begin{answer}
C
\end{answer}

\begin{solution}
设容器底面的两边长分别为 \(x>0\)、\(y>0\). 由体积为 \(4\mathrm{~m}^3\) 且高为 \(1\mathrm{~m}\)，得 \(xy=4\). 底面造价为 \(20\times4=80\) 元，四个侧面的面积为 \(2(x+y)\mathrm{~m}^2\)，侧面造价为 \(10\times2(x+y)=20(x+y)\) 元. 因此总造价 \(C=80+20(x+y)\). 由基本不等式，\(x+y\geqslant2\sqrt{xy}=4\)，等号在 \(x=y=2\) 时成立，所以 \(C\geqslant80+20\times4=160\) 元. 因此最低总造价为 \(160\) 元，选 C.
\end{solution}
\end{problem}

\begin{problem}
设 \(M\) 为平行四边形 \(ABCD\) 对角线交的点，\(O\) 为平行四边形 \(ABCD\) 所在平面内任意一点，则 \(\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} + \overrightarrow{OD}\) 等于（\quad）

\choices
    {\(\overrightarrow{OM}\)}
    {\(2\overrightarrow{OM}\)}
    {\(3\overrightarrow{OM}\)}
    {\(4\overrightarrow{OM}\)}

\begin{answer}
D
\end{answer}

\begin{solution}
设各点的位置向量均以 \(O\) 为起点. 平行四边形的对角线互相平分，所以 \(\overrightarrow{OA}+\overrightarrow{OC}=2\overrightarrow{OM}\)，且 \(\overrightarrow{OB}+\overrightarrow{OD}=2\overrightarrow{OM}\). 两式相加得 \(\overrightarrow{OA}+\overrightarrow{OB}+\overrightarrow{OC}+\overrightarrow{OD}=4\overrightarrow{OM}\). 因此选 D.
\end{solution}
\end{problem}

\begin{problem}
已知圆 \(C: (x - a)^2 + (y - b)^2 = 1\)，平面区域 \(\Omega: \begin{cases}
x + y - 7 \leqslant 0,\\
x - y + 3 \geqslant 0,\\
y \geqslant 0,
\end{cases}\) 若圆心 \(C \in \Omega\)，且圆 \(C\) 与 \(x\) 轴相切，则 \(a^2 + b^2\) 的最大值为（\quad）

\choices
    {5}
    {29}
    {37}
    {49}

\begin{answer}
C
\end{answer}

\begin{solution}
圆 \(C\) 的半径为 \(1\)，且与 \(x\) 轴相切，所以圆心的纵坐标满足 \(|b|=1\). 又圆心 \(C\in\Omega\) 且 \(y\geqslant0\)，故 \(b=1\). 将 \((a,1)\) 代入区域条件，得 \(a+1\leqslant7\) 和 \(a-1+3\geqslant0\)，即 \(-2\leqslant a\leqslant6\). 于是 \(a^2+b^2=a^2+1\). 在区间 \([-2,6]\) 上，\(a^2\) 的最大值为 \(36\)，在 \(a=6\) 时取得，所以最大值为 \(37\). 因此选 C.
\end{solution}
\end{problem}

\begin{problem}
在平面直角坐标系中，两点 \(P_{1}(x_{1}, y_{1})\)，\(P_{2}(x_{2}, y_{2})\) 间的 “\(\mathrm{L}\)-距离” 定义为 \(\|P_1P_2\| = |x_1 - x_2| + |y_1 - y_2|\)，则平面内与 \(x\) 轴上两个不同的定点 \(F_{1}\)，\(F_{2}\) 的 “\(\mathrm{L}\)-距离” 之和等于定值（大于 \(\|F_1F_2\|\)）的点的轨迹可以是（\quad）

\choices
    {\choicebitmap[width=0.15\paperwidth]{img/2014/fujian_liberal/q12_choice_a.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2014/fujian_liberal/q12_choice_b.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2014/fujian_liberal/q12_choice_c.png}}
    {\choicebitmap[width=0.15\paperwidth]{img/2014/fujian_liberal/q12_choice_d.png}}

\begin{answer}
A
\end{answer}

\begin{solution}
在 \(x\) 轴上取两定点的中点为原点，设 \(F_1=(-c,0)\)、\(F_2=(c,0)\)，其中 \(c>0\). 设动点为 \(P=(x,y)\)，两点的“\(\mathrm{L}\)-距离”之和为 \(S\)，则 \(S=|x+c|+|y|+|x-c|+|y|=|x+c|+|x-c|+2|y|\). 题设给出 \(S>2c\). 当 \(|x|\leqslant c\) 时，\(S=2c+2|y|\)，所以 \(|y|=\frac{S-2c}{2}\)，得到上下两条水平线段；当 \(|x|\geqslant c\) 时，\(S=2|x|+2|y|\)，所以 \(|x|+|y|=\frac{S}{2}\)，得到连接这些线段端点与左右端点的四条斜线段. 因此轨迹是左右尖、上下平的中心对称六边形，与图 A 相符. 因此选 A.
\end{solution}
\end{problem}

\section{填空题}

\begin{problem}
如图，在边长为 \(1\) 的正方形中，随机撒 \(1000\ \text{粒}\) 豆子，有 \(180\ \text{粒}\) 落到阴影部分，据此估计阴影部分的面积为\fillinblank{}.

\bitmapfigure[max width=0.30\linewidth]{img/2014/fujian_liberal/q13_fig1.png}

\begin{answer}
0.18
\end{answer}

\begin{solution}
随机撒豆子时，落入阴影部分的频率可估计阴影部分占正方形面积的比例. 该频率为 \(\frac{180}{1000}=0.18\)，而正方形面积为 \(1^2=1\)，所以阴影部分面积估计为 \(0.18\).
\end{solution}
\end{problem}

\begin{problem}
在 \(\triangle ABC\) 中，\(A = 60^\circ\)，\(AC = 2\)，\(BC = \sqrt{3}\)，则 \(AB\) 等于\fillinblank{}.

\begin{answer}
1
\end{answer}

\begin{solution}
在三角形 \(ABC\) 中，\(AB\) 与 \(AC\) 的夹角为 \(60^\circ\). 由余弦定理，\(BC^2=AB^2+AC^2-2\cdot AB\cdot AC\cos60^\circ\). 代入 \(BC=\sqrt3\)、\(AC=2\)，得 \(3=AB^2+4-2AB\)，即 \((AB-1)^2=0\). 因此 \(AB=1\).
\end{solution}
\end{problem}

\begin{problem}
函数 \(f(x) = \begin{cases}
x^2 - 2, & x \leqslant 0,\\
2x - 6 + \ln x, & x > 0,
\end{cases}\) 的零点个数是\fillinblank{}.

\begin{answer}
2
\end{answer}

\begin{solution}
当 \(x\leqslant0\) 时，\(f(x)=x^2-2\)，由 \(x^2-2=0\) 得 \(x=\pm\sqrt2\)，其中只有 \(x=-\sqrt2\) 满足定义域，所以这一段有 \(1\) 个零点.

当 \(x>0\) 时，令 \(g(x)=2x-6+\ln x\)，则 \(g'(x)=2+\frac1x>0\)，所以 \(g\) 在 \((0,+\infty)\) 上严格递增. 又 \(\displaystyle\lim_{x\to0^+}g(x)=-\infty\)，且 \(g(3)=\ln3>0\)，故由零点存在性定理，\(g\) 在 \((0,+\infty)\) 上恰有一个零点. 因此 \(f(x)\) 共有 \(2\) 个零点.
\end{solution}
\end{problem}

\begin{problem}
已知集合 \(\{a, b, c\} = \{0, 1, 2\}\)，且下列三个关系：

\begin{circlelist}
\item \(a \neq 2\)；
\item \(b = 2\)；
\item \(c \neq 0\)
\end{circlelist}

有且只有一个正确，则 \(100a + 10b + c =\)\fillinblank{}.

\begin{answer}
201
\end{answer}

\begin{solution}
因为 \(\{a,b,c\}=\{0,1,2\}\)，所以 \(a\)，\(b\)，\(c\) 是 \(0\)，\(1\)，\(2\) 的一个排列. 若 \(b=2\)，则 \(a\)，\(c\) 为 \(0,1\)，此时 \(a\neq2\) 与 \(b=2\) 同时正确，不符合题意. 因此 \(b\neq2\). 若再有 \(a\neq2\)，则 \(a\)，\(b\) 为 \(0,1\)，从而 \(c=2\)，这时 \(a\neq2\) 与 \(c\neq0\) 同时正确，也不符合题意. 因此 \(a=2\). 于是 \(b\)，\(c\) 为 \(0,1\)，且 \(b=2\) 与 \(a\neq2\) 均不正确；要恰有一个关系正确，必须 \(c\neq0\)，所以 \(c=1\)、\(b=0\). 因此 \(100a+10b+c=100\times2+10\times0+1=201\).
\end{solution}
\end{problem}

\section{解答题}

\begin{problem}
在等比数列 \(\{a_n\}\) 中，\(a_2 = 3\)，\(a_5 = 81\).

\begin{enumerate}
\item 求 \(a_n\)；
\item 设 \(b_n = \log_{3} a_n\)，求数列 \(\{b_n\}\) 的前 \(n\) 项和 \(S_n\).
\end{enumerate}

\begin{solution}
\begin{enumerate}
\item 设等比数列的公比为 \(q\). 由 \(a_5=a_2q^3\)，得 \(81=3q^3\)，所以 \(q^3=27\)，从而 \(q=3\). 又 \(a_1=a_2/q=1\)，故 \(a_n=a_1q^{n-1}=3^{n-1}\).
\item 由 \(a_n=3^{n-1}>0\)，得 \(b_n=\log_3a_n=n-1\). 因此 \(S_n=\sum_{k=1}^{n}b_k=\sum_{k=1}^{n}(k-1)=\frac{n(n-1)}{2}\).
\end{enumerate}
\end{solution}
\end{problem}

\begin{problem}
已知函数 \( f(x) = 2\cos x (\sin x + \cos x) \).

\begin{enumerate}
\item 求 \( f\left(\frac{5\pi}{4}\right) \) 的值；
\item 求函数 \( f(x) \) 的最小正周期及单调递增区间.
\end{enumerate}

\begin{solution}
\begin{enumerate}
\item 将 \(x=\frac{5\pi}{4}\) 代入，得 \(f\left(\frac{5\pi}{4}\right)=2\cos\frac{5\pi}{4}\left(\sin\frac{5\pi}{4}+\cos\frac{5\pi}{4}\right)=2\).
\item 化简得 \(f(x)=2\sin x\cos x+2\cos^2x=1+\sin2x+\cos2x=1+\sqrt2\sin\left(2x+\frac\pi4\right)\). 因此最小正周期满足 \(2T=2\pi\)，即 \(T=\pi\). 又 \(f'(x)=2\sqrt2\cos\left(2x+\frac\pi4\right)\)，所以在单调递增区间内 \(f'(x)\geqslant0\)，且内部除端点外为正，即 \(-\frac\pi2+2k\pi\leqslant2x+\frac\pi4\leqslant\frac\pi2+2k\pi\)，从而 \(k\pi-\frac{3\pi}{8}\leqslant x\leqslant k\pi+\frac\pi8\). 故函数的单调递增区间为 \(\left[k\pi-\frac{3\pi}{8},k\pi+\frac\pi8\right]\)，其中 \(k\in\Z\).
\end{enumerate}
\end{solution}
\end{problem}

\begin{problem}
如图，三棱锥 \(A - BCD\) 中，\(AB \perp\) 平面 \(BCD\)，\(CD \perp BD\).

\begin{enumerate}
\item 求证：\(CD \perp\) 平面 \(ABD\)；
\item 若 \(AB = BD = CD = 1\)，\(M\) 为 \(AD\) 中点，求三棱锥 \(A - MBC\) 的体积.
\end{enumerate}

\bitmapfigure[max width=0.36\linewidth]{img/2014/fujian_liberal/q19_fig1.png}

\begin{solution}
\begin{enumerate}
\item 因为 \(AB\perp\) 平面 \(BCD\)，且 \(CD\) 在平面 \(BCD\) 内，所以 \(AB\perp CD\). 题设又给出 \(BD\perp CD\)，而 \(AB\) 与 \(BD\) 是平面 \(ABD\) 内相交的两条直线. 因此由直线与平面垂直的判定定理，\(CD\perp\) 平面 \(ABD\).
\item 建立空间直角坐标系，取 \(B=(0,0,0)\)、\(D=(1,0,0)\)、\(C=(1,1,0)\)、\(A=(0,0,1)\)，则条件 \(AB\perp\) 平面 \(BCD\)、\(AB=BD=CD=1\) 均满足. 因为 \(M\) 是 \(AD\) 的中点，所以 \(M=\left(\frac12,0,\frac12\right)\). 于是 \(\overrightarrow{AM}=\left(\frac12,0,-\frac12\right)\)，\(\overrightarrow{AB}=(0,0,-1)\)，\(\overrightarrow{AC}=(1,1,-1)\). 计算得 \(\overrightarrow{AB}\times\overrightarrow{AC}=(1,-1,0)\)，从而 \(V_{A-MBC}=\frac16\left|\overrightarrow{AM}\cdot\left(\overrightarrow{AB}\times\overrightarrow{AC}\right)\right|=\frac16\times\frac12=\frac1{12}\).
\end{enumerate}
\end{solution}
\end{problem}

\begin{problem}
根据世行 \(2013\) 年新标准，人均 \(\mathrm{GDP}\) 低于 \(1035\ \text{美元}\) 为低收入国家；人均 \(\mathrm{GDP}\) 为 \(1035\text{—}4085\ \text{美元}\) 为中等偏下收入国家；人均 \(\mathrm{GDP}\) 为 \(4085\text{—}12616\ \text{美元}\) 为中等偏上收入国家；人均 \(\mathrm{GDP}\) 不低于 \(12616\ \text{美元}\) 为高收入国家. 某城市有 \(5\) 个行政区，各区人口占该城市人口比例及人均 \(\mathrm{GDP}\) 如下表：

\begin{center}
\begin{tabular}{|c|c|c|}
\hline
行政区 & 区人口占城市人口比例 & 区人均 \(\mathrm{GDP}\)（单位：\(\text{美元}\)） \\
\hline
A & \(25\%\) & \(8000\) \\
\hline
B & \(30\%\) & \(4000\) \\
\hline
C & \(15\%\) & \(6000\) \\
\hline
D & \(10\%\) & \(3000\) \\
\hline
E & \(20\%\) & \(10000\) \\
\hline
\end{tabular}
\end{center}

\begin{enumerate}
\item 判断该城市人均 \(\mathrm{GDP}\) 是否达到中等偏上收入国家标准；
\item 现从该城市 \(5\) 个行政区中随机抽取 \(2\) 个，求抽到的 \(2\) 个行政区人均 \(\mathrm{GDP}\) 都达到中等偏上收入国家标准的概率.
\end{enumerate}

\begin{solution}
\begin{enumerate}
\item 以全市人口为 \(1\)，按各行政区人口比例加权，城市人均 \(\mathrm{GDP}\) 为 \(0.25\times8000+0.30\times4000+0.15\times6000+0.10\times3000+0.20\times10000=6400\) 美元. 因为 \(4085\leqslant6400<12616\)，所以该城市达到中等偏上收入国家标准.
\item 达到中等偏上收入国家标准的行政区为 A、C、E，共 \(3\) 个. 从 \(5\) 个行政区中随机抽取 \(2\) 个，基本事件总数为 \(\mathrm C_5^2=10\)，有利事件数为从 A、C、E 中抽取 \(2\) 个，即 \(\mathrm C_3^2=3\). 因此所求概率为 \(\frac{\mathrm C_3^2}{\mathrm C_5^2}=\frac3{10}\).
\end{enumerate}
\end{solution}
\end{problem}

\begin{problem}
已知曲线 \(\Gamma\) 上的点到点 \(F(0,1)\) 的距离比它到直线 \(y = -3\) 的距离小 2.

\begin{enumerate}
\item 求曲线 \(\Gamma\) 的方程；
\item 曲线 \(\Gamma\) 在点 \(P\) 处的切线 \(l\) 与 \(x\) 轴交于点 \(A\). 直线 \(y = 3\) 分别与直线 \(l\) 及 \(y\) 轴交于点 \(M\)，\(N\). 以 \(MN\) 为直径作圆 \(C\)，过点 \(A\) 作圆 \(C\) 的切线，切点为 \(B\). 试探究：当点 \(P\) 在曲线 \(\Gamma\) 上运动（点 \(P\) 与原点不重合）时，线段 \(AB\) 的长度是否发生变化？证明你的结论.
\end{enumerate}

\begin{solution}
\begin{enumerate}
\item 设曲线 \(\Gamma\) 上任意一点为 \(P(x,y)\). 由题意，\(\sqrt{x^2+(y-1)^2}=|y+3|-2\). 当 \(y\geqslant-3\) 时，右端为 \(y+1\)，因而 \(y\geqslant-1\)，平方并化简得 \(x^2=4y\)，进而 \(y\geqslant0\). 当 \(y<-3\) 时，右端为 \(-y-5\)，要使右端非负必须 \(y\leqslant-5\)，平方得 \(x^2=12(y+2)<0\)，不可能. 因此曲线方程为 \(y=\frac{x^2}{4}\).
\item 设 \(P=\left(t,\frac{t^2}{4}\right)\)，其中 \(t\neq0\). 抛物线在 \(P\) 处的切线斜率为 \(\frac t2\)，所以切线 \(l\) 的方程为 \(y-\frac{t^2}{4}=\frac t2(x-t)\)，即 \(y=\frac t2x-\frac{t^2}{4}\). 令 \(y=0\)，得 \(A=\left(\frac t2,0\right)\)；令 \(y=3\)，得 \(M=\left(\frac{t^2+12}{2t},3\right)\). 又 \(N=(0,3)\). 记 \(u=\frac{t^2+12}{2t}\)，则以 \(MN\) 为直径的圆的圆心为 \(C=\left(\frac u2,3\right)\)，半径为 \(r=\frac{|u|}{2}\). 由点 \(A\) 向圆作切线，切线长满足 \(AB^2=AC^2-r^2\). 于是 \(AB^2=\left(\frac t2-\frac u2\right)^2+9-\frac{u^2}{4}=\frac{t^2-2tu}{4}+9=\frac{t^2-(t^2+12)}4+9=6\). 所以 \(AB=\sqrt6\)，与 \(P\) 的位置无关，线段 \(AB\) 的长度不发生变化.
\end{enumerate}
\end{solution}
\end{problem}

\begin{problem}
已知函数 \( f(x) = \e^{x} - ax \)（\(a\) 为常数）的图象与 \(y\) 轴交于点 \(A\)，曲线 \( y = f(x) \) 在点 \(A\) 处的切线斜率为 \(-1\).

\begin{enumerate}
\item 求 \(a\) 的值及函数 \(f(x)\) 的极值；
\item 证明：当 \(x > 0\) 时，\(x^2 < \e^x\)；
\item 证明：对任意给定的正数 \(c\)，总存在 \(x_0\)，使得当 \(x \in (x_0, +\infty)\) 时，恒有 \(x^2 < c\e^x\).
\end{enumerate}

\begin{solution}
\begin{enumerate}
\item \(f(0)=1\)，故图象与 \(y\) 轴交于 \(A=(0,1)\). 又 \(f'(x)=\e^x-a\)，所以切线斜率为 \(f'(0)=1-a=-1\)，从而 \(a=2\). 此时 \(f'(x)=\e^x-2\)，当 \(x<\ln2\) 时 \(f'(x)<0\)，当 \(x>\ln2\) 时 \(f'(x)>0\). 因此函数在 \(x=\ln2\) 处取得极小值 \(f(\ln2)=\e^{\ln2}-2\ln2=2-2\ln2\). 又 \(\displaystyle\lim_{x\to+\infty}f(x)=+\infty\)，所以函数没有最大值.
\item 令 \(g(x)=\e^x-x^2\)，则 \(g'(x)=\e^x-2x\). 由第（1）问，函数 \(\e^x-2x\) 的最小值为 \(2-2\ln2\). 因为 \(0<2<\e\)，所以 \(\ln2<1\)，从而 \(2-2\ln2>0\)，故 \(g'(x)>0\)，即 \(g\) 在 \(\R\) 上递增. 又 \(g(0)=1>0\)，所以当 \(x>0\) 时 \(g(x)>g(0)>0\)，即 \(x^2<\e^x\).
\item 给定 \(c>0\)，取 \(x_0=\max\left\{1,2\ln\frac4c\right\}\). 当 \(x>x_0\) 时，\(x>0\)，且 \(x>2\ln\frac4c\). 由第（2）问应用于 \(\frac x2\)，得 \(\frac{x^2}{4}<\e^{x/2}\)，即 \(x^2<4\e^{x/2}\). 又由 \(x>2\ln\frac4c\) 得 \(4<c\e^{x/2}\)，所以 \(4\e^{x/2}<c\e^x\). 综上，\(x^2<c\e^x\).
\end{enumerate}
\end{solution}
\end{problem}
