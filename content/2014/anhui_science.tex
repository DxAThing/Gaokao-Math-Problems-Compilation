\section{单选题}

\begin{problem}
设 \(\i\) 是虚数单位，\(\bar z\) 表示复数 \(z\) 的共轭复数. 若 \(z = 1 + \i\)，则 \(\frac{z}{\i} + \i \cdot \bar z = \)（\quad）

\choices
    {\(-2\)}
    {\(-2\i\)}
    {\(2\)}
    {\(2\i\)}
\answer{C}

\begin{solution}
由于 \(z=1+\i\)，所以 \(\bar z=1-\i\)，从而 \(\dfrac{z}{\i}=\dfrac{1+\i}{\i}=1-\i\)，\(\i\cdot\bar z=\i(1-\i)=1+\i\). 因此 \(\dfrac{z}{\i}+\i\cdot\bar z=2\)，故选 C.
\end{solution}
\end{problem}

\begin{problem}
“\(x < 0\)”是“\(\ln(x + 1) < 0\)”的（\quad）

\choices
    {充分不必要条件}
    {必要不充分条件}
    {充分必要条件}
    {既不充分也不必要条件}
\answer{B}

\begin{solution}
\(\ln(x+1)<0\) 首先要求 \(x+1>0\). 由于对数函数在其定义域上单调递增，且 \(\ln 1=0\)，所以 \(\ln(x+1)<0\) 等价于 \(0<x+1<1\)，即 \(-1<x<0\). 因而“\(\ln(x+1)<0\)”能推出“\(x<0\)”，但“\(x<0\)”不能保证 \(x+1>0\)，也不能推出前一个不等式，例如 \(x=-2\) 时对数式无意义，所以“\(x<0\)”是必要不充分条件，故选 B.
\end{solution}
\end{problem}

\begin{problem}
如图所示，程序框图（算法流程图）的输出结果是（\quad）

\bitmapfigure[max width=0.42\linewidth]{img/2014/anhui_science/q3_fig1.png}

\choices
    {\(34\)}
    {\(55\)}
    {\(78\)}
    {\(89\)}
\answer{B}

\begin{solution}
程序开始时 \(x=y=1\). 每次循环先计算 \(z=x+y\)，若 \(z\leqslant50\)，再依次令 \(x=y\)，\(y=z\)，因此循环中得到的 \(z\) 依次为 \(2\)，\(3\)，\(5\)，\(8\)，\(13\)，\(21\)，\(34\)，\(55\). 前一个结果 \(34\leqslant50\)，更新后得到 \(55>50\)，程序输出 \(55\)，故选 B.
\end{solution}
\end{problem}

\begin{problem}
以平面直角坐标系的原点为极点，\(x\) 轴的正半轴为极轴，建立极坐标系，两种坐标系中取相同的长度单位，已知直线 \(l\) 的参数方程是 \(\begin{cases}
x = t + 1,\\
y = t - 3,
\end{cases}\)（\(t\) 为参数），圆 \(C\) 的极坐标方程是 \(\rho = 4\cos \theta\)，则直线 \(l\) 被圆 \(C\) 截得的弦长为（\quad）

\choices
    {\(\sqrt{14}\)}
    {\(2 \sqrt{14}\)}
    {\(\sqrt{2}\)}
    {\(2\sqrt{2}\)}
\answer{D}

\begin{solution}
由极坐标方程 \(\rho=4\cos\theta\)，得 \(\rho^{2}=4\rho\cos\theta\)，即 \(x^{2}+y^{2}=4x\)，所以圆 \(C\) 的圆心为 \((2,0)\)，半径为 \(2\). 由直线的参数方程消去 \(t\)，得 \(y=x-4\)，即 \(x-y-4=0\). 圆心到直线的距离为 \(\dfrac{|2-0-4|}{\sqrt{2}}=\sqrt{2}\)，所以弦长为 \(2\sqrt{2^{2}-(\sqrt{2})^{2}}=2\sqrt{2}\)，故选 D.
\end{solution}
\end{problem}

\begin{problem}
\(x\)，\(y\) 满足约束条件 \(\begin{cases}
x + y - 2 \leqslant 0,\\
x - 2y - 2 \leqslant 0,\\
2x - y + 2 \geqslant 0,
\end{cases}\) 若 \(z = y - ax\) 取得最大值的最优解不唯一，则实数 \(a\) 的值为（\quad）

\choices
    {\(\frac{1}{2}\) 或 \(-1\)}
    {\(2\) 或 \(\frac{1}{2}\)}
    {\(2\) 或 \(1\)}
    {\(2\) 或 \(-1\)}
\answer{D}

\begin{solution}
三个边界直线分别为 \(y=-x+2\)、\(y=\dfrac12x-1\) 和 \(y=2x+2\)，它们围成的可行域是顶点为 \((-2,-2)\)、\((0,2)\)、\((2,0)\) 的三角形. 目标函数 \(z=y-ax\) 的等值线为 \(y=ax+z\)，最优解不唯一时，等值线必须与可行域的一条边重合.
当 \(a=-1\) 时，\(z=x+y\leqslant2\)，在边 \(x+y=2\) 上取得最大值；当 \(a=2\) 时，\(z=y-2x\leqslant2\)，在边 \(2x-y+2=0\) 上取得最大值. 另一条边的斜率为 \(\dfrac12\)，但当 \(a=\dfrac12\) 时，目标函数在三个顶点处的值依次为 \(-1\)，\(2\)，\(-1\)，最大值只在 \((0,2)\) 处取得. 所以 \(a=2\) 或 \(-1\)，故选 D.
\end{solution}
\end{problem}

\begin{problem}
设函数 \(f(x)\)（\(x \in \R\)）满足 \( f(x + \pi) = f(x) + \sin x \). 当 \( 0 \leqslant x < \pi \) 时，\( f(x) = 0 \)，则 \( f\left(\frac{23\pi}{6}\right) = \)（\quad）

\choices
    {\( \frac{1}{2} \)}
    {\( \frac{\sqrt{3}}{2} \)}
    {\(0\)}
    {\(-\frac{1}{2}\)}
\answer{A}

\begin{solution}
令 \(x_0=\dfrac{5\pi}{6}\). 因为 \(0\leqslant x_0<\pi\)，所以 \(f(x_0)=0\). 由递推关系，\(f(x_0+\pi)=f(x_0)+\sin x_0=\dfrac12\)，\(f(x_0+2\pi)=f(x_0+\pi)+\sin(x_0+\pi)=0\)，\(f(x_0+3\pi)=f(x_0+2\pi)+\sin(x_0+2\pi)=\dfrac12\). 又 \(\dfrac{23\pi}{6}=x_0+3\pi\)，故选 A.
\end{solution}
\end{problem}

\begin{problem}
一个多面体的三视图如图所示，则该多面体的表面积为（\quad）

\bitmapfigure[max width=0.47\linewidth]{img/2014/anhui_science/q7_fig1.png}

\choices
    {\(21 + \sqrt{3}\)}
    {\(18 + \sqrt{3}\)}
    {\(21\)}
    {\(18\)}
\answer{A}

\begin{solution}
由三个视图可知，该多面体可看作边长为 \(2\) 的正方体分别截去两个相对顶点的角，两个截面都经过相应顶点三条棱的中点. 正方体原表面积为 \(6\cdot2^{2}=24\). 每截去一个角，原来的三个直角三角形面积之和为 \(3\cdot\dfrac12\cdot1\cdot1=\dfrac32\)，新增截面为边长 \(\sqrt{2}\) 的正三角形，面积为 \(\dfrac{\sqrt{3}}{4}(\sqrt{2})^{2}=\dfrac{\sqrt{3}}2\). 因而截去两个角后表面积为 \(24-2\cdot\dfrac32+2\cdot\dfrac{\sqrt{3}}2=21+\sqrt{3}\)，故选 A.
\end{solution}
\end{problem}

\begin{problem}
从正方体六个面的对角线中任取两条作为一对，其中所成的角为 \(60^{\circ}\) 的共有（\quad）

\choices
    {\(24\) 对}
    {\(30\) 对}
    {\(48\) 对}
    {\(60\) 对}
\answer{C}

\begin{solution}
正方体的六个面各有两条对角线，共有 \(12\) 条. 按对角线所在面的坐标方向分类，可分为 \(xy\)、\(xz\)、\(yz\) 三类，每类有 \(4\) 条. 同一类中两条对角线的方向向量平行或垂直，所成角不是 \(60^{\circ}\). 不同类的两条对角线可分别取方向向量 \((\pm1,\pm1,0)\) 与 \((\pm1,0,\pm1)\) 等，它们的长度均为 \(\sqrt{2}\)，内积的绝对值均为 \(1\)，故所成锐角的余弦为 \(\dfrac{1}{2}\)，即为 \(60^{\circ}\). 三类中任取两类共有 \(\mathrm C_3^2\) 种，每种有 \(4\cdot4\) 对，所以共有 \(\mathrm C_3^2\cdot4\cdot4=48\) 对，故选 C.
\end{solution}
\end{problem}

\begin{problem}
若函数 \( f(x) = |x + 1| + |2x + a| \) 的最小值为 3，则实数 \( a \) 的值为（\quad）

\choices
    {\(5\) 或 \(8\)}
    {\(-1\) 或 \(5\)}
    {\(-1\) 或 \(-4\)}
    {\(-4\) 或 \(8\)}
\answer{D}

\begin{solution}
将 \(\lvert2x+a\rvert\) 写成 \(2\left\lvert x+\dfrac a2\right\rvert\)，则 \(f(x)=\lvert x+1\rvert+2\left\lvert x+\dfrac a2\right\rvert\). 由三角不等式，
\(f(x)=\left(\lvert x+1\rvert+\left\lvert x+\dfrac a2\right\rvert\right)+\left\lvert x+\dfrac a2\right\rvert\geqslant\left\lvert1-\dfrac a2\right\rvert+\left\lvert x+\dfrac a2\right\rvert\geqslant\left\lvert1-\dfrac a2\right\rvert\). 当 \(x=-\dfrac a2\) 时，\(f(x)=\left\lvert1-\dfrac a2\right\rvert\)，故函数最小值为 \(\left\lvert1-\dfrac a2\right\rvert\). 由题意 \(\left\lvert1-\dfrac a2\right\rvert=3\)，得 \(a=-4\) 或 \(a=8\)，故选 D.
\end{solution}
\end{problem}

\begin{problem}
在平面直角坐标系 \(xOy\) 中，已知向量 \(\bs{a}\)，\(\bs{b}\)，\(|\bs{a}| = |\bs{b}| = 1\)，\(\bs{a} \cdot \bs{b} = 0\)，点 \(Q\) 满足 \(\overrightarrow{OQ} = \sqrt{2}(\bs{a} + \bs{b})\). 曲线 \(C = \left\{P \mid \overrightarrow{OP} = \bs{a} \cos \theta + \bs{b} \sin \theta, 0 \leqslant \theta < 2\pi\right\}\)，区域 \(\Omega = \left\{P \mid 0 < r \leqslant \left|\overrightarrow{PQ}\right| \leqslant R, r < R\right\}\). 若 \(C \cap \Omega\) 为两段分离的曲线，则（\quad）

\choices
    {\(1 < r < R < 3\)}
    {\(1 < r < 3 \leqslant R\)}
    {\(r \leqslant 1 < R < 3\)}
    {\(1 < r < 3 < R\)}
\answer{A}

\begin{solution}
取 \(\bs{a}\)，\(\bs{b}\) 为平面内两条互相垂直的单位向量作为坐标基底，则点 \(P\) 的坐标可表示为 \((\cos\theta,\sin\theta)\)，点 \(Q\) 的坐标为 \((\sqrt{2},\sqrt{2})\). 因而 \(\lvert\overrightarrow{PQ}\rvert^{2}=(\cos\theta-\sqrt{2})^{2}+(\sin\theta-\sqrt{2})^{2}=5-2\sqrt{2}(\cos\theta+\sin\theta)=5-4\cos\left(\theta-\dfrac{\pi}{4}\right)\).

所以 \(\lvert\overrightarrow{PQ}\rvert\) 的最小值为 \(1\)，最大值为 \(3\)，且在圆 \(C\) 上分别只有一个最小点和一个最大点. 若 \(r\leqslant1\)，内边界不会截去最小点附近的弧段；若 \(R\geqslant3\)，外边界不会截去最大点附近的弧段，这两种情形都不能得到两段分离的曲线. 只有 \(1<r<R<3\) 时，内、外两个边界分别截去最小点和最大点附近的弧段，剩余部分恰为两段分离的曲线，故选 A.
\end{solution}
\end{problem}

\section{填空题}

\begin{problem}
若将函数 \( f(x) = \sin \left(2x + \frac{\pi}{4}\right) \) 的图象向右平移 \( \varphi \) 个单位，所得图象关于 \( y \) 轴对称，则 \( \varphi \) 的最小正值是\fillinblank{}.
\answer{\(\frac{3\pi}{8}\)}

\begin{solution}
平移后的函数为 \(g(x)=\sin\left(2(x-\varphi)+\dfrac{\pi}{4}\right)=\sin(2x+\delta)\)，其中 \(\delta=\dfrac{\pi}{4}-2\varphi\). 要使图象关于 \(y\) 轴对称，需使 \(g\) 为偶函数. 展开得 \(g(x)=\sin2x\cos\delta+\cos2x\sin\delta\)，比较 \(g(x)\) 与 \(g(-x)\) 可知必须且只需 \(\cos\delta=0\). 因此 \(\delta=\dfrac{\pi}{2}+k\pi\)，即 \(\varphi=-\dfrac{\pi}{8}-\dfrac{k\pi}{2}\). 取最小正值时 \(k=-1\)，得到 \(\varphi=\dfrac{3\pi}{8}\).
\end{solution}
\end{problem}

\begin{problem}
数列 \( \{a_{n}\} \) 是等差数列. 若 \(a_{1} + 1\)，\(a_{3} + 3\)，\(a_{5} + 5\) 构成公比为 \( q \) 的等比数列，则 \( q =\fillinblank{} \).
\answer{\(1\)}

\begin{solution}
设 \(u=a_{1}+1\)，\(v=a_{3}+3\)，\(w=a_{5}+5\). 由 \(\{a_n\}\) 是等差数列，得 \(a_{1}+a_{5}=2a_{3}\)，从而 \(u+w=2v\). 又 \(u\)，\(v\)，\(w\) 构成等比数列，故 \(v^{2}=uw\). 于是 \((u-w)^{2}=(u+w)^{2}-4uw=4v^{2}-4v^{2}=0\)，所以 \(u=v=w\). 因公比定义为后一项与前一项之比，故 \(q=\dfrac vu=1\).
\end{solution}
\end{problem}

\begin{problem}
设 \(a \neq 0\)，\(n\) 是大于 1 的自然数，\(\left(1 + \frac{x}{a}\right)^n\) 的展开式为 \(a_0 + a_1x + a_2x^2 + \cdots + a_nx^n\). 若点 \(A_i(i, a_i)\)（\(i = 0\)，\(1\)，\(2\)）的位置如图所示，则 \(a =\fillinblank{}\).

\bitmapfigure[max width=0.34\linewidth]{img/2014/anhui_science/q13_fig1.png}
\answer{\(3\)}

\begin{solution}
二项式展开式中 \(a_i=\mathrm C_n^i\dfrac{1}{a^i}\). 由图中 \(A_0=(0,1)\)、\(A_1=(1,3)\)、\(A_2=(2,4)\)，得 \(a_0=1\)，\(a_1=3\)，\(a_2=4\). 因而 \(\dfrac na=3\)，\(\dfrac{\mathrm C_n^2}{a^2}=4\). 由 \(n=3a\) 代入第二式，得 \(\dfrac{n(n-1)}{2a^2}=4\)，即 \(\dfrac{3a(3a-1)}{2a^2}=4\). 因 \(a\neq0\)，化简得 \(a^2-3a=0\)，所以 \(a=3\).
\end{solution}
\end{problem}

\begin{problem}
设 \(F_{1}\)，\(F_{2}\) 分别是椭圆 \(E: x^{2} + \frac{y^{2}}{b^{2}} = 1\)（\(0 < b < 1\)）的左，右焦点，过点 \(F_{1}\) 的直线交椭圆 \(E\) 于 \(A\)，\(B\) 两点，若 \(|AF_{1}| = 3|BF_{1}|\)，\(AF_{2} \perp x\) 轴，则椭圆 \(E\) 的方程为\fillinblank{}.

\answer{\(x^{2} + \frac{3}{2}y^{2} = 1\)}

\begin{solution}
设椭圆焦半距为 \(c\)，则 \(c^{2}=1-b^{2}\)，且 \(F_{1}=(-c,0)\)，\(F_{2}=(c,0)\). 由 \(AF_{2}\perp x\) 轴，点 \(A\) 的横坐标为 \(c\). 将 \(x=c\) 代入椭圆方程，得 \(y^{2}=b^{4}\)，所以 \(A=(c,\pm b^{2})\). 对上方情形 \(A=(c,b^{2})\) 作如下计算；下方情形只需将 \(b^{2}\) 换成 \(-b^{2}\)，代入后的交点方程仍相同，所得距离比也相同.

参数化直线 \(F_{1}A\)：\(X(t)=(-c,0)+t(2c,b^{2})\)，其中 \(t=1\) 对应点 \(A\). 代入椭圆方程，得 \(c^{2}(2t-1)^{2}+b^{2}t^{2}=1\). 该方程的一个根为 \(1\)，另一个根 \(t_B\) 满足 \(t_B=\dfrac{c^{2}-1}{4c^{2}+b^{2}}=-\dfrac{b^{2}}{4c^{2}+b^{2}}\). 因而 \(B\) 在 \(F_1\) 的另一侧，且 \(\lvert BF_1\rvert=\dfrac{b^{2}}{4c^{2}+b^{2}}\lvert AF_1\rvert\). 由 \(\lvert AF_1\rvert=3\lvert BF_1\rvert\)，得 \(4c^{2}+b^{2}=3b^{2}\)，即 \(b^{2}=2c^{2}\). 再结合 \(b^{2}+c^{2}=1\)，得 \(b^{2}=\dfrac23\). 所以椭圆方程为 \(x^{2}+\dfrac{3}{2}y^{2}=1\).
\end{solution}
\end{problem}

\begin{problem}
已知两个不相等的非零向量 \(\bs{a}\)，\(\bs{b}\)，两组向量 \(\bs{x}_{1}\)，\(\bs{x}_{2}\)，\(\bs{x}_{3}\)，\(\bs{x}_{4}\)，\(\bs{x}_{5}\) 和 \(\bs{y}_{1}\)，\(\bs{y}_{2}\)，\(\bs{y}_{3}\)，\(\bs{y}_{4}\)，\(\bs{y}_{5}\) 均由 2 个 \(\bs{a}\) 和 3 个 \(\bs{b}\) 排列而成，记 \(S = \bs{x}_{1} \cdot \bs{y}_{1} + \bs{x}_{2} \cdot \bs{y}_{2} + \bs{x}_{3} \cdot \bs{y}_{3} + \bs{x}_{4} \cdot \bs{y}_{4} + \bs{x}_{5} \cdot \bs{y}_{5}\). \(S_{\min}\) 表示 \(S\) 所有可能取值中的最小值. 则下列命题正确的是\fillinblank{}. （写出所有正确命题的编号）

\begin{circlelist}
\item \(S\) 有 5 个不同的值；

\item 若 \(\bs{a} \perp \bs{b}\)，则 \(S_{\min}\) 与 \(|\bs{a}|\) 无关；

\item 若 \(\bs{a} \parallel \bs{b}\)，则 \(S_{\min}\) 与 \(|\bs{b}|\) 无关；

\item 若 \(|\bs{b}| > 4|\bs{a}|\)，则 \(S_{\min} > 0\)；

\item 若 \(|\bs{b}| = 2|\bs{a}|\)，\(S_{\min} = 8|\bs{a}|^2\)，则 \(\bs{a}\) 与 \(\bs{b}\) 的夹角为 \(\frac{\pi}{4}\).
\end{circlelist}
\answer{\(\circled{2}\circled{4}\)}

\begin{solution}
把每个向量的五个分量看作五个位置. 设 \(M\) 是所有五对 \((\bs{x}_i,\bs{y}_i)\) 中两个对应分量同时为 \(\bs{a}\) 的位置总数. 因为五个 \(\bs{x}_i\) 中共有 \(10\) 个 \(\bs{a}\) 分量，所以在 \(\bs{x}_i\) 中为 \(\bs{a}\)、而在 \(\bs{y}_i\) 中为 \(\bs{b}\) 的位置共有 \(10-M\) 个；同理，在 \(\bs{x}_i\) 中为 \(\bs{b}\)、而在 \(\bs{y}_i\) 中为 \(\bs{a}\) 的位置也有 \(10-M\) 个. 再由五对向量共有 \(25\) 个对应位置，两个分量均为 \(\bs{b}\) 的位置数为 \(5+M\).

因此 \(S=M\lvert\bs{a}\rvert^{2}+2(10-M)\bs{a}\cdot\bs{b}+(5+M)\lvert\bs{b}\rvert^{2}=5\lvert\bs{b}\rvert^{2}+20\bs{a}\cdot\bs{b}+M\lvert\bs{a}-\bs{b}\rvert^{2}\). 因 \(\bs{a}\neq\bs{b}\)，有 \(\lvert\bs{a}-\bs{b}\rvert^{2}>0\). 每一对向量中两个 \(\bs{a}\) 的位置交集可有 \(0\)，\(1\)，\(2\) 个；五对向量的排列彼此独立，因此取若干对使交集分别为 \(2\)，至多再取一对使交集为 \(1\)，其余取 \(0\)，即可使总数 \(M\) 取得 \(0\) 到 \(10\) 的每一个整数. 因而 \(S\) 实际有 \(11\) 个不同的值，命题 \(\circled{1}\) 错误，且 \(S_{\min}=5\lvert\bs{b}\rvert^{2}+20\bs{a}\cdot\bs{b}\).

若 \(\bs{a}\perp\bs{b}\)，则 \(S_{\min}=5\lvert\bs{b}\rvert^{2}\)，与 \(\lvert\bs{a}\rvert\) 无关，命题 \(\circled{2}\) 正确. 若 \(\bs{a}\parallel\bs{b}\)，则 \(\bs{a}\cdot\bs{b}=\pm\lvert\bs{a}\rvert\lvert\bs{b}\rvert\)，所得 \(S_{\min}=5\lvert\bs{b}\rvert^{2}\pm20\lvert\bs{a}\rvert\lvert\bs{b}\rvert\) 仍与 \(\lvert\bs{b}\rvert\) 有关，命题 \(\circled{3}\) 错误. 若 \(\lvert\bs{b}\rvert>4\lvert\bs{a}\rvert\)，由柯西不等式得 \(S_{\min}\geqslant5\lvert\bs{b}\rvert^{2}-20\lvert\bs{a}\rvert\lvert\bs{b}\rvert=5\lvert\bs{b}\rvert(\lvert\bs{b}\rvert-4\lvert\bs{a}\rvert)>0\)，命题 \(\circled{4}\) 正确. 若 \(\lvert\bs{b}\rvert=2\lvert\bs{a}\rvert\) 且 \(S_{\min}=8\lvert\bs{a}\rvert^{2}\)，则 \(\bs{a}\cdot\bs{b}=-\dfrac35\lvert\bs{a}\rvert^{2}\)，从而夹角余弦为 \(-\dfrac{3}{10}\)，不等于 \(\cos\dfrac{\pi}{4}\)，命题 \(\circled{5}\) 错误. 所以正确命题的编号为 \(\circled{2}\)\(\circled{4}\)，故填 \(\circled{2}\circled{4}\).
\end{solution}
\end{problem}

\section{解答题}

\begin{problem}
设 \(\triangle ABC\) 的内角 \(A\)，\(B\)，\(C\) 所对边的长分别是 \(a\)，\(b\)，\(c\)，且 \(b = 3\)，\(c = 1\)，\(A = 2B\).

\begin{enumerate}
\item 求 \(a\) 的值；
\item 求 \(\sin\left(A+\frac{\pi}{4}\right)\) 的值.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 由正弦定理，\(\dfrac{b}{\sin B}=\dfrac{c}{\sin C}\). 因为 \(A=2B\)，所以 \(C=\pi-3B\)，从而 \(\sin C=\sin 3B\). 代入 \(b=3\)，\(c=1\)，得 \(\sin 3B=\dfrac{1}{3}\sin B\). 由于 \(0<B<\dfrac{\pi}{3}\)，有 \(\sin B>0\)，于是 \(3\sin B-4\sin^{3}B=\dfrac{1}{3}\sin B\)，即 \(\sin^{2}B=\dfrac{2}{3}\). 因为 \(B<\dfrac{\pi}{3}\)，所以 \(\cos B=\dfrac{1}{\sqrt{3}}\)，故 \(\cos A=\cos 2B=1-2\sin^{2}B=-\dfrac{1}{3}\). 由余弦定理，\(a^{2}=b^{2}+c^{2}-2bc\cos A=9+1-6\left(-\dfrac{1}{3}\right)=12\)，因此 \(a=2\sqrt{3}\).
\item 由 \(\sin A=\sin 2B=2\sin B\cos B=\dfrac{2\sqrt{2}}{3}\)，以及 \(\cos A=-\dfrac{1}{3}\)，得 \(\sin\left(A+\dfrac{\pi}{4}\right)=\sin A\cos\dfrac{\pi}{4}+\cos A\sin\dfrac{\pi}{4}=\dfrac{2\sqrt{2}}{3}\cdot\dfrac{\sqrt{2}}{2}-\dfrac{1}{3}\cdot\dfrac{\sqrt{2}}{2}=\dfrac{4-\sqrt{2}}{6}\).
\end{enumerate}
\end{solution}

\begin{problem}
甲乙两人进行围棋比赛，约定先连胜两局者直接赢得比赛，若赛完 5 局仍未出现连胜，则判定获胜局数多者赢得比赛，假设每局甲获胜的概率为 \(\frac{2}{3}\)，乙获胜的概率为 \(\frac{1}{3}\)，各局比赛结果相互独立.

\begin{enumerate}
\item 求甲在 4 局以内（含 4 局）赢得比赛的概率；
\item 记 \(X\) 为比赛决出胜负时的总局数，求 \(X\) 的分布列和均值（数学期望）.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 记甲、乙每局获胜的概率分别为 \(p=\dfrac{2}{3}\)，\(q=\dfrac{1}{3}\). 甲在第 2 局获胜的唯一序列为甲甲，概率为 \(p^{2}\)；在第 3 局获胜的序列为乙甲甲，概率为 \(qp^{2}\)；在第 4 局获胜时，前 3 局不能出现连胜，且第 3、4 局必须为甲甲，所以序列只能是甲乙甲甲，概率为 \(p^{3}q\). 因而甲在 4 局以内赢得比赛的概率为 \(p^{2}+qp^{2}+p^{3}q=\dfrac{4}{9}+\dfrac{4}{27}+\dfrac{8}{81}=\dfrac{56}{81}\).
\item 当 \(X=2\) 时，前两局同一方获胜，故 \(P(X=2)=p^{2}+q^{2}=\dfrac{5}{9}\). 当 \(X=3\) 时，前两局不同而第 2、3 局相同，序列为乙甲甲或甲乙乙，故 \(P(X=3)=qp^{2}+pq^{2}=\dfrac{2}{9}\). 当 \(X=4\) 时，前 3 局没有连胜且第 3、4 局相同，序列为甲乙甲甲或乙甲乙乙，故 \(P(X=4)=p^{3}q+pq^{3}=\dfrac{10}{81}\). 当 \(X=5\) 时，前 4 局必须交替进行，序列前缀为甲乙甲乙或乙甲乙甲，第 5 局无论谁获胜都在第 5 局决出胜负，故 \(P(X=5)=p^{2}q^{2}+q^{2}p^{2}=\dfrac{8}{81}\). 因此分布列为
\begin{center}
\begin{tabular}{c|cccc}
\(X\) & 2 & 3 & 4 & 5 \\ \hline
\(P(X=k)\) & \(\frac{5}{9}\) & \(\frac{2}{9}\) & \(\frac{10}{81}\) & \(\frac{8}{81}\)
\end{tabular}
\end{center}
且 \(E(X)=2\cdot\dfrac{5}{9}+3\cdot\dfrac{2}{9}+4\cdot\dfrac{10}{81}+5\cdot\dfrac{8}{81}=\dfrac{224}{81}\).
\end{enumerate}
\end{solution}

\begin{problem}
设函数 \( f(x) = 1 + (1 + a)x - x^2 - x^3 \)，其中 \( a > 0 \).

\begin{enumerate}
\item 讨论 \(f(x)\) 在其定义域上的单调性；
\item 当 \(x \in [0,1]\) 时，求 \(f(x)\) 取得最大值和最小值时的 \(x\) 的值.
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 对函数求导，得 \(f'(x)=1+a-2x-3x^{2}\). 令 \(f'(x)=0\)，得 \(x=\dfrac{-1\pm\sqrt{4+3a}}{3}\). 记 \(\alpha=\dfrac{-1-\sqrt{4+3a}}{3}\)，\(\beta=\dfrac{-1+\sqrt{4+3a}}{3}\)，则 \(\alpha<\beta\)，且 \(f'(x)=-3(x-\alpha)(x-\beta)\). 因此 \(f(x)\) 在 \(\left(-\infty,\alpha\right)\) 和 \(\left(\beta,+\infty\right)\) 上单调递减，在 \(\left(\alpha,\beta\right)\) 上单调递增，即在 \(\left(-\infty,\dfrac{-1-\sqrt{4+3a}}{3}\right)\) 和 \(\left(\dfrac{-1+\sqrt{4+3a}}{3},+\infty\right)\) 上单调递减，在 \(\left(\dfrac{-1-\sqrt{4+3a}}{3},\dfrac{-1+\sqrt{4+3a}}{3}\right)\) 上单调递增.
\item 因为 \(a>0\)，所以 \(\alpha<0\). 若 \(a\geqslant4\)，则 \(\beta\geqslant1\)，函数在 \([0,1]\) 上单调递增，故取得最大值时 \(x=1\)，取得最小值时 \(x=0\). 若 \(0<a<4\)，则 \(0<\beta<1\)，函数在 \([0,\beta]\) 上递增，在 \([\beta,1]\) 上递减，故取得最大值时 \(x=\beta=\dfrac{-1+\sqrt{4+3a}}{3}\). 又因为 \(f(0)=1\)，\(f(1)=a\)，比较两个端点的函数值可知：当 \(0<a<1\) 时最小值对应的 \(x=1\)；当 \(a=1\) 时最小值对应的 \(x=0\) 或 \(x=1\)；当 \(1<a<4\) 时最小值对应的 \(x=0\).
\end{enumerate}
\end{solution}

\begin{problem}
如图，已知两条抛物线 \(E_{1}: y^{2} = 2p_{1}x\)（\(p_{1} > 0\)）和 \(E_{2}: y^{2} = 2p_{2}x\)（\(p_{2} > 0\)），过原点 \(O\) 的两条直线 \(l_{1}\) 和 \(l_{2}\)，\(l_{1}\) 与 \(E_{1}\)，\(E_{2}\) 分别交于 \(A_{1}\)，\(A_{2}\) 两点，\(l_{2}\) 与 \(E_{1}\)，\(E_{2}\) 分别交于 \(B_{1}\)，\(B_{2}\) 两点.

\item 过原点 \(O\) 作直线 \(l\)（异于 \(l_{1}\)，\(l_{2}\)）与 \(E_{1}\)，\(E_{2}\) 分别交于 \(C_{1}\)，\(C_{2}\) 两点. 记 \(\triangle A_{1}B_{1}C_{1}\) 与 \(\triangle A_{2}B_{2}C_{2}\) 的面积分别为 \(S_{1}\) 与 \(S_{2}\)，求 \(\frac{S_{1}}{S_{2}}\) 的值.

\bitmapfigure[max width=0.42\linewidth]{img/2014/anhui_science/q19_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 设 \(l_{1}:y=k_{1}x\)，\(l_{2}:y=k_{2}x\). 由于每条直线还与抛物线有非原点交点，故 \(k_{1}\)，\(k_{2}\) 均不为零. 对于抛物线 \(E_i:y^{2}=2p_i x\)，将 \(y=kx\) 代入，得 \(k^{2}x^{2}=2p_i x\). 除去原点后，交点坐标为 \(\left(\dfrac{2p_i}{k^{2}},\dfrac{2p_i}{k}\right)\). 因此可写成 \(A_i=p_i\left(\dfrac{2}{k_{1}^{2}},\dfrac{2}{k_{1}}\right)\)，\(B_i=p_i\left(\dfrac{2}{k_{2}^{2}},\dfrac{2}{k_{2}}\right)\)，从而 \(\overrightarrow{A_iB_i}=p_i\left(2\left(\dfrac{1}{k_{2}^{2}}-\dfrac{1}{k_{1}^{2}}\right),2\left(\dfrac{1}{k_{2}}-\dfrac{1}{k_{1}}\right)\right)\). 所以 \(\overrightarrow{A_{1}B_{1}}=\dfrac{p_{1}}{p_{2}}\overrightarrow{A_{2}B_{2}}\)，故 \(A_{1}B_{1}\parallel A_{2}B_{2}\).
\item 设直线 \(l\) 的斜率为 \(k_{3}\)，同理可得 \(C_i=p_i\left(\dfrac{2}{k_{3}^{2}},\dfrac{2}{k_{3}}\right)\). 因而三角形 \(A_{1}B_{1}C_{1}\) 是三角形 \(A_{2}B_{2}C_{2}\) 以原点为中心、相似比 \(\dfrac{p_{1}}{p_{2}}\) 的位似图形，面积比等于相似比的平方，所以 \(\dfrac{S_{1}}{S_{2}}=\left(\dfrac{p_{1}}{p_{2}}\right)^{2}=\dfrac{p_{1}^{2}}{p_{2}^{2}}\).
\end{enumerate}
\end{solution}

\begin{problem}
如图，四棱柱 \(ABCD - A_{1}B_{1}C_{1}D_{1}\) 中，\(A_{1}A \perp\) 底面 \(ABCD\). 四边形 \(ABCD\) 为梯形，\(AD \parallel BC\)，且 \(AD = 2BC\). 过 \(A_{1}\)，\(C\)，\(D\) 三点的平面记为 \(\alpha\)，\(BB_{1}\) 与 \(\alpha\) 的交点为 \(Q\).

\begin{enumerate}
\item 证明：\(Q\) 为 \(BB_{1}\) 的中点；
\item 求此四棱柱被平面 \(\alpha\) 所分成上下两部分的体积之比；
\item 若 \(A_{1}A = 4\)，\(CD = 2\)，梯形 \(ABCD\) 的面积为 6，求平面 \(\alpha\) 与底面 \(ABCD\) 所成二面角的大小.
\end{enumerate}

\bitmapfigure[max width=0.42\linewidth]{img/2014/anhui_science/q20_fig1.png}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 设 \(BC=s\)，建立空间直角坐标系，使底面为 \(z=0\)，并设 \(A=(0,0,0)\)，\(D=(2s,0,0)\)，\(B=(u,v,0)\)，\(C=(u+s,v,0)\)，其中 \(s>0\)，\(v>0\). 设棱柱高为 \(H\)，则 \(A_{1}=(0,0,H)\). 平面 \(\alpha\) 经过 \(D\)，且其中两个方向向量可取 \(\overrightarrow{DC}=(u-s,v,0)\)，\(\overrightarrow{DA_{1}}=(-2s,0,H)\)，故其一个法向量为 \(\bs{n}=(vH,-(u-s)H,2sv)\). 因而平面 \(\alpha\) 的方程为 \(vH(x-2s)-(u-s)Hy+2svz=0\). 设 \(Q\) 在 \(BB_{1}\) 上，写成 \(Q=(u,v,tH)\)，代入上式得 \(svH(2t-1)=0\)，所以 \(t=\dfrac{1}{2}\)，即 \(Q\) 为 \(BB_{1}\) 的中点.
\item 平面 \(\alpha\) 在底面各点上方的高度是关于 \(x\)，\(y\) 的一次函数，记为 \(h(x,y)\). 由平面经过 \(A_{1}\)，并经过底面上的 \(C\)，\(D\)，以及上面的结论，得 \(h(A)=H\)，\(h(B)=\dfrac{H}{2}\)，\(h(C)=h(D)=0\). 对角线 \(AC\) 将梯形分成三角形 \(ABC\) 和 \(ACD\)，其面积分别为 \(\dfrac{sv}{2}\) 和 \(sv\). 一次函数在三角形上的平均值等于三个顶点函数值的平均值，因此平面下方部分的体积为 \(V_{\text{下}}=\dfrac{sv}{2}\cdot\dfrac{H+H/2+0}{3}+sv\cdot\dfrac{H+0+0}{3}=\dfrac{7svH}{12}\). 整个棱柱体积为 \(V=\dfrac{3sv}{2}H=\dfrac{18svH}{12}\)，所以平面上方部分的体积为 \(V_{\text{上}}=V-V_{\text{下}}=\dfrac{11svH}{12}\)，从而 \(V_{\text{上}}:V_{\text{下}}=11:7\).

\end{enumerate}
\end{solution}

\begin{problem}
设实数 \(c > 0\)，整数 \(p > 1\)，\(n \in \N^*\).

\begin{enumerate}
\item 证明：当 \(x > -1\) 且 \(x \neq 0\) 时，\((1 + x)^p > 1 + px\)；
\item 数列 \(\{a_{n}\}\) 满足 \(a_1 > c^{1/p}\)，\(a_{n+1} = \frac{p-1}{p}a_n + \frac{c}{p}a_n^{1-p}\)，证明：\(a_n > a_{n+1} > c^{1/p}\).
\end{enumerate}
\end{problem}

\begin{solution}
\begin{enumerate}
\item 设 \(g(x)=(1+x)^{p}-1-px\)，其中 \(x>-1\). 则 \(g(0)=0\)，且 \(g'(x)=p\left((1+x)^{p-1}-1\right)\). 当 \(x>0\) 时，\((1+x)^{p-1}>1\)，所以 \(g'(x)>0\)，从而 \(g(x)>g(0)=0\). 当 \(-1<x<0\) 时，\(0<1+x<1\)，所以 \((1+x)^{p-1}<1\)，从而 \(g'(x)<0\). 由于 \(g\) 在 \((x,0)\) 上递减，故 \(g(x)>g(0)=0\). 综上，当 \(x>-1\) 且 \(x\neq0\) 时，\((1+x)^{p}>1+px\).
\item 记 \(r=c^{1/p}>0\)，并令 \(u_n=\dfrac{a_n}{r}\). 由 \(a_1>r\) 得 \(u_1>1\). 假设 \(u_n>1\)，由递推式得 \(u_{n+1}=\dfrac{p-1}{p}u_n+\dfrac{1}{p}u_n^{1-p}\). 因为 \(u_n>1\) 且 \(p>1\)，有 \(u_n^{1-p}<1<u_n\)，于是 \(u_n-u_{n+1}=\dfrac{1}{p}\left(u_n-u_n^{1-p}\right)>0\)，即 \(u_{n+1}<u_n\). 另一方面，将 \(p-1\) 个数 \(u_n\) 和一个数 \(u_n^{1-p}\) 应用算术—几何平均不等式，得 \(\dfrac{(p-1)u_n+u_n^{1-p}}{p}>\sqrt[p]{u_n^{p-1}u_n^{1-p}}=1\)，不等号严格成立是因为 \(u_n\neq u_n^{1-p}\). 因而 \(u_{n+1}>1\). 由数学归纳法，对任意 \(n\in\N^*\)，均有 \(u_n>u_{n+1}>1\)，乘以 \(r\) 得 \(a_n>a_{n+1}>c^{1/p}\).
\end{enumerate}
\end{solution}
