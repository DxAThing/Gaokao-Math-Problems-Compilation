\begin{problem}

\choices
    {\(1 - \i\)}
    {\(-1 + \i\)}
    {\(\frac{17}{25} + \frac{31}{25}\i\)}
    {\(-\frac{17}{7} + \frac{25}{7}\i\)}
\end{problem}

\begin{problem}
设变量 \(x, y\) 满足约束条件 \(\left\{ \begin{array}{l} x + y - 2 \geqslant 0, \\ x - y \leqslant 0, \\ y \geqslant 1, \end{array} \right.\) 则目标函数 \(z = x + 2y\) 的最小值为（\quad）

    {3}
    {4}
    {5}

\begin{problem}

\begin{problem}
已知函数 \( f(x) = \sqrt{3}\sin \omega x + \cos \omega x (\omega > 0), x \in \R \). 在曲线 \( y = f(x) \) 与三、解答题直线 \( y = 1 \) 的交点中，若相邻交点距离的最小值为 \( \frac{2}{3} \)，则 \( f(x) \) 的最小正周期为（\quad）

\begin{problem}
某校夏令营有 3 名男同学 A, B, C 和 3 名女同学 X, Y, Z，其年级情况如下表. 一年级 二年级 三年级 男同学 A B C 女同学 X Y Z 现从这 6 名同学中随机选出 2 人参加知识竞赛 (每人被选到的可能性相同). (1) 用表中字母列举出所有可能的结果; (2) 设 M 为事件“选出的 2 人来自不同年级且恰有 1 名男同学和 1 名女同学”，求事件 M 发生的概率.

\begin{problem}
已知 \(q\) 和 \(n\) 均为给定的大于1的自然数. 设集合 \(M = \{0, 1, 2, \cdots, q-1\}\)，集合 \(A = \{x \mid x = x_1 + x_2q + \cdots + x_nq^{n-1}, x_i \in M, i = 1, 2, \cdots, n\}\). (1) 当 \(q = 2, n = 3\) 时，用列举法表示集合 \(A\); (2) 设 \(s, t \in A, s = a_1 + a_2q + \cdots + a_nq^{n-1}, t = b_1 + b_2q + \cdots + b_nq^{n-1}\)，其中 \(a_i, b_i \in M, i = 1, 2, \cdots, n\). 证明: 若 \(a_n < b_n\)，则 \(s < t\).
\end{problem}

\end{problem}
