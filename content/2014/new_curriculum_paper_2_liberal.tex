\begin{problem}
设 \(F_{1}\)，\(F_{2}\) 分别是椭圆 \(C: \frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1 \) （\(a > b > 0\)）的左，右焦点，\(M\) 是 \(C\) 上一点且 \(MF_{2}\) 与 \(x\) 轴垂直，直线 \(MF_{1}\) 与 \(C\) 的另一个交点为 \(N\).
\begin{enumerate}
\item 若直线 \(MN\) 的斜率为 \(\frac{3}{4}\)，求 \(C\) 的离心率；
\item 若直线 \(MN\) 在 \(y\) 轴上的截距为 2，且 \(|MN| = 5|F_1N|\)，求 \(a\)，\(b\).
\end{enumerate}
\end{problem}

\begin{problem}
已知函数 \( f(x) = x^3 - 3x^2 + ax + 2 \)，曲线 \( y = f(x) \) 在点(0,2)处的切线与 \( x \) 轴交点的横坐标为\(-2\).
\begin{enumerate}
\item 求 \(a\)；
\item 证明：当 \(k < 1\) 时，曲线 \(y = f(x)\) 与直线 \(y = kx - 2\) 只有一个交点.
\end{enumerate}
\end{problem}
