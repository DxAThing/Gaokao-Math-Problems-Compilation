\begin{problem}
在 \(\triangle ABC\) 中，角 \(A, B, C\) 所对的边分别为 \(a, b, c\). 已知 \(\cos C + (\cos A - \sqrt{3}\sin A)\cos B = 0\). (1) 求角 B 的大小; (2) 若 \(a + c = 1\)，求 \(b\) 的取值范围.
\end{problem}

\begin{problem}
正项数列 \(\{a_{n}\}\) 的前 \(n\) 项和 \(S_{n}\) 满足: \(S_{n}^{2} - (n^{2} + n - 1)S_{n} - (n^{2} + n) = 0\). (1) 求数列 \(\{a_{n}\}\) 的通项公式: (2) 令 \( b_n = \frac{1}{(n + 2)^2 a_n^2} \)，数列 \( \{b_n\} \) 的前 \( n \) 项和为 \( T_n \). 证明：对于任意 \( n \in \mathbf{N}^* \)，都有 \( T_n < \frac{2}{64} \).
\end{problem}

\end{problem}
