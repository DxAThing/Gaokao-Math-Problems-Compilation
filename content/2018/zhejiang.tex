\begin{problem}
设 \(0<p<1\)，随机变量 \(\xi\) 的分布列是

\begin{center}

\choices
    {减小}
    {增大}
    {先减小后增大}
    {先增大后减小}

\begin{problem}
已知四棱锥 \(S-ABCD\) 的底面是正方形，侧棱长均相等，\(E\) 是线段 \(AB\) 上的点（不含端点），设 \(SE\) 与 \(BC\) 所成的角为 \(\theta_1\)，\(SE\) 与平面 \(ABCD\) 所成的角为 \(\theta_2\)，二面角 \(S-AB-C\) 的平面角为 \(\theta_3\)，则（\quad）

\begin{problem}
我国古代数学著作《张邱建算经》中记载百鸡问题：“今有鸡翁一，值钱五；鸡母一，值钱三；鸡雏三，值钱一. 凡百钱，买鸡百只，问鸡翁，母，雏各几何？”设鸡翁，鸡母，鸡雏个数分别为 \(x\)，\(y\)，\(z\)，则
\examdisplaycases{}{
x+y+z=100,\\
5x+3y+\dfrac{1}{3}z=100
}
当 \(z=81\) 时，\(x=\)\fillinblank{}，\(y=\)\fillinblank{}.
\end{problem}

}
则 \(z=x+3y\) 的最小值是\fillinblank{}，最大值是\fillinblank{}.
\end{problem}

\begin{problem}
已知角 \(\alpha\) 的顶点与原点 \(O\) 重合，始边与 \(x\) 轴的非负半轴重合，它的终边过点 \(P\left(-\dfrac35,-\dfrac45\right)\).

\begin{enumerate}
  \item 求 \(\sin(\alpha+\pi)\) 的值；
  \item 若角 \(\beta\) 满足 \(\sin(\alpha+\beta)=\dfrac{5}{13}\)，求 \(\cos\beta\) 的值.
\end{enumerate}
\end{problem}

\begin{problem}
已知函数 \(f(x)=\sqrt{x}-\ln x\).

\begin{enumerate}
  \item 若 \(f(x)\) 在 \(x=x_1\)，\(x_2\)（\(x_1\ne x_2\)）处导数相等，证明：\(f(x_1)+f(x_2)>8-8\ln2\)；
  \item 若 \(a\le3-4\ln2\)，证明：对于任意 \(k>0\)，直线 \(y=kx+a\) 与曲线 \(y=f(x)\) 有唯一公共点.
\end{enumerate}
\end{problem}
